# 演练画像：东南亚 B2B SaaS 跨境电商客户

> 本文档定义演练使用的客户画像。
> 数据为内部合成，**不代表任何真实企业**。

## 一、行业定位

- **产品定位**：B2B SaaS 工具，**只卖给东南亚跨境电商企业**
- **目标行业**：家居品类（home goods）东南亚出海
- **目标客户**：年营收 500 万-5000 万人民币的中小跨境电商
- **目标地区**：印尼、泰国、越南、马来西亚、菲律宾（5 国重点）

## 二、客户画像维度（评分依据）

| 维度 | 权重 | 说明 |
|---|---|---|
| 行业匹配度 | 30% | 是否主营家居品类（含 3C 周边、灯具、小家电等"广义家居"） |
| 营收规模 | 25% | 年营收 500-5000 万为优，< 500 万付费能力弱，> 5000 万倾向自研 |
| 平台覆盖 | 15% | Shopee/Lazada/TikTok Shop 多平台优于单平台 |
| 团队规模 | 10% | 10-100 人为优，过小无人决策，过大层级长 |
| 数字化成熟度 | 10% | 已在用 ERP/SaaS 工具的优于 Excel 管理 |
| 增长信号 | 10% | 近 12 月招人 / 上新品 / 融资 |

## 五、画像的用途

| 阶段 | 用法 |
|---|---|
| Stage 1（已完成） | 评分依据 |
| Stage 2（prospect→research） | 扩充每家公司的详细背景 |
| Stage 3（score） | 按权重计算综合分 |
| Stage 4（draft） | 按画像写开发信 |
| Stage 5（approval） | 人工模拟审批 + 哈希绑定 |
| Stage 6（deliverables） | 输出 §二定义的 7 个交付物 |
