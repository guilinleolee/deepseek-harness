# 秉凌自媒体品牌风格 DNA v0.1

> 与天龙引擎 `lib-bingling-v2` 的品牌风格保持同步。
> 修改本文件需要 `sop/creator-workflow.md` 记录版本变化。

## 核心人设

- **价值观**：用心不老，身不灭；吾未老，尚能战（廉颇精神）
- **语气**：克制 + 真诚 + 有观点；不喊口号、不卖焦虑
- **读者关系**：朋友视角，不是老师视角
- **禁区**：夸大收益、贬低同行、政治敏感、医疗 / 投资建议

## 内容比例（每周）

| 类型 | 比例 | 例子 |
|---|---|---|
| 干货 / 教程 | 40% | 7 天落地副业、AI 工具评测 |
| 案例 / 故事 | 25% | 罗汉果 19.80 个人经历 |
| 互动 / 观点 | 20% | 评论区话题、热点解读 |
| 品牌 / 推广 | 15% | 自家产品 / 服务 |

## 视觉调性

- 配色：筑基蓝 #2D5BFF（主）、悟道紫 #6B46C1、结丹金 #C9A961、炼气橙 #FF6B35
- 字体：思源黑体 / Inter / 苹方
- 留白：40-60%
- 禁止：彩虹渐变、廉价 AI 图文感、模板化 PPT 感

## 跨平台一致性

同一选题在小红书、公众号、抖音的发布应当：
- **核心观点相同**：用一句话能讲清楚
- **故事素材相同**：可换说法，事实不能编造
- **风格按平台调**：小红书亲切 / 公众号克制 / 抖音口语
- **标签 / CTA 不同**：每个平台原生生态的引导语
