# dsh-experimental-agent-roster

English | [中文](README.zh.md)

Read-only access to the [dragon-engine V2.5](https://github.com/guilinleolee/dragon-engine) agent roster mirrored under `dragon-assets/agents/`. This package registers a Cordis Service that walks every `*.md` file under that directory, parses a minimal frontmatter + first-heading + first-paragraph + capabilities section, and exposes the result as a typed roster keyed by the upstream 00-99 numeric id.

This is an experimental package. It only mounts when its owning composition asks for it; no release package may declare it as a dependency.

## What it reads

`dragon-assets/agents/` holds 182 markdown files plus three subdirectories that the mirror keeps intact (`shibazi/`, `zcf/`, `.gitnexus/`). The service:

| Source | Behavior |
|---|---|
| `dragon-assets/agents/*.md` | Parsed as agent role definitions |
| `dragon-assets/agents/shibazi/`, `zcf/`, `.gitnexus/` | Always skipped (default exclusion) |
| `dragon-assets/agents/<other>/` | Skipped when listed in `excludeSubdirs` |
| `dragon-assets/agents/` missing | `loadAll()` returns an empty roster |

The parser extracts, per file:

- **id** — basename without `.md`
- **displayName** — first `# heading` text (Chinese names preserved when present)
- **description** — first non-heading paragraph after the heading
- **numericPrefix** — leading `NN` or `NN-NN` from the displayName (e.g. `00`, `28-10`)
- **family** — bucket derived from numeric prefix (`core` 00-09, `platform` 10-15, `data` 16-19, `business` 22-25, `finance` 26-29, `social` 31-35, `sales` 38-40, `commerce` 45-47, `finance-2` 60-89, `hr` 90-99, `unknown` otherwise)
- **capabilities** — bullets from the `## 能力` or `## Capabilities` section
- **license** — first `license:` line in YAML frontmatter, if present
- **path** — workspace-relative path inside `dragon-assets/agents/`

## Config

| Field | Default | Meaning |
|---|---|---|
| `dragonAssetsRoot` | `<workspace>/dragon-assets` (or `$DRAGON_ASSETS_ROOT` if set) | Filesystem root for the mirror |
| `excludeSubdirs` | `['shibazi', 'zcf', '.gitnexus']` | Directory names under `agents/` to ignore |

## Service API

```ts
import AgentRoster from '@deepseek-ai/dsh-experimental-agent-roster'

const fiber = await ctx.plugin(AgentRoster, { dragonAssetsRoot: '...' })

const roster = await ctx.agentRoster.loadAll()
const core = ctx.agentRoster.byFamily('core')
const matches = ctx.agentRoster.search({ text: '博主', limit: 10 })
const analyst = ctx.agentRoster.get('00-analyst')
```

`loadAll()` is idempotent and may be called repeatedly after upstream rebuilds. `search()`, `get()`, and `byFamily()` operate on the cached roster and never touch disk.

## Model Experience

### What the model sees

Nothing — the service is internal to DSH and never reaches the model directly. Consumers may choose to surface search results through their own tools.

### Token effect

None.

### KV Cache effect

None.

## Known Limitations and Deferred Work

- **No upstream rebuild** — this package reads but does not refresh `dragon-assets/agents/`. The mirror is regenerated by the dragon-engine toolchain.
- **No CN/EN separation** — both displayName and displayNameZh share the same parsed text when the source heading is bilingual. A future iteration may split them via a `## 中文名` section.
- **Capability section heuristics** — bullets from `## 能力` and `## Capabilities` are picked up; any other section heading is ignored. Roles using a custom heading name will silently have no capabilities parsed.
- **License from frontmatter only** — `LICENSE` file presence is not consulted; an agent without a `license:` line in frontmatter records `license: undefined`.
- **Frozen snapshots** — like `skill-index`, the roster is deeply frozen; callers must clone before mutating.
- **Family buckets are opinionated** — the 00-99 ranges are derived from `dragon-engine CLAUDE.md §3` rather than from a declarative table in this package. If upstream re-buckets, regenerate this code, not the call sites.
