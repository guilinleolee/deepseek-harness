# dsh-experimental-skill-index

English | [中文](README.zh.md)

Read-only access to the [dragon-engine V2.5](https://github.com/guilinleolee/dragon-engine) asset index mirrored under `dragon-assets/index/`. This package registers a Cordis Service that reads the five `*.jsonl` files and exposes them as a queryable snapshot.

This is an experimental package. It only mounts when its owning composition asks for it; no release package may declare it as a dependency.

## What it reads

The `dragon-assets/` mirror holds five jsonl files generated by `dragon-engine/scripts/build-index.py`:

| File | Assets | Examples |
|---|---|---|
| `SKILLS.jsonl` | 784 | async-task-pattern, cinema-director-laoli, a-stock-data-bridge |
| `AGENTS.jsonl` | 187 | 00-analyst, 35-06-blogger-distiller, 28-10-finance-data-base |
| `HOOKS.jsonl` | 90 | session-start, preToolUse guard, postToolUse |
| `COMMANDS.jsonl` | 156 | /check, /review, /commit-push-pr |
| `PLUGINS.jsonl` | 7 | code-review, feature-dev, hookify |

The package reads all five files concurrently, freezes the snapshot, and serves lookups against the in-memory copy. The index is regenerated upstream by `dragon-engine`; this package never writes.

## Config

| Field | Default | Meaning |
|---|---|---|
| `dragonAssetsRoot` | `<workspace>/dragon-assets` (or `$DRAGON_ASSETS_ROOT` if set) | Filesystem root for the mirror |

## Service API

```ts
import DragonAssetIndex from '@deepseek-ai/dsh-experimental-skill-index'

const fiber = await ctx.plugin(DragonAssetIndex, { dragonAssetsRoot: '...' })

const snapshot = await ctx.dragonIndex.loadAll()
const matches = ctx.dragonIndex.search({ kind: 'skill', text: 'blogger', limit: 5 })
const skill = ctx.dragonIndex.get('async-task-pattern', 'skill')
```

`loadAll()` is idempotent and may be called repeatedly after upstream rebuilds. `search()` and `get()` operate on the cached snapshot and never touch disk. Snapshot objects are deeply frozen; consumers must clone before mutating.

## Model Experience

### What the model sees

Nothing — the service is internal to DSH and never reaches the model directly. Consumers may choose to surface search results to the model through their own tools; this package only owns the read path.

### Token effect

None.

### KV Cache effect

None.

## Known Limitations and Deferred Work

- **No upstream rebuild** — this package reads but does not refresh `dragon-assets/index/*.jsonl`. A dragon-engine maintainer must regenerate the index upstream.
- **No schema migration** — the service accepts every field present in the jsonl; future schema additions land as `unknown`-typed accessors until typed accessors are added.
- **No model-facing tool** — only Service Definition ships here. Pairing this with a `tool-dragon-search` Cordis package that exposes `search()` to the model is a future decision.
- **Synchronous JSON.parse loop** — the service parses the entire index in one pass. Acceptable up to a few thousand entries; consider streaming if the index grows past ~50k assets.
- **No CJK path validation** — the service returns paths verbatim. Callers that consume paths on Windows must validate before passing to `fs`.
- **AGPL-3.0 assets live alongside MIT assets** — callers must filter by `license` before invoking any AGPL-tagged entry (see the `dsh-experimental-license-policy` package, deferred).
