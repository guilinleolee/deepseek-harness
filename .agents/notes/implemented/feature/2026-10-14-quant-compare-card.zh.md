# Agent Note：面板在同一尺度上对比两条快照

状态：已实现

[English](2026-10-14-quant-compare-card.md) | 中文

## 问题

每张净值卡片只画一条存量曲线。对比两次运行——持久化快照的意义所在——意味着肉眼比较两条各自缩放的 sparkline，而那根本不构成对比：5% 与 12% 收益的两条曲线在各自私有 min/max 映射下看起来可以一模一样。

## 决策

- **`CompareLines` 加入图表家族。** `charts.tsx` 中的第二个内联 SVG 组件：两条 polyline 以同一数值尺度叠加，下方一行色彩图例。几何（`compareLinesPoints`）与同族一样是纯函数——两序列的 min/max 并集映射到内边距内的高度，两条序列都铺满全宽——单测无需渲染即可钉住坐标。零新依赖。
- **对比是卡片局部下拉，不是全局模式。** 展开快照卡片照旧取自己的曲线；对比下拉（列出其余快照及其头条收益）选一次取所选曲线并叠加两线。Remote 面、服务与工具表面零改动——这是面板已有数据之上的纯呈现。
- **一个共享尺度、两条全宽曲线。** 并集区间是叠加两条净值曲线唯一诚实的做法；各自缩放正是要修的 bug。较短的序列仍铺满全宽（末点落在右缘），日期范围差异通过线密度可见。
- **颜色走设计令牌。** 主曲线用 accent 令牌带字面回退；对比线用 danger 令牌——主题系统已保证可区分的两个色相。

## 考虑过的替代方案

**两条曲线归一化为收益率（重定基到 1.0）。** 延期：重定基会掩盖不同 `initial_cash` 运行间的绝对资金差；共享绝对尺度让这一点保持可见。若调用方需要，归一化模式只是一个纯函数的距离。

**跨卡片"钉选对比"交互。** 暂缓：需要面板全局选择状态与拖放交互；卡片局部下拉用既有 Remote 读取回答同一个问题。

**用虚线样式区分两条曲线。** 否决：sparkline 密度下虚线无法区分；双颜色加图例是最低限度的诚实编码。

## 后果

代价：每次对比多一次 Remote 读取（第二条曲线），缓存在卡片状态里，重新选择不会重取主曲线。验证：330 vitest 全绿——新用例钉住共享尺度几何（并集区间映射到内边距带、两条序列全宽铺开）、双 polyline 加图例的渲染与空输入 null 分支，以及卡片全流程（展开 → 选择 → 两条曲线带另一快照的标签）。双语 README 已更新；Agent Note 三件套已记录。
