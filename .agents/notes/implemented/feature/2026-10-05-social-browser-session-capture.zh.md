# Agent Note: 社媒主页采集以浏览器会话读取落地，配频率闸，而非爬虫

Status: implemented

[English](2026-10-05-social-browser-session-capture.md) | 中文

## 问题

画像的社媒分析此前只能匿名抓取主页 URL，而全部支持的主页（小红书/抖音/微博/公众号/B站/头条）回应的都是 JS 反爬壳或登录墙——分析诚实地报告"无可读正文"，功能上线即不可用。2026-10-05 的抓取调研钉死了合规路径：用户通过**自己的**已登录浏览器会话、在本机、以低频读取**自己的**主页；签名逆向是刑法分水岭，永不实现。

## 决策

- **一个 wire 面，两类输入。** `social` AI 操作新增可选 `profiles`（已采集的带标签分节）与 `links` 并存：已采集平台按原样分析、不再重复抓取，匿名抓取路径保留为自动回退，`manual-paste` 仍是终端回退。
- **contentOutputs 上四个 Remote 面**：`socialStatuses`（各平台会话在场 + 当日计数）、`socialStartLogin`（启动**有头**浏览器由用户自行登录；未等完成即返回，调用方轮询 statuses）、`socialCapture`（无头已登录读取一个主页 URL，返回带标签分节文本）、`socialForget`。用户的浏览器会话存储以 0600 JSON 持久化在 `<dsh home>/social-states/`——凭证与采集数据永不离机。
- **登录检测锚定 Cookie 而非 DOM。** 各平台"已登录"信号是一个知名会话 Cookie（`web_session`/`sessionid`/`SUB`/`SESSDATA`）的存在，不受页面改版影响。DOM 提取片段采用社区已记载的已登录 DOM 形态并带回退，是明示的现场迭代面；每条失败路径都降级为指向手动回退的具体消息。
- **频率闸计次数而非成败。** `consumeCapture` 在浏览器打开之前执行：每平台每日硬上限（配置 `maxDailyCaptures`，默认 3，范围 1–10）以指明上限的消息拒绝；计数器 0600 持久化、按本地日翻转。低频是让已登录读取远离平台风控雷达的合规姿态。
- **头条不进采集平台集**是设计决定（字节系 VM 签名、无官方 API、价值密度最低）；其第 2 步行保留普通链接路径与手动粘贴指引。

## 被否决的备选

**匿名 HTTP 的签名逆向适配器（x-s/x-bogus/a1）。** 永久否决：它是非法获取计算机信息系统数据罪的司法分水岭，商业产品分发此类代码面临更重的"提供工具"暴露，且平台每次更新算法即全量失效。

**第三方付费数据 API（新榜/蝉妈妈/灰豚）。** 否决：无公开 API 与定价，小红书侧服务在官方严打中下线（合规连带），且其颗粒度（大盘/达人榜）与单用户自画像错配。

**加密存储会话状态。** 暂缓：dsh 对凭证相邻本地文件的既有模式是 0600 + 用户主目录（画像清单同样如此）；为单一文件类引入密钥管理层，留待威胁模型提出要求。

## 后果

代价：四个 DOM 提取器是明示的维护面——平台改版只会把那一个平台降级为手动粘贴并给出具体错误（登录已过期 vs 页面结构可能已改版），绝不静默失败；采集内容是向导内的临时状态（不上 wire 持久化——被采纳的字段才是持久化），采纳前关闭向导只会丢失采集文本。验证：两包共 96 个测试（会话往返、频率上限与日期翻转、分节渲染、假浏览器采集编排、过期与改版区分、profiles-vs-links 社媒分析、第 2 步接线），触及文件类型检查与 lint 干净，typert 工件已为新 wire 面再生。
