# Agent Note：模板库 M2——弹窗结构化草稿、选题库第二个消费者、内置模板包

Status: implemented

[English](2026-09-27-dsh-content-studio-template-library-m2.md) | 中文

## 问题

M1 交付的全局模板库只有一个消费者、单目标弹窗契约，M2 留了三件事：v2 方案的结构化渲染输出（`{title, body, tags}`）、证明契约可泛化的第二个栏目、freemium 分发载体（可分享模板包）。创作工作台 `_templates.json` 与互动方案 localStorage 回复话术的统一评估也还开着。

## 决策

- **结构化输出由弹窗计算，而非宿主计算。**`pickerConfirm` 现在交给每个宿主一个 `TemplatePickDraft { title, body, tags, values, template }`：`title` 取已填的 `{{title}}` 变量、回退模板自身名称；`tags` 携带模板标签对已加载分类学的名称解析结果；原始 `values` 留给多字段宿主。在弹窗算一次，未来每个消费者共享同一套 title/tags 约定而无需各自推导——弹窗填表步骤把这条规则明示给用户。
- **选题库是第二个消费者，走预填——绝不利 put。**头部与空态各一个「从模板新建」入口打开 category `topic` 的弹窗；结构化草稿填进创建表单（标题/描述/标签），表单保持用户可编辑的草稿态——"渲染不落盘"铁律在第二个接入点存活。两处配套改动：`submitCreate` 现在携带可选字段（空值产出的形状与旧版完全一致，纯手工快加路径逐字节不变）；创建表单仅在可选字段有内容时渲染它们，单字段快加不受扰动。
- **第二个消费者揪出一个真语义修正：必填=正文活跃。**`missingRequired` 原先只要任一声明为必填的变量未填就阻塞确认——包括占位符已从正文消失的变量。一个以正文为唯一事实的库、其弹窗却按元数据事实执行必填，自相矛盾；校验现按正文实际使用的占位符过滤（`missingRequired(body, variables, values)`），弹窗的禁用确认共享同一调用。
- **内置模板包是数据，不是特性分支。**`starter-pack.ts` 内置八个跨六分类的骨架，稳定可读 id（`starter-*`）；库页头部与空态触发 `importStarterPack()`，走普通导入面 + `skip` 策略——重导入幂等，后续付费模板包复用完全相同的 `dsh-template-pack` 格式与导入面。包 spec 钉住：信封形状、id 稳定性、分类合法、标签引用，以及用库自己的扫描器验证"正文每个占位符都有声明元数据"。
- **统一评估结论：不统一。**创作工作台 `_templates.json` 保留占位符白名单（`assertTemplateBody` 保存与生成双重校验、被网关 framed-prompt 管线消费）——统一要么打破线校验，要么把自由变量塞进管线，两边都受损。互动方案的 localStorage 止损建议在该栏目上线前废弃：其话术应经模板库（category `interaction`）同一弹窗取用，零迁移成本。两条结论已记入方案文档（§5）。

## 与方案文本的偏离

- 方案的逐栏目 **field manifest**（可填充字段清单）落地为结构化草稿 + `values` 按名约定：两个消费者之后，宿主填充的字段恰好是 `title`/`body`/`tags`——manifest 注册表只会复述草稿类型已声明的内容。第三个消费者需要不同形状时再重开。
- **日历不接入（裁决）**：排期条目是时间元组（标题/时间/平台），没有骨架可填的正文落点；待规划中的日历 v2（事件=派生视图）落地 note 类表面后再评估。

## 备选方案

**宿主自算 title/tags。**让每个宿主自行推导标题回退、解析标签名，会把约定散到 N 处；第一个分歧（某宿主对空标题另作处理）正是结构化草稿要防的漂移。

**apply 时直接建选题。**跳过表单、用渲染草稿直接 `topics.put` 能省一次点击，但违反"渲染不落盘"，也剥夺了用户在 AI 骨架变成记录前的修改机会；预填表单正是规则要求的草稿态。

**把 `_templates.json` 迁入模板库。**把创作工作台的生成模板挪进模板库的自由变量 schema，等于删掉网关在保存与生成两端校验的白名单；维持两个存储的代价是多一个面板，而破坏生成契约的代价是创作栏目的提示词质量。

## 后果

两个栏目从可版本化模板初始化真实草稿，空库一键变可用，模板包格式有了已交付的 freemium 参照实现。代价：starter pack 随客户端 bundle 分发（纯数据；id 一经发布即冻结——改名的 starter id 会作为新条目重复导入）；title/tags 约定住在弹窗里约束未来所有宿主；必填语义变化（仅正文活跃）——若有模板依赖"required 但正文未用"来阻塞保存会感知到，现实中不存在这种模板。跨会话备注：发布与复盘栏目在本工作期间于同批文件落地；M2 只触碰模板模块、共享文件的增量接线、每本字典一块追加式 locale、以及选题库创建路径（向后兼容）。
