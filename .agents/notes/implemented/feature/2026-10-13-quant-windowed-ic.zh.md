# Agent Note：分窗横截面 IC 判读状态稳定性

状态：已实现

[English](2026-10-13-quant-windowed-ic.md) | 中文

## 问题

横截面 IC 报告把整个面板历史聚合成一个 ICIR。一个因子完全可能连续两年同号强 IC、第三年翻负，而全样本均值仍然体面——单一数字掩盖了翻转。延期项中的标准解法就是：把 IC 序列分窗、逐窗聚合，让状态依赖性显形。

## 决策

- **`ic_windows`（2-6，合规封顶）在事后切分 IC 序列。** `windowedIC` 把已算出的横截面 IC 点等分（数量）为连续窗口（尾部余量丢弃），各自经既有 `summarizeIC` 独立聚合并记录日期区间。面板数学不变——同样的K线、因子与前视收益喂给同样的逐日 IC；只有报告多了一个透镜。
- **结论是符号判读。** 窗口表渲染每窗的有效截面、平均 IC 与 ICIR，随后给三种结论之一：符号恒正（跨窗口方向稳定）、符号恒负（稳定的反向因子——值越高收益越低）、符号翻转（受状态影响；全样本结论需谨慎对待）。判读用 ICIR 符号而非平均 IC 符号，因为 ICIR 才是信噪比陈述。
- **退化离散度钳到零，而非无穷。** 某窗 IC 读数（数值上）恒定时 std 约 1e-16，直接除会得到 ~1e16 的 ICIR。`summarizeIC` 现在把低于一个基点的 std 钳为 0，此类窗口报告 ICIR 0（无可测离散度、无信念）——与既有零 std 分支声明的约定一致。
- **合规把上限并入既有链。** `inspectCrossPanelCaps` 增加 `ic_windows` 整数检查（2-6）；无新规则函数、无新工具——参数搭载在已封顶的工具上。

## 考虑过的替代方案

**日期锚定窗（日历半年/季度）。** 否决：等数量窗口对面板自身的交易日历是确定性的，不需要时区或节假日策略；稀疏面板按日历切可能产生空窗。

**状态检测（波动率或趋势分桶）。** 延期：按市场状态分桶需要一个插件不拥有的状态定义；等数量窗口无需发明定义即可回答"因子符号是否随时间存活"。

**始终渲染窗口表。** 否决：短面板的窗口太薄、无意义；参数保持默认报告紧凑，由调用方主动选择状态透镜。

## 后果

代价：`ic_windows` 丢弃至多 `windows − 1` 个尾部读数（文档已声明）；钳制不改变任何既有输出——此前零离散度序列只在 std 恰为 0 时按约定报 ICIR 0，而近零 std 会产生任何调用方都无法使用的荒谬比值。验证：321 vitest 全绿——新用例覆盖带日期区间的等数量切分、尾部余量丢弃、非法窗口数、三种结论分支（稳定/反向/翻转）、退化离散度钳制、合规上限，以及工具级 `ic_windows` 流入落定报告。双语 README 行已扩展；Agent Note 三件套已记录。
