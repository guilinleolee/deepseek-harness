## 5. 边界 / 不要这样做

| ❌ 错误 | ✅ 正确 |
|--------|--------|
| 把 guizang 当 SaaS 部署（AGPL 网络服务）| 仅交付 PNG 商单（AGPL § 13 例外）|
| 删 guizang/SamurAIGPT 版权声明 | 保留 LICENSE 全文 + 致谢 |
| 把 muapi 生成结果标成「博主本人手绘」| 「多模态生成」 ≠ 「原创手绘」|
| 用 emoji / "beautiful" / "cinematic 8k" 空泛词 | 用具体描述（"牛皮纸咖啡馆 + 50mm 镜头"）|
| 把 SamurAIGPT 或 muapi 标成天龙自有 | 上游独立项目，单独致谢 |
| 跑实操时漏掉 IP 授权检查（laoli_bro_2026）| 必须 `ip-profiles/<id>/ip_consent.txt` 在有效期内 |
| L0 描述 > 15 字 | 强制 ≤15 字（standardizer 硬约束）|
| L1 描述 < 50 或 > 100 字 | 强制 50-100 字 |
| 改 MEMORY.md 已有路径行 | 路径变了才改，文案不改 |
| 不跑 smoke test 就 merge 新 skill | 必跑 `tests/smoke.sh` 至少 1 轮 |
