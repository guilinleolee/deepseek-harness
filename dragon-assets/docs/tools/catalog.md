# Tools Catalog

ASCII-only index of every script under `scripts/`. Use this when you need
to find a tool by capability, not by name. Last updated 2026-08-05.

## How to read this doc

| column | meaning |
|--------|---------|
| **script** | relative path from repo root |
| **purpose** | one-line job-to-be-done |
| **inputs** | what the script reads |
| **outputs** | what the script writes |
| **flags** | common CLI flags |

## 1. Index builder (the core)

### `scripts/build-index.py`

Walk the repo and emit `index/{SKILLS,AGENTS,HOOKS,COMMANDS,PLUGINS}.jsonl`
plus `index/INDEX_MASTER.json` and `index/INDEX_README.md`.

- **schema**: `dragon-index/1.0`
- **inputs**: `skills/`, `agents/`, `hooks/`, `commands/`, `plugins/`,
  optional `--library <path>` for recursion
- **outputs**: 5 jsonl + INDEX_MASTER.json + INDEX_README.md
- **flags**:
  - (no flag): scan main repo only
  - `--include-library`: also scan `~/.claude/library/muapi/`
  - `--kind <skill|agent|hook|command|plugin>`: single kind
  - `--stats`: print stats, don't write
  - `--root <path>`: scan a different root

```bash
python scripts/build-index.py --include-library
```

### `tests/test_index.py`

4-class health assertions over the index. Exit code != 0 fails CI.

- T1 schema: every entry has required fields
- T2 integrity: ids unique, paths resolve, sizes > 0
- T3 retrieval: 12 known queries (guizang, a-stock, nuwa, darwin, cangjie,
  blogger, 博主蒸馏, 短视频编导, 财经数据底座, dragon-commander,
  code-review, checkpoint) all resolve to >= 1 entry
- T4 cross-version: master vs library-recurse produce consistent total

```bash
python tests/test_index.py
```

## 2. Data quality

### `scripts/skill-admin.py`

5 health-check classes:

| class | meaning | threshold |
|-------|---------|-----------|
| A: license unknown | skill/agent/command without license tag | < 800 |
| B: triggers missing | no `triggers:` in frontmatter | < 600 |
| C: AGPL no NOTICE | AGPL asset without NOTICE file | == 0 |
| D: size / pycache | suspicious size or __pycache__ commit | == 0 |
| E: stale (pre-2026) | last_used older than 2026-01-01 | < 100 |

- **flags**:
  - (no flag): pretty print
  - `--json`: machine-readable
  - `--strict`: exit != 0 if any issue
  - `--kind <x>`: limit scan

```bash
python scripts/skill-admin.py           # human-readable
python scripts/skill-admin.py --json    # for STATUS.md
python scripts/skill-admin.py --strict  # CI gate
```

## 3. Filename health

### `scripts/check-cjk-filenames.py`

Detect filenames containing GBK-misread codepoints. Writes an ASCII
runbook so user can manually `git mv` in Windows cmd.

- **detected chars**: U+7487 (璋), U+93CB (鏋), U+9416 (鐢), U+6D43 (浣),
  U+7480 (璁), U+9399 (鍙), U+7039 (瀹), U+696D (楠)
- **flags**:
  - (no flag): pretty print summary
  - `--emit-runbook <path>`: write ASCII `cjk-rename-runbook.md`

```bash
python scripts/check-cjk-filenames.py
python scripts/check-cjk-filenames.py --emit-runbook docs/cjk-rename-runbook.md
```

### `scripts/data-quality-fixes.py`

Dry-run + apply for the 3 over-threshold categories:

| section | what | apply impact |
|---------|------|--------------|
| C | write AGPL NOTICE file | +2 NOTICE files (no SKILL.md change) |
| B | infer triggers from dir/H1 | +830 SKILL.md frontmatter |
| A | stamp license: UNKNOWN | +1085 SKILL.md frontmatter |

```bash
python scripts/data-quality-fixes.py --preview C   # dry-run 2 NOTICE files
python scripts/data-quality-fixes.py --apply C     # write them
python scripts/data-quality-fixes.py --preview B   # dry-run 830 triggers
python scripts/data-quality-fixes.py --apply B     # stamp them
python scripts/data-quality-fixes.py --preview A   # dry-run 1085 license stamps
python scripts/data-quality-fixes.py --apply A     # stamp them
```

After any apply: rerun `make index-with-library && make test-admin`.

### `docs/cjk-rename-runbook.md`

Manual `git mv` checklist generated by `--emit-runbook`. The user runs
each line in Windows cmd (bash mojibake hides original codepoints).

**Important**: original characters are not algorithmically recoverable.
The mapping table in the runbook is a heuristic guess based on chunk
patterns. User must verify before committing.

## 4. Status dashboard

### `scripts/gen-status-md.py`

Aggregate INDEX_MASTER + skill-admin + cjk-check into a single
ASCII `STATUS.md` for repo root.

- **flags**:
  - (no flag): write `STATUS.md`
  - `--output <path>`: write to custom path
  - `--json-only`: print status as JSON

```bash
python scripts/gen-status-md.py              # writes STATUS.md
python scripts/gen-status-md.py --json-only  # for scripts
```

### `STATUS.md`

3 sections: 5-asset totals, data-quality counts, CJK mojibake count.
Last block is the weekly health checklist.

## 5. Sync (cross-tree)

### `scripts/sync-dragon.py`

Sync V8-restored tree into main tree. **Safe mode** only adds
files that don't exist in main.

```bash
python scripts/sync-dragon.py --check    # only check
python scripts/sync-dragon.py            # actually sync
```

### `scripts/diff-repos.py`

Compare main tree vs V8 tree: skills, agents, commands, BIBLE.md,
CLAUDE.md, MEMORY.md. Used for "how do these two repos differ?"

```bash
python scripts/diff-repos.py
```

## 7. CI workflows

### `.github/workflows/index-sync.yml`

Runs on push to master/main, every PR, weekly Sunday 03:00 UTC.

Steps:
1. `python scripts/build-index.py --include-library`
2. `python tests/test_index.py` (fail-fast)
3. Drift detection (INDEX_MASTER.json total + counts)
4. `python scripts/skill-admin.py --json`
5. `python scripts/check-cjk-filenames.py`
6. Auto-commit `index/` if drift detected (master only)
