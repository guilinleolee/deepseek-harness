# 百度SEO优化指南

## 概述

百度是中国最大的搜索引擎，市场份额约70%。百度SEO有其独特的规则和算法，与Google SEO有显著差异。

## 百度 vs Google SEO 核心差异

| 维度 | 百度 | Google |
|------|------|--------|
| **市场份额** | ~70% (中国) | ~90%+ (全球) |
| **算法更新** | 频繁但无规律 | 更透明、更规律 |
| **外链权重** | 高权重外链很重要 | 外链仍然重要但更注重质量 |
| **内容时效性** | 更强调时效性 | 更注重权威性和E-E-A-T |
| **备案要求** | 网站备案影响排名 | 无备案要求 |
| **本地化** | 更注重中文内容 | 全球通用 |
| **社交信号** | 微博、微信影响大 | Twitter/Facebook影响小 |

## 百度索引规则

### 1. 收录机制
- 百度爬虫：BaiduSpider
- 首选协议：HTTPS
- 支持协议：HTTP/HTTPS
- 移动优先：百度已实现移动优先索引

### 2. 影响收录的因素
| 因素 | 权重 | 说明 |
|------|------|------|
| 网站备案 | 高 | 有备案的网站更容易收录 |
| 内容质量 | 高 | 原创、有价值的内容 |
| 网站速度 | 中 | 百度对速度敏感 |
| 域名年龄 | 中 | 老域名有优势 |
| 更新频率 | 中 | 定期更新有利于收录 |
| 结构优化 | 中 | 清晰的网站结构 |

### 3. 加速收录的方法
1. 百度资源平台提交
2. 自动推送代码安装
3. sitemap.xml提交
4. 主动推送/MRDP推送
5. 关联熊掌号/百度小程序

## 百度算法规避

### 百度清风算法
- **目标**：打击标题作弊、关键词堆砌
- **规避**：标题简洁、关键词自然分布
- **建议**：
  - 标题不重复、不堆砌
  - 标题与内容高度相关
  - 关键词密度自然（2-8%）

### 百度闪电算法
- **目标**：打击加载慢的页面
- **首屏加载标准**：<2秒
- **建议**：
  - 压缩CSS/JS
  - 图片懒加载
  - CDN加速

### 百度惊雷算法
- **目标**：打击刷点击、作弊排名
- **规避**：白帽SEO，不要尝试作弊
- **建议**：通过正规渠道优化用户体验

### 百度飓风算法
- **目标**：打击采集/伪原创内容
- **规避**：纯原创或高质量伪原创
- **建议**：
  - 保持70%以上原创度
  - 添加独特见解和数据分析
  - 引用权威来源并注明

## 百度资源平台（搜索资源平台）

### 1. 站点管理
- 添加网站并验证
- 选择站点类型（PC/Mobile/自适应）
- 提交sitemap

### 2. 链接提交
| 方式 | 说明 | 配额 |
|------|------|------|
| 自动推送 | 代码自动推送 | 无限制 |
| 主动推送 | API主动推送 | 按站点等级 |
| sitemap | XML地图提交 | 最多50个 |
| 手动提交 | 手动提交URL | 每天10条 |

### 3. robots.txt配置
```
User-agent: Baiduspider
Allow: /

User-agent: *
Disallow: /admin/
```

## 中文关键词优化

### 1. 关键词选择
- 优先百度指数词
- 分析百度下拉和相关搜索
- 参考百度知道、贴吧内容

### 2. 关键词密度
- 标题：关键词出现1次
- 描述：关键词出现1-2次
- 正文：关键词密度2-8%
- H标签：自然融入关键词

### 3. 中文分词
百度使用中文分词技术，理解词义而非字符匹配。

示例：
- "SEO优化服务" 会被分词为 "SEO" + "优化" + "服务"
- 优化时应考虑词组完整性

## 错误处理

| 场景 | 处理方式 |
|------|----------|
| 百度爬虫无法访问 | 检查robots.txt、服务器IP白名单 |
| 收录量过低 | 检查内容质量、提交sitemap、提高更新频率 |
| 排名突然下降 | 检查是否触发算法、排查作弊嫌疑 |
| 备案问题 | 建议网站完成ICP备案 |
