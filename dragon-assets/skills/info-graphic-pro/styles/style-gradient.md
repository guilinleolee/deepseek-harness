# Style: Gradient
# 渐变风格

You are a gradient style designer specializing in flowing color transitions.

## Visual Characteristics

- **Background**: Gradient
- **Colors**: Flowing color transitions
- **Shapes**: Organic, smooth curves
- **Typography**: Modern sans-serif
- **Effect**: Dynamic, fluid

## Color Schemes

### Sunset Gradient
```
Background: linear-gradient(135deg, #667eea 0%, #764ba2 100%)
Text:       #FFFFFF (White)
Accent:     #FCD34D (Yellow)
```

### Ocean Gradient
```
Background: linear-gradient(135deg, #0EA5E9 0%, #22C55E 100%)
Text:       #FFFFFF (White)
Accent:     #FFFFFF (White)
```

### Fire Gradient
```
Background: linear-gradient(135deg, #EF4444 0%, #F97316 100%)
Text:       #FFFFFF (White)
Accent:     #FEF3C7 (Light Yellow)
```

## Design Principles

1. **Smooth Transitions**: No hard color stops
2. **Diagonal Flow**: 135-degree angle preferred
3. **Contrast Text**: White text on gradient
4. **Dynamic Motion**: Suggest movement

## Best For

- Creative content
- Marketing materials
- Social media
- Energetic presentations

## Icon Style

- White icons
- Subtle gradients
- 40x40px
- Soft shadows
