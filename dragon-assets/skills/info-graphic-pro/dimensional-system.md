# Info-Graphic-Pro 维度系统

## 维度定义

### Layout × Style = 340 组合

```
20 Layout × 17 Style = 340 种风格组合
```

---

## Layout - 布局类型 (20种)

### 列表类布局

#### list-vertical - 垂直列表
- **结构**: 上下排列的列表项
- **元素**: 图标/编号 + 标题 + 描述
- **间距**: 垂直节奏均匀
- **最佳场景**: 步骤、排名、清单

```
┌─────────────────┐
│ 1. Title        │
│    Description  │
├─────────────────┤
│ 2. Title        │
│    Description  │
└─────────────────┘
```

#### list-horizontal - 水平列表
- **结构**: 左右排列的列表项
- **元素**: 图标 + 标题 + 描述
- **间距**: 水平流式布局
- **最佳场景**: 流程、阶段、对比

```
┌────┐ ┌────┐ ┌────┐
│Step│ │Step│ │Step│
│  1 │ │  2 │ │  3 │
└────┘ └────┘ └────┘
```

### 网格类布局

#### grid-2x2 - 2x2网格
- **结构**: 四象限
- **元素**: 4个等大区块
- **间距**: 统一间距
- **最佳场景**: 四象限、矩阵分析

```
┌─────┬─────┐
│ Q1  │ Q2  │
├─────┼─────┤
│ Q3  │ Q4  │
└─────┴─────┘
```

#### grid-3x3 - 3x3网格
- **结构**: 九宫格
- **元素**: 9个等大区块
- **间距**: 统一间距
- **最佳场景**: 九宫格、分类展示

```
┌───┬───┬───┐
│ 1 │ 2 │ 3 │
├───┼───┼───┤
│ 4 │ 5 │ 6 │
├───┼───┼───┤
│ 7 │ 8 │ 9 │
└───┴───┴───┘
```

### 时间类布局

#### timeline-linear - 线性时间轴
- **结构**: 水平时间线
- **元素**: 时间点 + 事件
- **流向**: 左到右
- **最佳场景**: 历史发展、里程碑

```
────┬────┬────┬────
 T1 │ T2 │ T3 │ T4
    │    │    │
   E1   E2   E3
```

#### timeline-vertical - 垂直时间轴
- **结构**: 垂直时间线
- **元素**: 时间点 + 事件
- **流向**: 上到下
- **最佳场景**: 项目进度、路线图

```
    T1 ───┐
         E1
    T2 ───┤
         E2
    T3 ───┘
```

### 流程类布局

#### flowchart-linear - 线性流程图
- **结构**: 线性流程节点
- **元素**: 节点 + 箭头
- **流向**: 单一方向
- **最佳场景**: 工作流、操作步骤

```
┌───→ ┌───→ ┌───→ ┌───
│Start│ │Step│ │Step│ │End
└────┘ └────┘ └────┘ └───
```

#### flowchart-branch - 分支流程图
- **结构**: 分支决策节点
- **元素**: 菱形决策 + 分支
- **流向**: 多方向
- **最佳场景**: 决策树、逻辑分支

```
      ┌───┐
      │Dec│
      └─┬─┘
    ┌───┴───┐
   Yes     No
   ↓        ↓
┌─────┐ ┌─────┐
│True ││False│
└─────┘ └─────┘
```

### 对比类布局

#### comparison-side - 并列对比
- **结构**: 左右并列
- **元素**: 对比项A vs 对比项B
- **布局**: 50% | 50%
- **最佳场景**: 优缺点、产品对比

```
┌──────────┬──────────┐
│   Option │  Option  │
│     A    │    B     │
├──────────┼──────────┤
│   Point  │  Point   │
├──────────┼──────────┤
│   Point  │  Point   │
└──────────┴──────────┘
```

#### comparison-table - 表格对比
- **结构**: 表格形式
- **元素**: 行参数 × 列对比项
- **布局**: 网格对齐
- **最佳场景**: 参数对比、竞品分析

```
┌──────┬──────┬──────┐
│Feature│ Pro  │ Pro  │
├──────┼──────┼──────┤
│  F1   │  ✓   │  ✗   │
├──────┼──────┼──────┤
│  F2   │  ✗   │  ✓   │
└──────┴──────┴──────┘
```

### 层级类布局

#### pyramid - 金字塔
- **结构**: 三角形层级
- **元素**: 层级块
- **流向**: 下宽上窄
- **最佳场景**: 层级结构、重要性

```
      ┌───┐
      │ L1│
     ┌─┴─┬─┴─┐
     │L2 │L2 │
    ─┴───┴───┴─
      │  L3  │
    ─┴───────┴─
```

#### funnel - 漏斗
- **结构**: 倒三角形
- **元素**: 层级块
- **流向**: 上宽下窄
- **最佳场景**: 转化流程、筛选

```
    ┌───────┐
    │  L1   │
   ─┴─────┬─┴─
     │ L2  │
    ─┴───┬─┴───
     │  L3   │
    ─┴────┴───
```

#### tree - 树状图
- **结构**: 树形分支
- **元素**: 根节点 + 子节点
- **流向**: 自上而下
- **最佳场景**: 组织结构、层级

```
       ┌─Root─┐
       │      │
    ┌──┴──┐ ┌─┴─┐
    │     │ │   │
   ─┴─ ──┴─ ┴─ ┴─
  L1 L1   L1 L1
```

### 循环类布局

#### cycle - 循环
- **结构**: 圆形循环
- **元素**: 循环节点
- **流向**: 闭合循环
- **最佳场景**: 循环流程、迭代

```
    ┌─────┐
   ╱   3   ╲
  ╱    ↑    ╲
 │ 1 ←   2 │
  ╲    ↓    ╱
   ╲   4   ╱
    └─────┘
```

### 关系类布局

#### mind-map - 思维导图
- **结构**: 中心发散
- **元素**: 中心主题 + 分支
- **布局**: 放射状
- **最佳场景**: 知识结构、发散思维

```
       ┌─1─┐
     ╱   │   ╲
    2    3    4
   ╱│╲  ╱│╲  ╱│╲
  5 6 7 8 9 ...
```

#### venn - 韦恩图
- **结构**: 圆形交集
- **元素**: 集合圆
- **布局**: 重叠区域
- **最佳场景**: 集合关系、交集

```
    ╭─────╮
  ╱   A   ╲
╱   ╱   ╲   ╲
│  ╱─────╲  │
│  │Intersection
│  ╲─────╱  │
  ╲   ╱   ╱
    ╲ B ╱
     ╰───╯
```

### 分析类布局

#### radar - 雷达图
- **结构**: 多维雷达
- **元素**: 维度轴 + 数据点
- **布局**: 放射轴
- **最佳场景**: 多维评估、能力分析

```
      ↑ Dim1
     ╱│╲
    ╱ │ ╲
   ╱  │  ╲
Dim4  │  Dim2
   ╲  │  ╱
    ╲ │ ╱
     ╲│╱
      ↓ Dim3
```

#### gauge - 仪表盘
- **结构**: 半圆仪表
- **元素**: 刻度 + 指针
- **布局**: 弧形
- **最佳场景**: 进度、百分比

```
      100%
     ╱───╲
    │  ●  │
     ╲───╱
       0%
```

#### matrix-swot - SWOT矩阵
- **结构**: 2x2分析矩阵
- **元素**: S/W/O/Q四象限
- **布局**: 标注象限
- **最佳场景**: 战略分析

```
┌──────────┬──────────┐
│Strengths │Weaknesses│
│优势      │劣势      │
├──────────┼──────────┤
│Opportuni │Threats   │
│机会      │威胁      │
└──────────┴──────────┘
```

#### canvas-lean - 精益画布
- **结构**: 9块商业模式
- **元素**: 问题/解决方案等9块
- **布局**: 3x3结构
- **最佳场景**: 商业模式

```
┌─────┬─────┬─────┐
│Prob │Solu │Alt  │
├─────┼─────┼─────┤
│UAV  │UAV  │Chann│
├─────┼─────┼─────┤
│Cost │Rev  │Unfair│
└─────┴─────┴─────┘
```

## Style - 视觉风格 (17种)

### 极简风格

#### minimal - 极简
- **配色**: 黑白灰 + 单色强调
- **形状**: 几何、简洁
- **字体**: 无衬线
- **效果**: 现代简约

```
背景: #FFFFFF (白)
主色: #000000 (黑)
强调: #3B82F6 (蓝)
```

#### flat - 扁平
- **配色**: 纯色
- **形状**: 扁平、无阴影
- **字体**: 圆润无衬线
- **效果**: 友亲和

```
背景: #F8FAFC
主色: #6366F1
强调: #EC4899
```

#### monochrome - 单色
- **配色**: 同色系深浅
- **形状**: 简约
- **字体**: 等宽
- **效果**: 专业

```
背景: #F1F5F9 (浅灰)
主色: #475569 (中灰)
强调: #0F172A (深灰)
```

#### glassmorphism - 玻璃拟态
