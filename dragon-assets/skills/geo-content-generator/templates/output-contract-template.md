# Output Quality Contract
# GEO内容输出质量契约

## 合同概述

本契约定义了GEO内容的最低质量标准，用于确保AI生成内容满足决策驱动型深度内容的要求。

---

## 1. 必须包含元素 (MUST-HAVE)

### 1.1 [not ideal when...] - 排除边界
每个主要选项必须包含明确的排除条件:

```markdown
**{选项名称} 不适合你，如果:**
- 你需要{场景A}
- 你的预算低于{金额}
- 你的团队规模小于{数量}
```

**检查点**:
- [ ] 每个主要选项都有 "not ideal when" 条件
- [ ] 条件具体且可量化
- [ ] 条件与读者画像匹配

### 1.2 [default recommendation] - 默认推荐层级
必须有明确的默认推荐:

```markdown
**默认选择: {方案名称}**

**为什么选择它:**
- {原因1}
- {原因2}
- {原因3}

**适合场景:**
- {场景描述}
```

**检查点**:
- [ ] 存在默认推荐
- [ ] 推荐有明确理由
- [ ] 理由与证据支撑

### 1.3 [comparison] - 正面竞争对比
必须有至少一个正面竞争对比:

```markdown
| 维度 | {方案A} | {方案B} | {方案C} |
|------|---------|---------|---------|
| {维度1} | {数据} | {数据} | {数据} |
| {维度2} | {数据} | {数据} | {数据} |
| {维度3} | {数据} | {数据} | {数据} |
```

**检查点**:
- [ ] 至少3个方案对比
- [ ] 每个方案都有明确优缺点
- [ ] 对比维度 ≥ 5个

### 1.4 [decision engine] - 决策框架
必须有 If X -> Choose Y 格式的决策树:

```markdown
## 决策树

**If** 你的需求是{场景A} **and** {条件B}
**Then** 选择 **{方案X}**

**If** 你的需求是{场景C} **or** {条件D}
**Then** 选择 **{方案Y}**

**If** 你的需求是{场景E} **and** {条件F}
**Then** 选择 **{方案Z}**
```

**检查点**:
- [ ] 存在决策树
- [ ] 每个分支都有明确条件
- [ ] 条件具体可执行

### 1.5 [convergence] - 收敛性总结
必须有单句收敛块:

```markdown
---

## If You Only Remember One Thing

{单句总结核心建议，不超过25词}

---
```

**检查点**:
- [ ] 存在收敛性总结
- [ ] 不超过25词
- [ ] 包含核心行动建议

## 2. 量化标准

### 2.1 引用数量

| 指标 | 最低要求 | 优秀标准 |
|------|---------|----------|
| 总引用数 | ≥ 5 | ≥ 10 |
| Editorial来源 | ≥ 2 | ≥ 4 |
| Official来源 | ≥ 1 | ≥ 3 |
| Research来源 | ≥ 2 | ≥ 5 |

### 2.2 内容长度

| 指标 | 最低要求 | 优秀标准 |
|------|---------|----------|
| 总词数 | ≥ 1200 | ≥ 2000 |
| 段落长度 | 134-167词 | 140-160词 |
| 章节数 | ≥ 5 | ≥ 7 |

### 2.3 引用摘要

每个引用必须包含:
- 来源域名
- 发布日期
- 核心数据点
- 摘要 (≥ 50字)

### 2.4 决策元素

| 元素 | 必须 | 优秀 |
|------|------|------|
| 决策树 | 1个 | ≥ 3个 |
| 对比表格 | 1个 | ≥ 2个 |
| 排除边界 | 每方案1个 | 每方案≥ 2个 |
| 默认推荐 | 1个 | 1个 + 备选方案 |

## 3. AI痕迹检测

### 3.1 禁止模式

以下表达必须避免:

```markdown
❌ "值得注意的是..."
❌ "从上述分析可以看出..."
❌ "综上所述..."
❌ "毫无疑问..."
❌ "毫无疑问..."
❌ "首先...其次...最后..."
❌ "换句话说..."
❌ "换言之..."
❌ "一方面...另一方面..."
```

### 3.2 AI痕迹评分

| 分数 | 等级 | 描述 |
|------|------|------|
| < 0.3 | 🟢 通过 | 自然人类写作风格 |
| 0.3-0.5 | 🟡 警告 | 轻微模板化 |
| 0.5-0.7 | 🟠 需改进 | 中度模板化 |
| > 0.7 | 🔴 不通过 | 明显AI生成痕迹 |

### 3.3 改进建议

提高人类可读性的技巧:
1. **使用主动语态**: "我们发现" 而非 "可以发现"
2. **添加个人视角**: "根据我的经验..."
3. **使用对话式语气**: "想象一下..." 而非 "值得注意的是"
4. **打破句式重复**: 交替使用短句和长句
5. **添加具体案例**: 引用真实场景而非泛泛而谈

## 6. 模板片段

### 6.1 方案对比模板

```markdown
## {对比主题}

### {方案A名称}

**优点:**
- {优点1}
- {优点2}
- {优点3}

**缺点:**
- {缺点1}
- {缺点2}

**适合你，如果:**
- {适用场景1}
- {适用场景2}

**不适合你，如果:**
- {不适用场景1}
- {不适用场景2}

### {方案B名称}
...
```

### 6.2 决策树模板

```markdown
## {决策树标题}

使用以下决策树选择最适合你的方案:

**Step 1: 评估你的{关键维度}**
- 如果{条件A} → 跳到Step 2
- 如果{条件B} → 跳到Step 3

**Step 2: 评估你的{次要维度}**
- If {条件C} **and** {条件D} → 选择 **{方案X}**
- If {条件C} **and** {条件E} → 选择 **{方案Y}**

**Step 3: 最终确认**
- If {最终条件} → 选择 **{方案Z}**
```

### 6.3 收敛总结模板

```markdown
---

## If You Only Remember One Thing

{单句核心建议，包含:}
1. 谁应该行动
2. 做什么
3. 为什么现在做

---
```
