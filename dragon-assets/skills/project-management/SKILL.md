# 项目管理技能

本技能提供了一套通用的项目管理规范和工作流程，旨在确保项目高效、规范地进行，涵盖从项目初始化、需求管理、开发、测试到部署的全过程。

## 触发条件

- 用户说"项目管理"、"任务追踪"、"需求管理"
- 项目章程（`AGENTS.md`）或用户指令中要求
- 需要进行需求、任务或缺陷管理
- 需要整理项目结构或创建新文档

## 目录结构

```
/                              # 仓库根目录
├── workshops/                   # 所有仓库包含的开发项目所在地
│   └── <project-name>/            # 单个项目目录
│       ├── AGENTS.md              # 单个项目的章程
│       ├── TODO.md                # 单个项目特定的任务列表
│       ├── docs/                  # 单个项目特定的文档
│       │   ├── requirements/        # 单个项目的需求文档列表
│       │   └── specs/               # 单个项目的整体设计文档
│       └── src/                   # 项目源代码
├── skills/                      # 仓库特定 Skill
├── local-inbox/                 # 「收件箱」目录
├── CLAUDE.md                    # 仓库的章程
├── TODO.md                      # 全局的、跨项目的任务列表
└── ...
```

## 需求与任务管理

### 文档管理规范

创建任何文档时必须遵循：

1. **确定位置**: 根据本 Skill 和项目章程文件确定目标文档位置
2. **获取时间戳**: **必须**先运行 `date +'%Y-%m-%d-%H-%M'` 命令获取当前时间
3. **命名文件**: 文件名必须是 `YYYY-MM-DD-HH-mm-{文档名称}.md` 的格式
4. **更新 TODO**: 在创建文档后，应在相应的 `TODO.md` 任务中添加对该文档的引用链接

### 任务追踪管理

所有用户提出的任务都要：

1. 记录在对应的 `TODO.md` 文件中进行追踪
2. 将 `TODO.md` 的条目链接到更详细的文档
3. 根据任务要求，编写对应的需求、缺陷、Spec 文档

**TODO.md 状态列表**：
- `进行中 (In Progress)`
- `待办 (TODO)`
- `阻塞 (Blocked)`
- `已完成 (Done)`
- `已搁置 (On Hold)`

**任务单元**：
- **任务 (Task)**: 一个宏观的目标，通常需要拆解成更小的"开发项"
- **开发项 (Development Item)**: 一个具体的、可直接执行的工作单元

## 开发验证与测试

### TDD 模式的开发流程

1. 确保章程、Spec 文档、需求文档齐备
2. commit 变更（文档变更）
3. 编写测试用例和文档，覆盖预期功能和边界情况
4. 进行开发、运行测试，确保所有测试通过
5. 更新 Spec，需求，测试文档（如有必要）
6. commit 变更（代码和文档变更）

### Git 分支策略

**分支命名**：
- `main`: 主分支，始终保持可部署状态
- `dev`: 开发分支，用于集成各个功能
- `feat/{feat_name}`: 特定功能的分支
- `fix/{bug_name}`: 缺陷修复分支

**提交信息规范**：
- `feat: ...` (新功能)
- `fix: ...` (缺陷修复)
- `docs: ...` (文档变更)
- `test: ...` (测试相关)
- `refactor: ...` (代码重构)
- `chore: ...` (构建、工具等)

## 通用要求

### 理解上下文

在执行任何操作前，必须首先确定是在**全局**层面还是在**项目**层面。

1. **检查用户指令**:
   - 如果指令明确提到项目名称，则进入项目层面工作流
   - 如果指令模糊或涉及多个项目，则优先从全局 `TODO.md` 开始分析

2. **读取核心文件**:
   - **全局层面**: 读取根目录的 `CLAUDE.md` 和 `TODO.md`
   - **项目层面**: 读取 `workshops/${project_name}/AGENTS.md` 和 `TODO.md`

### 私钥和 Token 管理

**核心原则**：严禁将任何密钥、Token、密码推送到 Git 仓库。

- 所有密钥存储在 `.secrets` 文件中
- `.secrets` 文件**必须**被添加到 `.gitignore`
- 可创建 `.secrets.example` 文件供参考，但不能包含真实密钥
