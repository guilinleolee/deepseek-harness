# Commercial Legal - 商事法律技能包

## L0: 一句话描述 (≤15字)
商事交易全周期护航，从签约到履约

## L1: 使用场景 (50-100字)
当需要进行合同审查、商业谈判、公司治理结构设计、投融资法律事务处理，或需要制定商事风险防控策略时，使用本技能包。支持合同法、公司法、证券法、破产法四大领域。

## L2: 详细文档

### 核心能力

| 技能 | 功能 | 核心能力 |
|------|------|---------|
| **contract-draft** | 合同起草 | 合同条款设计+风险识别+权责明确化 |
| **contract-review** | 合同审查 | 条款分析+风险评估+修改建议 |
| **contract-negotiation** | 商业谈判 | 谈判策略制定+底线设定+利益最大化 |
| **term-sheet** | 投资条款清单 | TS核心条款起草+估值调整机制+保护性条款 |
| **cap-table** | 股权结构分析 | 股权稀释计算+持股比例+期权池 |
| **moa-draft** | 章程协议起草 | 公司章程+股东协议+议事规则 |
| **due-digence** | 法律尽职调查 | 目标公司法律尽调+风险清单+披露函 |
| **corporate-governance** | 公司治理 | 三会一层运作+关联交易审查+合规体系 |
| **restructuring** | 重组并购 | 交易结构设计+监管审批+交割执行 |
| **liquidation** | 破产清算 | 债权申报+资产处置+分配方案 |
| **regulatory-filing** | 监管报批 | 审批流程+材料准备+监管沟通 |
| **dispute-triage** | 商事争议分类 | 争议类型识别+策略建议+路径规划 |

### IRAC分析框架

所有商事分析遵循IRAC框架：

```
Issue（问题）→ Rule（规则）→ Application（适用）→ Conclusion（结论）
```

### 置信度分级

| 标记 | 含义 | 使用场景 |
|------|------|---------|
| `[CONFIRMED]` | 确认 | 现行法律/有效判例 |
| `[LIKELY]` | 可能 | 监管口径/司法倾向 |
| `[UNCERTAIN]` | 不确定 | 存在争议/需要论证 |
| `[VERIFY]` | 需核实 | 事实需要验证/监管动态 |

### 核心命令

```bash
# 合同起草
/contract-draft --type sale/loan/joint-venture --party "交易对手"

/contract-review --file "合同路径" --risk-level high

# 投资条款
/term-sheet --round "A轮" --valuation "估值金额"

# 股权分析
/cap-table --scenario "稀释后" --option-pool "10%"

# 尽职调查
/due-diligence --target "目标公司" --scope full/limited

# 公司治理
/corporate-governance --company-type "有限公司/股份公司"

# 重组并购
/restructuring --type merger/acquisition/spin-off

# 破产清算
/liquidation --proceed voluntary/involuntary
```

### 风险矩阵

| 风险等级 | 触发条件 | 建议行动 |
|----------|---------|---------|
| 🔴高 | 合同无效/主体不适格/监管重大违规 | 立即停止+法务介入 |
| 🟠中高 | 条款模糊/权责不对等/潜在诉讼 | 修改条款+保护性安排 |
| 🟡中 | 履行瑕疵风险/对价不足/证明困难 | 明确履约标准+留存证据 |
| 🟢低 | 格式问题/表述优化/常规修订 | 润色完善+标准化 |

## L2扩展

### 合同法要素

```
1. 合同效力
   - 主体资格（民事行为能力/授权代理）
   - 意思表示（真实/无瑕疵）
   - 合法性（不违反强制性规定）

2. 合同履行
   - 履行标准（质量/数量/期限/地点/方式）
   - 抗辩权（同时履行/先履行/不安抗辩）
   - 保全措施（代位权/撤销权）

3. 合同变更与转让
   - 协议变更
   - 债权转让通知
   - 债务承担

4. 违约责任
   - 继续履行
   - 损害赔偿（实际损失+可得利益）
   - 违约金（司法调整）
```

### 公司法核心

```
1. 公司设立
   - 出资方式（货币/实物/知识产权/土地使用权）
   - 出资期限与验资
   - 公司章程制定

2. 治理结构
   - 股东会/股东大会（最高权力机构）
   - 董事会/执行董事（经营决策）
   - 监事会/监事（监督职能）
   - 经理层（执行机构）

3. 股权与转让
   - 股权转让限制
   - 优先购买权
   - 同股不同权（股份有限公司除外）

4. 合并与分立
   - 吸收合并/新设合并
   - 程序要求（通知债权人/公告）
   - 股东会决议（特别多数）
```

### 投融资关键条款

```
1. 估值条款
   - Pre-money/Post-money估值
   - 估值调整机制（对赌条款）
   - 反稀释保护（全棘轮/加权平均）

2. 控制权条款
   - 董事会席位
   - 保护性条款（重大事项否决权）
   - 共同出售权（Tag-along）
   - 拖带权（Drag-along）

3. 退出条款
   - 回购权（回购价格/触发条件）
   - 随售权（共同出售比例）
   - 清算优先权（Liquidation Preference）

4. 保护性条款
   - 重大资产处置
   - 关联交易
   - 股权激励计划
   - 后续融资
```

### 商事尽职调查清单

```
□ 主体资格
  □ 营业执照、公司章程、股权结构
  □ 法定代表人及授权情况

□ 主要资产
  □ 不动产（房产证/土地使用权）
  □ 知识产权（商标/专利/著作权）
  □ 重大设备采购合同

□ 重大合同
  □ 采购合同、销售合同
  □ 借款担保合同
  □ 关联交易合同

□ 劳动人事
  □ 劳动合同签订情况
  □ 社保公积金缴纳
  □ 竞业限制协议

□ 诉讼仲裁
  □ 未决诉讼清单
  □ 行政处罚情况
  □ 仲裁案件

□ 环保合规
  □ 环评批复
  □ 排污许可证
  □ 行政处罚记录
```
