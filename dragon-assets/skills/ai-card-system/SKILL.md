### 卡牌稀有度与概率体系

```yaml
稀有度分布:
  N (普通):     60% 概率, 免费/1元档
  R (稀有):     25% 概率, 9元档
  SR (超稀有):  10% 概率, 29元档
  SSR (超级稀有): 4% 概率, 99元档
  UR (终极稀有): 0.8% 概率, 299元档
  限定 (Limited): 0.2% 概率, 限定活动

保底机制:
  十连保底: 10连必出R或更高
  百连保底: 100连必出SR或更高
  井机制: 井抽(180抽)必出SSR/UR

抽卡定价:
  单抽: 10元
  十连: 90元(9折)
  月卡订阅: 29元/月(每日1抽)
  季卡订阅: 79元/季(每日1抽+额外礼包)
```

### 命令调用

```bash
# AI卡牌生成
ai-card generate --theme "二次元少女" --rarity "SSR" --style anime

# 卡牌批量生成
ai-card batch --quantity 100 --rarity "mixed" --output "./cards/"

# 卡牌系统设计
ai-card design --theme "科幻" --mechanics "收集+对战"

# 盲盒概率配置
ai-card gacha --pity 100 --guarantee "SR" --pricing 10

# 订阅制设置
ai-card subscription --tiers "29-79-199" --daily-pull true

# 数字身份卡生成
ai-card identity --type "professional" --avatar "custom"
```

### MCP工具调用

```bash
# AI卡牌批量生成
mcp__ai_card__generate "二次元少女" --theme anime --quantity 50 --rarity mixed

# 卡牌系统创建
mcp__ai_card__create_system "科幻卡牌对战" --rarity-levels 6 --mechanics collect+battle

# 盲盒配置
mcp__ai_card__configure_gacha --pity-10 1 --pity-100 1 --guaranteed "SR" --price 10

# 订阅制管理
mcp__ai_card__subscription --tier "monthly" --price 29 --daily-pull-count 1

# 数字身份卡
mcp__ai_card__identity_card "律师职业形象" --avatar-style professional --bg corporate

# 卡牌数据分析
mcp__ai_card__analytics --card-id "SSR-001" --track conversion,retention
```
