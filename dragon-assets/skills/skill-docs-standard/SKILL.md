# SKILL 中文文档标准

> 天龙引擎技能文档规范 —— 统一格式，提升复用效率

## 目的

为天龙引擎所有SKILL建立标准化中文文档格式，确保：
- L0/L1/L2三层渐进披露结构统一
- 核心能力表、方案、集成、命令、场景五要素完整
- 天龙九部协同链路清晰
- 使用者能快速定位所需能力

---

## 标准格式

### L0: 一句话描述 (≤15字)

用最简洁的语言描述技能核心价值。15字以内，动词+宾语结构。

**示例：**
- `网页常亮不掉线自动保持`
- `AI水印文字覆盖自动去除`
- `恢复任意网页历史版本`

### L1: 使用场景 (50-100字)

描述触发条件和典型使用情境。让用户快速判断是否需要此技能。

**结构：** 当用户需要[需求]时触发。支持[场景A]和[场景B]。

**示例：**
> 当用户需要从图片/视频中去除AI水印、Logo、文字覆盖、文字遮挡，或需要对图像进行去噪、增强、修复时触发。适用于清理截图、文档处理、图像修复等场景。

### L2: 详细文档

包含以下子章节：

#### 1. 核心能力表

| 能力 | 说明 | 优先级 |
|------|------|--------|
| 能力A | 描述 | P0 |
| 能力B | 描述 | P1 |

- P0：必备能力，无则技能不完整
- P1：重要能力，强烈推荐实现
- P2：增强能力，可选实现

#### 2. 工作流程（可选）

如技能涉及多步骤流程，给出流程图：

```
1. 接收输入 → 2. 处理 → 3. 输出 → 4. 交付结果
```

#### 3. 方案/脚本实现

至少提供2种实现方案，覆盖不同使用场景：

- **方案一：[场景/技术栈]** — 适用于[场景描述]
- **方案二：[场景/技术栈]** — 适用于[场景描述]
- **方案三：[场景/技术栈]** — 适用于[场景描述]

每种方案包含：
- 简短描述（1-2句）
- 核心代码/配置
- 依赖要求

#### 4. 天龙引擎集成

| 天龙岗位 | 集成方式 |
|----------|-----------|
| 01调研师 | 场景描述 |
| 07记录师 | 场景描述 |

- 列出所有受益的天龙岗位
- 明确协同方式和效果

#### 5. 使用命令

```bash
# 基础用法
命令示例1

# 进阶用法
命令示例2

# 参数说明
```

#### 6. 适用场景表

| 场景 | 推荐方案 | 效果 |
|------|---------|------|
| 场景A | 方案一 | 描述 |

#### 7. 限制与注意事项

1. **限制A** — 说明
2. **限制B** — 说明
3. **注意C** — 说明

## 文件结构规范

```
skill-name/
├── SKILL.md                    # 本文件（必需）
├── scripts/                      # 脚本目录（推荐）
│   ├── script1.py               # 主脚本
│   └── helper.py                # 辅助模块
├── extension/                    # 浏览器扩展目录（可选）
│   ├── manifest.json
│   └── background.js
└── README.md                     # 使用说明（可选）
```

---

## 命名规范

### 文件名
- 使用 kebab-case：`ai-watermark-skill`、`wayback-machine-skill`
- 避免下划线、特殊字符
- 中文说明在SKILL.md内部提供

### 代码内部
- 函数名：snake_case（Python）、camelCase（JS/TS）
- 常量：UPPER_SNAKE_CASE
- 类名：PascalCase

---

## 版本信息规范

在SKILL.md末尾包含：

```markdown
## 版本信息

- **版本**: 1.0.0
- **更新日期**: YYYY-MM-DD
- **来源**: [项目名] [Stars] [License]
- **_stars**: N/A 或具体数字
```

## 质量检查清单

创建SKILL.md后，逐项检查：

- [ ] L0一句话 ≤15字
- [ ] L1场景 50-100字，触发条件明确
- [ ] L2包含核心能力表（P0/P1/P2）
- [ ] 至少2种实现方案
- [ ] 天龙岗位集成表完整
- [ ] 使用命令示例可执行
- [ ] 适用场景表覆盖主要场景
- [ ] 限制与注意事项完整
- [ ] 版本信息完整
- [ ] 文件结构符合规范
- [ ] 代码无语法错误

## 维护指南

### 新增SKILL
1. 按本标准创建SKILL.md
2. 运行质量检查清单
3. 更新天龙九部协同链路

### 更新SKILL
1. 更新版本号（如1.0.0 → 1.1.0）
2. 更新「更新日期」
3. 在CHANGELOG章节追加变更记录

### 废弃SKILL
1. 在SKILL.md顶部添加「⚠️ 已废弃」标记
2. 说明替代SKILL名称
3. 保留90天后可删除
