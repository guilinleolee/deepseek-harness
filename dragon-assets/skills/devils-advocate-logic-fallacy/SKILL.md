### 谬误分类体系（完整32类）

#### 1. 形式谬误（Formal Fallacies）- 演绎逻辑错误

| 谬误名称 | 识别特征 | 反驳策略 |
|---------|---------|---------|
| **肯定后件** | A→B, B成立 → A成立 | 指出其他导致B的原因 |
| **否定前件** | A→B, ¬A → ¬B | 指出其他导致B的原因 |
| **不当肯定选言** | A∨B, A → ¬B（错误） | 指出A和B可同时成立 |
| **否定合取** | ¬(A∧B) → ¬A∧¬B（错误） | 指出至少一者仍成立 |
| **肯定合取** | A, B → A∧B（总是真） | 验证A和B是否独立 |

#### 2. 实质谬误（Material Fallacies）- 归纳逻辑错误

| 谬误名称 | 识别特征 | 反驳策略 |
|---------|---------|---------|
| **草率归纳** | 样本太小→概括 | 要求更大样本或限定范围 |
| **不当类比** | 两事物类比但关键差异被忽略 | 指出关键不相似点 |
| **虚假原因（Post Hoc）** | A在B前 → A导致B | 要求因果机制说明 |
| **滑坡谬误** | A必然导致Z，每步假设过度 | 要求每步独立证明 |
| **合成谬误** | 局部真→整体真 | 指出整体可能有不同属性 |
| **分割谬误** | 整体真→局部真 | 指出整体属性不等于部分 |
| **模棱两可** | 关键词义在论证中改变 | 要求明确定义 |

#### 3. 语言谬误（Verbal Fallacies）

| 谬误名称 | 识别特征 | 反驳策略 |
|---------|---------|---------|
| **歧义谬误** | 多义词在论证中滑移 | 要求统一术语 |
| **复合歧义** | 模糊集合边界 | 要求精确边界定义 |
| **重心偏移** | 论点A被悄悄替换为B | 指出论点漂移 |
| **稻草人谬误** | 曲解对方论点后反驳 | 还原对方真实论点 |
| **语义循环** | 定义用被定义项本身 | 要求外部定义 |

#### 4. 相关性谬误（Relevance Fallacies）- 论据与论点无关

| 谬误名称 | 识别特征 | 反驳策略 |
|---------|---------|---------|
| **诉诸情感** | 诉诸恐惧/怜悯/愤怒 | 要求逻辑论证替代 |
| **诉诸权威** | "专家X说"但X非领域专家 | 要求领域相关性证明 |
| **诉诸公众** | "多数人认为" | 指出多数≠正确 |
| **诉诸传统** | "一直这样做" | 要求当前合理性证明 |
| **诉诸自然** | "自然的→好的" | 要求独立证明 |
| **人身攻击（Ad Hominem）** | 攻击人而非论点 | 要求论点本身评判 |
| **背景谬误** | 背景信息≠论证相关性 | 剥离无关背景 |
| **起点循环** | 论点依赖自身证明 | 要求外部证明 |

#### 5. 研究场景专业谬误（Research-Specific Fallacies）

| 谬误名称 | 识别特征 | 反驳策略 |
|---------|---------|---------|
| **确认偏见** | 只选支持己见的证据 | 要求对立证据审视 |
| **幸存者偏差** | 只看成功案例 | 要求失败案例分析 |
| **元数据滥用** | 引用与自己结论相矛盾的元研究 | 要求解读原文 |
| **过度泛化** | 小样本→大结论 | 要求样本量说明 |
| **生态谬误** | 群体统计→个体推断 | 要求个体层面证据 |
| **还原论** | 复杂现象→单一原因 | 要求多因素分析 |
| **幸存者偏差（新）** | 失败案例被忽视 | 要求完整数据集 |
| **基率忽视** | 忽视先验概率 | 要求贝叶斯分析 |
| **指数增长谬误** | 假设指数持续不衰减 | 要求饱和模型 |

#### 6. 概率谬误（Probabilistic Fallacies）

| 谬误名称 | 识别特征 | 反驳策略 |
|---------|---------|---------|
| **赌徒谬误** | 过去随机事件影响未来概率 | 指出每次独立事件 |
| **热手谬误** | 连续成功→下次成功概率高 | 指出每次独立事件 |
| **检察官谬误** | P(证据\|无罪)小 → P(无罪\|证据)小 | 要求贝叶斯重新计算 |
| **因时谬误** | 长期趋势→短期必然 | 要求趋势稳定性证明 |

### 谬误检测工作流

```
输入论证/决策文本
    ↓
Step 1: 论点提取
    ├── 核心主张（Claim）："我们应该采用微服务架构"
    ├── 支撑论据（Evidence）："Netflix等公司使用微服务"
    └── 逻辑结构（Structure）：类比论证
    ↓
Step 2: 谬误扫描（6类32种）
    ├── 形式谬误扫描
    ├── 实质谬误扫描
    ├── 语言谬误扫描
    ├── 相关性谬误扫描
    ├── 研究场景谬误扫描
    └── 概率谬误扫描
    ↓
Step 3: 谬误分类输出
    ├── 谬误类型
    ├── 具体位置（引用原文）
    ├── 识别依据
    └── 反驳策略
    ↓
Step 4: 融入09-01质疑框架
    ├── 场景盲点质疑
    ├── 规模盲点质疑
    ├── 团队盲点质疑
    ├── 技术盲点质疑
    └── 业务盲点质疑
```
