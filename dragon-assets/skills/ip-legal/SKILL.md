# IP Legal - 知识产权法律技能包

## L0: 一句话描述 (≤15字)
知识产权全生命周期管理，从侵权到维权

## L1: 使用场景 (50-100字)
当需要进行知识产权侵权分析、商标保护、专利风险评估、版权维权，或需要制定知识产权战略时，使用本技能包。支持商标、专利、著作权、商业秘密四大领域。

## L2: 详细文档

### 核心能力

| 技能 | 功能 | 核心能力 |
|------|------|---------|
| **ip-clause-review** | IP条款审查 | 知识产权归属/许可/保密协议审查 |
| **cease-desist** | 侵权警告函 | 发送或回应知识产权侵权警告 |
| **takedown** | 下架投诉 | 电商/平台知识产权侵权投诉 |
| **clearance** | 权属清廉 | 商标/专利自由运行分析 |
| **fto-triage** | FTO筛查 | 自由实施分析快速分类 |
| **infringement-triage** | 侵权分析 | 侵权可能性快速评估 |
| **oss-review** | 开源合规 | 开源许可证合规审查 |
| **portfolio** | 组合管理 | 知识产权组合管理 |

### IRAC分析框架

所有IP分析遵循IRAC框架：

```
Issue（问题）→ Rule（规则）→ Application（适用）→ Conclusion（结论）
```

| 标记 | 含义 | 使用场景 |

### IP侵权分析流程

```bash
# 启动IP侵权分析
[@78-01] 分析某产品是否侵犯竞品商标

# FTO快速筛查
[@78-01] 筛查技术方案FTO风险

# 商标清廉分析
[@76-02] 检索商标"XX"是否可注册
```

### 核心命令

```bash
# 侵权分析
/ip-analysis "产品名称" --type trademark/patent/copyright

# 商标检索
/ip-trademark-search "商标名" --classes 9,42

# 专利FTO筛查
/ip-fto-screen "技术方案" --region CN/US

# 开源合规审查
/ip-oss-review --directory ./src --license-type all
```

## L2扩展

### 商标分析要素

```
1. 标识相同/近似判断
   - 文字：读音、含义、字形
   - 图形：构图、颜色、整体视觉
   - 商品/服务类似判断

2. 混淆可能性评估
   - 原告商标知名度
   - 被告主观意图
   - 实际混淆证据

3. 在先权利抗辩
   - 在先注册商标
   - 在先使用未注册商标
   - 肖像权/姓名权
```

### 专利侵权判断

```
1. 权利要求分解
   - 技术特征逐一比对
   - 等同特征认定

2. 抗辩事由
   - 现有技术抗辩
   - 权利用尽抗辩
   - 临时保护期使用

3. 损害赔偿计算
   - 实际损失
   - 侵权获利
   - 许可费倍数
```
