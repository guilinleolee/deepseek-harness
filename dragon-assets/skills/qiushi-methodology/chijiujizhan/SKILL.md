## 核心理念
> "战略上藐视敌人，战术上重视敌人" —— 既要有必胜信心，又要有耐心恒心。

## 核心原则

```
┌─────────────────────────────────────────────────────────────┐
│                 持久战略 两层原则                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  战略层面: 藐视困难                                          │
│  ├── 相信困难可以被克服                                      │
│  ├── 坚定长期目标不动摇                                      │
│  └── 不被短期挫折动摇信心                                    │
│                                                             │
│  战术层面: 重视困难                                          │
│  ├── 认真对待每个具体问题                                    │
│  ├── 耐心解决每个阶段挑战                                    │
│  └── 积小胜为大胜                                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 三阶段模型

| 阶段 | 特征 | 策略 |
|------|------|------|
| **战略防御阶段** | 困难大，资源有限 | 保存实力，等待时机，避免决战 |
| **战略相持阶段** | 僵持拉锯 | 巩固阵地，逐步推进，积累力量 |
| **战略反攻阶段** | 条件成熟 | 抓住时机，全力推进，扩大战果 |

## 阶段判断标准

| 判断维度 | 防御期特征 | 相持期特征 | 反攻期特征 |
|----------|-----------|-----------|-----------|
| **难度** | 高 | 中 | 低 |
| **资源** | 不足 | 基本够用 | 充裕 |
| **进展** | 缓慢 | 有进展 | 快速 |
| **信心** | 低迷 | 平稳 | 高涨 |
