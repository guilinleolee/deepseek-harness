## 核心理念
> "没有调查，没有发言权。" —— 一切结论产生于调查情况的末尾，而不是它的先头。

## 何时使用
- 面对陌生领域，信息不足
- 多个信息源说法不一致，需要交叉验证
- 需要做出重要决策，但缺乏第一手资料

## 七项注意

```
┌─────────────────────────────────────────────────────────────┐
│                   调查研究 七项注意                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 调查基于客观事实                                        │
│     ├── 深入实际，不浮于表面                                │
│     └── 尊重事实，不预设立场                                │
│                                                             │
│  2. 系统性收集证据                                          │
│     ├── 多角度、多来源                                      │
│     └── 区分事实与观点                                      │
│                                                             │
│  3. 具体问题具体分析                                        │
│     ├── 分析问题的具体环境和条件                            │
│     └── 避免教条主义和经验主义                              │
│                                                             │
│  4. 透过现象看本质                                          │
│     ├── 区分主要矛盾和次要矛盾                              │
│     └── 抓住问题的核心和关键                                │
│                                                             │
│  5. 理论联系实际                                            │
│     ├── 理论为实践服务                                      │
│     └── 用实践检验和发展理论                                │
│                                                             │
│  6. 全面辨证地分析                                          │
│     ├── 既看正面也看反面                                    │
│     └── 既看成绩也看问题                                    │
│                                                             │
│  7. 及时复盘与纠偏                                          │
│     ├── 发现错误及时调整                                    │
│     └── 保持开放心态                                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 五步流程

| 步骤 | 名称 | 内容 |
|------|------|------|
| 1 | 明确目的 | 确定调查要解决的问题和预期成果 |
| 2 | 制定计划 | 设计调查方法、对象、时间和资源 |
| 3 | 实施调查 | 收集信息，多方印证，去伪存真 |
| 4 | 分析研究 | 归纳整理，抓住本质，形成判断 |
| 5 | 实践检验 | 将判断付诸实践，检验是否正确 |

## 常见错误

| 错误 | 正确做法 |
|------|---------|
| 先有结论后找证据 | 先调研后形成结论 |
| 浮于表面，走马观花 | 深入实际，解剖麻雀 |
| 听一面之词 | 多方印证，去伪存真 |
| 教条主义/经验主义 | 具体问题具体分析 |
