## 根据地四要素

| 要素 | 说明 | 检查项 |
|------|------|-------|
| **成果** | 有可验证的成果 | 成果是否可量化？ |
| **方法** | 有可复制的路径 | 方法是否可标准化？ |
| **团队** | 有愿意投入的人 | 核心团队是否稳定？ |
| **资源** | 有持续的资源 | 资源是否可持续？ |

## 常见错误

| 错误 | 正确做法 |
|------|---------|
| 追求完美，不启动 | 先跑起来，再迭代 |
| 切入点太大 | 从最小切入点开始 |
| 不验证，闷头做 | 快速MVP验证假设 |
| 成功后不总结 | 建立可复制的根据地 |
| 只守着自己的一亩三分地 | 主动扩大影响 |
