## 核心理念
> "统筹兼顾" —— 既要抓住主要矛盾，又不忽视次要矛盾；既要当前，又要长远。

## 六步动态平衡法

```
┌─────────────────────────────────────────────────────────────┐
│                 统筹兼顾 六步动态平衡法                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Step 1: 识别所有利益相关方                                  │
│  └── 列出受影响的各方                                        │
│                                                             │
│  Step 2: 了解各方诉求                                        │
│  └── 收集各方的核心需求和关切                                │
│                                                             │
│  Step 3: 找共同利益                                          │
│  └── 识别各方的共同点和交汇处                              │
│                                                             │
│  Step 4: 权衡取舍                                           │
│  └── 分析矛盾，找到平衡点                                    │
│                                                             │
│  Step 5: 制定兼顾方案                                       │
│  └── 设计让各方都能接受的方案                              │
│                                                             │
│  Step 6: 动态调整                                          │
│  └── 随着情况变化，持续调整平衡                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 权衡矩阵

| 维度 | 极端A | 极端B | 平衡点 |
|------|-------|-------|--------|
| 速度 vs 质量 | 快速但粗糙 | 完美但慢 | 质量底线+最快速 |
| 短期 vs 长期 | 短期利益 | 长期发展 | 短期不损长期 |
| 局部 vs 全局 | 局部最优 | 全局最优 | 局部可扩展 |
| 成本 vs 效果 | 省钱但差 | 贵但好 | 性价比最优 |

## 常见错误

| 错误 | 正确做法 |
|------|---------|
| 只顾一头 | 统筹兼顾，各方平衡 |
| 忽视次要矛盾 | 既抓主要矛盾，又不忽视次要 |
| 一成不变 | 动态调整，持续平衡 |
| 各打五十大板 | 找共同利益，引导各方 |
| 头痛医头脚痛医脚 | 全局思考，统筹规划 |
