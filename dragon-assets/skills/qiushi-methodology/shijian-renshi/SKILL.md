## 迭代循环

```
┌─────────────────────────────────────────────────────────────┐
│               实践认识论 认知-实践-再认知循环                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│    ┌─────────┐                                              │
│    │  认知   │ ←── 从理论/经验形成初步判断                  │
│    └────┬────┘                                              │
│         │                                                   │
│         ▼                                                   │
│    ┌─────────┐                                              │
│    │  实践   │ ←── 将判断付诸行动，观察结果                  │
│    └────┬────┘                                              │
│         │                                                   │
│         ▼                                                   │
│    ┌─────────┐                                              │
│    │ 再认知  │ ←── 基于实践结果修正/深化认识                 │
│    └────┬────┘                                              │
│         │                                                   │
│         └─────────── 循环迭代，认识逐步深化 ───────────────┘│
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 五步流程

| 步骤 | 名称 | 内容 |
|------|------|------|
| 1 | 收集 | 从多个来源收集分散的意见和信息 |
| 2 | 系统化 | 用矛盾分析法等工具分析整理成连贯计划 |
| 3 | 反馈 | 用可理解的方式将计划呈现给用户 |
| 4 | 检验 | 通过执行观察结果，用实践检验计划 |
| 5 | 再收集 | 循环改进，每次迭代更加准确有效 |

## 与群众路线协同

```
┌─────────────────────────────────────────────────────────────┐
│              实践认识论 × 群众路线 协同框架                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  命令主义 (Commandism) ❌                                  │
│  └── 不咨询实际执行者就制定计划                            │
│      → 避免：必须收集一线执行者意见                        │
│                                                             │
│  尾巴主义 (Tailism) ❌                                     │
│  └── 用户说什么就做什么，缺乏专业分析                       │
│      → 避免：必须对用户意见进行专业综合                    │
│                                                             │
│  正确做法 ✅                                                │
│  └── 收集(多方意见) → 系统化(专业分析) → 反馈(用户理解)   │
│                    → 检验(执行观察) → 再收集(循环改进)     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 两种错误

| 错误 | 表现 | 后果 | 避免方法 |
|------|------|------|---------|
| **命令主义** | 不调研就决策 | 执行者不认可，落地困难 | 必须咨询一线执行者 |
| **尾巴主义** | 用户说什么就做什么 | 缺乏专业判断，质量低 | 必须有专业分析综合 |
