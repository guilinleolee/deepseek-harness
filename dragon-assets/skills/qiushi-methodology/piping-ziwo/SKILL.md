## 核心理念
> "治病救人" —— 批评是为了帮助改进，不是为了追究责任。

## 批评原则

| 原则 | 说明 | 违反表现 |
|------|------|---------|
| **事实为依据** | 批评必须有具体事实，不能道听途说 | "有人说你..."、"据说..." |
| **对事不对人** | 批评工作表现，不攻击人格 | 人身攻击、贴标签 |
| **治病救人** | 目的是帮助改进，不是惩罚 | 无限上纲、翻旧账 |
| **与人为善** | 怀着帮助的心，不是为了显示自己 | 冷嘲热讽、幸灾乐祸 |
| **有则改之** | 被批评者要虚心接受 | 辩解、推卸、反驳 |

## 自我批评原则

| 原则 | 说明 | 实践要求 |
|------|------|---------|
| **直面问题** | 不回避，不推卸 | 主动承认错误 |
| **深刻反省** | 不仅改正表象，更要找根源 | 挖思想根源、工作方法根源 |
| **有则改之** | 对批评有则改之，无则加勉 | 不因批评过度自责，也不因无批评而松懈 |

## 输出格式

### 批评模板

```markdown
## 批评意见

**对象**: [具体的工作/行为]
**事实依据**: [具体事实1] [具体事实2]
**问题分析**: [问题的本质是什么]
**改进建议**: [如何改进]
```

### 自我批评模板

```markdown
## 自我批评

**问题**: [具体问题]
**事实**: [具体事实]
**根源分析**:
- 表象原因: [直接原因]
- 深层原因: [思想/方法根源]

**改进措施**:
1. [具体改进措施1]
2. [具体改进措施2]

**承诺**: [具体的改进承诺]
```

## 常见错误对照

| 错误 | 正确做法 |
|------|---------|
| 道听途说，没有事实 | 具体事实为依据 |
| 人身攻击，贴标签 | 对事不对人 |
| 无限翻旧账 | 就事论事 |
| 冷嘲热讽 | 与人为善 |
| 不接受批评 | 有则改之，无则加勉 |
| 表面应付，不深刻 | 直击根源，切实改进 |
