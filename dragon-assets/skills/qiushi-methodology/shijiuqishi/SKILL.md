## 版本信息

## 核心原则
> "实事求是" —— 一切从实际出发，理论联系实际，在实践中检验真理和发展真理。

## 总原则定义

**实事求是**是一切判断的**元规则**，是求是方法论体系的最高准则：

```
┌─────────────────────────────────────────────────────────────┐
│                    实事求是 三大铁律                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 事实先于结论                                            │
│     ├── 不对事实挑三拣四                                     │
│     ├── 结论必须由事实推导                                  │
│     └── 不能先有结论再找证据                                 │
│                                                             │
│  2. 承认未知                                                │
│     ├── "不知道"是诚实的调查结论                            │
│     └── 标记为"需要进一步确认"                              │
│                                                             │
│  3. 错了就改                                                │
│     ├── 如果事实与预期不符，修改的是结论而非事实             │
│     └── 坚持错误结论才是最大的"不实事求是"                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 行为规则

| 规则 | 要求 | 禁止 |
|------|------|------|
| **证据规则** | 每个结论必须附带具体证据 | 空口断言 |
| **验证规则** | 声称完成前必须验证 | 未经核实就声称 |
| **诚实规则** | 明确标记不确定信息 | 把推测当事实 |
| **调查规则** | 遇阻时调查原因，尝试替代路径 | 遇到障碍就放弃 |

## 调用格式

### 当需要做判断时

```markdown
## 实事求是检查

**判断内容**: [你的初步判断]

**支撑事实**:
- 事实1: [具体数据/证据]
- 事实2: [具体数据/证据]
- 事实3: [具体数据/证据]

**不确定之处** (需要进一步确认):
- 不确定1: [标记为"待确认"]
- 不确定2: [标记为"待确认"]

**结论**: 基于以上事实，得出[判断]

**如果事实不符预期**: 我将修改[判断]而不是忽视[事实]
```

### 当信息不足时

```markdown
## 实事求是声明

**当前状态**: 信息不足，无法做出可靠判断

**已知事实**:
- [事实1]
- [事实2]

**未知领域**:
- [需要调研才能确认的问题]

**建议行动**: 在做出判断前，先进行[具体调研]
```

## 常见错误对照

| 错误做法 | 实事求是做法 |
|---------|-------------|
| 先有结论后找证据 | 先收集事实再推导结论 |
| 对不符合结论的事实视而不见 | 如果事实与结论不符，修改结论 |
| 不确定的地方假装确定 | 明确标记"待确认" |
| 没调查就发言 | "没有调查，没有发言权" |
| 别人说什么就信什么 | 用事实检验他人的结论 |
