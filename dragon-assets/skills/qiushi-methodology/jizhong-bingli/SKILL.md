# 集中兵力 (Ji Zhong Bing Li)

## 版本信息
- **版本**: V1.0
- **日期**: 2026-04-08

## 核心理念
> "集中兵力各个击破" —— 在决定性地点，投入决定性的力量。

## 核心原则

```
┌─────────────────────────────────────────────────────────────┐
│                 集中兵力 两大原则                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  原则一: 有所不为才能有所为                                  │
│  ├── 不分散力量                                            │
│  ├── 避免全面铺开、到处出击                                │
│  └── 聚焦核心目标                                          │
│                                                             │
│  原则二: 2:1兵力优势                                        │
│  ├── 在关键点上形成压倒性优势                              │
│  ├── 局部战场集中绝对力量                                  │
│  └── 快速解决，避免拉锯                                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 优先级矩阵

| 优先级 | 类型 | 描述 | 策略 |
|--------|------|------|------|
| **P0** | 核心 | 非做不可，失败会导致全局崩盘 | 集中全部资源 |
| **P1** | 重要 | 显著影响目标达成 | 优先保障资源 |
| **P2** | 一般 | 有帮助但非必须 | 有余力再做 |
| **P3** | 可选 | 锦上添花 | 暂缓或放弃 |

## 决策检查

```markdown
## 集中兵力检查

**问题1**: 这是必须解决的吗？
- 如果不是 → 考虑暂缓或放弃
- 如果是 → 继续

**问题2**: 资源够集中吗？
- 是否有多个并行任务分散注意力？
- 是否在次要问题上花费过多时间？
- 如果是 → 重新聚焦核心

**问题3**: 能否形成压倒性优势？
- 时间是否集中投入？
- 人员是否专注？
- 如果不能 → 调整计划，确保聚焦
```
