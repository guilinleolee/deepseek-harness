## 两种错误

| 错误 | 表现 | 后果 | 避免方法 |
|------|------|------|---------|
| **命令主义** | 不咨询执行者就制定计划 | 执行者不认可，落地困难 | 必须收集一线执行者意见 |
| **尾巴主义** | 用户说什么就做什么 | 缺乏专业判断，质量低 | 必须有专业分析综合 |

## 正确做法

| 阶段 | 动作 | 说明 |
|------|------|------|
| 1 | 收集分散意见 | 多方咨询，不预设立场 |
| 2 | 专业化综合 | 用专业知识分析，不是简单汇总 |
| 3 | 用户理解 | 用用户能理解的方式呈现 |
| 4 | 执行验证 | 在实践中检验效果 |
| 5 | 循环改进 | 不断迭代优化 |

## 命令主义 vs 尾巴主义对照

```
┌─────────────────────────────────────────────────────────────┐
│                     两种错误倾向                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  命令主义 ❌                                                │
│  └── 专业判断 + 不听取意见                                  │
│      问题：计划执行不下去，执行者不认可                     │
│                                                             │
│  尾巴主义 ❌                                                │
│  └── 听从意见 + 无专业判断                                  │
│      问题：质量低下，用户其实也不知道什么是最好的           │
│                                                             │
│  正确做法 ✅                                                │
│  └── 收集意见 + 专业分析 + 用户理解 + 实践检验              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 输出格式

```markdown
## 群众路线分析报告

### 意见收集
| 来源 | 意见 | 类型 |
|------|------|------|
| [用户A] | [意见] | 需求/问题/建议 |
| [用户B] | [意见] | 需求/问题/建议 |

### 专业分析
**综合判断**: [基于专业知识的综合结论]
**与原始意见差异**: [如果有差异，说明原因]

### 用户反馈
**呈现方式**: [如何让用户理解这个结论]
**用户理解度**: [用户是否认可这个判断]

### 执行计划
[将判断转化为具体行动]
```
