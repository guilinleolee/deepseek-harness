# 矛盾分析法 (Mao Dun Fen Xi)

## 版本信息
- **版本**: V1.0
- **日期**: 2026-04-08
- **来源**: HughYau/qiushi-skill
- **集成**: 天龙引擎V8.86

## 核心理念
> "研究任何过程，如果是存在着两个以上矛盾的复杂过程的话，就要用力找出它的主要矛盾。捉住了这个主要矛盾，一切问题就迎刃而解了。"

## 何时使用
- 面对复杂问题，多个力量相互冲突
- 优先级不清晰，多个任务相互阻塞
- 进展受阻，不知道突破口在哪里

## 六步分析框架

```
┌─────────────────────────────────────────────────────────────┐
│                   矛盾分析法 六步流程                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Step 1: 识别所有矛盾                                        │
│  └── 列出问题中所有对立的力量/因素                          │
│                                                             │
│  Step 2: 确定主要矛盾                                        │
│  └── 找出那个控制/影响其他矛盾的关键矛盾                   │
│                                                             │
│  Step 3: 分析主导方面                                        │
│  └── 在当前形势下，哪一方主导着局面                        │
│                                                             │
│  Step 4: 矛盾分类                                            │
│  └── 对抗性(零和) vs 非对抗性(共同利益)                    │
│                                                             │
│  Step 5: 选择解决方法                                        │
│  └── 对抗性→果断行动；非对抗性→协商讨论                    │
│                                                             │
│  Step 6: 监控转化                                            │
│  └── 跟踪矛盾是否随着工作推进而转化                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 矛盾分类

| 类型 | 定义 | 解决方法 |
|------|------|---------|
| **对抗性矛盾** | 零和博弈，一方所得即另一方所失 | 果断行动、强制决策 |
| **非对抗性矛盾** | 共同利益，可以调和 | 协商讨论、妥协方案 |

## 常见错误

| 错误 | 正确做法 |
|------|---------|
| 不分析就行动 | 先分析再行动 |
| 用同一种方法解决所有矛盾 | 每个矛盾有其独特性质 |
| 忽略主要矛盾 | 聚焦控制全局的关键矛盾 |
| 忽视矛盾转化 | 动态监控矛盾变化 |
