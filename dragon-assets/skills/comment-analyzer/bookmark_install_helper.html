方法1：检查是否已安装

  1. 查看浏览器顶部是否有书签栏
  2. 在书签栏中寻找名为 "微博爬取" 的书签
  3. 找不到书签栏？ 按 Ctrl + Shift + B 显示

  2. 在"名称"字段输入：微博爬取
  3. 在"URL"或"地址"字段，粘贴刚才复制的代码

方法3：右键添加书签

  1. 在书签栏空白处右键点击
  2. 选择"添加页面"或"添加书签"
  3. 输入名称：微博爬取
  4. 粘贴上面的代码到URL字段
  5. 保存

使用方法（安装后）

  1. 打开微博文章页面：清真食堂争议微博
  2. 确保已登录微博账号
  3. 点击书签栏中的 "微博爬取" 书签
  4. 等待自动完成（约4-8分钟）
  5. 自动下载JSON文件
