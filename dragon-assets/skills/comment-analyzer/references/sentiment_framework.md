# 情感分析框架

## 四分类情感体系

基于用户反馈的实际需求，我们将评论情感分为四类：

### 1. 正面（Positive）
- **描述**：支持、喜爱、赞扬
- **关键词**：支持、喜欢、棒、优秀、推荐、赞、好、爱
- **权重**：+1.0
- **颜色**：#4CAF50（绿色）
- **示例**：
  - "完全支持这个观点！"
  - "内容很棒，学到了很多"
  - "强烈推荐给大家"

### 2. 建议（Suggestion）
- **描述**：理性反馈、改进意见
- **关键词**：建议、希望、可以、改进、优化、考虑
- **权重**：+0.5
- **颜色**：#2196F3（蓝色）
- **示例**：
  - "建议增加更多实例"
  - "希望下次能讲得更详细"
  - "可以考虑换个方式表达"

### 3. 中性（Neutral）
- **描述**：询问、描述、观望
- **关键词**：什么、如何、为什么、怎么、请问
- **权重**：0
- **颜色**：#FFC107（黄色）
- **示例**：
  - "这是什么意思？"
  - "如何实现这个功能？"
  - "为什么要这样做？"

### 4. 负面（Negative）
- **描述**：质疑、批评、不满
- **关键词**：差、失望、批评、不满、反对、不行、问题
- **权重**：-1.0
- **颜色**：#F44336（红色）
- **示例**：
  - "内容质量太差了"
  - "很失望，浪费了时间"
  - "强烈反对这个观点"

## 情感计算方法

### 基础算法
```python
sentiment_score = sum(情感词权重) + 否定词反转 + 程度词加权
```

### 规则说明

#### 否定词处理
当出现否定词时，情感反转：
- 否定词：不、没、非、无、别、未
- 示例：
  - "不好" → 负向（-1.0）
  - "不喜欢" → 负向（-1.0）
  - "不支持" → 负向（-1.0）

#### 程度词加权
程度词增强或减弱情感强度：
- 程度高：非常、特别、极其、太（×1.5）
- 程度中：很、挺、相当（×1.2）
- 程度低：有点、稍微、略微（×0.8）
- 示例：
  - "非常好" → +1.5
  - "有点好" → +0.8
  - "不太好" → -0.8（否定+程度低）

#### 情感分类阈值
```
得分 >= 0.3  → 正面
0 < 得分 < 0.3  → 建议
-0.3 < 得分 < 0  → 中性
得分 <= -0.3  → 负面
```

## 置信度评分

为每条评论的情感分类添加置信度（0-1）：

```python
confidence = min(1.0, abs(情感词数量) / 3 + 匹配度加成)
```

**置信度等级**：
- 0.9-1.0：非常确定（3个以上情感词）
- 0.7-0.9：确定（2个情感词）
- 0.5-0.7：基本确定（1个情感词+上下文）
- <0.5：不确定（无明确情感词）
