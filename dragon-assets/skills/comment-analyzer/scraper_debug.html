🔍 微博爬取工具 - 调试版

上次只爬取到3条评论，这个版本会显示详细调试信息

⚠️ 重要检查：
  1. 确保你已经登录微博
  2. 确保你能看到评论列表（手动滚动一下）
  3. 如果看不到评论，可能是页面没有完全加载

操作步骤

  1. 打开微博页面：清真食堂争议微博
  2. 按 F12 打开控制台
  3. 输入 allow pasting 并按 Enter
  4. 点击下方按钮复制脚本
  5. 在控制台粘贴并按 Enter
✅ 已复制！

调试信息说明

执行后控制台会显示：

[调试] 检查评论列表元素... [调试] 找到评论列表: .wbpro-list [调试] 初始评论数: XX [调试] 开始滚动加载... [1/200] 已加载: XX 条评论 ...

如果显示"未找到评论列表"，说明页面结构变了，请截图给我。
