🔧 微博爬取工具 - 控制台操作指南

⚠️ 重要：请严格按照以下步骤操作，否则无法执行。

1打开微博页面

点击下方按钮打开微博：

🔗 打开微博页面

2打开控制台

在微博页面中按 F12 键

然后点击顶部的 Console 或 控制台 标签

3允许粘贴（重要！）

Warning: Don't paste code...
Please type 'allow pasting' below and press Enter to allow pasting.

> 在这里输入: allow pasting

操作：

  1. 在控制台底部输入框中，用键盘输入：allow pasting
  2. 按 Enter 键

4复制脚本

点击下方按钮复制脚本：

✅ 已复制！

5粘贴并执行

在控制台中：

  1. 按 Ctrl + V 粘贴脚本
  2. 按 Enter 执行
✅ 成功标志：控制台显示彩色文字和进度信息
