# advertising-copy

## L0: 一句话描述 (≤15字)
广告文案创作，基于prompts.chat Advertiser角色

## L1: 使用场景 (50-100字)

**适用场景**：
- 品牌广告与营销文案创作
- 电商产品描述与卖点提炼
- 社交媒体广告素材
- 落地页文案与转化优化
- 品牌故事与价值主张

**触发关键词**：`/advertise`、`/ad-copy`、`/marketing-copy`

## L2: 详细文档

### 来源
基于 prompts.chat Advertiser角色扩展，融合AIDA、PAS等广告学框架。

### 核心能力

#### 1. 创作原则

```
I want you to act as an Advertiser.
Create compelling ad copies that capture attention and drive action.
Use emotional triggers, clear value propositions, and strong CTAs.
```

**广告文案核心**：
- **吸引力法则**：开头3秒决定一切
- **价值可视化**：让好处可感知、可量化
- **情感共鸣**：连接而非说服
- **行动号召**：明确、直接、可执行

#### 2. AIDA文案框架

```
┌─────────────────────────────────────────────────────────────┐
│ A - Attention (注意力)                                     │
├─────────────────────────────────────────────────────────────┤
│ 目标: 打破惯性，吸引目光                                    │
│ 方法:                                                        │
│ • 惊人数据: "93%的CEO承认..."                               │
│ • 痛点共鸣: "还在为X问题头疼?"                              │
│ • 反常识陈述: "这个习惯正在毁掉你的..."                      │
│ • 视觉化承诺: "30天练出马甲线"                               │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ I - Interest (兴趣)                                        │
├─────────────────────────────────────────────────────────────┤
│ 目标: 深化关注，建立相关性                                   │
│ 方法:                                                        │
│ • 故事化: 引入真实用户/场景                                 │
│ • 问题展开: 深入描述痛点场景                                 │
│ • 悬念设置: "关键是第三步..."                               │
│ • 社会证明: 引用用户证言/数据                                │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ D - Desire (欲望)                                          │
├─────────────────────────────────────────────────────────────┤
│ 目标: 激发渴望，塑造美好想象                                 │
│ 方法:                                                        │
│ • 利益具象化: 描述使用后的改变                               │
│ • 恐惧诉求: 不行动的代价                                    │
│ • 稀缺性: 限时/限量/专属                                   │
```

#### 3. PAS痛点文案框架

```
┌─────────────────────────────────────────────────────────────┐
│ P - Problem (问题)                                          │
├─────────────────────────────────────────────────────────────┤
│ 明确目标受众正在经历的痛点                                   │
│ "每天加班到深夜，项目文档还是写不完..."                      │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ A - Agitate (放大)                                          │
├─────────────────────────────────────────────────────────────┤
│ 深入挖掘痛点的情感影响                                       │
│ "眼看着deadline逼近，焦虑到失眠..."                          │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ S - Solution (方案)                                         │
├─────────────────────────────────────────────────────────────┤
│ 自然引入你的产品/服务作为解决方案                            │
│ "DocAI帮你30分钟完成文档工作..."                            │
└─────────────────────────────────────────────────────────────┘
```

#### 4. 平台适配文案

| 平台 | 文案特点 | 长度 | 核心要素 |
|------|---------|------|---------|
| **抖音** | 视觉优先，前3秒是关键 | 15-60秒 | 强开头+反转+信息量 |
| **小红书** | 真实分享，种草属性强 | 500-1000字 | 场景化+个人体验 |
| **公众号** | 深度内容，长阅读 | 1500-3000字 | 标题+结构+金句 |
| **电梯广告** | 极简短，重复曝光 | 5-15字 | 核心卖点+品牌名 |
| **信息流** | 原生化，不打扰 | 30-50字 | 软植入+场景 |

#### 5. 标题公式

| 公式 | 示例 |
|------|------|
| 数字+好处 | "5个方法让你效率翻倍" |
| 痛点+解决方案 | "总是拖延？3步告别拖延症" |
| 惊人事实 | "99%的人不知道的X秘密" |
| 提问引发好奇 | "为什么成功的人都做X？" |
| 命令式 | "立即Get这个技能" |
| 标签式 | "#职场人必看# 沟通技巧" |

#### 6. 卖点提炼矩阵

| 维度 | 问题 | 提炼方向 |
|------|------|---------|
| **功能** | 能解决什么问题？ | 核心功能，差异化功能 |
| **体验** | 使用感受如何？ | 便捷、舒适、省时 |
| **情感** | 带来什么感受？ | 自信、成就感、归属感 |
| **社会** | 他人会怎么看？ | 身份认同、社交货币 |
| **价格** | 性价比如何？ | 免费、划算、投资回报 |

### 使用示例

```bash
# 创作信息流广告
/advertising-copy feed --product "在线课程" --platform douyin --length 30s

# 电商产品描述
/advertising-copy product --item "无线耳机" --usp "降噪+续航"

# 品牌故事
/advertising-copy brand --company "科技公司" --value "创新改变生活"

# AIDA框架文案
/advertising-copy aida --offer "电子书" --goal "订阅转化"
```
