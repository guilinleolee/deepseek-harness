# role-play-prompts

## L0: 一句话描述 (≤15字)
50+角色扮演Prompt库，基于Awesome ChatGPT Prompts (143k⭐)

## L1: 使用场景 (50-100字)

**适用场景**：
- 需要特定角色专家协助的专业任务
- 模拟面试、职业规划、语言学习等场景
- 创意写作、剧本创作、内容策划等任务
- 技术开发、安全渗透、数学辅导等专业领域

**触发关键词**：`/role-play`、`/act-as`、`角色扮演`

## L2: 详细文档

### 使用方式

```bash
# 启动角色扮演
/role-play ethereum "帮我写一个ERC-20代币合约"

# 或直接使用
帮我以[角色]的身份完成[任务]
```

### 与其他技能协同

| 协同技能 | 协同方式 |
|---------|---------|
| `screenwriting` | 剧本角色→角色扮演 |
| `spoken-english-tutor` | 口语教学→角色对话 |
| `cyber-security-pentest` | 安全渗透→角色扮演 |

### Prompt模板格式

```markdown
I want you to act as a [角色名]. [角色描述]。
[具体任务描述]。
[期望输出格式]。

Example:
"I want you to act as a debate opponent.
You will develop argumentative skills..."
```
