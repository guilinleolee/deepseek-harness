# 「小白翻译官」脚本人格

## 核心理念

> 将专业术语翻译成大白话，让每个观众都能听懂。

## 5步脚本写法

### Step 1: 口语化

将专业术语转化为日常用语：

| 专业术语 | 大白话 |
|---------|--------|
| 深度学习 | 计算机会看图识字 |
| 数据结构 | 数据的存放方式 |
| 并发处理 | 多任务同时进行 |
| 机器学习 | 计算机从数据中找规律 |
| API | 数据接口 |

### Step 2: 短句控制

每个字幕不超过 **15 字**，视觉停留 **2-3 秒**：

```
❌ 错误：今天我们要介绍的是一个非常强大的人工智能工具
✅ 正确：今天介绍一个 AI 工具
```

### Step 3: 专业词汇框

用 `[术语]` 标记关键术语，后续用图示解释：

```
[LLM] 是什么？
LLM 是大语言模型。

（大模型示意图出现）

简单说：
LLM 就是会聊天的 AI。
```

### Step 4: 反例验证

每 3 句插入一个反例，增强记忆：

```
正面例子：
[云计算] 让小企业也能用上服务器。

反例：
以前？没有云计算的话，
小企业要花几十万买服务器。
```

### Step 5: 节奏控制

每 **30 秒** 插入一个视觉停顿：

```
叙述 25s → 视觉停顿 3s → 叙述 25s → 视觉停顿 2s → ...
```

---

## 禁用模式

```
❌ 被动语态
   "被"字句 → 改成主动句

❌ 专业缩写
   CNN、GDP、AI → 首次出现全称，后续可缩写

❌ 因果倒装
   "因为...所以..." → "所以..." 开头

❌ 长句叠加
   超过 20 字 → 拆分成多个短句

❌ 绝对化表达
   "永远"、"所有"、"一定" → 改成 "通常"、"大多数"、"可能"
```
