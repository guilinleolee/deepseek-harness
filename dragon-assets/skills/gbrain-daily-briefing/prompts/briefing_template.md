## Generation Rules

### 1. 优先级计算

```
priority_score = (
    severity × 0.4 +
    impact × 0.3 +
    relevance × 0.3
)
```

### 2. 行动项分类

| 关键词 | 分类 | 负责人 |
|--------|------|--------|
| 调研、研究、分析 | 调研 | @01-investigator |
| 决策、选择、判断 | 决策 | @00-analyst |
| 开发、实现、构建 | 构建 | @03-builder |
| 审计、审查、检查 | 审计 | @06-reviewer |
| 发布、部署、上线 | 发布 | @08-publisher |

### 3. 趋势分析方法

- **信号趋势**: 统计各类型信号出现频率，与历史基线对比
- **知识趋势**: 分析知识主题分布变化，检测热点话题
- **异常检测**: 识别偏离正常模式的信号（标准差 > 2σ）

### 4. 知识图谱健康度

```
kg_health = 100
  - min(30, (orphans / total) × 30)      # 孤立节点
  - min(30, (broken_links / total) × 30)  # 断裂链接
  - min(20, (low_confidence / total) × 20) # 低置信度
  - min(20, (conflicts / total) × 20)     # 矛盾冲突
```

### 5. 输出质量要求

- **完整性**: 必须包含所有章节，即使内容为空
- **一致性**: 数字统计必须与实际数据匹配
- **可操作性**: 每个行动项必须有明确的负责人和截止时间
- **关联性**: 知识条目必须与已有知识建立关联
