# GBrain Daily Briefing
# 每日情报简报生成器

## L0: 一句话描述
聚合每日信号和知识摄入，生成结构化情报简报，驱动天龙引擎持续学习和组织演进。

## L1: 使用场景

### 核心触发场景
- **每日情报生成**: 每天定时运行，聚合全天的信号检测和知识摄入
- **事件驱动简报**: 当重要信号累积超过阈值时即时生成
- **周期回顾简报**: 周报/月报场景，跨时间窗口聚合

### 天龙九部适用
- **07记录师**: 情报简报归档到 MemPalace 和 Wiki 知识库
- **00分析师**: 每日情报输入决策分析流程
- **01调研师**: 信号简报驱动深度调研任务
- **09-02编排协调师**: 基于简报调整次日编排优先级
- **09-03元审查师**: 简报作为自演化驱动的关键输入

## L2: 详细文档

### 核心能力

GBrain Daily Briefing 从 GBrain 的 Thin Harness / Fat Skills 哲学出发，
作为情报聚合层，连接信号检测 → 知识摄入 → 组织记忆三大能力闭环。

```
┌─────────────────────────────────────────────────────────────┐
│           GBrain Daily Briefing 架构                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  输入层（今日）                                              │
│  ├── gbrain-signal-detector  → 信号事件                    │
│  ├── gbrain-multimodal-ingest → 知识摄入                  │
│  ├── gbrain-identity-audit   → 身份审计变更               │
│  └── 外部知识源            → 行业资讯/竞品动态              │
│                         ↓                                   │
│  处理层                                                      │
│  ├── 事件聚合（按主题/Agent/时间聚类）                     │
│  ├── 知识提炼（提取关键洞察和行动项）                       │
│  ├── 关系构建（关联 MemPalace 知识图谱）                   │
│  └── 优先级排序（按重要性/紧急度）                          │
│                         ↓                                   │
│  输出层                                                      │
│  ├── 每日简报（Markdown → MemPalace Room）                │
│  ├── 行动项（Task → 编排协调师队列）                       │
│  └── 知识卡片（Wiki → llm-wiki-compiler 归档）             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### CLI 命令

```bash
# 生成今日简报
python ~/.claude/skills/gbrain-daily-briefing/scripts/briefing_generator.py daily

# 生成指定日期简报
python ~/.claude/skills/gbrain-daily-briefing/scripts/briefing_generator.py daily --date 2026-04-18

# 生成周报
python ~/.claude/skills/gbrain-daily-briefing/scripts/briefing_generator.py weekly

# 生成事件驱动简报（当信号累积超过阈值）
python ~/.claude/skills/gbrain-daily-briefing/scripts/briefing_generator.py event-driven --severity high

# 查询历史简报
python ~/.claude/skills/gbrain-daily-briefing/scripts/briefing_generator.py query --topic "架构演进"

# 列出所有简报
python ~/.claude/skills/gbrain-daily-briefing/scripts/briefing_generator.py list
```

### 配置文件 (config.yaml)

```yaml
# GBrain Daily Briefing 配置
# gbrain-daily-briefing/config.yaml

briefing:
  name: "GBrain 每日简报"
  version: "V1.0"

  # 简报生成策略
  generation:
    mode: "daily"              # daily | event-driven | weekly
    schedule: "0 8 * * *"     # 每天早上8点生成
    timezone: "Asia/Shanghai"
    lookback_hours: 24        # 回溯时间窗口

  # 阈值配置
  thresholds:
    event_driven_min_signals: 5    # 触发即时简报的最小信号数
    high_priority_threshold: 0.7     # 高优先级信号阈值
    knowledge_recency_hours: 6       # 知识新鲜度阈值

  # 优先级排序权重
  priority_weights:
    signal_severity: 0.4      # 信号严重度
    agent_impact: 0.3         # Agent影响范围
    knowledge_relevance: 0.3  # 知识相关性

  # 输出格式
  output:
    format: "markdown"
    storage_path: ".claude/gbrain/briefings/"
    archive_after_days: 90
    include_attachments: true

  # 知识图谱关联
  knowledge_graph:
    enabled: true
    auto_link: true
    confidence_threshold: 0.6

# 天龙引擎集成配置
tianlong_integration:
  attached_role: "07-scribe"
  upstream:
    - gbrain-signal-detector
    - gbrain-multimodal-ingest
    - gbrain-identity-audit
  downstream:
    - tianlong-09-02-orchestrator  # 行动项进入编排队列
    - mempalace                    # MemPalace 归档
    - llm-wiki-compiler           # Wiki 归档

  # 存储层
  storage_layers:
    - MemPalace (V8.85)
    - llm-wiki-compiler (V8.85)
    - advanced-memory-sync (V8.61)
    - claude-mem (V8.6)

  # 接收通知的 Agent
  notify_agents:
    - "00-analyst"
    - "01-investigator"
    - "09-02-orchestrator"

  # 行动项分类
  action_categories:
    - name: "调研"
      keywords: ["调研", "研究", "分析"]
      owner: "01-investigator"
    - name: "决策"
      keywords: ["决策", "选择", "判断"]
      owner: "00-analyst"
    - name: "构建"
      keywords: ["开发", "实现", "构建"]
      owner: "03-builder"
    - name: "审计"
      keywords: ["审计", "审查", "检查"]
      owner: "06-reviewer"
    - name: "发布"
      keywords: ["发布", "部署", "上线"]
      owner: "08-publisher"

# 趋势分析配置
trend_analysis:
  enabled: true
  window_days: 7              # 趋势窗口
  min_signals_for_trend: 10   # 最小信号数
  anomaly_detection: true
  seasonality_analysis: false

# 通知配置
notifications:
  enabled: true
  channels:
    - type: "file"
      path: ".claude/gbrain/briefings/daily/"
    - type: "mempalace"
      room: "gbrain-briefings"
    - type: "claude-mem"
      tag: "daily-briefing"
```

