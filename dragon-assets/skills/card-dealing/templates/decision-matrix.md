# 发牌质量评估决策矩阵
# Card Dealing Quality Assessment Decision Matrix
# 系统性评估发牌质量与决策的框架

---

## 一、质量评估维度

### 1.1 信息价值评估

| 维度 | 指标 | 权重 | 评估标准 |
|------|------|------|----------|
| **不确定性降低** | 不确定性变化量 | 25% | 降低≥30%得满分，<10%不得分 |
| **行动清晰度** | 下一步行动明确度 | 25% | 有明确行动得满分，选择困难不得分 |
| **时效性** | 信息新鲜度 | 15% | 5分钟内新鲜得满分，>1小时不得分 |
| **相关性** | 与当前任务关联度 | 20% | 直接相关得满分，关联度低不得分 |
| **完整性** | 信息覆盖度 | 15% | 完整覆盖得满分，有遗漏扣分 |

### 1.2 发牌时机评估

| 维度 | 指标 | 权重 | 评估标准 |
|------|------|------|----------|
| **心流保护** | 是否尊重心流状态 | 20% | 心流中不发牌/延迟得满分，打断心流不得分 |
| **自然断点** | 是否在自然断点发牌 | 20% | 自然断点发牌得满分，中间打断不得分 |
| **频率控制** | 发牌频率是否合理 | 15% | <3张/小时得满分，超出不得分 |
| **用户状态匹配** | 与用户当前状态匹配度 | 25% | 完全匹配得满分，不匹配不得分 |
| **沉默协议协同** | 与沉默协议配合度 | 20% | 完全协同得满分，冲突不得分 |

### 1.3 卡片质量评估

| 维度 | 指标 | 权重 | 评估标准 |
|------|------|------|----------|
| **内容质量** | 信息准确度 | 25% | 100%准确得满分，有错误不得分 |
| **表达清晰度** | 表述是否清晰 | 20% | 清晰易懂得满分，模糊不得分 |
| **行动可行性** | 建议是否可执行 | 20% | 明确可行得满分，不可执行不得分 |
| **风险评估** | 风险是否充分揭示 | 15% | 充分揭示得满分，有遗漏扣分 |
| **优先级合理性** | 优先级是否恰当 | 20% | 恰当得满分，明显错误不得分 |

## 二、决策质量评估

### 2.1 是否发牌决策

| 场景 | 决策 | 质量评分 | 说明 |
|------|------|----------|------|
| 应发牌且发了 | 正确发牌 | 1.0 | 最佳决策 |
| 应发牌但未发 | 漏发 | 0.3 | 错失价值交付机会 |
| 不应发牌但发了 | 误发 | 0.4 | 造成不必要的打断 |
| 不应发牌且未发 | 正确沉默 | 1.0 | 最佳决策 |
| 犹豫后发了 | 延迟发牌 | 0.6 | 价值打了折扣 |
| 犹豫后未发 | 过度沉默 | 0.5 | 可能错失机会 |

### 2.2 发什么牌决策

| 场景 | 决策 | 质量评分 | 说明 |
|------|------|----------|------|
| 最优卡类型 | 选择了最优 | 1.0 | 最佳选择 |
| 次优卡类型 | 选择了次优 | 0.7 | 可接受 |
| 一般卡类型 | 选择了普通 | 0.5 | 有改进空间 |
| 错误卡类型 | 选错了类型 | 0.2 | 决策失误 |

### 2.3 发牌时机决策

| 场景 | 决策 | 质量评分 | 说明 |
|------|------|----------|------|
| 最佳时机 | 心流结束后/自然断点 | 1.0 | 完美时机 |
| 良好时机 | 用户空闲时 | 0.8 | 合理 |
| 一般时机 | 非自然断点 | 0.5 | 可接受但有打断 |
| 糟糕时机 | 打断心流 | 0.2 | 决策失误 |

## 三、卡片类型选择决策树

```
发牌请求
    │
    ├─► 风险检测 → 严重风险 → [WARNING_CARD] → 立即发送
    │
    ├─► 下一步行动明确？
    │       │
    │       ├─► 是 → 行动可执行？
    │       │       │
    │       │       ├─► 是 → [ACTION_CARD] → 确认后发送
    │       │       │
    │       │       └─► 否 → 有多个选项？
    │       │               │
    │       │               ├─► 是 → [RECOMMENDATION_CARD] → 建议后发送
    │       │               │
    │       │               └─► 否 → [CONFIRMATION_CARD] → 确认理解
    │       │
    │       └─► 否 → 不确定性高？
    │               │
    │               ├─► 是 → [RECOMMENDATION_CARD] → 提供选项
    │               │
    │               └─► 否 → 信息价值>阈值？
    │                       │
    │                       ├─► 是 → [INFORMATION_CARD] → 空闲时展示
    │                       │
    │                       └─► 否 → 延迟发牌
    │
    └─► 频率检查 → >3张/小时？
            │
            ├─► 是 → 延迟最低优先级卡片
            │
            └─► 否 → 继续发牌流程
```

## 四、评估场景示例

### 场景A：用户深度工作 + 紧急消息

| 步骤 | 决策 | 质量 | 分析 |
|------|------|------|------|
| 1 | 检测到深度工作状态 | ✅ | 心流检测正确 |
| 2 | 收到紧急消息 | ✅ | 优先级识别正确 |
| 3 | 评估：深度工作vs紧急性 | - | 需要权衡 |
| 4 | 决策：发WARNING_CARD | ✅ | 严重风险override沉默协议 |
| 5 | 发送并等待确认 | ✅ | 符合协议 |
| **总分** | | **1.0** | **最佳决策链** |

### 场景B：用户空闲 + 一般信息

| 步骤 | 决策 | 质量 | 分析 |
|------|------|------|------|
| 1 | 检测到用户空闲 | ✅ | 状态识别正确 |
| 2 | 收到一般信息 | ✅ | 优先级识别正确 |
| 3 | 评估不确定性降低 | - | 降低20%，低于阈值 |
| 4 | 决策：延迟发牌 | ✅ | 质量门控生效 |
| 5 | 用户继续空闲，重新评估 | - | 等待更好的时机 |
| **总分** | | **0.8** | **良好，等待更好时机** |

### 场景C：用户会议中 + 非紧急建议

| 步骤 | 决策 | 质量 | 分析 |
|------|------|------|------|
| 1 | 检测到会议状态 | ✅ | 场景识别正确 |
| 2 | 收到非紧急建议 | ✅ | 紧急度评估正确 |
| 3 | 评估：会议中发牌打断度 | 高 | 会议打断成本高 |
| 4 | 决策：队列等待 | ✅ | 正确的延迟策略 |

## 五、决策质量评分公式

### 5.1 综合决策质量

```
decision_quality = (
    decision_correctness × 0.35 +
    card_type_appropriateness × 0.30 +
    timing_appropriateness × 0.25 +
    user_value_delivered × 0.10
)
```

### 5.2 发牌价值评估

```
card_value = (
    uncertainty_reduction × 0.40 +
    action_clarity_boost × 0.35 +
    time_sensitivity × 0.15 +
    relevance × 0.10
)
```

### 5.3 用户满意度预测

```
predicted_satisfaction = (
    perceived_helpfulness × 0.30 +
    timing_appropriateness × 0.25 +
    information_quality × 0.25 +
    frequency_appropriateness × 0.20
)
```

## 六、质量改进触发条件

| 触发条件 | 优先级 | 建议行动 |
|---------|--------|---------|
| 确认率 < 80% | 高 | 优化卡片内容，提升价值感知 |
| 行动完成率 < 70% | 高 | 检查行动可行性，改进行动描述 |
| 打断投诉率 > 10% | 高 | 加强心流检测，延迟非紧急卡片 |
| 漏发率 > 15% | 中 | 降低发牌阈值，更积极发牌 |
| 误发率 > 20% | 中 | 提高发牌阈值，减少非必要发牌 |
| 响应时间 > 5分钟 | 中 | 优化决策算法，加速处理 |
