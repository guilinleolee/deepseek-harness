# 实体优化提示词

> 让AI准确识别和理解内容核心实体

## 🎯 核心目标

将内容中的核心实体明确化、结构化，使AI能够：
1. 准确识别实体
2. 理解实体含义
3. 建立实体关联
4. 正确引用内容

## 📋 实体优化原则

### 原则1：实体数量控制

```
每页核心实体 ≤ 3个

原因：
- AI理解负载有限
- 多实体分散注意力
- 引用决策困难

例外：
- 综述类文章可适当增加
- 实体间有强关联时可增加
```

### 原则2：实体首次定义

```
规则：核心实体首次出现时，必须提供完整定义

格式：
[实体名称]（[实体类型]）：[一句话定义]

示例：
人工智能（技术领域）：研究、开发用于模拟、延伸和扩展人的智能的理论、方法、技术及应用系统的一门新的技术科学。
```

### 原则3：实体一致性

```
规则：同一实体在整个文档中使用一致的名称

错误示例：
- AI
- 人工智能
- 机器智能
（同一实体，多种名称）

正确示例：
- 统一使用"人工智能"
- 首次定义后保持一致
```

### 模板1：实体定义模板

```markdown

### [实体1名称]

**定义**：[一句话定义，20-50字]

- [属性1]：[描述]
- [属性2]：[描述]
**关联实体**：[相关实体列表]

### [实体2名称]
...
```

### 模板2：实体上下文模板

```markdown
在讨论[实体A]时，我们需要理解其与[实体B]的关系。
[实体A]是[定义]，而[实体B]是[定义]。
两者的主要区别在于[差异点]。

示例：
在讨论"深度学习"时，我们需要理解其与"机器学习"的关系。
深度学习是机器学习的一个子集，专注于使用多层神经网络进行特征学习。
两者的主要区别在于特征提取方式：机器学习需要人工特征工程，而深度学习能自动学习特征。
```

## 📝 优化检查清单

### 检查项1：实体识别

- [ ] 是否识别出所有核心实体？
- [ ] 核心实体数量是否≤3个？
- [ ] 每个实体是否有明确类型？

### 检查项2：实体定义

- [ ] 核心实体首次出现时是否有定义？
- [ ] 定义是否简洁明了（20-50字）？
- [ ] 定义是否准确无歧义？

### 检查项3：实体一致性

- [ ] 同一实体是否使用一致的名称？
- [ ] 是否避免了同义词混用？
- [ ] 缩写是否首次出现时解释？

### 检查项4：实体关联

- [ ] 相关实体是否有内部链接？
- [ ] 实体间关系是否清晰？
- [ ] 是否使用Schema标记实体？

## 🚫 常见错误

### 错误1：实体过多

```markdown
❌ 错误示例：
本文将讨论人工智能、机器学习、深度学习、自然语言处理、计算机视觉、强化学习等多个技术领域。

✅ 正确示例：
本文聚焦人工智能的三大核心技术：机器学习、深度学习和自然语言处理。
```

### 错误2：定义缺失

```markdown
❌ 错误示例：
深度学习是AI的重要分支...

✅ 正确示例：
深度学习（技术领域）：使用多层神经网络进行特征学习的机器学习方法，是人工智能的重要分支。
```

### 错误3：名称不一致

```markdown
❌ 错误示例：
人工智能正在改变世界。AI技术发展迅速。机器智能应用广泛...

✅ 正确示例：
人工智能正在改变世界。人工智能技术发展迅速。人工智能应用广泛...
```
