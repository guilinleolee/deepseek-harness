# 引用分析框架

> 分析AI引用行为，优化内容引用价值

## 🎯 核心目标

1. 理解AI引用决策机制
2. 识别引用价值因素
3. 优化内容以增加引用概率
4. 追踪和分析引用效果

## 📊 AI引用决策模型

### 决策链分析

```
AI引用决策流程：

1. 可发现性（Discovery）
   └── 内容是否能被AI找到？
       ├── robots.txt允许
       ├── sitemap.xml包含
       ├── 内部链接可达
       └── 外部引用存在

2. 理解性（Comprehension）
   └── AI是否能理解内容？
       ├── 语言清晰度
       ├── 结构化程度
       ├── 实体明确性
       └── 上下文完整

3. 信任性（Trust）
   └── AI是否信任内容？
       ├── 来源权威性
       ├── 数据准确性
       ├── 作者资质
       └── 引用来源

4. 相关性（Relevance）
   └── 内容是否相关？
       ├── 主题匹配度
       ├── 时效性
       ├── 用户意图
       └── 上下文关联

5. 引用价值（Citation Value）
   └── 是否值得引用？
       ├── 信息增量
       ├── 独特观点
       ├── 数据支撑
       └── 权威背书
```

### 引用概率公式

```
P(引用) = f(可发现性 × 理解性 × 信任性 × 相关性 × 引用价值)

权重分布（估算）：
- 信任性：30%
- 引用价值：25%
- 相关性：20%
- 理解性：15%
- 可发现性：10%
```

## 📈 引用价值因素

### 因素1：数据支撑（权重：25%）

| 数据类型 | 价值评分 | 示例 |
|---------|---------|------|
| 具体数字 | 0.9 | "市场规模达到150亿元" |
| 百分比 | 0.85 | "同比增长23.5%" |
| 排名数据 | 0.8 | "全球排名第3" |
| 时间数据 | 0.7 | "2025年推出" |
| 对比数据 | 0.75 | "比竞品快30%" |

**优化建议**：
```markdown
❌ 定性描述：市场规模很大
✅ 定量描述：市场规模达到150亿元，同比增长23.5%

❌ 模糊表述：用户增长迅速
✅ 具体数据：月活用户从100万增长至500万，增长率400%
```

### 因素2：权威来源（权重：25%）

| 来源类型 | 信任评分 | 示例 |
|---------|---------|------|
| 学术论文 | 1.0 | Nature, Science |
| 官方数据 | 0.95 | 政府统计, 官方报告 |
| 权威媒体 | 0.85 | 新华社, 财新 |
| 行业报告 | 0.8 | 麦肯锡, 德勤 |
| 专家观点 | 0.7 | 行业KOL |

**优化建议**：
```markdown
❌ 无来源：研究表明...
✅ 有来源：根据麦肯锡2025年报告显示...

❌ 弱来源：有人说...
✅ 强来源：哈佛大学教授XXX在《Nature》发表的研究表明...
```

### 因素3：结构清晰（权重：20%）

| 结构元素 | 价值评分 | 说明 |
|---------|---------|------|
| 标题层级 | 0.9 | H1-H3结构清晰 |
| 列表格式 | 0.85 | 有序/无序列表 |
| 表格数据 | 0.8 | 数据表格呈现 |
| 摘要导语 | 0.75 | 开头有摘要 |
| 结论总结 | 0.7 | 结尾有总结 |

**优化建议**：
```markdown
✅ 清晰结构：
## 概述
[摘要段落]

## 核心发现
1. 发现1
2. 发现2

## 数据表格
| 指标 | 数值 | 变化 |

## 结论
[总结段落]
```

### 因素4：独特观点（权重：15%）

| 观点类型 | 价值评分 | 说明 |
|---------|---------|------|
| 原创洞察 | 1.0 | 独家分析 |
| 反共识 | 0.9 | 与主流观点不同 |
| 深度解读 | 0.85 | 超出表面的分析 |
| 案例分析 | 0.8 | 独特案例 |
| 趋势预测 | 0.75 | 未来判断 |

### 因素5：时效性（权重：15%）

| 时效性 | 价值评分 | 说明 |
|--------|---------|------|
| 24小时内 | 1.0 | 突发新闻 |
| 1周内 | 0.9 | 最新动态 |
| 1月内 | 0.8 | 近期趋势 |
| 3月内 | 0.7 | 季度分析 |
| 1年内 | 0.6 | 年度总结 |

## 🔍 引用追踪方法

### 方法1：手动搜索

```
Perplexity搜索：
1. 打开 perplexity.ai
2. 搜索目标关键词
3. 查看引用来源
4. 记录引用情况

Google SGE搜索：
1. 打开 Google
2. 启用SGE
3. 搜索目标关键词
4. 查看AI概述引用
```

### 方法2：API追踪（Perplexity）

```javascript
// 使用Perplexity API追踪引用
const response = await fetch('https://api.perplexity.ai/chat/completions', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    model: 'llama-3.1-sonar-large-128k-online',
    messages: [
      { role: 'user', content: '关键词' }
    ]
  })
});

// 分析响应中的citations字段
const citations = response.citations;
```

## 📊 引用效果指标

### 核心指标

| 指标 | 计算方式 | 目标值 |
|------|---------|--------|
| **引用率** | 被引用次数/内容总数 | >15% |
| **引用位置分** | 首引3分/中引2分/尾引1分 | >2.0 |
| **引用准确性** | 正确引用/总引用 | >90% |
| **引用增长率** | 月度增长 | >10% |

### 辅助指标

| 指标 | 说明 | 用途 |
|------|------|------|
| 平台分布 | 各AI平台引用占比 | 策略调整 |
| 关键词排名 | 被引用时的关键词 | 内容优化 |
| 竞品对比 | vs竞品引用率 | 竞争分析 |
| 时效性 | 发布到被引用的时间 | 内容策略 |

## 💡 优化策略

### 策略1：提升数据密度

```markdown
目标：每段包含≥1个数据点

方法：
1. 添加市场规模数据
2. 添加增长率数据
3. 添加对比数据
4. 添加排名数据

示例：
原文：人工智能市场发展迅速
```
