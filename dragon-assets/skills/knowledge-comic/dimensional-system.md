# Knowledge-Comic 维度系统

## 维度定义

### Art Style × Tone = 35 组合

```
5 Art Styles × 7 Tones = 35 种风格组合
```

---

## Art Style - 艺术风格 (5种)

### manga - 日漫风格

#### 视觉特征
- **眼睛**: 大眼睛，高光突出
- **表情**: 夸张情感表达
- **动作**: 动态姿势，速度线
- **背景**: 简化或风格化

#### 最佳场景
- 动漫爱好者
- 年轻受众
- 活力内容
- 流行动画风格

#### 颜色方案
```
主色: 鲜艳对比
皮肤: #FFE4C4 (浅色)
头发: 各种亮色
眼睛: 大而突出
```

---

### comic-strip - 美式连环画

#### 视觉特征
- **线条**: 清晰轮廓线
- **角色**: 卡通化，夸张特征
- **对话框**: 经典气泡框
- **排版**: 横向分格

#### 最佳场景
- 报纸风格
- 幽默教育
- 传统漫画
- 全年龄段

#### 颜色方案
```
主色: 平涂色彩
线条: #000000 (黑色)
背景: #FFFFFF (白色)
阴影: 简单渐变
```

---

### webtoon - 韩式条漫

#### 视觉特征
- **布局**: 竖屏滚动
- **分镜**: 长条形面板
- **色彩**: 全彩，细腻
- **阅读**: 移动端优化

#### 最佳场景
- 移动端发布
- 社交媒体
- 竖屏阅读
- 韩式风格

#### 颜色方案
```
主色: 丰富全彩
渐变: 细腻过渡
光效: 柔和光影
色调: 统一风格
```

---

### chibi - Q版卡通

#### 视觉特征
- **比例**: 头大身小 (2-3头身)
- **表情**: 可爱，简单线条
- **动作**: 萌系姿势
- **风格**: 可爱轻松

#### 最佳场景
- 可爱轻松
- 全年龄段
- 轻松科普
- 萌系内容

#### 颜色方案
```
主色: 粉嫩柔和
皮肤: #FFDDC1 (粉嫩)
脸颊: #FFB6C1 (腮红)
色调: 马卡龙色系
```

---

### sketch - 手绘草图

#### 视觉特征
- **线条**: 手绘感，不规则
- **细节**: 简化，即兴
- **注释**: 手写文字
- **风格**: 笔记风格

#### 最佳场景
- 即兴教学
- 笔记风格
- 快速绘制
- 教育场景

#### 颜色方案
```
主色: 铅笔/墨水
线条: #333333 (深灰)
纸张: #FFFDF5 (米白)
阴影: 排线/点
```

---

## Tone - 叙述语气 (7种)

### educational - 教育科普

#### 特征
- **语言**: 清晰准确
- **节奏**: 系统讲解
- **例子**: 具体实例
- **深度**: 适中深度

#### 对话示例
```
"让我来解释一下这个概念..."
"这里的重点是..."
"记住这个公式..."
```

#### 适用内容
- 系统学习
- 知识传授
- 教程教学

---

### humorous - 幽默风趣

#### 特征
- **语言**: 轻松搞笑
- **节奏**: 活泼跳跃
- **例子**: 有趣类比
- **深度**: 浅显易懂

#### 对话示例
```
"哈哈，这个就像..."
"没想到吧？"
"其实是这样的..."
```

#### 适用内容
- 轻松学习
- 趣味科普
- 社交传播

---

### serious - 严肃专业

#### 特征
- **语言**: 专业术语
- **节奏**: 稳重严谨
- **例子**: 精确案例
- **深度**: 深入讲解

#### 对话示例
```
"根据研究表明..."
"关键参数是..."
"这一步需要..."
```

#### 适用内容
- 深度讲解
- 学术内容
- 专业领域

---

### story - 故事化

#### 特征
- **语言**: 叙事性强
- **节奏**: 情节推进
- **例子**: 角色对话
- **深度**: 情景带入

#### 对话示例
```
"小明遇到了一个问题..."
"让我们看看发生了什么..."
"故事的结局是..."
```

#### 适用内容
- 情景带入
- 案例教学
- 故事叙述

---

### casual - 随意轻松

#### 特征
- **语言**: 口语化
- **节奏**: 自由灵活
- **例子**: 日常类比
- **深度**: 浅层了解

#### 对话示例
```
"就是那么回事..."
"简单说就是..."
"差不多是这样..."
```

#### 适用内容
- 社交媒体
- 碎片学习
- 轻松阅读

---

### inspiring - 励志鼓舞

#### 特征
- **语言**: 激励向上
- **节奏**: 充满激情
- **例子**: 成功案例
- **深度**: 情感共鸣

#### 对话示例
```
"你可以做到的..."
"相信自己的潜力..."
"让我们一起..."
```

#### 适用内容
- 激发兴趣
- 正能量
- 励志内容

---

### mysterious - 悬疑探索

#### 特征
- **语言**: 引发好奇
- **节奏**: 悬念推进
- **例子**: 解谜过程
- **深度**: 探索发现

#### 对话示例
```
"你有没有想过..."
"秘密在于..."
"让我们揭开..."
```

#### 适用内容
- 吸发好奇
- 解谜探索
- 发现之旅

## 组合推荐

### 热门组合

| Art | Tone | 效果描述 | 适用场景 |
|-----|------|---------|---------|
| manga | educational | 日漫科普 | 动漫爱好者学习 |
| chibi | humorous | Q版幽默 | 全年龄段轻松科普 |
| sketch | story | 手绘故事 | 笔记风格叙事 |
| webtoon | casual | 条漫轻松 | 社交媒体传播 |
| comic-strip | serious | 连环画专业 | 报纸教育专栏 |

### 内容类型推荐

| 内容类型 | 推荐Art | 推荐Tone |
|---------|---------|----------|
| 科学知识 | manga, sketch | educational, story |
| 技术教程 | comic-strip, sketch | serious, educational |
| 轻知识 | chibi, webtoon | humorous, casual |
| 历史故事 | manga, comic-strip | story, mysterious |
| 励志内容 | manga, webtoon | inspiring, story |
| 社交科普 | chibi, webtoon | casual, humorous |
| 学术内容 | sketch, comic-strip | serious, educational |
