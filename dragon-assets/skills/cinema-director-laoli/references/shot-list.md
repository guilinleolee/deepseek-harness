# 老李风 8 套电影镜头库 · cinema-director-laoli V1.0

> **来源**：天龙自研 + 借调 huashu-design cinematic-patterns（11KB）+ 35-05 V10.3 实拍经验
> **触发**：cinema-director-laoli 选中后，按情绪自动匹配 1-8 套

---

## 镜头 1 · close-up 特写

**适用情绪**：强调 / 顿悟 / 关键判断

**老李风典型 prompt 片段**：
```
镜头推近脸部，半秒，焦外虚化背景暖光
人物眼神从思考转为笃定，眼角微动
背景暖棕色牛皮纸质感，光从右上方 45°
```

**参数**：
- 时长：2-3 秒
- 景深：浅（f/1.4-f/2.8）
- 镜头语言：slow dolly-in 或 cut-to-close-up
- 老李声纹：可叠加 whisper narration

---

## 镜头 2 · wide-shot 远景

**适用情绪**：场景铺设 / 收束 / 升华

**老李风典型 prompt 片段**：
```
镜头拉远，俯瞰整个场景
人物小到画面 1/9，体现"普通人"位置
背景留白 60%，给文字呼吸感
```

**参数**：
- 时长：3-5 秒
- 景深：深（f/8-f/11）
- 镜头语言：crane-up 或 zoom-out
- 收尾用：老李兄弟喜欢用远景收束，让画面"留味"

---

## 镜头 3 · dolly 推拉

**适用情绪**：引入 / 退出 / 节奏切换

**老李风典型 prompt 片段**：
```
从门口 dolly-in 到桌前，3 秒匀速
速度不变，给观众"进入感"
或反向：从桌前 dolly-out 到门口，退出场景
```

**参数**：
- 时长：2-4 秒
- 镜头语言：物理 dolly 轨道或 smooth zoom
- 老李风节奏：匀速，**不加速不减速**

---

## 镜头 4 · crane 升降

**适用情绪**：宏大 / 收束 / 反差

**老李风典型 prompt 片段**：
```
从桌面 crane-up 到天花板，2 秒
揭示"小细节"如何撑起"大判断"
或反向：从天花板 crane-down 到桌面
```

**参数**：
- 时长：2-3 秒
- 镜头语言：crane 机械臂或 digital pan
- 收尾用：老李兄弟升降镜头结尾，给"看完后再看一遍"的感觉

---

## 镜头 5 · orbit 旋转

**适用情绪**：紧迫 / 思考 / 内心冲突

**老李风典型 prompt 片段**：
```
镜头围绕人物 360° 旋转 5 秒
速度先慢后快，焦点始终在眼睛
背景做 radial blur
```

**参数**：
- 时长：4-6 秒
- 镜头语言：slider orbit 或 digital orbit
- 老李声纹：可叠加内心独白

---

## 镜头 6 · montage 蒙太奇

**适用情绪**：节奏 / 知识密度 / 多案例并列

**老李风典型 prompt 片段**：
```
快速 6 帧切，每帧 0.5 秒
每帧一个老李风格的"小段子"
最后 1 帧定格 + 大字标题
```

**参数**：
- 时长：3-4 秒
- 镜头语言：jump cut × 6 + 末帧 freeze
- 老李风要点：6 帧必须有节奏感（前 3 慢、后 3 快）

---

## 镜头 7 · time-cut 时间跳切

**适用情绪**：节奏 / 情绪跳跃 / 对比

**老李风典型 prompt 片段**：
```
同场景不同季节快速切换
春 → 夏 → 秋 → 冬，每 0.8 秒一帧
最后回到现在时刻
```

**参数**：
- 时长：3-5 秒
- 镜头语言：digital dissolve 或季节色温对比
- 老李风要点：颜色节奏（春暖 → 夏热 → 秋凉 → 冬冷）

---

## 镜头 8 · B&W-flash 黑白闪回

**适用情绪**：回忆 / 反思 / 历史对比

**老李风典型 prompt 片段**：
```
突然切到黑白 1 秒（强烈对比）
再回彩色 2 秒，给"恍如隔世"感
仅用于关键记忆点，不能滥用
```

**参数**：
- 时长：2-3 秒
- 镜头语言：digital desaturation + grain
- 老李声纹：可叠加略带沙哑的"那一年..."

## 反 AI slop 提示（来自 huashu-design cinematic-patterns）

- ❌ **不要**把所有 8 套都用上 → 真实分镜 ≤ 8 套，超出反而失真
- ❌ **不要**用纯 CG 镜头 → 老李风必须是"实拍质感 + 自然光"
- ❌ **不要**加任何 emoji / sticker / AR 特效 → 老李风禁忌
- ✅ **要**保持"普通人拍纪录片的味道"
- ✅ **要**每个镜头都有"为什么用这个镜头"的合理理由
