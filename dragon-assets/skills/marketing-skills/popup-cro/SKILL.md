# Popup CRO

> **核心价值**：弹窗是把双刃剑，好的弹窗提升转化，差的弹窗伤害体验。

## Before Starting

1. 确认已完善 `product-marketing-context`
2. 明确弹窗目标（收集邮箱/促销通知/功能引导）

---

## 弹窗类型与时机

### 1. 弹窗类型

| 类型 | 转化率 | 用户接受度 | 适用场景 |
|------|--------|------------|----------|
| **退出意图弹窗** | 3-5% | 高 | 防止流失 |
| **延迟弹窗** | 2-4% | 中 | 新用户优惠 |
| **滚动触发弹窗** | 2-3% | 中 | 内容相关 |
| **点击触发弹窗** | 5-10% | 高 | 用户主动 |

### 2. 触发时机

| 触发条件 | 建议 | 原因 |
|----------|------|------|
| **时间延迟** | 30-60秒 | 让用户先浏览 |
| **滚动深度** | 50-70% | 用户已感兴趣 |
| **退出意图** | 鼠标移出 | 最后机会挽救 |
| **页面浏览数** | 第2-3页 | 有一定了解后 |

### 3. 设计原则

```
┌─────────────────────────────────────┐
│  [关闭按钮X]                         │
├─────────────────────────────────────┤
│                                     │
│   ★ 吸引人的标题                    │
│   清晰的价值描述                     │
│                                     │
│   [输入框]                          │
│                                     │
│   [行动按钮]                        │
│                                     │
│   信任元素/隐私说明                 │
└─────────────────────────────────────┘
```
