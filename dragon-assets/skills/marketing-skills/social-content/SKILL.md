# Social Content

> **核心价值**：持续产出高互动的社媒内容，构建品牌影响力。

## Before Starting

1. 确认已完善 `product-marketing-context`
2. 确定目标平台和内容类型

## 内容创作框架

### 1. 内容类型矩阵

```
┌─────────────────────────────────────────────────┐
│                   内容价值矩阵                   │
├─────────────────────────────────────────────────┤
│                                                 │
│  教育型        │  娱乐型                        │
│  - 干货教程    │  - 趣味故事                    │
│  - 行业洞察    │  - 段子梗图                    │
│  - 案例分析    │  - 反转剧情                    │
│  ──────────────┼────────────────────────────── │
│  激发型        │  连接型                        │
│  - 励志故事    │  - 用户故事                    │
│  - 成功案例    │  - 互动话题                    │
│  - 热点解读    │  - 社区活动                    │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 2. 爆款内容公式

```
爆款 = 选题(40%) + 标题(30%) + 内容(20%) + 时机(10%)

选题来源：
1. 热点话题（微博热搜、抖音热榜）
2. 用户痛点（评论、客服反馈）
3. 竞品爆款（对标账号分析）
4. 行业趋势（报告、白皮书）
```

### 3. 标题公式

```markdown
1. 数字型："3个技巧帮你..."
2. 疑问型："为什么90%的人..."
3. 对比型："X vs Y，谁更..."
4. 利益型："如何用X达成Y"
5. 好奇型："揭秘行业不为人知的..."
6. 紧迫型："限时分享，即将删除"
```

## 互动优化

### 提升互动率的技巧

1. **提问式结尾**：引导用户评论
2. **投票/选择**：降低互动门槛
3. **话题标签**：增加曝光
4. @提及：增加传播
5. 评论互动：提升算法推荐

### 数据追踪

| 指标 | 健康值 | 优化方向 |
|------|--------|----------|
| 互动率 | >3% | 内容质量+CTA优化 |
| 完播率 | >50% | 开头吸引+内容节奏 |
| 分享率 | >1% | 价值感+情感共鸣 |
| 涨粉率 | >1% | 内容价值+人设塑造 |
