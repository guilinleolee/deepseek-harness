# Pricing Strategy

> **核心价值**：定价是最强的利润杠杆——价格提升1%，利润提升11%。

## Before Starting

1. 确认已完善 `product-marketing-context`
2. 收集现有定价数据（如有）

---

## Core Principles

### 1. 定价不是成本定价，是价值定价

**错误思维**：成本 + 利润率 = 价格
**正确思维**：客户感知价值 = 价格上限

**价值定价公式**：
```
价格 = 客户获得的可量化价值 × 价值获取比例(10-30%)

示例：
- 产品帮客户节省$10,000/年
- 定价$1,000-3,000/年（10-30%价值获取）
```

### 2. 定价决定定位

价格本身就是定位信号。

| 价格区间 | 定位信号 | 用户期望 |
|----------|----------|----------|
| 低价 | 入门级、自助 | 基础功能、有限支持 |
| 中价 | 专业级、团队 | 完整功能、标准支持 |
| 高价 | 企业级、定制 | 全功能、专属支持、定制 |

### 3. 简单胜过完美

**规则**：
- 层级不超过 **3-4个**
- 每个层级差异明确
- 避免复杂计算

### 4. 价格透明度影响转化

| 透明度 | 适用场景 | 转化影响 |
|--------|----------|----------|
| 完全公开 | 标准产品 | 最高转化 |
| 联系销售 | 企业产品 | 中等转化 |
| 隐藏价格 | 高端定制 | 需要培育 |

## Pricing Frameworks

### 1. 三层级定价模型（最常用）

```
┌─────────────────────────────────────────────┐
│                 Enterprise                  │
│              $XXX/月 · 定制功能             │
│         所有功能 + 专属支持 + API           │
└─────────────────────────────────────────────┘
                    ↑ 引导上
┌─────────────────────────────────────────────┐
│                   Pro                       │
│              $XX/月 · 推荐 ★                │
│            核心功能 + 优先支持              │
└─────────────────────────────────────────────┘
                    ↑ 主推
┌─────────────────────────────────────────────┐
│                  Free                       │
│                $0/月                        │
│              基础功能 + 社区支持            │
└─────────────────────────────────────────────┘
```

**设计要点**：
- 中间层标注"推荐"或"最受欢迎"
- 高价层衬托中间层性价比
- 免费层作为转化入口

### 2. 用量定价模型（SaaS常用）

| 模型 | 适用场景 | 示例 |
|------|----------|------|
| 用户数定价 | 协作工具 | $X/用户/月 |
| 存储定价 | 云服务 | $X/GB/月 |
| API调用定价 | 开发工具 | $X/1000次调用 |
| 功能层级定价 | 工具软件 | 基础版/专业版/企业版 |

### 3. 混合定价模型

```
基础订阅 + 用量超限费用

示例：
- 基础：$99/月（含1000次调用）
- 超限：$0.05/次调用

优点：降低入门门槛，高用量用户付费更多
```

### 4. 免费增值模型（Freemium）

**决策矩阵**：

| 条件 | 推荐模型 |
|------|----------|
| 获客成本高 | 免费增值 |
| 产品自传播 | 免费增值 |
| 企业客户为主 | 免费试用 |
| 复杂产品 | 免费试用 |

**关键指标**：
- 免费转付费率：**2-5%** 为健康
- 付费用户ARPU：覆盖免费用户成本

## Pricing Psychology

### 1. 价格锚定

```markdown
原价：$299/月  ← 锚点
现价：$99/月   ← 实际价格

用户感知：省了$200（实际只是定价策略）
```

### 2. 价格分解

```markdown
年付 $999 → 显示 "$83/月"
日付 $2.7/天 → 显示 "每天一杯咖啡钱"

降低心理门槛
```

### 3. 尾数定价

| 价格 | 感知 | 适用场景 |
|------|------|----------|
| $100 | 高端 | 奢侈品、企业产品 |
| $99 | 划算 | 消费品、个人产品 |
| $97 | 特殊 | 课程、促销 |

### 4. 价格不敏感区间

用户对以下价格变化不敏感：
- **B2C**：$X.99 vs $X
- **B2B**：$X,000 vs $X,500（大额差异小）
