# Form CRO

> **核心价值**：表单每减少一个字段，转化率提升10-20%。

## Before Starting

1. 确认已完善 `product-marketing-context`
2. 分析表单当前转化数据

---

## 表单优化框架

### 1. 字段优化

**原则**：
- 必填字段 ≤ 4个
- 可选字段明确标注
- 避免重复输入

**字段类型优化**：

| 字段类型 | 问题 | 优化方案 |
|----------|------|----------|
| 电话 | 格式要求严 | 自动格式化 |
| 邮箱 | 拼写错误 | 自动验证+建议 |
| 地址 | 输入繁琐 | 地址自动补全 |
| 密码 | 要求复杂 | 显示要求+强度提示 |

### 2. 布局优化

```
单列布局（推荐）：
┌─────────────────────┐
│ 标题                │
│ 副标题              │
├─────────────────────┤
│ [字段1]             │
│ [字段2]             │
│ [字段3]             │
│ [提交按钮]          │
└─────────────────────┘

多列布局（不推荐）：
┌─────────────────────┐
│ [字段1]    [字段2]  │
│ [字段3]    [字段4]  │
│ [提交按钮]          │
└─────────────────────┘
```

### 3. 错误处理

**原则**：
- 实时验证（失焦时）
- 具体错误信息
- 指出修复方法

**错误信息对比**：
```
❌ "请输入有效的邮箱"
✅ "邮箱地址缺少@符号，请检查后重试"

❌ "密码不符合要求"
✅ "密码需要至少8位，包含字母和数字"
```
