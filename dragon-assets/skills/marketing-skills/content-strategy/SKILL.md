# Content Strategy

> **核心价值**：内容策略让每一篇内容都有明确的目标和受众。

## Before Starting

1. 确认已完善 `product-marketing-context`
2. 明确内容营销目标（品牌/线索/转化）

---

## 内容策略框架

### 1. 内容矩阵

```
内容类型 vs 用户旅程：
                认知 → 考虑 → 决策 → 留存
博客文章         ✅     ✅
白皮书/报告      ✅     ✅
案例研究               ✅     ✅
产品对比               ✅     ✅
用户指南                      ✅     ✅
FAQ                           ✅     ✅
视频教程                ✅     ✅     ✅
```

### 2. 内容主题规划

| 主题类型 | 示例 | 发布频率 |
|----------|------|----------|
| **教育型** | 行业趋势、最佳实践 | 2-3篇/周 |
| **产品型** | 功能介绍、更新日志 | 1-2篇/周 |
| **案例型** | 客户成功故事 | 1篇/周 |
| **互动型** | 投票、问答、活动 | 1-2篇/周 |

### 3. 内容日历

```markdown
## 月度内容日历

| 周次 | 周一 | 周三 | 周五 |
|------|------|------|------|
| 第1周 | 教育博客 | 产品更新 | 案例故事 |
| 第2周 | 行业报告 | 视频教程 | 社媒互动 |
| 第3周 | 最佳实践 | 白皮书 | 用户故事 |
| 第4周 | 趋势分析 | 功能深度 | 月度总结 |
```

## 内容质量标准

### 结构标准

```
博客文章结构：
├── 标题（吸引+关键词）
├── 导语（1-2段，核心观点）
├── 正文（H2/H3分层）
│   ├── 要点1
│   ├── 要点2
│   └── 要点3
├── 结论/行动号召
└── 相关推荐
```

### SEO检查

| 检查项 | 标准 |
|--------|------|
| 标题长度 | 50-60字符 |
| 元描述 | 150-160字符 |
| 关键词密度 | 1-2% |
| 内链数量 | 3-5个 |
| 外链数量 | 1-3个 |
| 图片Alt | 全部添加 |
