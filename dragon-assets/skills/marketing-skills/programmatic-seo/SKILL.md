# Programmatic SEO

> **核心价值**：一个模板，生成1000+高质量SEO页面。

## Before Starting

1. 确认已完善 `product-marketing-context`
2. 确定可规模化的关键词模式

---

## 程序化SEO框架

### 1. 关键词模式识别

```
模式类型：
├── 地理位置型：[产品] in [城市]
│   示例：瑜伽课 in 北京、瑜伽课 in 上海...
│   规模：城市数量（100+）
│
├── 属性组合型：[属性1] [产品] for [属性2]
│   示例：免费CRM for 小企业、付费CRM for 大企业...
│   规模：属性组合（50+）
│
├── 对比型：[产品A] vs [产品B]
│   示例：Salesforce vs HubSpot、Notion vs Obsidian...
│   规模：竞品组合（30+）
│
└── 问题型：How to [动词] [对象]
    示例：How to write code、How to design logo...
    规模：动词+对象组合（500+）
```

### 2. 页面模板设计

```markdown
## [关键词变量] - [品牌名]

### 什么是[关键词变量]？
[动态内容段落1]

### [关键词变量]的核心特点
1. [特点1]
2. [特点2]
3. [特点3]

### 为什么选择[品牌名]？
[动态价值主张]

### 常见问题
Q: [问题1]
A: [答案1]

[CTA按钮]
```

### 3. 内容质量保障

| 风险 | 预防措施 |
|------|----------|
| **重复内容** | 动态变量占比>40% |
| **低质量** | 人工审核核心页面 |
| **惩罚风险** | 避免纯模板填充 |
| **用户体验** | 添加独特价值 |
