# Ad Creative

> **核心价值**：好的创意让广告效果提升3-5倍。

## Before Starting

1. 确认已完善 `product-marketing-context`
2. 明确广告平台和格式要求

---

## 创意类型矩阵

| 格式 | 适用平台 | 最佳时长 | 核心要素 |
|------|----------|----------|----------|
| 静态图片 | 全平台 | - | 视觉冲击+简洁文案 |
| 短视频 | 抖音/小红书/FB | 15-30s | 前3秒抓注意力 |
| 轮播图 | FB/小红书 | 3-5张 | 讲故事递进 |
| 信息流 | 全平台 | - | 原生化+真实感 |

---

## 创意公式

### 1. 标题公式（高点击率）

```
公式1：痛点 + 解决方案
"还在为[痛点]烦恼？试试这个方法"

公式2：数字 + 结果
"3步帮你节省[具体数字]"

公式3：好奇心缺口
"为什么90%的人不知道这个技巧"

公式4：社会证明
"[数量]人都在用的方法"

公式5：紧迫感
"限时24小时，错过再等一年"
```

### 2. 视觉原则

**F型视觉流向**：
```
┌────────────────────────┐
│ ★★★ 标题/Logo         │
│ ●●● 关键信息           │
│                        │
│   图片/视频主体        │
│                        │
│ [CTA按钮]              │
└────────────────────────┘
```

**颜色对比**：
- CTA按钮：与背景对比度 > 70%
- 文字：可读性优先，避免低对比度

### 3. CTA优化

| CTA类型 | 示例 | 适用场景 |
|---------|------|----------|
| 行动型 | "立即注册" | 高意向用户 |
| 探索型 | "了解更多" | 信息收集阶段 |
| 激励型 | "领取免费试用" | 需要激励 |
| 紧迫型 | "限时优惠" | 促转化 |

## A/B测试框架

### 测试优先级

```
1. 标题（影响最大） → 先测
2. CTA按钮
3. 主图/视频前3秒
4. 文案内容
5. 配色/布局
```

### 测试规则

- 每次只测1个变量
- 样本量：每个变体≥1000次展示
- 显著性：置信度>95%
- 周期：3-7天

### 测试记录模板

| 测试ID | 变量 | 对照组 | 实验组 | CTR提升 | 结论 |
|--------|------|--------|--------|---------|------|
| 001 | 标题 | A版 | B版 | +25% | 采用B |
