# Page CRO (Conversion Rate Optimization)

> **核心价值**：转化率提升1%，收入提升10%+。

## Before Starting

1. 确认已完善 `product-marketing-context`
2. 获取页面现有转化数据

---

## 转化漏斗分析

```
访问 → 浏览 → 互动 → 转化
 ↓       ↓       ↓       ↓
CTR    跳出率  深度    CVR
```

### 诊断指标

| 指标 | 健康值 | 警告值 | 问题诊断 |
|------|--------|--------|----------|
| 跳出率 | <40% | >60% | 内容不匹配/加载慢 |
| 停留时间 | >2分钟 | <30秒 | 内容不吸引 |
| 滚动深度 | >70% | <30% | 内容结构问题 |
| 转化率 | >3% | <1% | CTA/信任问题 |

---

## 优化框架

### 1. 首屏优化（Above the Fold）

**5秒测试**：用户5秒内能否理解：
- 这是什么？
- 能得到什么？
- 下一步做什么？

**优化要素**：
```
┌─────────────────────────────────────┐
│  Logo     导航           [CTA按钮]  │
├─────────────────────────────────────┤
│                                     │
│   ★ 主标题（价值主张）              │
│   副标题（补充说明）                 │
│                                     │
│   [主图/视频演示]                   │
│                                     │
│   [主CTA按钮]                       │
│   信任徽章                          │
└─────────────────────────────────────┘
```

### 2. 内容结构（PAS框架）

```
P - Problem（问题）
    描述用户痛点，建立共鸣

A - Agitation（放大）
    放大痛点影响，激发紧迫感

S - Solution（解决方案）
    展示产品如何解决问题
```

### 3. 信任元素

| 元素 | 位置 | 效果 |
|------|------|------|
| 客户logo | 首屏 | +15%信任度 |
| 用户评价 | 中部 | +20%信任度 |
| 数据证明 | 全页 | +25%信任度 |
| 安全徽章 | CTA附近 | +10%信任度 |
| 案例/认证 | 底部 | +15%信任度 |

### 4. CTA优化

**位置**：
- 首屏必须有
- 长页面重复出现（每2屏一个）
- 底部固定按钮

**文案原则**：
- 动词开头："立即开始" vs "开始"
- 说明价值："免费试用" vs "注册"
- 创造紧迫："限时优惠"

## A/B测试策略

### 测试优先级

| 优先级 | 测试元素 | 预期提升 |
|--------|----------|----------|
| 1 | 标题 | 20-50% |
| 2 | CTA文案 | 10-30% |
| 3 | 主图 | 10-25% |
| 4 | 表单字段 | 15-40% |
| 5 | 页面布局 | 5-15% |

### 测试规则

```yaml
最小样本量: 每个变体1000访客
测试周期: 最少7天，最多14天
显著性: 95%置信度
单变量: 每次只测1个元素
```
