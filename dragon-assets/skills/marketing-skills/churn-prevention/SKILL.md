# Churn Prevention

> **核心价值**：获客成本是留存的5倍，预防流失是最具ROI的增长策略。

## Before Starting

1. 确认已完善 `product-marketing-context`
2. 获取用户行为数据和流失历史

---

## 流失预警模型

### 流失信号识别

| 信号类型 | 具体表现 | 风险等级 |
|----------|----------|----------|
| **行为下降** | 登录频率↓、功能使用↓ | 高 |
| **互动减少** | 打开邮件↓、点击↓ | 中 |
| **负面反馈** | 工单投诉、低评分 | 高 |
| **账户变化** | 降级、减少席位 | 高 |
| **竞品信号** | 查看竞品页面 | 中 |

### 预警阈值设定

```yaml
# 高危流失预警
condition:
  - no_login_days >= 14
  - usage_decline >= 50%
  - ticket_complaint = true
action:
  - tag: churn_risk_high
  - notify: customer_success
  - trigger: retention_sequence

# 中危预警
condition:
  - no_login_days >= 7
  - email_open_rate < 10%
action:
  - tag: churn_risk_medium
  - trigger: re_engagement_email
```

## 流失原因分析

### 常见流失原因

| 原因类型 | 占比 | 应对策略 |
|----------|------|----------|
| **价值认知不足** | 35% | 加强教育、展示成功案例 |
| **产品问题** | 25% | 快速修复、补偿方案 |
| **价格敏感** | 20% | 优惠方案、价值重申 |
| **竞品替代** | 15% | 差异化强调、功能对齐 |
| **其他** | 5% | 具体问题具体分析 |

### 流失访谈框架

```markdown
## 流失用户访谈问题

1. 使用背景
   - 您最初为什么选择我们？
   - 主要使用哪些功能？

2. 流失原因
   - 是什么让您决定不再使用？
   - 具体遇到了什么问题？

3. 替代方案
   - 您现在用什么替代方案？
   - 它比我们好在哪里？

4. 挽回可能
   - 如果我们解决X问题，您会回来吗？
   - 还有什么能改变您的决定？
```

## 挽回策略矩阵

### 按阶段分层挽回

```
┌─────────────────────────────────────────────────────────┐
│                    流失挽回策略矩阵                      │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  高价值用户     │  低价值用户                           │
│  ─────────────  │  ─────────────                        │
│  1v1专属客服    │  自动化挽回邮件                       │
│  定制优惠方案   │  标准优惠                             │
│  功能定制承诺   │  产品教育                             │
│  CEO直接沟通    │  社区邀请                             │
│                                                         │
│  高流失风险 ←──┼──→ 低流失风险                         │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 挽回邮件序列

```yaml
# 挽回邮件序列
trigger: churn_risk_detected
sequence:
  - email: check_in, delay: 0h
    tone: 关心询问
    content: "一切都好吗？需要帮助吗？"

  - email: value_reminder, delay: 72h
    tone: 价值重申
    content: "您可能错过的X功能..."

  - email: offer, delay: 168h
    tone: 激励挽留
    content: "专属优惠：延长试用期/X折..."

  - email: goodbye, delay: 336h
    tone: 优雅告别
    content: "我们会想念您，随时欢迎回来"
```

## 留存优化

### 提升留存的关键动作

| 阶段 | 关键动作 | 目标 |
|------|----------|------|
| **激活期** | 新手引导、首次价值体验 | 7天留存+30% |
| **成长期** | 功能教育、习惯培养 | 30天留存+20% |
| **稳定期** | 价值深化、社区连接 | 长期留存稳定 |
| **风险期** | 预警挽回、问题解决 | 流失率-50% |

### 留存健康指标

| 指标 | 健康值 | 优秀值 |
|------|--------|--------|
| 7天留存 | >40% | >60% |
| 30天留存 | >25% | >40% |
| 90天留存 | >15% | >25% |
| 年度流失率 | <20% | <10% |
| NRR | >100% | >120% |
