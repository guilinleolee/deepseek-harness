# Sales Enablement

> **核心价值**：销售赋能让销售团队效率提升30%，成交率提升20%。

## Before Starting

1. 确认已完善 `product-marketing-context`
2. 了解销售团队痛点和需求

---

## 销售赋能框架

### 1. 销售工具包

| 工具类型 | 内容 | 更新频率 |
|----------|------|----------|
| **产品资料** | 产品手册、功能介绍、更新日志 | 每月 |
| **竞品对比** | 对比表、差异化话术 | 每季度 |
| **案例库** | 成功案例、ROI证明 | 持续更新 |
| **定价信息** | 价格表、折扣政策、打包方案 | 每季度 |
| **异议处理** | 常见异议+应对话术 | 每月 |

### 2. 异议处理库

```
常见异议分类：
├── 价格异议
│   "太贵了" → 强调ROI和价值
│   "没有预算" → 分期/试用/降级方案
│
├── 竞品异议
│   "竞品更便宜" → 对比功能差异
│   "竞品功能更多" → 强调核心优势
│
├── 时间异议
│   "再考虑一下" → 紧迫感+风险
│   "不需要现在买" → 早买早受益
│
└── 信任异议
    "没听说过你们" → 客户案例+背书
    "你们能保证吗" → SLA+退款承诺
```

### 3. 销售培训内容

| 培训模块 | 内容 | 时长 |
|----------|------|------|
| **产品培训** | 功能演示、使用场景 | 2小时 |
| **竞品培训** | 竞品对比、差异化 | 1小时 |
| **话术培训** | 异议处理、谈判技巧 | 2小时 |
| **工具培训** | CRM使用、报价工具 | 1小时 |

## 关键指标

| 指标 | 目标 | 说明 |
|------|------|------|
| **销售工具使用率** | >80% | 销售使用工具包频率 |
| **培训完成率** | 100% | 新销售培训完成比例 |
| **成交周期** | 缩短20% | 从线索到成交的时间 |
| **转化率提升** | +20% | 使用工具包后的转化率 |
