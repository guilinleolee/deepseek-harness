# Marketing Psychology

> **核心价值**：理解用户决策背后的心理机制，设计更有效的营销策略。

## Before Starting

1. 确认已完善 `product-marketing-context`
2. 明确要解决的具体问题（转化、留存、定价等）

---

## Core Principles

### 1. 损失厌恶 > 获得愉悦

用户对损失的痛苦感是获得愉悦感的 **2.5倍**。

**应用场景**：
- ❌ "节省$100/月" → ✅ "别再浪费$1200/年"
- ❌ "获得功能升级" → ✅ "防止功能过期"

### 2. 社会证明驱动决策

用户在不确定时，会参考他人行为。

**证据层级**：
1. 专家背书（最强）
2. 名人代言
3. 用户评价
4. 数量证明（最弱）

**应用公式**：
```
[权威来源] + [具体数据] + [时间框架]
= "被10,000+产品团队使用"
```

### 3. 稀缺性创造紧迫感

稀缺性触发用户的FOMO（错失恐惧）。

**稀缺类型**：
| 类型 | 示例 | 效果 |
|------|------|------|
| 数量稀缺 | "仅剩5个名额" | ⭐⭐⭐⭐⭐ |
| 时间稀缺 | "限时24小时" | ⭐⭐⭐⭐ |
| 访问稀缺 | "需邀请才能加入" | ⭐⭐⭐⭐⭐ |

### 4. 互惠原则驱动回报

先给予，再索取。

**应用模式**：
- 免费工具 → 收集邮箱
- 免费课程 → 产品推广
- 免费试用 → 付费转化

### 5. 锚定效应影响判断

用户对价格的判断受第一个看到的价格影响。

**定价应用**：
```
原价 $199 → 划线价
现价 $99 → 实际价格

用户感知：$99很划算（锚定$199）
```

## Psychological Frameworks

### Cialdini's 7 Principles

| 原则 | 定义 | 营销应用 |
|------|------|----------|
| **互惠** | 先给予，后索取 | 免费试用、免费内容 |
| **承诺一致** | 小承诺导致大承诺 | 免费试用→付费订阅 |
| **社会证明** | 他人行为影响决策 | 用户评价、使用数量 |
| **权威** | 专家意见更可信 | 行业认证、专家推荐 |
| **喜好** | 喜欢的人更有说服力 | 品牌故事、价值观共鸣 |
| **稀缺** | 稀有的更有价值 | 限量、限时 |
| **统一** | 群体认同 | 社区、品牌社群 |

### Fogg Behavior Model

用户行为 = 动机 × 能力 × 触发

```
         高动机
            │
            │   ● 触发成功区
            │  ●
            │ ●
    ────────┼──────── 高能力
            │
            │
            │
         低动机
```

**优化策略**：
- 动机不足 → 增加激励、降低痛点
- 能力不足 → 简化流程、减少步骤
- 触发不足 → 优化时机、增加提醒

### Decision Paradox

选项越多，决策越难。

**黄金法则**：
- 最优选项数：**3-5个**
- 超过5个 → 用户放弃决策
- 推荐策略：标注"最受欢迎"或"推荐"

## Task-Specific Applications

### 1. 转化率优化（CRO）

**诊断清单**：
- [ ] 是否展示了社会证明？
- [ ] 是否有紧迫感元素？
- [ ] 是否降低了认知负担？
- [ ] 是否有明确的下一步？
- [ ] 是否消除了风险？（退款保证）

### 2. 文案优化

**心理触发词库**：

| 触发词 | 心理机制 | 示例 |
|--------|----------|------|
| "独家" | 稀缺性 | "独家方法论" |
| "限时" | 紧迫感 | "限时优惠" |
| "免费" | 互惠原则 | "免费试用" |
| "保证" | 风险消除 | "30天退款保证" |
| "仅剩" | 稀缺性 | "仅剩3个名额" |
| "已验证" | 社会证明 | "已被10,000+团队验证" |

### 3. 定价策略

**心理学定价技巧**：

| 技巧 | 示例 | 效果 |
|------|------|------|
| 尾数定价 | $99 vs $100 | 感知便宜10% |
| 锚定定价 | 划线原价 | 感知价值提升 |
| 分解定价 | $2.7/天 vs $80/月 | 降低心理门槛 |
| 捆绑定价 | $199套餐 vs 单买$300 | 感知超值 |

### 4. 用户留存

**留存心理机制**：

| 阶段 | 心理机制 | 策略 |
|------|----------|------|
| 首次使用 | 峰终定律 | 设计峰值体验 |
| 持续使用 | 沉没成本 | 展示累计价值 |
| 流失预警 | 损失厌恶 | 强调失去的内容 |
