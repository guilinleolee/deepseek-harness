# Marketing Ideas

> **核心价值**：好创意是增长的起点，但要快速验证，小步试错。

## Before Starting

1. 确认已完善 `product-marketing-product-marketing-context`
2. 明确目标（品牌/增长/转化）

---

## 创意生成框架

### 1. 创意维度

| 维度 | 问题 | 示例 |
|------|------|------|
| **产品化** | 如何让用户成为传播者？ | Dropbox推荐奖励 |
| **内容化** | 如何创造可传播内容？ | Slack的"工作地狱"测试 |
| **事件化** | 如何借势/造势？ | 各类节日营销 |
| **游戏化** | 如何增加趣味性？ | Duolingo连续打卡 |
| **社会化** | 如何利用社交网络？ | 小红书种草 |

### 2. 创意公式

```
好创意 = 惊喜 + 相关 + 可执行

惊喜：打破预期，引起注意
相关：与用户需求/品牌相关
可执行：能够快速落地测试
```

### 3. 灵感来源

| 来源 | 具体方法 |
|------|----------|
| **竞品分析** | 看竞品在做什么 |
| **跨界借鉴** | 其他行业的成功案例 |
| **用户反馈** | 用户说想要什么 |
| **数据洞察** | 发现意外增长点 |
| **团队头脑风暴** | 集思广益 |

## 创意评估框架

### ICE评分

| 维度 | 评分(1-10) | 说明 |
|------|------------|------|
| **Impact** | 影响力 | 能带来多大增长 |
| **Confidence** | 信心度 | 成功的可能性 |
| **Ease** | 难易度 | 实施的难度 |

**优先级 = (Impact × Confidence) / Ease**

### 快速验证

```
验证步骤：
1. 定义成功指标
2. 设计最小可行实验
3. 3-7天快速测试
4. 分析结果
5. 放大或放弃
```
