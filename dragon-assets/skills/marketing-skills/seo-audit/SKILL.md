# SEO Audit

> **核心价值**：发现SEO问题，制定优化策略，提升自然流量。

## Before Starting

1. 确认已完善 `product-marketing-context`
2. 获取网站访问权限和分析数据

---

## 审计框架

### 1. 技术SEO检查

| 检查项 | 工具 | 健康标准 |
|--------|------|----------|
| 索引状态 | Google Search Console | 无错误页面 |
| 页面速度 | PageSpeed Insights | >90分 |
| 移动适配 | Mobile-Friendly Test | 通过 |
| HTTPS | 浏览器 | 有效证书 |
| sitemap.xml | GSC | 已提交且有效 |
| robots.txt | 在线检查 | 无错误配置 |
| 结构化数据 | Rich Results Test | 无错误 |
| 重复内容 | Screaming Frog | 无重复 |

### 2. 内容SEO检查

```
页面层级检查：
├── 首页（权重最高）
│   ├── 分类页1
│   │   ├── 文章页1-1
│   │   └── 文章页1-2
│   └── 分类页2
│       └── 文章页2-1

点击深度：≤3次点击到达任意页面
```

**内容质量评估**：
- [ ] 标题包含目标关键词
- [ ] H1唯一且包含关键词
- [ ] 内容长度符合主题深度
- [ ] 内链结构合理
- [ ] 图片有alt标签
- [ ] 元描述有吸引力

### 3. 关键词分析

| 关键词类型 | 搜索量 | 竞争度 | 优先级 |
|------------|--------|--------|--------|
| 核心关键词 | 高 | 高 | 中 |
| 长尾关键词 | 中 | 低 | 高 |
| 问题关键词 | 中 | 低 | 高 |
| 品牌关键词 | 低 | 低 | 高 |

- [ ] 页面速度优化
- [ ] 移动端体验

- [ ] 内链结构优化

### 长期规划（P2）
- [ ] 内容矩阵建设
