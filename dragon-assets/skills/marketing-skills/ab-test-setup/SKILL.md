# A/B Test Setup

> **核心价值**：数据驱动的决策，让每一次改动都有据可依。

## Before Starting

1. 确认已完善 `product-marketing-context`
2. 明确测试假设和目标

---

## A/B测试框架

### 1. 测试假设

```
假设格式：
如果我们 [改动X]，那么 [指标Y] 会 [提升/降低Z%]，
因为 [理由]。
```

### 2. 样本量计算

| 指标 | 公式 | 说明 |
|------|------|------|
| **基准转化率** | 当前值 | 控制组 |
| **最小检测效应** | 期望提升 | 如10%相对提升 |
| **显著性水平** | 通常95% | α = 0.05 |
| **统计功效** | 通常80% | β = 0.2 |

**样本量估算**：
```
每个变体最小样本 = (16 × 变异系数²) / 效应大小²

简化公式：
每组样本量 ≈ 16 / (基准率 × (1-基准率) × 效应²)
```

### 3. 测试优先级

| 优先级 | 改动类型 | 预期提升 | 难度 |
|--------|----------|----------|------|
| P1 | 标题 | 20-50% | 低 |
| P2 | CTA | 10-30% | 低 |
| P3 | 图片 | 10-25% | 中 |
| P4 | 布局 | 5-15% | 高 |
| P5 | 颜色 | 2-10% | 低 |

---

## 测试规则

### 单变量原则

```
❌ 错误：同时改标题+图片+CTA
✅ 正确：只改标题，其他不变
```

### 测试周期

| 周期 | 最短 | 最长 | 原因 |
|------|------|------|------|
| **高流量** | 7天 | 14天 | 快速达标 |
| **中流量** | 14天 | 28天 | 需要积累 |
| **低流量** | 28天 | 60天 | 数据不足 |

### 结果判断

```
统计显著 ≠ 实际显著

判断标准：
1. 统计显著性 ≥ 95%
2. 样本量达标
3. 实际业务意义（提升≥2%）
```
