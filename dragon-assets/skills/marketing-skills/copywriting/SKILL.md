# Copywriting

> **核心价值**：好文案让转化率提升3-5倍。

## Before Starting

1. 确认已完善 `product-marketing-context`
2. 明确文案用途和目标受众

---

## Core Principles

### 1. 清晰胜过创意

```
❌ 不好的文案：
"体验前所未有的智能解决方案"

✅ 好的文案：
"把每周4小时的报告工作缩短到15分钟"
```

### 2. 利益胜过功能

| 功能描述 | 利益描述 |
|----------|----------|
| "自动生成报告" | "每周节省4小时" |
| "云端存储" | "随时随地访问，永不丢失" |
| "团队协作" | "团队效率提升50%" |

### 3. 具体胜过模糊

```
❌ 模糊： "节省大量时间"
✅ 具体： "每周节省4小时"

❌ 模糊： "大量用户使用"
✅ 具体： "10,000+团队信赖"
```

### 4. 用户语言胜过公司语言

**使用用户原话**：
- 从评价、访谈、客服中提取
- 镜像用户的表达方式
- 避免行业术语

## 文案框架

### 1. AIDA框架

```
A - Attention（吸引注意）
    前3秒抓住用户：问题、数据、好奇心

I - Interest（激发兴趣）
    点出用户痛点，建立共鸣

D - Desire（建立欲望）
    展示解决方案和具体利益

A - Action（引导行动）
    明确的下一步指令
```

### 2. PAS框架

```
P - Problem（问题）
    描述用户当前的痛点

A - Agitation（放大）
    放大痛点的影响和后果

S - Solution（解决方案）
    展示产品如何解决问题
```

### 3. FAB框架

```
F - Features（功能）
    产品有什么功能

A - Advantages（优势）
    这个功能比竞品好在哪里

B - Benefits（利益）
    用户能得到什么具体好处
```

## 高转化文案模板

### 标题公式

```markdown
1. 痛点型："[痛点]？这里有解决方案"
2. 结果型："[具体数字]方法帮你[达成目标]"
3. 好奇型："[行业内幕]，90%的人不知道"
4. 社会证明型："[数字]人都在用的方法"
5. 紧迫型："[时间限制]，错过再等一年"
6. 对比型："[竞品] vs [我们]，谁更值得选"
```

### CTA文案优化

| 普通 | 优化后 | 提升效果 |
|------|--------|----------|
| "注册" | "免费开始" | +20% |
| "提交" | "获取方案" | +15% |
| "购买" | "立即升级" | +10% |
| "了解更多" | "查看案例" | +25% |

## 文案检查清单

- [ ] 标题是否在前3秒抓住注意？
- [ ] 是否使用了用户语言？
- [ ] 是否具体而非模糊？
- [ ] 是否展示了明确利益？
- [ ] 是否有社会证明？
- [ ] CTA是否明确？
- [ ] 是否有紧迫感元素？
- [ ] 是否消除了风险顾虑？

## Output Format

```markdown
## 文案方案

### 版本A（主推）
**标题**：[标题文案]

**正文**：
[正文内容]

**CTA**：[按钮文案]

**预期效果**：CTR [X]%, CVR [Y]%

### 版本B（备选）
[同上]

### A/B测试建议
- 测试变量：[变量名]
- 测试原因：[原因]
```
