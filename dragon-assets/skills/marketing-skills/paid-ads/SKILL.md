# Paid Ads

> **核心价值**：用最小预算获取最大ROI，让每一分钱都有回报。

## Before Starting

1. 确认已完善 `product-marketing-context`
2. 明确广告目标（品牌曝光/线索获取/直接转化）

## Core Frameworks

### 1. 广告账户结构

```
广告账户
├── 广告系列（按目标/渠道）
│   ├── 广告组（按受众/关键词）
│   │   ├── 广告创意A
│   │   ├── 广告创意B
│   │   └── 广告创意C
│   └── 广告组2
└── 广告系列2
```

### 2. 关键词策略（搜索广告）

| 关键词类型 | 意向度 | 竞价策略 | 示例 |
|------------|--------|----------|------|
| 品牌词 | 最高 | 高竞价 | "品牌名" |
| 产品词 | 高 | 中竞价 | "产品类别+功能" |
| 竞品词 | 中高 | 中竞价 | "竞品替代" |
| 长尾词 | 中 | 低竞价 | "具体问题+解决方案" |

### 3. 受众定向（社媒广告）

```
核心受众： demographics + interests + behaviors
├── 人口统计：年龄、性别、地区、语言
├── 兴趣标签：相关兴趣、行为偏好
└── 行为定向：购买历史、设备使用

再营销受众：高转化潜力
├── 网站访问者（按页面分类）
├── 视频观看者（按完成度）
└── 互动用户（点赞、评论、分享）

相似受众：规模化扩展
├── 基于客户列表
├── 基于高价值用户
└── 基于转化用户
```

## 优化策略

### 每日检查
- [ ] 预算消耗是否正常
- [ ] CPC/CPM是否异常波动
- [ ] 高表现广告组追加预算
- [ ] 低表现广告组暂停或优化

### 每周优化
- [ ] 关键词搜索词报告 → 添加否定词
- [ ] 广告创意A/B测试结果分析
- [ ] 受众定向效果评估
- [ ] 着陆页转化率检查

### 关键指标阈值

| 指标 | 警告线 | 健康线 | 优秀线 |
|------|--------|--------|--------|
| CTR | <1% | 2-3% | >5% |
| CPC | >行业均值 | 行业均值 | <行业均值 |
| CVR | <1% | 2-3% | >5% |
| ROAS | <2x | 3-5x | >5x |
