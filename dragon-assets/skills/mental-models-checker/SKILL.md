# Mental Models Checker - 思维模型检查器

> 来源：openclaw-strategist (https://github.com/wade56754/openclaw-strategist)
> 集成时间：2026-03-15

## 功能

25种认知偏差自查 + 跨学科思维模型应用，防止决策盲区。

## 触发词

- `/check-bias`
- "思维模型"
- "认知偏差"
- "偏误检查"

## 25种认知偏差检查清单

### 决策类偏误（8种）

| 编号 | 偏误名称 | 检查问题 | 典型表现 |
|------|---------|---------|---------|
| B1 | 锚定效应 | 我的判断是否被第一印象锁定？ | 过度依赖最初信息 |
| B2 | 确认偏误 | 我是否只找支持我的证据？ | 过滤反对信息 |
| B3 | 沉没成本 | 我是否因为已投入而不愿放弃？ | "已经花了这么多..." |
| B4 | 可得性偏差 | 我是否因为容易想到就认为常见？ | 近期事件过度加权 |
| B5 | 代表性偏差 | 我是否用表面相似做判断？ | 刻板印象 |
| B6 | 框架效应 | 问题表述方式是否影响我的判断？ | 同一事物的不同描述 |
| B7 | 后见之明 | 我是否认为"早知道会这样"？ | 过度自信 |
| B8 | 结果偏见 | 我是否只看结果不看过程？ | 以成败论英雄 |

| B11 | 控制幻觉 | 我是否认为自己能控制不可控的事？ | 迷信行为 |
| B12 | 乐观偏见 | 我是否只看好的一面？ | 低估风险 |
| B13 | 悲观偏见 | 我是否只看坏的一面？ | 高估风险 |
| B14 | 自我中心 | 我是否以为别人都和我一样想？ | 投射效应 |

## 跨学科思维模型库

### 经济学模型（5个）

| 模型 | 说明 | 应用场景 |
|------|------|---------|
| **机会成本** | 选择A意味着放弃B的价值 | 资源分配决策 |
| **安全边际** | 为不确定性留出缓冲 | 风险决策 |
| **激励相容** | 让个体利益与整体利益一致 | 制度设计 |
| **复利效应** | 小变化的长期累积 | 长期规划 |
| **二阶效应** | 行动的后果的后果 | 战略决策 |

### 心理学模型（4个）

| 模型 | 说明 | 应用场景 |
|------|------|---------|
| **逆向思维** | 先想怎么失败，再避免 | 风险预防 |
| **峰终定律** | 体验由高峰和结尾决定 | 用户体验设计 |
| **损失厌恶** | 损失的痛苦>获得的快乐 | 定价策略 |
| **稀缺效应** | 稀缺的东西更有价值 | 营销策略 |

### 系统思维模型（4个）

| 模型 | 说明 | 应用场景 |
|------|------|---------|
| **反馈循环** | 正反馈放大，负反馈稳定 | 系统分析 |
| **临界点** | 量变到质变的节点 | 趋势判断 |
| **杠杆点** | 小改变能带来大影响 | 策略优化 |
| **延迟效应** | 原因和结果有时间差 | 预测规划 |

### 博弈论模型（3个）

| 模型 | 说明 | 应用场景 |
|------|------|---------|
| **纳什均衡** | 双方都不愿意单方面改变策略 | 竞争分析 |
| **囚徒困境** | 个人理性导致集体非理性 | 合作决策 |
| **零和vs正和** | 你输我赢 vs 双赢 | 竞争策略 |

## 使用示例

```bash
# 触发偏误检查
/check-bias "我觉得这个项目一定能成功，因为竞品都失败了"

# 输出：
# 🔴 B12 乐观偏见 - 低估了竞争难度
# 🔴 B23 幸存者偏差 - 只看了失败的竞品，没看成功的
# 🟡 B2 确认偏误 - 只找支持"一定能成功"的证据
#
# 建议：寻找成功的竞品案例，分析他们做对了什么
```

## 硬性规则

1. **每次决策必须检查** - 至少检查B1-B8决策类偏误
2. **高风险标注** - 发现偏误必须标注风险等级
3. **给出对策** - 不能只指出问题，必须给出对策
4. **记录到决策存档** - 偏误检查结果作为决策存档的一部分
