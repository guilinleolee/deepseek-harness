# Litigation Legal - 诉讼法律技能包

## L0: 一句话描述 (≤15字)
诉讼全流程管理，从立案到执行

## L1: 使用场景 (50-100字)
当需要进行诉讼案件分析、证据管理、程序性事务处理、法律文书撰写，或需要制定诉讼策略时，使用本技能包。支持民事诉讼、行政诉讼、仲裁程序三大领域。

## L2: 详细文档

### 核心能力

| 技能 | 功能 | 核心能力 |
|------|------|---------|
| **matter-intake** | 案件受理 | 案件信息收集+利益冲突检查+案件分类 |
| **matter-briefing** | 案件汇报 | 事实梳理+法律问题识别+策略建议 |
| **demand-intake** | 诉前需求接收 | 客户诉求收集+请求权基础初步分析 |
| **demand-draft** | 诉请起草 | 诉讼请求撰写+请求权要件分解 |
| **demand-received** | 诉请接收回应 | 相对方诉请分析+答辩策略制定 |
| **subpoena-triage** | 传票处理 | 传票分类+程序审查+应诉准备 |
| **legal-hold** | 证据保全 | 电子证据保全+禁令申请+证据清单管理 |
| **claim-chart** | 诉请图表 | 事实/法律依据/证据三栏对照表 |
| **chronology** | 事实年表 | 争议事实时间线梳理+证据对应 |
| **deposition-prep** | 庭前准备 | 证人询问提纲+质证要点整理 |
| **privilege-log-review** | 特权清单审查 | 律师-客户特权认定+特权清单审核 |
| **brief-section-drafter** | 文书分段撰写 | 法律论证分段起草+引用标注 |

### IRAC分析框架

所有诉讼分析遵循IRAC框架：

```
Issue（问题）→ Rule（规则）→ Application（适用）→ Conclusion（结论）
```

### 置信度分级

| 标记 | 含义 | 使用场景 |
|------|------|---------|
| `[CONFIRMED]` | 确认 | 已有判决/生效法律文书 |
| `[LIKELY]` | 可能 | 同类案例倾向 |
| `[UNCERTAIN]` | 不确定 | 需要进一步研究 |
| `[VERIFY]` | 需核实 | 事实需要验证 |

### 诉讼分析流程

```bash
# 启动案件分析
[@78-01] 分析某合同纠纷的诉讼策略

# 诉请起草
[@78-01] 起草某侵权案件的诉讼请求

# 证据年表
[@78-01] 梳理某劳动争议的事实年表

# 庭前准备
[@78-01] 准备某案的庭前质证要点
```

### 核心命令

```bash
# 案件受理
/matter-intake --client "客户名称" --type civil/arbitration

# 诉请起草
/demand-draft --case "案件编号" --claims "诉请内容"

# 证据保全
/legal-hold --type preservation/injunction --evidence "证据清单"

# 事实年表
/chronology --case "案件编号" --timeline "时间线描述"

# 特权审查
/privilege-log-review --documents "待审文件"

# 文书撰写
/brief-section-drafter --section argument --topic "论证主题"
```

### 约束条件

⚠️ **不提供最终判决建议** - 本技能包提供诉讼分析和文书起草支持，不涉及对案件最终结果的预测或法律建议的提供。

## L2扩展

### 民事诉讼要素

```
1. 诉请确定
   - 诉讼请求（给付/确认/形成）
   - 请求权基础（合同/侵权/物权等）
   - 事实与理由

2. 证据管理
   - 证据清单编制
   - 证据目录（编号/名称/形式/证明目的/页码）
   - 质证意见预准备

3. 程序审查
   - 管辖权审查
   - 当事人资格审查
   - 诉讼时效审查

4. 答辩策略
   - 答辩要点归纳
   - 反诉/抵销预判
   - 和解空间评估
```

### 仲裁程序要点

```
1. 仲裁协议审查
   - 仲裁条款效力
   - 仲裁范围
   - 仲裁机构选定

2. 仲裁程序
   - 仲裁申请受理
   - 答辩与反请求
   - 仲裁庭组成
   - 仲裁审理

3. 裁决执行
   - 裁决效力
   - 执行申请
   - 不予执行抗辩
```

### 庭前准备检查清单

```
□ 事实年表完成
□ 证据目录编制
□ 诉请/答辩状交换
□ 法律问题清单
□ 证人询问提纲
□ 专家证人（如需）
□ 证据原件核对
□ 诉讼时效复核
□ 管辖权确认
□ 代理词初稿
```
