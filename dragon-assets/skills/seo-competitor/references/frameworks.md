# Competitor Analysis Reference

## Competitor Identification Matrix

| Type | Definition | Example |
|------|------------|---------|
| **Direct** | Same product/service | HubSpot vs Salesforce |
| **Indirect** | Same problem, different solution | Notion vs Excel |
| **Substitute** | Different category, same need | Netflix vs Cinema |

## Gap Analysis Framework

### Keyword Gap Categories

| Category | Definition | Action |
|----------|------------|--------|
| **Win** | You rank, they don't | Protect & expand |
| **Lose** | They rank, you don't | High priority opportunity |
| **Tie** | Both rank | Improve your position |

### Content Gap Types

| Type | Description | Effort |
|------|-------------|--------|
| **Topic Gap** | Entire subject not covered | High |
| **Depth Gap** | More comprehensive content | Medium |
| **Format Gap** | Missing content type (video, tool) | Medium |
