# Metrics Benchmarks Reference

## Unit Economics Benchmarks

### LTV:CAC Ratio

| Tier | Ratio | Description | Action |
|------|-------|-------------|--------|
| **Excellent** | 7-8x | Maximum efficiency, strong unit economics | Maintain and optimize |
| **Healthy** | 3x | Good efficiency, sustainable growth | Monitor trends |
| **Average** | 2x | Marginal, need improvement | Focus on retention |
| **Dangerous** | <1x | Losing money on acquisition | Immediate fix needed |

**Formula:**
```
LTV:CAC = LTV / CAC
```

### CAC Payback Period

| Tier | Period | Description | Action |
|------|--------|-------------|--------|
| **Excellent** | <6 months | Fast payback, efficient spend | Scale confidently |
| **Healthy** | <12 months | Reasonable payback | Continue monitoring |
| **Average** | 12-18 months | Long payback, risky | Reduce CAC or increase ARPU |
| **Dangerous** | >18 months | Very long payback | Stop acquisition, fix product |

**Formula:**
```
CAC Payback = CAC / (ARPU × Gross Margin)
```

### LTV (Lifetime Value)

| Tier | LTV | Description | Action |
|------|-----|-------------|--------|
| **Excellent** | >$100K | High-value customers | Focus on retention |
| **Healthy** | $30K-$100K | Solid customer value | Expand use cases |
| **Average** | $10K-$30K | Moderate value | Increase pricing |
| **Dangerous** | <$10K | Low-value customers | Rethink ICP or pricing |

**Formula:**
```
LTV = ARPU × Gross Margin / Churn Rate
```

## Cash Management Benchmarks

### Burn Multiple

| Tier | Multiple | Description | Action |
|------|----------|-------------|--------|
| **Excellent** | <0.5x | Highly efficient growth | Optimal runway extension |
| **Healthy** | <1x | Efficient growth | Continue current path |
| **Average** | 1-2x | Inefficient, need improvement | Reduce burn or accelerate growth |
| **Dangerous** | >2x | Severely inefficient | Emergency intervention required |

**Formula:**
```
Burn Multiple = Net Burn / Net New ARR
```

### Runway

| Tier | Months | Description | Action |
|------|--------|-------------|--------|
| **Excellent** | >24 months | Strong runway | Strategic investments |
| **Healthy** | 18-24 months | Comfortable runway | Maintain discipline |
| **Average** | 12-18 months | Tight runway | Extend runway urgently |
| **Dangerous** | <12 months | Critical runway | Immediate action required |

**Formula:**
```
Runway = Cash / Monthly Burn
```

### Cash Conversion Score

| Tier | Score | Description | Action |
|------|-------|-------------|--------|
| **Excellent** | >100% | Turning operations into cash | Reinvest profits |
| **Healthy** | 75-100% | Good cash generation | Maintain operations |
| **Average** | 50-75% | Moderate conversion | Improve collections |
| **Dangerous** | <50% | Poor cash conversion | Review payment terms |

**Formula:**
```
Cash Conversion = Operating Cash Flow / Net Income
```

## Revenue Efficiency Benchmarks

### Magic Number

| Tier | Number | Description | Action |
|------|--------|-------------|--------|
| **Excellent** | >1.0 | Efficient sales efficiency | Scale sales team |
| **Healthy** | 0.5-1.0 | Good efficiency | Continue growth |
| **Average** | 0.25-0.5 | Moderate efficiency | Optimize sales process |
| **Dangerous** | <0.25 | Poor efficiency | Stop hiring, fix funnel |

**Formula:**
```
Magic Number = Net New ARR / S&M Spend
```

### Revenue per Employee

| Tier | Revenue | Description | Action |
|------|---------|-------------|--------|
| **Excellent** | >$1M | Highly efficient team | Maintain and grow |
| **Healthy** | $500K-$1M | Good productivity | Continue scaling |
| **Average** | $250K-$500K | Moderate productivity | Invest in automation |
| **Dangerous** | <$250K | Low productivity | Review headcount |

**Formula:**
```
Revenue per Employee = Revenue / FTE Count
```

### Gross Margin

| Tier | Margin | Description | Action |
|------|--------|-------------|--------|
| **Excellent** | >80% | High-margin business | Leverage for growth |
| **Healthy** | 70-80% | Good margins | Maintain efficiency |
| **Average** | 60-70% | Moderate margins | Reduce COGS |
| **Dangerous** | <60% | Low margins | Fundamental restructuring |

**Formula:**
```
Gross Margin = (Revenue - COGS) / Revenue × 100
```

## SaaS-Specific Benchmarks

### Rule of 40

| Tier | Score | Description | Action |
|------|-------|-------------|--------|
| **Excellent** | >80% | Balanced growth and profitability | Optimal state |
| **Healthy** | 40-80% | Good balance | Continue path |
| **Average** | 20-40% | Growth or profit only | Balance priorities |
| **Dangerous** | <20% | Neither growth nor profit | Strategic pivot |

**Formula:**
```
Rule of 40 = Growth Rate % + Profit Margin %
```

## Working Capital Benchmarks

### Days Sales Outstanding (DSO)

| Tier | Days | Description | Action |
|------|------|-------------|--------|
| **Excellent** | <30 | Fast collections | Optimal state |
| **Healthy** | 30-45 | Normal collections | Monitor trends |
| **Average** | 45-60 | Slow collections | Improve terms |
| **Dangerous** | >60 | Very slow collections | Urgent intervention |

**Formula:**
```
DSO = (Accounts Receivable / Revenue) × 365
```

### Days Payable Outstanding (DPO)

| Tier | Days | Description | Action |
|------|------|-------------|--------|
| **Excellent** | >60 | Good payment leverage | Maintain |
| **Healthy** | 45-60 | Normal terms | Continue |
| **Average** | 30-45 | Short payment terms | Negotiate longer |
| **Dangerous** | <30 | Very short terms | Urgent renegotiation |

**Formula:**
```
DPO = (Accounts Payable / COGS) × 365
```

### Cash Conversion Cycle (CCC)

| Tier | Days | Description | Action |
|------|------|-------------|--------|
| **Excellent** | Negative | Cash-first business | Leverage for growth |
| **Healthy** | 0-30 | Efficient operations | Maintain |
| **Average** | 30-60 | Normal operations | Monitor |
| **Dangerous** | >60 | Cash-strapped | Optimize cycle |

**Formula:**
```
CCC = DSO + DIO - DPO
DIO = (Inventory / COGS) × 365
```

## Industry-Specific Context

### Bootstrapped vs VC-Backed

| Metric | Bootstrapped Target | VC-Backed Target |
|--------|-------------------|------------------|
| LTV:CAC | 5x+ | 3x+ |
| CAC Payback | <12 months | <18 months acceptable |
| Burn Multiple | <1x | <2x acceptable |
| Runway | 24+ months | 18+ months acceptable |
| Growth | 30-50% YoY sustainable | 100%+ expected |

| Metric | B2B SaaS | B2C SaaS |
|--------|----------|----------|
| LTV:CAC | 3-5x | 2-3x |
| CAC Payback | 12-18 months | 6-12 months |
| Gross Margin | 70-80% | 60-70% |
| NRR | 100-120% | 80-100% |
