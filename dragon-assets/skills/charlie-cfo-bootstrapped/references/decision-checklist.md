# Decision Checklists Reference

## 精益创业CFO决策检查清单

基于Charlie Munger多元思维模型，为Bootstrapped创业公司提供逆向决策框架。

---

## 1. 新客户获取决策

### 核心问题
> "我们是否应该在获客上投入更多资金？"

### 逆向思维检查

| # | 检查项 | ✅ 通过 | ❌ 不通过 | 权重 |
|---|--------|--------|---------|------|
| 1 | **LTV:CAC ≥ 3x？** | 继续 | 暂停 | 30% |
| 2 | **CAC Payback < 12个月？** | 继续 | 暂停 | 25% |
| 3 | **边际CAC在降低？** | 继续 | 分析原因 | 20% |
| 4 | **非营销获客占比 > 30%？** | 继续 | 加大口碑 | 15% |
| 5 | **客户留存率 > 90%？** | 继续 | 先留存在获客 | 10% |

### 二阶思维检查

- [ ] 获取这个客户的直接成本是多少？
- [ ] 3年后，这个客户的价值是多少？
- [ ] 如果我们不获取这个客户，机会成本是什么？
- [ ] 获取这个客户会改变我们的单位经济学吗？
- [ ] 我们是否在追逐虚荣指标而不是核心价值？

### 能力圈检查

- [ ] 我们对目标客户有深入理解吗？
- [ ] 我们的产品/服务真正解决了客户问题吗？
- [ ] 客户会向其他人推荐我们吗（NPS > 50）？
- [ ] 我们能持续为这个客户提供价值吗？

### 决策树

```
                    LTV:CAC ≥ 3x？
                    /           \
                   否            是
                   /              \
               暂停              CAC Payback < 12个月？
               分析              /           \
               单位经济            否            是
                               /              \
                           暂停              边际CAC降低？
                           优化产品          /           \
                                         否            是
                                         /              \
                                     分析原因        非营销获客 > 30%？
                                                   /           \
                                                  否            是
                                                  /              \
                                              加大口碑        ✅ 可以获客
                                              减少付费广告
```

## 2. 融资时机决策

### 核心问题
> "我们应该在什么时候融资？应该融资多少？"

### 逆向思维检查

| # | 检查项 | ✅ 通过 | ❌ 不通过 | 权重 |
|---|--------|--------|---------|------|
| 1 | **Burn Multiple < 1.5x？** | 融资时机好 | 先优化效率 | 30% |
| 2 | **Runway < 12个月？** | 需要融资 | 暂时不需要 | 25% |
| 3 | **有明确里程碑需要资金？** | 是 | 先明确目标 | 20% |
| 4 | **条款有利于创始人？** | 是 | 重新谈判 | 15% |
| 5 | **融资后能到达盈利？** | 是 | 谨慎融资 | 10% |

### 融资时机矩阵

```
                    Runway
              < 6个月    6-12个月    12-18个月    > 18个月
             /    \        \           /           |
Burn Multiple                                   |
< 0.5x        🔴紧急    🟠需要      🟡考虑      🟢暂缓
0.5-1x        🔴紧急    🟠需要      🟡考虑      🟡考虑
1-1.5x        🟠需要    🟡考虑      🟢暂缓      🟢暂缓
> 1.5x        🟠需要    🟠需要      🟡考虑      🟡考虑

图例：
🔴紧急 - 立即融资
🟠需要 - 6个月内融资
🟡考虑 - 根据里程碑决定
🟢暂缓 - 暂不需要融资
```

### 二阶思维检查

- [ ] 如果现在不融资，6个月后的情景是什么？
- [ ] 如果现在融资，我们的股权稀释是多少？
- [ ] 估值过高还是过低对未来影响更大？
- [ ] 投资者的附加价值（人脉、资源）是否值得稀释？
- [ ] 如果融资失败，我们的Plan B是什么？

### 融资规模计算

```
最小融资额 = (12个月运营成本 × 安全倍数) + 里程碑资金

安全倍数：1.5x - 2x（Bootstrap建议使用2x）
里程碑资金：具体可交付成果所需的额外资金

示例：
- 每月运营成本：$50,000
- 安全倍数：2x
- 里程碑资金：$100,000（用于招聘1名工程师）
- 最小融资额 = ($50,000 × 12 × 2) + $100,000 = $1,300,000
```

### 估值逆向谈判

| 策略 | 反向思维 |
|------|---------|
| 高估值 | "如果估值高但条款差，不如低估值好条款" |
| 低估值 | "估值低但快速到账，保留控制权更重要" |
| 不融资 | "零稀释的代价是什么？机会成本" |

## 3. 招聘决策

### 核心问题
> "我们应该在什么时候招聘？招聘什么样的人？"

### 逆向思维检查

| # | 检查项 | ✅ 通过 | ❌ 不通过 | 权重 |
|---|--------|--------|---------|------|
| 1 | **新人ROI > 2x？** | 可以招聘 | 暂缓 | 30% |
| 2 | **Revenue/Employee保持或增长？** | 是 | 优化现有 | 25% |
| 3 | **有12个月现金支撑？** | 有 | 暂缓招聘 | 20% |
| 4 | **关键岗位空缺影响增长？** | 是 | 可以等 | 15% |
| 5 | **创始人无法外包的核心能力？** | 是 | 考虑外包 | 10% |

### ROI计算模板

```
新人ROI = (新人贡献收入 - 新人成本) / 新人成本

新人贡献收入计算：
- 销售额增长：$X/月
- 成本节约：$Y/月
- 间接贡献（能力解锁）：$Z/月

新人成本计算：
- 薪资：$A/月
- 福利：$B/月
- 招聘成本：$C/次
- 培训时间成本：$D

示例：
- 销售工程师：带来$30,000/月新增收入
- 成本：$10,000/月薪资 + $2,000/月福利
- 招聘成本摊销（12个月）：$3,000/月
- 培训成本：$5,000（一次性）
- 月度ROI = ($30,000 - $15,000) / $15,000 = 100%
- 年度ROI = 120%（含培训一次性成本）
```

### 招聘顺序矩阵

```
                    对收入影响
              高影响      低影响
            /     \         \
           /       \         \
核心能力   1.优先招聘  2.尽快招聘   核心团队
           创始人亲自带 快速上手

支持能力   3.考虑外包  4.自动化     非核心
           专业外包    工具替代

图例：
1. 优先招聘 - CEO/Founder亲自带教
2. 尽快招聘 - 快速培训上岗
3. 考虑外包 - 使用专业外包服务
4. 自动化 - 使用工具替代
```

### 二阶思维检查

- [ ] 这个岗位真的需要全职吗？兼职/外包是否可行？
- [ ] 招聘这个人的时间成本是否值得？
- [ ] 如果招聘失败，我们能承受吗？
- [ ] 这个人会改变公司文化吗？
- [ ] 我们是否在用招聘来逃避问题？

### 招聘时机检查

- [ ] 当前团队是否已经在超负荷运转？
- [ ] 业务增长是否可持续支撑新薪资？
- [ ] 是否已有候选人而不是"为了招聘而招聘"？
- [ ] 招聘流程是否足够严谨（至少3轮面试）？

## 4. 定价决策

### 核心问题
> "我们应该定什么价格？是否应该涨价？"

### 逆向思维检查

| # | 检查项 | ✅ 通过 | ❌ 不通过 | 权重 |
|---|--------|--------|---------|------|
| 1 | **LTV > 3x CAC？** | 定价合理 | 考虑涨价 | 30% |
| 2 | **客户愿意支付更多？** | 是 | 测试涨价 | 25% |
| 3 | **价格低于市场价值？** | 是 | 可以涨价 | 20% |
| 4 | **涨价不影响留存？** | 是 | 谨慎涨价 | 15% |
| 5 | **有差异化价值主张？** | 是 | 先建价值 | 10% |

### 定价心理账户

```
心理账户层级（从高到低）：

1. 投资账户
   - ROI明显
   - 价格敏感度低
   - 例："每月$500帮我省$5000"

2. 身份账户
   - 社会认同
   - 价格敏感度低
   - 例："用XXX的人都是顶级公司"

3. 运营账户
   - 运营必需品
   - 价格敏感度中
   - 例："客服软件是我们的运营成本"

4. 便利账户
   - 节省时间
   - 价格敏感度中
   - 例："每月$29帮我节省10小时"

5. 娱乐账户
   - 享受/爱好
   - 价格敏感度高
   - 例："这个工具不错，但有点贵"
```

## 5. 支出决策

### 核心问题
> "我们应该在哪里花钱？什么时候花钱？"

### 逆向思维检查

| # | 检查项 | ✅ 通过 | ❌ 不通过 | 权重 |
|---|--------|--------|---------|------|
| 1 | **这项支出能增加收入吗？** | 是 | 优先删减 | 30% |
| 2 | **不花这笔钱的风险是什么？** | 低 | 可以花 | 25% |
| 3 | **这是核心能力还是支持能力？** | 核心 | 可以省 | 20% |
| 4 | **有更便宜的替代方案吗？** | 有 | 比较后决定 | 15% |
| 5 | **创始人亲自使用/监督吗？** | 是 | 谨慎支出 | 10% |

### 支出优先级矩阵

```
                    对收入影响
              直接增加      间接增加
            /     \         \
           /       \         \
必要性     1.必要支出  2.战略投资   核心投入
           必须支出    长期价值     优先保证

非必要性   3.可延迟    4.可以削减   成本优化
           延迟支出    立即削减     最后考虑

图例：
1. 必要支出 - 立即支付
2. 战略投资 - 谨慎评估后支付
3. 可延迟 - 6个月后重新评估
4. 可以削减 - 立即削减
```

### 二阶思维检查

- [ ] 这笔支出是否在掩盖更深层的问题？
- [ ] 如果这项支出没有效果，我们能承受吗？
- [ ] 这笔钱有更好的用途吗？
- [ ] 我们是在"购买成功"还是真正解决问题？

## 6. 退出/并购决策

### 核心问题
> "我们应该接受收购offer吗？"

### 逆向思维检查

| # | 检查项 | ✅ 通过 | ❌ 不通过 | 权重 |
|---|--------|--------|---------|------|
| 1 | **是否达到个人/团队目标？** | 是 | 继续独立 | 30% |
| 2 | **条款对团队是否有利？** | 是 | 重新谈判 | 25% |
| 3 | **独立发展 vs 被收购的价值对比？** | 收购更优 | 继续独立 | 20% |
| 4 | **收购方能提供什么附加价值？** | 显著 | 一般 | 15% |
| 5 | **收购后创始人是否想继续？** | 是 | 需要考虑 | 10% |

### 独立 vs 收购决策矩阵

```
                    收购价值
              高估值      低估值
            /     \         \
           /       \         \
战略价值   1.认真考虑  2.谈判争取   谈判优先
           高使命契合  争取更好条款

低战略价值 3.拒绝      4.拒绝        明确拒绝
           使命不合    条件不好      坚持独立
```

### 二阶思维检查

- [ ] 如果我们拒绝，5年后的公司价值是多少？
- [ ] 收购后我们的团队会被保留吗？
- [ ] 这是否是对团队、客户、用户的最佳选择？
- [ ] 我们是否因为"累"而想退出？

## 7. 精益复盘决策

### 季度复盘检查

| 领域 | 检查项 | 目标 | 实际 | 差距 |
|------|--------|------|------|------|
| **收入** | ARR增长 | >30% YoY | ? | ? |
| **盈利能力** | 毛利率 | >70% | ? | ? |
| **单位经济** | LTV:CAC | >5x | ? | ? |
| **现金** | Runway | >18个月 | ? | ? |
| **客户** | NRR | >100% | ? | ? |
| **团队** | Revenue/Employee | >$500K | ? | ? |

### 逆向成功检查

```
成功标准（Bootstrap优先顺序）：

1. 盈利能力
   □ 毛利率 > 70%
   □ 营业利润率 > 20%
   □ 现金流为正

2. 可持续增长
   □ ARR增长 30-50% YoY
   □ 客户留存率 > 90%
   □ 净推荐值 (NPS) > 50

3. 独立自主
   □ 零外部债务
   □ 创始团队控制权完整
   □ 产品路线图自主决定

4. 团队幸福
   □ 员工留存率 > 90%
   □ 团队规模精简但高效
   □ 工作生活平衡
```

## 8. 决策框架速查

### Charlie Munger逆向思维清单

```
┌─────────────────────────────────────────────────────────────┐
│                    逆向思维决策检查                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 反过来想                                                │
│     "成功取决于避免失败"                                    │
│     → 我做了什么会导致失败？                                │
│                                                             │
│  2. 二阶思维                                               │
│     "第一阶想的是对现在的影响"                              │
│     → 第二阶想的是对未来影响的影                            │
│                                                             │
│  3. 心理账户                                               │
│     "同样的钱在不同账户价值不同"                            │
│     → 这笔钱的机会成本是什么？                              │
│                                                             │
│  4. 能力圈                                                │
│     "只在能力圈内行动"                                      │
│     → 我们真的懂这个领域吗？                               │
│                                                             │
│  5. 激励相容                                               │
│     "谁受益谁决策"                                         │
│     → 这个决策对谁有利？                                    │
│                                                             │
│  6. 长期主义                                               │
│     "用10年的视角做决策"                                    │
│     → 10年后这个决策还正确吗？                            │
│                                                             │
│  7. 清单革命                                               │
│     "用清单避免认知盲区"                                    │
│     → 我们的决策清单够全面吗？                            │
│                                                             │
│  8. 逆向工程                                               │
│     "从目标反推行动"                                        │
│     → 为了达到目标我们必须做什么？                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
