# voxcpm-streaming · V1.0

> VoxCPM2 实时流式 TTS · 直播/实时语音场景专用
> 首字节延迟 < 300ms · 句子级分块合成 · WebSocket/RTSP 双协议

## L0: 一句话描述 (≤15字)

**VoxCPM2 实时流式配音（直播级）**

## L1: 使用场景 (50-100字)

为直播/实时语音场景设计的 VoxCPM2 流式 TTS 封装：

1. **首字节延迟 < 300ms**（流式 chunked 输出）
2. **句子级分块合成**（边输入边输出，无需等全文）
3. **WebSocket + RTSP 双协议**（浏览器/移动端/直播推流）
4. **5 类实时场景**：直播弹幕/智能助手/有声书续写/客服语音/会议纪要
5. **6 维流控参数**：语速/音调/情绪/停顿/重叠/淡入淡出
6. **背压控制**：客户端来不及播放时自动降速
7. **连接生命周期管理**：握手 → 鉴权 → 流式合成 → 断连
8. **伦理护栏**：同意书/水印/黑名单（继承 voxcpm-tts-integration）

### V1.0 完整调用示例

```bash
# 1. 启动流式服务
python ~/.claude/skills/voxcpm-streaming/scripts/server.py \
  --host 0.0.0.0 --port 8765 --backend pytorch

# 2. 客户端流式合成
python ~/.claude/skills/voxcpm-streaming/scripts/client.py \
  --text "欢迎来到直播间" \
  --mode voice_design \
  --voice-desc "(年轻女性,活泼,快语速)" \
  --output live_stream.wav
```

### V1.0 流控参数（6 维）

| 维度 | 范围 | 默认 | 说明 |
|------|------|------|------|
| `speed` | 0.5-2.0 | 1.0 | 语速倍率 |
| `pitch` | -12~+12 | 0 | 半音 |
| `emotion` | 10 类别 | 平静 | 情绪 |
| `pause_ms` | 0-2000 | 200 | 句间停顿 |
| `overlap` | 0-0.5 | 0 | 句首重叠（用于连读）|
| `fade_ms` | 0-500 | 50 | 句首淡入 |
