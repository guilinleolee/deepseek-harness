# 媒体文件整理工作流

本技能指导将一个包含杂乱媒体文件的目录整理成标准化结构。强调与用户协作，确保最终的组织方式符合用户需求。

## 触发条件

- 用户说"整理媒体文件"、"整理图片/视频"
- 需要将杂乱的媒体目录标准化
- 生成媒体索引文档

## 工作流

### 步骤 1: 确定源目录

1. 请用户提供包含待整理媒体文件的目录路径
2. 确认路径有效且可访问

### 步骤 2: 提出整理计划

1. 使用 `ls -R` 列出源目录中的文件
2. **澄清文件内容**: 对文件名含义不明确的文件，主动询问用户
3. 提出子分类，默认分类：
   - `community-content`: 外部来源内容（YouTube评测、文章等）
   - `internal-demos`: 内部团队创建的演示和用例
   - `generated-examples`: 模型自动生成的内容
   - `assets`: 辅助材料（Logo、封面、倒计时视频等）
4. 提出命名规范：`{YYYYMMDD}_{分类}_{描述}_{编号}.{后缀}`
   - **重要**: `{YYYYMMDD}` 使用文件的**最后修改时间**
5. 生成完整的文件迁移计划
6. **暂停并请求用户确认**

### 步骤 3: 执行迁移

用户批准后：
1. 创建新的子分类目录
2. 执行文件迁移
3. 清理源目录（需与用户确认）

### 步骤 4: 生成文档

1. 为每个分类目录生成 `README.md`
2. 更新父目录的 `README.md`

### 步骤 5: 最终审查

1. 通知用户整理完成
2. 显示新的目录结构
3. 询问用户是否满意

此技能增强天龙引擎07记录师的文件整理能力:

### 使用示例

```bash

"帮我整理这个媒体文件夹"

# 指定分类
"把这些视频按类型整理好"
```

## 文件命名模板

```
{YYYYMMDD}_{分类}_{描述}_{编号}.{后缀}

示例:
20260304_internal-demos_product-demo_v1.mp4
20260304_assets_logo-final.png
```
