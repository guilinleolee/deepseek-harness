# 客户健康度仪表盘（account-health-dashboard）

天龙 CEC v1.0 核心 skill。FDE 工作流 **close** 阶段的客户价值守护工具，覆盖健康度四象限 + churn 预警 + 扩单机会识别。

## L0: 一句话描述 (≤15字)
FDE客户健康度四象限仪表盘

## L1: 使用场景 (50-100字)
用于 FDE 客户项目的 close 阶段 + 长期 CS 监控。基于使用度/满意度/续约概率/扩单信号四象限打分（0-10），自动识别 churn 风险与扩单机会。与 [[agents/41-customer-success-architect]] 和 `/aar` command 协同使用。

## L2: 详细文档

### 健康度四象限

```
              满意度（高）
                ↑
   扩单象限    │   战略象限
   （保稳定）  │   （重点投入）
                │
   使用度（低）─┼──→ 使用度（高）
                │
   风险象限     │   培育象限
   （立即救援） │   （推使用）
                ↓
              满意度（低）
```

| 象限 | 特征 | 行动 |
|---|---|---|
| **战略** | 高使用 + 高满意 | 重点投入，扩单机会最大 |
| **扩单** | 低使用 + 高满意 | 推广使用（培训/最佳实践） |
| **培育** | 高使用 + 低满意 | 解决痛点（技术问题/期望管理） |
| **风险** | 低使用 + 低满意 | 立即救援（高层介入/QBR） |

### Churn 风险分级

| 等级 | 触发条件 | 响应时限 |
|---|---|---|
| 🔴 高危 | 健康分 < 15/40 + ≥ 3 个预警信号 | 24h 内高层介入 |
| 🟡 中危 | 健康分 15-25/40 + ≥ 2 个预警信号 | 72h 内 QBR |
| 🟢 低危 | 健康分 25-35/40 + 0-1 个预警信号 | 30 天例行回访 |
| ⭐ 战略 | 健康分 > 35/40 + 扩单信号 ≥ 2 个 | 主动扩单提案 |

### 续约预测模型（简易版）

```
续约概率 = 
    30% × 满意度均分
  + 25% × 使用度均分
  + 25% × 续约均分
  + 10% × 决策链态度（硬编码：支持=10，中立=5，反对=0）
  + 10% × 合同金额满意度（基于"价值感知"调研）
```

| 续约概率 | 行动 |
|---|---|
| ≥ 80% | 自动续约（无需人工干预） |
| 60-80% | 标准续约流程（提前 3 月启动） |
| 40-60% | 高介入续约（高层+QBR+定制方案） |
| < 40% | 风险预警（强制救援方案） |

### 扩单机会识别（5 大信号）

| 信号 | 检测方法 | 触发动作 |
|---|---|---|
| **使用饱和** | 用户数/功能使用率 ≥ 80% | 推荐扩容包 |
| **新需求涌现** | 客户主动提新功能 ≥ 2 次/月 | 跨售方案 |
| **决策升级** | 高层（VP+）主动约会议 | 高层拜访 + 战略方案 |
| **行业标杆** | 客户主动愿意被引用 | Case study + 转介绍 |
| **跨部门询问** | 多部门询问（HR→财务→IT） | 平台化升级方案 |

### 数据来源

| 来源 | 提供数据 | 频率 |
|---|---|---|
| 产品日志 | 登录/功能使用 | 实时 |
| 客服工单 | 投诉/响应时间 | 实时 |
| 满意度调研 | NPS/CSAT | 季度 |
| QBR 会议 | 战略/痛点 | 季度 |
| 续约对话 | 真实支付意愿 | 续约前 3 月 |

### 失败模式（红线）

- ❌ **只看使用度不看满意度**：使用度高但满意度低，可能随时翻脸
- ❌ **忽视低使用度客户**：可能是付费低也可能是已经放弃
- ❌ **churn 信号不立即响应**：客户流失往往 24h 内决策
- ❌ **扩单信号不主动抓**：被动等客户来，错过黄金窗口
- ❌ **健康度造假**：粉饰分数 = 真实风险被掩盖

### 关键原则

1. **数据 + 感知双驱动**：不只信数据，也要 QBR 验证
2. **趋势比绝对值重要**：从 7→6 比稳定在 5 更危险
3. **早识别早介入**：churn 信号出现 24h 内响应
4. **扩单信号主动**：等客户主动 = 错过 80% 机会
5. **健康度是 CSM 的命脉**：每个 CSM 每周必看
