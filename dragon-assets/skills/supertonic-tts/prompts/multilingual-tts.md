## 多语言合成策略

### 1. 翻译优先策略

```markdown
流程:
1. 原文(中文) → 翻译(目标语言)
2. 翻译文本 → TTS合成
3. 合并多语言音频

工具:
- 翻译: DeepSeek/Google Translate
- 合成: Supertonic TTS
```

### 2. 角色分配策略

```markdown
多语言对话角色分配:

| 语言 | 角色A | 角色B |
|-----|-------|-------|
| 中文 | M1 | F1 |
| 英文 | M1 | F1 |
| 日语 | - | F2 |
| 韩语 | - | F2 |

保持角色语言一致性
```

### 3. 本地化适配

```markdown
本地化检查清单:

□ 发音正确性（专业翻译）
□ 文化适应性（本地化表达）
□ 语速调整（不同语言节奏不同）
□ 情感表达（符合当地习惯）
□ 专业术语（行业标准）
```

## 多语言TTS质量优化

### 采样率设置

```markdown
所有语言统一: 44.1kHz
高质量需求: 48kHz (需后处理转换)
```

### 语速调整参考

```markdown
语速系数(相对中文1.0):

| 语言 | 推荐语速 | 原因 |
|-----|---------|------|
| 中文 | 1.0 | 声调语言，适中语速 |
| 英文 | 0.95 | 句子较长 |
| 日文 | 1.05 | 音节较短 |
| 韩文 | 1.0 | 节奏相似中文 |
| 德文 | 0.9 | 多音节词较多 |
| 法文 | 0.95 | 连读较多 |
```

## 故障排除

### 常见问题

```markdown
1. 发音错误
   原因: 专业术语/生僻字
   解决: 手动标注音标或替换词

2. 语调不自然
   原因: 长句无停顿
   解决: 添加标点符号或<breath>

3. 多语言混合
   原因: 切换语言时发音突兀
   解决: 单独合成后拼接
```
