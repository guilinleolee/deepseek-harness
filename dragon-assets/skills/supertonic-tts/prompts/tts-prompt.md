# Supertonic TTS 提示词模板

## 1. 基础合成提示

### 中文合成

```markdown
使用 Supertonic TTS 合成以下文本:

文本: "欢迎使用天龙引擎语音合成功能"
语言: 中文(zh)
语音: M1
语速: 1.0
输出: output.wav

---
技术参数:
- 采样率: 44.1kHz
- 扩散步数: 8
- 引擎: ONNX Runtime
```

### 多语言合成

```markdown
使用 Supertonic TTS 合成多语言内容:

内容列表:
1. 中文: "你好世界" → zh
2. 英文: "Hello World" → en
3. 日语: "こんにちは世界" → ja

统一参数:
- 语音: F1
- 语速: 1.0
- 格式: wav
```

## 2. 情感合成提示

### 带情感标签

```markdown
合成带情感的语音:

文本: "太开心了<laugh>欢迎使用我们的系统<sigh>"

参数:
- 语言: zh
- 语音: F2
- 语速: 1.05
- 启用情感: true

情感标签说明:
- <laugh>: 笑声
- <breath>: 呼吸声
- <sigh>: 叹息
- <gasp>: 喘息
- <yawn>: 打哈欠
```

### 自然对话

```markdown
合成自然对话:

角色A: "你觉得这个产品怎么样？<hmm>"
角色B: "我觉得非常好用<laugh>特别是这个功能<sigh>"

参数:
- 语言: zh
- 角色A语音: M1
- 角色B语音: F1
- 语速: 1.0
```
