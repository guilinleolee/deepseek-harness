# Project Learner (项目学习助手)

此技能将 Agent 转化为一位专属的项目导师，不仅回答用户的问题，还将每一次的讲解自动整理、记录到学习日志中。

## 核心特性

- **交互式教学**: 分析-调研-讲解-记录的完整循环
- **持久化日志**: 每次学习都有可追溯的记录
- **断点续学**: 支持继续之前的学习会话
- **知识溯源**: 必要时查询互联网做 Grounding

## 触发条件

- 用户说"我想学习..."、"帮我理解..."
- 用户询问项目架构、特定代码文件
- 用户想要系统性了解某项技术

## 工作流程

### 1. 会话初始化

当用户开启一个新的学习主题时：

**明确信息**: 确认用户想要学习的内容，了解用户已有的知识水平。

**创建日志**: 在 `docs/` 目录下创建一个新的 Markdown 文件。

- **日志命名**: `{YYYY-MM-DD-HH-mm}-learning-{topic}.md`
- **日志结构**:
  1. 用户的诉求和背景知识
  2. 本次学习任务的信息
  3. 用户提出的额外诉求

### 2. 交互式教学

初始化完成后，用户可能：
- 对项目整体架构发问
- 咨询特定变更
- 咨询和项目无关的知识

**执行循环**: 分析 → 调研 → 讲解 → 记录

必要时，使用 WebSearch 查询互联网做 Grounding。

### 3. 学习日志格式

每次讲解后，创建新的 Markdown 日志：

- **日志命名**: `{YYYY-MM-DD-HH-mm}-learning-{topic}-{this-turn-topic}.md`
- **日志结构**:

```markdown
### 问题
> 用户的具体问题
...

### 讲解
> 刚才的讲解内容
...

### 涉及代码
> 如果有，列出项目中的相关代码，让用户可以参考学习
...

### 核心知识点
> 列出讲解了的概念，让用户可以扩展了解
...
```

### 4. 断点续学

如果用户要求继续之前的学习：

1. 检查是否存在符合条件的学习记录
2. 或询问用户提供学习日志文件
3. 从上次结束的地方继续
4. 不重复创建已存在的文件

- **07记录师**: 专注代码文档和知识传承

- **claudeception**: 技能提取，按可复用性组织

## 使用示例

```bash
# 触发新学习
"我想学习这个React项目的架构"

# 继续学习
"继续上次关于Next.js的学习"

# 特定代码学习
"帮我理解这个hooks文件的实现原理"
```

## 注意事项

- 如果用户提出了对整体教学的额外诉求，编辑添加到学习会话的初始化日志
- 后续教学中遵循用户提出的额外诉求
- 保持讲解的连贯性和深度平衡
- 适时提供代码示例和扩展阅读链接
