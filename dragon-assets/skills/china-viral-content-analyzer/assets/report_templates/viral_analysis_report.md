## 🧮 爆款公式总结

### 通用爆款公式

```
爆款度 = (痛点精准度 × 3) + (情绪强度 × 2) + (信息密度 × 1.5) + (视觉吸引力 × 1)

其中：
- 痛点精准度：是否直击用户最关心的问题
- 情绪强度：是否引发强烈情绪反应
- 信息密度：是否提供有价值的新信息
- 视觉吸引力：是否在视觉上抓住注意力
```

### 各平台爆款公式

#### 小红书

```
爆款度 = 视觉冲击(40%) + 实用价值(35%) + 情绪共鸣(25%)

关键要素：
✨ 封面要精致（首图定生死）
📝 内容要干货（收藏是王道）
💬 互动要真诚（评论建立信任）
```

#### 抖音

```
爆款度 = 前3秒钩子(50%) + 情绪张力(30%) + 节奏感(20%)

关键要素：
⚡ 前3秒必须抓住（黄金3秒）
😂 情绪要到位（笑点/泪点/爽点）
🎵 节奏要紧凑（完播率是关键）
```

#### B站

```
爆款度 = 内容深度(40%) + 趣味性(30%) + 实用性(30%)

关键要素：
📚 硬核干货（投币体现认可）
🤝 弹幕互动（弹幕文化）
⏱️ 时长适中（5-15分钟最佳）
```

#### 知乎

```
爆款度 = 观点独特性(40%) + 逻辑严密性(35%) + 信息增量(25%)

关键要素：
💡 观点要独特（同质化必死）
🧠 逻辑要严密（被挑刺会掉赞）
📊 信息要增量（老生常谈没人看）
```

## ✍️ 创作建议

### 标题创作清单

创作标题时，确保满足以下条件：

- [ ] **是否包含具体数字？**
  - 3个、5步、10倍、100%...
  - 数字越具体越可信

- [ ] **是否直击痛点？**
  - 30岁、月薪3000、迷茫、焦虑...
  - 痛点越精准越共鸣

- [ ] **是否制造好奇？**
  - 为什么、怎么办、竟然、原来...
  - 好奇心驱动点击

- [ ] **是否提供价值？**
  - 教程、攻略、秘籍、方法...
  - 价值承诺提升吸引力

- [ ] **字数是否合适？**
  - 最佳区间：15-25字
  - 太短说不清，太长没人看

### 封面设计清单

- [ ] **是否有视觉冲击？**
  - 高对比度色彩
  - 突出的主体
  - 清晰的层次

- [ ] **关键信息是否一目了然？**
  - 大字报式标题
  - 关键数据展示
  - 3秒内get重点

- [ ] **风格是否符合平台调性？**
  - 小红书：精致美学
  - 抖音：真实接地气
  - B站：个性化特色
  - 知乎：理性专业

- [ ] **是否包含情绪元素？**
  - 真人表情（真诚、惊讶、喜悦）
  - 对比元素（前后、好坏）
  - 文字引导（必看、震惊）

### 内容结构清单

- [ ] **前3秒是否抓住注意力？**
  - 痛点共鸣型开头
  - 数据震撼型开头
  - 故事悬念型开头
  - 反常识型开头

- [ ] **是否提供实际价值？**
  - 干货占比70%+
  - 方法可操作
  - 信息有增量
  - 案例具体

- [ ] **是否有情绪起伏？**
  - 开头：焦虑/好奇
  - 中间：共鸣/治愈
  - 结尾：激励/行动

- [ ] **结尾是否引导互动？**
  - 引导关注
  - 引导收藏
  - 引导评论
  - 系列预告
