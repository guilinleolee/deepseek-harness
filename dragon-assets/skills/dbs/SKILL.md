## 核心方法论

### 1. 商业诊断框架（dbs-diagnosis）

**核心理念**: 消解问题，不回答问题

**诊断流程**:
1. 问题陈述 → 识别问题类型
2. 问题拆解 → 找到真正的问题
3. 问题消解 → 问题可能不存在
4. 行动建议 → 针对性解决方案

**输出格式**:
```markdown
## 商业诊断报告

### 原始问题
[用户描述的问题]

### 问题类型
- [ ] 战略问题
- [ ] 战术问题
- [ ] 执行问题
- [ ] 心理问题

### 问题拆解
1. 表面问题: [X]
2. 深层问题: [Y]
3. 根本问题: [Z]

### 问题消解
- 为什么这是个问题？[...]
- 这个问题真的存在吗？[...]
- 问题背后的假设是什么？[...]

### 行动建议
1. [行动1]
2. [行动2]
3. [行动3]
```

### 2. 五重过滤对标分析（dbs-benchmark）

**方法论**: 五重过滤，排除噪音

**过滤层级**:
1. **第一重**: 去除无效对标（规模差异>10倍）
2. **第二重**: 去除伪对标（行业本质不同）
3. **第三重**: 去除不可学对标（资源护城河）
4. **第四重**: 去除不可持续对标（短期红利）
5. **第五重**: 提取可复用模式

**输出格式**:
```markdown
## 对标分析报告

### 对标对象
[目标公司/产品]

### 五重过滤

#### 第一重：规模过滤
- 对标规模: [X]
- 你的规模: [Y]
- 结论: [有效/无效]

#### 第二重：行业过滤
- 对标行业: [X]
- 你的行业: [Y]
- 本质差异: [...]

#### 第三重：资源过滤
- 对标资源: [X]
- 你的资源: [Y]
- 护城河分析: [...]

#### 第四重：可持续性过滤
- 对标模式: [X]
- 可持续性: [高/中/低]

#### 第五重：可复用模式提取
1. [模式1]
2. [模式2]
3. [模式3]

### 行动建议
[...]
```

### 3. 内容五维检测（dbs-content）

**方法论**: 五维检测，全面评估内容质量

**检测维度**:
1. **价值维度**: 内容是否有价值？
2. **结构维度**: 逻辑是否清晰？
3. **表达维度**: 语言是否易懂？
4. **情感维度**: 是否引发共鸣？
5. **传播维度**: 是否易于传播？

### 五维检测

- 评分: [X]
- 问题: [...]
- 建议: [...]

#### 4. 情感维度 (X/10)
- 评分: [X]

### 4. 短视频开头优化（dbs-hook）

**方法论**: 诊断 + 生成10+方案

**开头类型**:
1. **问题开头**: 提出痛点问题
2. **数据开头**: 用惊人数据吸引
3. **故事开头**: 用场景带入
4. **对比开头**: 制造反差
5. **悬念开头**: 制造好奇

**输出格式**:
```markdown
## 短视频开头诊断

### 原开头分析
- 类型: [X]
- 问题: [Y]
- 评分: [X/10]

### 优化方案（10个）

#### 方案1: 问题开头
"你是不是也遇到过..."

#### 方案2: 数据开头
"95%的人都不知道..."

#### 方案3: 故事开头
"上周有个朋友问我..."

#### 方案4: 对比开头
"同样做X，为什么他成功了..."

#### 方案5: 悬念开头
"这可能是你今年看到的最..."

[...共10个方案]

### 推荐方案
[最佳方案] + [理由]
```

### 5. 执行力诊断（dbs-action）

**方法论**: 阿德勒心理框架

**诊断维度**:
1. **目的论**: 行为背后的目的是什么？
2. **课题分离**: 这是你的课题还是别人的课题？
3. **自卑与超越**: 是否有自卑情结阻碍行动？
4. **社会兴趣**: 行为是否符合社会利益？

**输出格式**:
```markdown
## 执行力诊断报告

### 阻塞分析

#### 1. 目的分析
- 你想做什么？[...]
- 为什么要做？[...]
- 真实目的是？[...]

#### 2. 课题分离
- 你的课题: [...]
- 他人的课题: [...]
- 混淆点: [...]

#### 3. 自卑情结检测
- 是否有自卑？[是/否]
- 表现形式: [...]
- 如何超越: [...]

#### 4. 社会兴趣评估
- 行为受益者: [...]
- 是否符合社会利益: [...]

### 阻塞类型
- [ ] 能力阻塞
- [ ] 意愿阻塞
- [ ] 资源阻塞
- [ ] 心理阻塞

### 解除方案
1. [方案1]
2. [方案2]
3. [方案3]
```

### 6. 概念拆解（dbs-deconstruct）

**方法论**: 维特根斯坦式语言审查

**拆解步骤**:
1. **语词分析**: 这个词是什么意思？
2. **语境分析**: 在什么语境下使用？
3. **边界分析**: 什么情况下不再适用？
4. **家族相似**: 与哪些概念相似？
5. **语言游戏**: 如何在实际中使用？

**输出格式**:
```markdown
## 概念拆解报告

### 概念: [X]

#### 1. 语词分析
- 字面意思: [...]
- 常见用法: [...]
- 专业定义: [...]

#### 2. 语境分析
- 使用场景: [...]
- 适用领域: [...]
- 不适用场景: [...]

#### 3. 边界分析
- 边界条件: [...]
- 例外情况: [...]

#### 4. 家族相似
- 相似概念: [...]
- 关键差异: [...]

#### 5. 语言游戏
- 实际用法示例: [...]

### 拆解结论
[核心洞察]
```
