# 四平台内容匹配度

把“平台匹配度”与“合规结论”分开。匹配度是运营建议，不是平台官方准入规则，也不能覆盖 R3/R4 风险。

## 匹配度等级

- `高`：原内容形态和表达只需小改即可适配；
- `中`：主题适合，但需要重构标题、节奏、信息密度或互动方式；
- `低`：可以发布，但原形态与平台消费习惯差异较大，改造成本高；
- `信息不足`：缺少画面、时长、账号定位或受众信息。

## 抖音

优先考虑：

- 有明显视觉动作、人物表达、现场感或前后变化的视频；
- 能在开头快速交代对象、冲突、问题或结果的内容；
- 可用口播 + 画面证据解释清楚的知识、事件和体验；
- 有连续系列潜力、评论互动点或站内行动的内容。

常见改造：

- 把 X 长 Thread 重构为一条主线，不逐句朗读；
- 前 3 秒交代对象和语境，避免先铺垫很久；
- 重要来源、时间、地点和声明同时放进可见画面；
- 删除其他平台 CTA、水印和无授权音乐，改用站内互动。

## 小红书

优先考虑：

- 可搜索、可收藏的经验、清单、教程、测评和避坑内容；
- 有真实过程、条件、限制和细节的图文或中短视频；
- 能说明“适合谁 / 不适合谁 / 我怎么验证”的内容；
- 视觉封面与正文信息一致，能用结构化小标题承载的内容。

常见改造：

- 把 X 观点帖补成“背景 + 证据 + 个人判断 + 适用边界”；
- 用多图卡片或清晰段落承载步骤，不堆无关热词；
- 商业测评说明样品来源、合作关系、使用周期和个体差异；
- 清理站外账号、二维码、水印和暗号导流。

## 微信视频号

优先考虑：

- 观点讲解、知识分享、人物故事、访谈切片和有完整上下文的视频；
- 适合熟人/社交关系转发、能用一句话说明分享价值的内容；
- 可与公众号、小程序、直播、商品等微信站内能力自然衔接的内容；
- 需要更多背景说明、受众年龄跨度较大也能理解的表达。

常见改造：

- 补足事件时间、地点和人物身份，减少只有海外用户才懂的梗；
- 用更完整的起承转合代替过度依赖平台热梗；
- 优先使用视频号/微信可用音乐或已授权音轨；
- CTA 使用微信生态内当前允许的能力，不做隐藏式外部联系引导。

## 快手

优先考虑：

- 生活纪录、实用技能、三农、本地生活、人物和真实场景内容；
- 口播直接、画面承载真实过程、可持续系列化发布的视频；
- 直播、本地服务或商品内容，前提是价格、库存、赠品、资质和商品卡一致。

常见改造：

- 把海外语境和棗补成中文受众能理解的对象、时间、地点和背景；
- 清除其他平台水印、未授权音乐和外部跳转指令；
- 带货/直播内容读取直播商业专项，不用虚假稀缺和互动绑定福利。

## 推荐平台的方法

当用户未指定平台时，按以下维度分别打 `高/中/低/信息不足`：

1. 内容形态：文字、图文、口播、现场、教程、访谈；
2. 信息密度：是否需要长上下文、步骤、来源列表；
3. 视觉证据：画面是否承担核心说服力；
4. 搜索与收藏价值：是否长期可查、可复用；
5. 社交转发价值：是否容易被一句话转给熟人；
6. 改造成本：需要重拍、重配音、重新授权还是只改文案。

先排除 R3/R4，再推荐“首发平台 + 次发平台 + 不建议原样搬运的平台”。不要用未经验证的流量预测承诺效果。
