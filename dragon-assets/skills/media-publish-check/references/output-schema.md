# 标准输出格式

保持简洁但必须可执行。没有对应信息时写“暂无”或“信息不足”，不要省略高风险栏目。

## 默认快速结果（用户只问“能不能发”时）

不使用长表格，严格控制在 6 行内：

```markdown
结论：审核没问题，可以直接发。
```

或：

```markdown
结论：不建议直接发。
问题 1：位置｜问题 → 怎么改
问题 2：位置｜问题 → 怎么改
问题 3：位置｜问题 → 怎么改
替换：`可直接发布的改写稿`
待确认：暂无 / [仅写会改变结论的事项]
```

只有用户要求完整审核、需要多平台对比，或命中 R3/R4 时，才使用以下完整模板。

## 抖音/星图导流专项快速结果（适用时）

只在用户指定星图商单预审，或明确要查外流、私域、第三方下载时使用。不取代完整抖音合规审核。

```markdown
结论：不建议直接发。
专项问题 1：[DYX-01～DYX-07]｜位置｜出现了什么 → 怎么改
专项问题 2：...
可保留：[只写已检查、且未触发专项的 1～2 项]
未检查：[画面/字幕/音轨/商品卡等]
官方复查：[只在规则时效影响结论或已收到预审驳回时提供]
```

专项代码只用于让用户复查与修改，不等于平台官方违规条款号。

## 写作要求

- 先给结论，不要先复述规则；
- 一项风险对应一个可执行动作；
- 视频使用时间码，图文使用图片序号和画面区域，文章使用段落或短原文定位；
- 明确写出“出现了什么”，不要只写抽象类别；
- 区分“不能发布”“修改后复审”和“建议优化”，不要夸大或弱化风险；
- 直播或带货内容逐项写明价格、库存、赠品、互动条件和商品卡是否已核验；普通内容写“本专项不适用”；
- 引用原文时只截取定位所需的短片段；
- 把法律/监管、平台官方、权利待证和经验提示分开；
- 修改稿不能通过暗语、谐音、拆字或遮挡继续保留违规意图；
- 对无法安全改写的内容说明原因，不强行生成发布稿。
- 跟随用户语言解释；中国平台发布稿用自然中文。用户不使用中文时，同时给出简短的同语种风险摘要。
- 普通初审只推荐最相关的官方入口；没有复查必要时写“暂无”，不要堆链接。
