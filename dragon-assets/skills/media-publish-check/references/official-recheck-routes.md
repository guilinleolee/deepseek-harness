# 官方复查入口

核验日期：2026-07-13。平台页面、菜单名称和登录路径会更新；网页打不开时优先使用对应 App 内的创作者中心、规则中心、发布页提示和账号通知。

## 使用原则

- 只推荐与当前风险有关的 1–3 个入口，不输出一整页无关链接；
- 区分“规则查询”“账号/作品检测”“事实/资质核验”“申诉”；
- 网页入口用于查规则和管理内容，真正的作品检测、发布声明勾选和申诉可能必须登录或在 App 内完成；
- 用户说“打开官方复查”或“继续深查”时，有浏览器能力就打开对应官方页面；
- 不把第三方违禁词检测、收录查询、流量诊断或课程网站称为官方审核。

## 抖音

### 官方网页

- [抖音创作者中心](https://creator.douyin.com/)：登录后管理作品、数据和创作者功能；
- [抖音规则中心](https://www.douyin.com/rule/main)：查询当前平台规则；
- [抖音安全与信任中心](https://95152.douyin.com/)：查看安全治理、公告和帮助；
- [抖音用户服务协议](https://www.douyin.com/agreements/?id=6773906068725565448)：核对内容发布、AI 标识、来源、版权和平台秩序基线。

### App 复查

在抖音 App 的创作者中心搜索或使用“账号检测 / 作品检测 / 违规记录 / 申诉”等当前可见入口。菜单名称可能随版本变化，以登录后的界面为准。

### 何时推荐

- 账号或作品已有处罚提示：优先 App 内违规记录和申诉；
- 规则是否更新影响结论：规则中心 + 当前发布页；
- AI 内容：发布页 AI 声明功能 + 安全与信任中心公告；
- 版权投诉：使用平台提示的侵权投诉或不侵权声明路径。

## 按内容类型做官方事实核验

- 时事、政策、社会事件：[中国互联网联合辟谣平台](https://www.piyao.org.cn/) + 事件主管部门或原始发布机构；
- 企业主体、经营状态和公司名称：[国家企业信用信息公示系统](https://www.gsxt.gov.cn/)；
- 药品、医疗器械和化妆品资质：[国家药品监督管理局政务服务窗口](https://www.nmpa.gov.cn/zwfwqjd/index.html)；
- 商标注册信息：[国家知识产权局商标查询](https://sbj.cnipa.gov.cn/sbj/sbcx/)；
- 广告绝对化用语和广告执法：[市场监管总局广告监管](https://www.samr.gov.cn/ggjgs/)；
- 法律条文：[国家法律法规数据库](https://flk.npc.gov.cn/)。

这些网站只能核验对应事实或资质，不能代替目标平台对完整作品的审核。

## 输出“官方复查卡”

每张卡只写：

```markdown
### 官方复查卡
- 为什么要复查：[当前具体风险]
- 先打开：[官方入口]
- 在哪里查：[网页栏目或 App 内关键词]
- 准备材料：[来源/授权/资质/截图/处罚通知]
- 复查后告诉我：[需要用户带回的结果]
```

不要让用户自己猜下一步。若需要登录，明确说明“请你本人登录完成，我可以根据页面结果继续判断”。
