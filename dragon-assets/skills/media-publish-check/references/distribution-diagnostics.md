# 低播放与分发诊断

用于回答“是不是限流”“为什么没播放”。不把低播放直接说成平台处罚，不猜测未公开算法。

## 先判断是哪一类

1. **明确处置**：账号/作品通知明示删除、禁言、不宜公开、不予推荐、功能限制或违规原因。保留截图和作品 ID，走官方检测/申诉。
2. **发布资格或权利限制**：行业资质、商业合作、音乐、原创保护或地域权利问题。先补材料，不先改标题。
3. **无处置证据的低表现**：只能做内容与发布匹配诊断，不使用“被限流”作确定结论。

## 可复核的经验信号

以下默认是 `E4/E5 经验提示`，只写“可能影响分发或用户留存”：

- 重复搬运、大段重用、明显的其他平台水印或账号层叠；
- 低清、黑边、拉伸、画音不同步、开头长时间空白/静止；
- 标题封面与内容不一致，无关标签堆叠，关键信息过晚；
- 反复广告、诱导互动、无法兑现的悬念或用户价值过低；
- 音乐/影视片段的权利范围不支持目标平台；
- 内容形态与目标平台和账号受众不匹配。

## 输出顺序

```text
官方状态：有明确处置 / 无明确处置 / 待查
确定问题：[...]
可能影响分发（经验）：[...]
先做：[不超过 3 项]
```

如用户已收到处置，再读取 [official-recheck-routes.md](official-recheck-routes.md)。
