# 其他平台名称｜严格专属模式

这是 `media-publish-check` 的默认产品策略：一份稿件只服务于当前目标平台，尽量不提其他平台、电商产品或通讯工具。这是严格发布策略，不声称所有平台名称都是法律违禁词。

## 默认判定

- 只保留目标平台自己的名称。
- 其他平台全称一旦出现，包括“我在淘宝买的”这类事实描述，默认为 `R2 平台发布风险`，结论使用“不建议直接发”。
- `打开/搜索/关注/添加/扫码/进群/购买/领取/去主页` + 外部平台、账号或联系方式，按 `R3 导流/站外交易`复核。
- 同一外部平台反复出现，或出现在标题、封面、开头、结尾、标签、简介、置顶评论和 CTA，优先级更高。

## 修改顺序

1. **能删则删**：删掉不影响核心信息的平台名。
2. **中性类别词**：确实需要交代渠道时，使用 `短视频平台 / 图文社区 / 电商平台 / 通讯工具`。这是首选改法。
3. **证据必须保真**：来源、授权、投诉、侵权证据或平台教程中不能用模糊词篡改对象。可保留真名，但结论仍为 R2，并提醒用户在发布页再复核。

## 常见对应

| 目标平台 | 默认需删改的其他平台示例 |
|---|---|
| 抖音 | 小红书、视频号、快手、淘宝、微信、X、YouTube 等 |
| 小红书 | 抖音、视频号、快手、淘宝、微信、X、YouTube 等 |
| 视频号 | 抖音、小红书、快手、淘宝、X、YouTube 等 |
| 快手 | 抖音、小红书、视频号、淘宝、微信、X、YouTube 等 |

## 谐音、颜色和别名

用户资料中常见：`某音 / 抖抖 / 橙色软件 / 小绿书 / 绿泡泡 / 小破站`。可以识别用户已有文案中的这些表达，但必须如实提醒：

- 这些别名不等于平台官方允许，不能算作“已过审”；
- 尽量不出现，首选删除或改为透明类别词；
- 不与搜索、购买、添加、扫码、账号或联系方式绑定；
- 不使用“放中段、只说一次就一定安全”这类无官方依据的保证。
