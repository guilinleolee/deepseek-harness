# 媒体证据检查流程

目标是“实际看到了什么，就对什么下结论”。不因用户只给了文案，就声称已经完成整条视频终审。

## 证据清单

| 素材 | 必查 | 结果定位 |
|---|---|---|
| 文章/文案 | 标题、正文、引用、来源、链接、标签、CTA | 标题/第 N 段/短原文 |
| 单图 | 文字、Logo、水印、二维码、人脸、产品、个人信息、AI 痕迹 | 左上/中部/右下等区域 |
| 图文 | 逐张执行单图检查，再检查顺序和前后一致 | 第 N 张 + 区域 |
| 音频 | 转写、说话人、拟声/AI 配音、音乐/采样权利、环境信息 | 时间码 + 口播/音乐 |
| 视频 | 封面、首尾、关键帧、OCR、口播、字幕、配乐、贴纸、商品、权利 | 时间码 + 口播/字幕/画面/音乐 |
| 链接 | 页面原文、日期、作者、后续更正、媒体附件、可访问性 | URL + 段落/时间码 |

## 视频执行顺序

1. 记录时长、尺寸和文件可读性，提取完整音频转写并保留时间码。
2. 检查封面、首帧、前 3 秒、片尾，再按转场/场景变化取关键帧；无法识别转场时使用固定间隔。
3. 对关键帧做 OCR，检查字幕、花字、水印、Logo、二维码、联系方式、商品信息和隐私。
4. 对命中医疗、金融、时事、伤害、未成年人、广告、导流或 AI 的片段加密抽帧，不用一张帧代表整段。
5. 对照口播、字幕、画面和商品卡，查找“声音说 A、字幕写 B、画面展示 C”的矛盾。
6. 单独记录音乐、影视片段、他人视频、字体、肖像和商标的权利来源。

## 证据范围声明

开头用一行写：

```text
已检查：[...]｜未检查：[...]
```

只有当目标平台已确定，且与内容有关的文字、画面、音轨、声明、来源和权利均已检查，才可使用“审核没问题，可以直接发。”

无法读取链接、解析音轨、识别小字或确认授权时：明确说明缺口，请用户补原文、截图、逐字稿或证明；不编造观看结果。
