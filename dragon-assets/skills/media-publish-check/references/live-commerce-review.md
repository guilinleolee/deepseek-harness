# 直播与商品交易专项审核

只在审核直播、直播切片、带货视频、商品卡、秒杀、赠品、抽奖、团购或商业互动时读取。本文件的直播细则来自用户提供的行业资料，属于 `E4 行业经验`；以目标平台当前发布页、商家/创作者后台规则和账号通知为准。

## 适用边界

- 普通图文、普通视频不因为没有真人出镜、未挂商品或未做实时互动而判风险；
- 已经录制完成的视频不要假装“正在直播”；真正的直播才检查挂播、录播、多开和真人互动；
- 对价格、赠品、秒杀、抽奖、商品卡和商业合作，必须同时检查口播、字幕、贴纸、背景板、商品详情、置顶评论和私信话术；
- 不把“秒杀”“免费”“最”“钱”等单个字词直接判违规，先核验交易事实、条件和兑现能力。

## 发布前专项检查

### 1. 价格、库存与时限

- 促销时间写明日期、开始/结束时间和时区；
- 库存、价格、优惠门槛、预售、不可配送地区和限制条件与商品页一致；
- 不宣传未上架、无法兑现或与实际不一致的低价、秒杀、免费送、全员免单或“不限量”福利；
- 不通过虚构原价、连续夸张降价、虚假倒计时或无法证实的稀缺制造购买压力；
- 秒杀或限时活动的关键信息在画面中清晰可见，不被人物、贴纸或裁切遮挡。

### 2. 赠品、抽奖与互动

- 赠品名称、数量、价值、领取条件、商家同意和兑现方式可证明；
- 不能承诺“人手一份”“不限量免费”却只准备少量库存或仅以截屏抽奖代替；
- 不把点赞、评论特定口令、停留时长、转发、关注或刷屏作为获得价格、改价、优先发货、包邮或购买资格的前提；
- 正常的站内互动可以保留，但不得用虚假利益承诺绑架互动。

### 3. 商品与商业主张

- 视频/直播展示的商品、型号、规格、价格、赠品和购物车/商品卡一致；
- 不用通用链接、错误链接或与画面无关的商品承接交易；
- 对食品、化妆品、医美、保健、医疗、金融、教育等高风险行业，额外核验资质、功效、适用范围和广告证明；
- 不虚构优惠、销量、使用体验、对比结论或品牌背书，不恶意贬低竞品；
- 招募主播、代理、合伙人或课程时，不承诺轻松赚钱、保底收入、上热门或平台内部资源。

### 4. 直播真实性与画面秩序

- 真直播避免长时间无主播、静止单画面、黑屏、循环录音或未经授权的录播；
- 不以多账号、多平台同步或非实名主体方式规避当前平台管理；
- 检查未成年人是否承担讲解、推广、带货或代言角色；
- 检查危险挑战、过量进食、酒烟、暴露着装、低俗擦边、迷信、暴力、仿真枪械和其他易模仿风险；
- 直播事故、弱势群体卖惨、恶意拉踩、虚假宠粉或煽动对立，只能在有公共利益和完整语境时另行高风险复核，不得作为卖货噱头。

### 5. 导流与交易绕行

- 删除外部二维码、电话、账号、群聊、私下交易、银行卡转账和绕平台下单引导；
- 不用“某微”“赚米”“某平台”“私下聊”等暗号继续保留同一目的；
- 真实的事实来源、授权归属或平台比较按 [platform-mention-policy.md](platform-mention-policy.md) 处理，不得为了删除名称而篡改事实。

## 风险结论与动作

- 交易事实无法证明、活动无法兑现、商品卡不一致、站外交易、虚假功效或收益承诺：至少 `R3 修改后复审`；
- 明显诈骗、非法交易、危险教唆、未成年人严重权益侵害、重大虚假信息：`R4 阻断`；
- 仅缺少库存/时限/赠品说明，但可立即补足且可验证：`R2/R3`，列出要补的证据；
- 普通视频不属于直播或商品推广时，写“本专项不适用”，不要输出无关直播问题。

## 需要用户补充的材料

- 商品页、活动规则、库存/价格截图、赠品约定和商家授权；
- 直播/视频是否为实时、是否使用录播、商品卡链接和账号主体；
- 行业资质、检测/广告证明、合作合同或佣金关系；
- 已被平台提示的具体违规原因、截图和申诉页面。

不要建议第三方敏感词工具、变体词或话术替换来绕过检查。用户要求“怎么规避”时，改为解释真实修复动作和官方复查路径。
