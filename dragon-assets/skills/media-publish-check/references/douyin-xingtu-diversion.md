# 抖音/星图导流与第三方下载专项

这是可选的高优先级预检，用于抖音星图商单、品牌合作或明确要查“外流/私域/下载”的素材。不取代 [platform-douyin.md](platform-douyin.md)、[legal-baseline.md](legal-baseline.md) 或当前发布页。

## 证据与定位

- 同时检查口播、字幕、封面、关键帧、贴纸、评论话术、置顶评论和商品卡。
- 只收到文字时，仅做文本专项初审；不能说完整视频已通过。
- 输出使用 `DYX-01` 到 `DYX-07` 作为本 Skill 内部复查代码，不要写成官方条款号。

## 行为目标测试

对每个疑似点先问：

1. 观众是否被要求、鼓励或默示去完成一个动作？
2. 这个动作是否把观众带到目标平台以外的联系、交易、阅读、下载或注册场景？
3. 口播、字幕、画面、二维码、指示符号和福利是否共同形成这个预期？

三者中任何一项证据不足，写“信息不足，需补充”，不自行认定。纯事实描述与面向观众的行动指令不能混为一谈；但按本 Skill 的严格平台专属策略，其他平台全称仍需单独处理。

## 专项复查代码

| 代码 | 复查触发条件 | 默认动作 |
|---|---|---|
| DYX-01 | 可识别的外部联系方式，或要求观众在平台外联系 | 删除联系方式和引导；改用当前平台允许的站内能力 |
| DYX-02 | 发出去外部平台、网站、店铺或其他渠道的行动指令 | 删除外部行动指令，不用暗号保留同一目的 |
| DYX-03 | 引导安装、搜索、注册、打开或使用目标平台以外的 App/小程序/网站 | 删除动作指令和跳转材料；需要证明规则时走官方复查 |
| DYX-04 | 用金额、礼品、资料、会员或优惠绑定外部行动 | 取消“外部动作 → 福利”绑定，另行核实活动资质和平台功能 |
| DYX-05 | 画面出现二维码、网址、应用店铺页、外部账号，或箭头/手势/动画指向上述元素 | 删除元素与指向关系；不只删口播 |
| DYX-06 | 用拆字、谐音、颜色词、表情或评论区暗示隐藏外部导流意图 | 还原真实意图后删改；不生成替代暗号 |
| DYX-07 | 纯事实提及其他平台/电商/通讯工具，但无外部行动指令 | 按严格平台专属模式作 R2 删除或中性化；不写成星图官方红线 |

DYX-01～DYX-06 通常至少作为 R3 高优先级复核候选；如能证明它是目标平台允许的站内功能、真实的授权必要信息，或只有不完整文本证据，必须在结论中写清降级原因。

## 可保留项

只在已检查素材中确认以下情况时，才可以写入“可保留”：

- 不含外部去向、注册、购买或联系指令的产品、经验或功能说明；
- 站内关注、评论、商品卡等动作，且它们的当前可用性已经用户在发布页确认；
- 针对素材、渠道或原作者的事实说明，且没有目标平台以外的行动指令。

“可保留”不等于平台保证通过。

## 规则证据与输出

- 本模块的代码是风险工作流，不是对具体官方 QA 、认定结果或生效日期的转述。
- 用户要求星图规则依据、或规则时效会改变结论时，读取 [official-recheck-routes.md](official-recheck-routes.md)，优先请用户在抖音/星图当前商家或创作者后台复核。
- 输出使用 [output-schema.md](output-schema.md) 的“星图专项快速结果”，并先写已检查/未检查模态。
