# 真实博主案例收集模板

只提交你自己拥有、或已经内容所有者明确同意用于内部评测的内容。不要发别人视频、商单素材、群聊记录或未公开信息。

## 发给我前先做脱敏

- 删除姓名、账号、电话、邮箱、订单、地址、身份证件、二维码、银行信息、未公开品牌合作信息。
- 用 `博主 A`、`品牌 B`、`平台 C` 代替可识别对象。
- 如有视频，可以先发字幕、口播和 3～8 张关键帧；不必先交出完整原片。

## 每个案例填这一份

```text
我有权提供此案例用于 Media Publish Check 的内部评测：是 / 否

案例类型：发布前 / 已发布后异常 / 收到违规通知 / 申诉后
目标平台：抖音 / 小红书 / 视频号 / 快手
内容形式：短视频 / 图文 / 直播切片 / 文章
账号/商业语境：个人创作 / 品牌合作 / 带货 / 星图商单 / 其他

已提供的证据：口播 / 字幕 / 封面 / 关键帧 / 音轨 / 商品卡 / 通知截图
未提供的证据：...

素材（已脱敏）：
...

当时实际结果：通过 / 低播放 / 违规通知 / 驳回 / 申诉结果 / 暂不知道
如果收到平台通知，可以提供的原文（已脱敏）：
...

你自己认为的问题：...
希望用这个案例测试什么：漏报 / 误报 / 导流 / AI / 授权 / 带货 / 其他
```

## 我们会怎么用

1. 先做一次单案复盘，不把你的个人经历立刻当成通用规则。
2. 只在授权、脱敏和人工复核都完成后，才写入 `owner-consented-anonymized` 评测集。
3. 记录实际平台结果、证据缺口和争议点，不用“一个案例”推导“所有账号都会这样”。
