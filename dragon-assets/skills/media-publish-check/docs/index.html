可选的个人账号记忆

经验只留在你的电脑里。

用户明确开启后，Skill 才在本机保存脱敏的审核结果和复盘反馈。它不会上传、共享或把一次低播放自动当成规则。

重要边界
个人经验只能作为账号提醒，不能覆盖平台官方规则、授权要求、事实来源或应有标注。候选提醒必须由账号主人确认后才生效。
常见问题

把边界和结论说清楚。

它能保证过审或不被限流吗？

它会对实际检查到的材料给出发布前建议。最终审核和分发由目标平台决定，低播放本身不能说明违规处置。

我可以直接上传自己的视频让它审核吗？

可以。把视频、图片、文案或口播稿上传到你自己使用的 Agent 即可。Skill 不会把素材提交到 GitHub 或公开经验库；内容如何由 Agent 服务处理，以你所用 Agent 的隐私设置为准。GitHub 的 Discussions 和 Issue 用于公开交流建议、Bug 与脱敏的规则反馈。

只给口播稿或封面，也能审核吗？

可以做文本或封面初审，但会清楚写出未检查的画面、音轨、授权和发布页信息，不会假装看过完整成片。

它会收集我的内容或账号数据吗？

普通审核不建立个人档案。只有你主动开启“个人账号记忆”并要求保存时，最小化、脱敏资料才保存在你自己的电脑里。

我能给规则或产品提建议吗？

可以在 GitHub Discussions 交流使用经验，或通过 Issue 模板提交可复现的 Bug、规则来源与已脱敏的平台反馈。
