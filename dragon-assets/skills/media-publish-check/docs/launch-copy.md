## 首页短文案

### 标题

国内自媒体发布前，先过这一关。

### 副标题

把视频、图文、文章、字幕或口播稿丢进来。Media Publish Check 会按抖音、小红书、视频号、快手的发布场景，告诉你能不能直接发、哪里有问题、怎么改，以及 AI、转载、营销、个人观点该怎么标。

### 三个卖点

1. **检查范围完整**：文字、画面、音轨、封面、来源、授权、商品卡和评论话术一起看。
2. **直接给出修改方案**：精确定位到时间码、图片区域或段落，并给可复制的修改稿。
3. **四个平台分别适配**：需要时给不同平台的发布版。

## 社交平台发布文案

### X 英文持续分发模板

#### 版本 D｜海外创作者问题

    Publishing the same video on TikTok, X, Douyin, and Xiaohongshu is not a copy-paste job.

    Before posting in China, I check the actual video, captions, source rights, AI use, commercial disclosures, and platform-specific publishing context.

    Media Publish Check is an open-source Skill for that pre-publish review:
    https://xshuiai.github.io/media-publish-check/for-overseas-creators/

#### 版本 E｜单个问题页

    If you publish on Weixin Video Accounts, a clean script is only one part of the release.

    This checklist covers the video, captions, cover, music, source rights, AI use, and publishing-page context:
    https://xshuiai.github.io/media-publish-check/weixin-video-accounts-publish-check/

每次只选一个真实问题页分发，配合自己的审核过程、公开规则链接或已匿名化的经验。不要把同一段宣传文案连续复制到多条帖文。

### 版本 A｜简洁发布

我做了一个给国内自媒体创作者用的发布前审核 Skill：**Media Publish Check**。

视频、图文、文章、字幕、口播稿、封面，直接丢进去；选择要发抖音、小红书、视频号还是快手，它会先告诉你能不能直接发，再指出具体问题位置和修改稿。

它会结合词表候选、画面、音轨、授权、来源、AI 标注、商业合作、导流、直播话术和平台适配给出建议，也不会承诺“100%过审”。

GitHub：`https://github.com/XshuiAi/media-publish-check`

### 版本 B｜痛点切入

很多内容需要调整后再发，例如：

- 字幕没问题，但封面、口播或音乐有问题；
- 发抖音能说的，发小红书不一定适合原样搬；
- AI、转载、品牌合作、个人观点不知道该怎么标；
- 看到“限流”就不知道到底是违规、资格限制，还是普通播放表现。

所以我做了 **Media Publish Check**：一个面向抖音、小红书、视频号、快手的发布前审核 Skill。

它的输出只有两种：可以直接发，或者不建议直接发；中间只列最关键的问题、精确位置和可直接替换的修改稿。

开源地址：`https://github.com/XshuiAi/media-publish-check`

### 版本 C｜面向海外创作者

如果你在 X、YouTube、TikTok 做内容，现在想进入中国的抖音、小红书、视频号或快手，难点通常在发布语境：来源、授权、AI 标注、商业披露、截图隐私、跨平台导流和平台适配。

**Media Publish Check** 会把一条已有的海外内容，变成一份中国平台发布前审核清单和可直接改写的发布稿。

支持视频、图文、文章、字幕、口播稿和链接。

GitHub：`https://github.com/XshuiAi/media-publish-check`
