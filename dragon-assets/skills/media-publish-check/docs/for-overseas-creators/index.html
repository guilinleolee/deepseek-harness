Prepare one piece of content for China’s creator platforms.

Media Publish Check reviews a finished video, graphic post, article, script, transcript, captions, or cover before you publish on Douyin, Xiaohongshu, Weixin Video Accounts, or Kuaishou.

Install from GitHubChina publishing checklist

What changes when content crosses platforms

Translation is only one step. A release version may need a different disclosure, source note, rights check, title, cover, call to action, or platform-specific publishing choice.

Review the evidence

Inspect what is actually visible and audible: spoken claims, captions, key frames, music, screenshots, QR codes, sources, and asset rights.

Clarify disclosures

Check truthful disclosure for AI-generated material, avatars, reenactments, sponsored content, reposts, and personal opinions.

Create separate release versions

Adapt one source asset for each intended platform. Do not assume that a call to action or platform reference travels unchanged.

Keep the limits clear

The Skill gives pre-publish guidance for inspected material. Final moderation, distribution, and current publishing options remain with the destination platform.
