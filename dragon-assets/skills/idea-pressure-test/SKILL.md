# idea-pressure-test (想法压力测试)

## L0: 一句话描述 (≤15字)
想法6问验证，拒绝虚假创业

## L1: 使用场景 (50-100字)
在投入任何开发资源之前，对创业想法进行残酷的6问验证。如果你的想法通不过这6问，趁早换一个。别等到写了10万行代码才发现没人愿意付钱。

## L2: 详细文档

### 背景

大多数创业失败不是因为产品不够好，而是从一开始就做错了产品。想法压力测试是**在写第一行代码之前**的最后一道防线。

### 6问框架

```
问题1: 真实痛点 (REAL PAIN)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
这个问题是你亲身经历的吗？还是道听途说？

✅ 强烈信号: 你自己就是目标用户，或者你深入访谈过10+个目标用户
⚠️ 警告信号: "我觉得" "朋友说" "市场调研显示"
❌ 危险信号: 从未与真实用户交谈过

如果答案是"道听途说"，立即停止，去做用户访谈。


问题2: 具体客户 (SPECIFIC PERSON)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
你能说出这个人的名字、行业、职位、每天的工作痛点吗？

✅ 强烈信号: 你知道他们的微信/邮箱，他们的名字就在你脑子里
⚠️ 警告信号: "中小企业主" "独立开发者" "电商卖家"（太宽泛）
❌ 危险信号: "需要项目管理工具的人"（连行业都没有）

如果答不出具体人名，继续访谈，直到你能画出这个人的样子。


问题3: 付费意愿 (WILLING TO PAY)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
如果明天收他们$29/月，他们会掏钱吗？你有把握吗？

✅ 强烈信号: 你已经问过他们，他们说"会"
⚠️ 警告信号: "我觉得他们会" "竞争对手收了这么多"
❌ 危险信号: 还没问过任何人

行动: 明天就给3个目标用户发消息，问他们愿不愿意预付$29。


问题4: 竞品缺口 (COMPETITIVE GAP)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
为什么现有方案做不好？他们为什么不换成更好的？

✅ 强烈信号: 你能说出具体哪个功能/体验做得差
⚠️ 警告信号: "价格太贵"（那你凭什么能更便宜？）
❌ 危险信号: "这个市场还没有人做"

行动: 列出3个竞品，逐一分析它们的弱点。


问题5: 防御壁垒 (DEFENSIBILITY)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
6个月后会有10个竞争对手吗？你有什么独特的？

✅ 强烈信号: 你有独家数据/渠道/关系/专业积累
⚠️ 警告信号: 技术壁垒（6个月够复制）
❌ 危险信号: "我先做了就有先发优势"

如果你的壁垒是"先发优势"，换一个想法。


问题6: 时间窗口 (TIME WINDOW)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
你的优势会在12个月内消失吗？外部环境会变吗？

✅ 强烈信号: 你的优势来自积累，不依赖外部变化
⚠️ 警告信号: 依赖某个平台政策/技术趋势
❌ 危险信号: "等XX出来我就没机会了"

行动: 明确你的优势来源，它能在没有你每天工作的情况下持续存在吗？
```

### 评分矩阵

| 问题 | 强烈信号 | 警告信号 | 危险信号 |
|------|---------|---------|---------|
| Q1 真实痛点 | 亲身经历+深度访谈 | 道听途说 | 从未访谈 |
| Q2 具体客户 | 知道名字+微信 | 宽泛人群 | 无人群画像 |
| Q3 付费意愿 | 用户亲口说会 | 我觉得会 | 没问过 |
| Q4 竞品缺口 | 具体功能弱点 | 价格因素 | 市场空白 |
| Q5 防御壁垒 | 积累性优势 | 技术壁垒 | 先发优势 |
| Q6 时间窗口 | 积累性优势持续 | 依赖外部 | 外部威胁 |

### 通过标准

```
✅ 通过 (可以继续): 6问中至少4问是"强烈信号"
⚠️ 有条件通过 (需改进): 3个强烈信号+2个警告信号
❌ 不通过 (重新验证): 不足3个强烈信号

如果通不过，重新访谈用户，重新思考问题，直到你能自信地回答这6问。
```

### 使用命令

```bash
# 启动想法压力测试
/founder-pressure-test

# 或自然语言触发
[@99-01] 测试我的创业想法: [你的想法描述]
```

### 天龙引擎协同

| 天龙岗位 | 协同方式 |
|---------|---------|
| **00分析师** | 提供市场数据和竞品分析 |
| **32-01市场研究** | Q1/Q4支持：市场调研 |
| **25-02精益创业导师** | 提供精益验证方法论 |
| **50-01产品策划** | PRD和需求验证 |

### 注意事项

1. **不要跳过访谈**：如果Q1/Q2的答案是"道听途说"，立刻去访谈真实用户
2. **不要假设付费**：如果Q3的答案是"我觉得会"，立刻去问
3. **不要自欺**：如果答案都是"危险信号"，诚实面对，换一个想法
4. **时间窗口是致命问题**：如果Q6是危险信号，外部变化可能在产品完成前摧毁市场
