# 十八子写作 - 选题侦察兵技能

> 快速评估选题价值，生成爆款标题

## ⚡ 核心能力

### 1. 爆款要素提取
- 情感触发点（愤怒、惊讶、好奇、温暖）
- 实用价值（技巧、工具、方法、资源）
- 社会认同（专家、数据、案例）
- 紧迫感（限时、限量、趋势）
- 易传播性（金句、段子、对比）

### 2. 市场洼地检测
- 搜索结果数统计
- 竞争等级评估（蓝海/黄海/红海）
- 差异化机会识别
- 信息增量空间评估

### 3. 三维匹配验证
- **人（Who）**：读者画像、需求、痛点
- **情境（Where/When）**：场景、时机、渠道
- **信息（What）**：核心信息、形式、密度

### 4. 信息增量评估
- 新信息量计算
- 信息增量百分比
- 增量来源分析

### 5. 标题推荐与评分
- 3个不同风格标题
- 洞察力评分（0-10）
- 利益点评分（0-10）
- 钩子力评分（0-10）
- 总分排序

---

## 🎯 使用场景

### 场景1：新选题评估
```bash
/shibazi-topic "Web3社交协议"
```
**适用**：开始写作前，评估选题价值

### 场景2：批量选题筛选
```bash
/shibazi-topic --batch "AI写作,Web3社交,React性能优化"
```
**适用**：有多个选题想法，需要筛选

### 场景3：爆款参考
```bash
/shibazi-topic "AI写作工具" --ref "https://xiaohongshu.com/p/123456"
```
**适用**：看到爆款内容，想复制其模式

### 场景4：快速决策
```bash
/shibazi-topic "Python自动化办公" --quick
```
**适用**：快速判断是否值得创作

## 📊 评分标准

### 综合评分计算
```
综合评分 = (
    爆款要素完整性 × 20% +
    市场洼地度 × 20% +
    三维匹配度 × 20% +
    信息增量 × 25% +
    最佳标题分 × 15%
)
```

### 评分等级
- **90-100分**：✅优秀，强烈推荐创作
- **80-89分**：⭐良好，推荐创作
- **70-79分**：⚠️一般，需要优化
- **60-69分**：❌较差，不建议创作
- **<60分**：🚫放弃选题

---

## 🚫 一票否决机制

**以下情况直接否决选题**：
- ❌ 信息增量 <30%
- ❌ 搜索结果 >500条（红海）
- ❌ 综合匹配度 <50分
- ❌ 所有标题评分 <15分
- ❌ 违反内容禁区

### Stage 1: 爆款分析
```
输入主题 → 爆款要素提取 → 爆款逻辑分析
```

```
关键词搜索 → 结果统计 → 竞争度评估 → 差异化识别
```

### Stage 3: 三维匹配验证
```
定义人×情境×信息 → 匹配度计算
```

### Stage 4: 信息增量评估
```
收集现有信息 → 识别新信息 → 计算增量
```

### Stage 5: 标题推荐
```
生成标题 → 多维评分 → 排序输出
```

## 💡 最佳实践

### 1. 提高选题评分
- ✅ 增加信息增量（独家数据、案例、观点）
- ✅ 优化目标读者（明确画像，提高匹配度）
- ✅ 差异化定位（寻找未被覆盖的角度）
- ✅ 强化爆款要素（情感触发、实用价值）

### 2. 标题优化技巧
- **洞察力**：增加新颖观点、深度思考
- **利益点**：明确读者收获，具体可信
- **钩子力**：增加反常识、冲突对比、数字冲击

### 3. 市场洼地判断
- **蓝海**（<10条）：✅机会或需求不足
- **黄海**（10-100条）：⚠️需差异化
- **红海**（>100条）：❌竞争激烈

## ❓ 常见问题

### Q: 市场洼地"蓝海"一定是好选题吗？
**A**: 不一定。蓝海可能意味着：
- ✅ 真正的机会（需求存在，供给不足）
- ⚠️ 需求不足（没人关心）

**建议**：结合三维匹配度综合判断。

### Q: 标题评分低怎么办？
**A**: 优化3个维度：
1. 洞察力：增加新颖观点、深度思考
2. 利益点：明确读者收获，具体可信
3. 钩子力：增加反常识、冲突对比、数字冲击

### Q: 可以跳过选题分析直接写作吗？
**A**: 可以，但**不推荐**。
- **风险**：可能遇到红海竞争、信息增量不足
- **建议**：至少使用 `--quick` 快速评估

## 🔧 故障排除

### 问题1：分析耗时过长
**原因**：主题过于复杂，搜索结果过多

**解决**：
- 使用 `--quick` 快速评估
- 缩小关键词范围
- 使用 `--audience` 明确目标读者

### 问题2：标题评分都很低
**原因**：选题缺乏吸引力

**解决**：
- 参考爆款文章（`--ref`）
- 优化标题的3个维度
- 考虑更换选题

### 问题3：市场洼地显示"红海"
**原因**：竞争激烈

**解决**：
- 寻找差异化角度
- 聚焦细分领域
- 考虑更换选题
