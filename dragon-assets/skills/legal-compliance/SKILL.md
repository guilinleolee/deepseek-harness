# Legal Compliance - 合规法律技能包

## L0: 一句话描述 (≤15字)
企业合规风险管理，从内部到外部

## L1: 使用场景 (50-100字)
当需要进行合规审查、监管报批、内部控制、风险管理、反垄断审查、数据合规、出口管制、反腐败调查，或需要制定合规体系时，使用本技能包。支持反垄断、数据合规、出口管制、反腐败、环境保护、劳动合规六大领域。

## L2: 详细文档

### 核心能力

| 技能 | 功能 | 核心能力 |
|------|------|---------|
| **compliance-review** | 合规审查 | 合规差距分析+整改建议+体系设计 |
| **regulatory-filing** | 监管报批 | 审批流程+材料准备+监管沟通 |
| **internal-control** | 内部控制 | 内控体系+审计配合+缺陷整改 |
| **risk-assessment** | 风险评估 | 合规风险识别+评估+缓释措施 |
| **anti-bribery** | 反腐败合规 | 反商业贿赂+礼品招待+利益冲突管理 |
| **data-privacy** | 数据合规 | 个人信息保护+数据跨境+合规整改 |
| **export-control** | 出口管制 | 禁限制清单筛查+最终用户核实+许可证申请 |
| **sanctions-screening** | 制裁筛查 | 黑名单比对+交易筛查+冻结执行 |
| **competition-law** | 反垄断合规 | 经营者集中申报+垄断协议+滥用市场支配地位 |
| **environmental-compliance** | 环保合规 | 环评批复+排污许可+行政处罚应对 |

### IRAC分析框架

所有合规分析遵循IRAC框架：

```
Issue（问题）→ Rule（规则）→ Application（适用）→ Conclusion（结论）
```

### 置信度分级

| 标记 | 含义 | 使用场景 |
|------|------|---------|
| `[CONFIRMED]` | 确认 | 现行法规/监管口径 |
| `[LIKELY]` | 可能 | 主流观点/倾向性意见 |
| `[UNCERTAIN]` | 不确定 | 存在争议/监管模糊地带 |
| `[VERIFY]` | 需核实 | 最新监管动态/窗口指导意见 |

### 核心命令

```bash
# 合规审查
/compliance-review --scope full/limited --entity "目标实体"
/compliance-review --type pre-deal/post-deal --standard SOX/ISO37301

# 监管报批
/regulatory-filing --type merger/acquisition --authority SAMR/NDRC
/regulatory-filing --timeline --estimate

# 内部控制
/internal-control --scope financial/operational/compliance
/internal-control --deficiency-assess --rating critical/major/minor

# 风险评估
/risk-assessment --area data-privacy/anti-bribery/export-control
/risk-assessment --heat-map --probability high/medium/low

# 数据合规
/data-privacy --impact-assessment --data-type personal/sensitive
/data-privacy --cross-border-transfer --mechanism SCC/BCR/adequacy

# 出口管制
/export-control --screen --item "物项描述" --destination "目的地"
/export-control --license-check --eccn "美国出口分类号"

# 制裁筛查
/sanctions-screening --entity "实体名称" --list OFAC/UN/EU
/sanctions-screening --transaction --amount --counterparty

# 反垄断
/competition-law --concentration-filing --turnover "营业额" --market-share "市场份额"
/competition-law --leniency --applicant "申请人" --cartel "卡特尔行为"

# 环保合规
/environmental-compliance --audit --facility "设施地址"
/environmental-compliance --permit-renewal --type discharge/emission
```

### 风险矩阵

| 风险等级 | 触发条件 | 建议行动 |
|----------|---------|---------|
| 🔴高 | 重大违规/高额罚款/刑事追责风险 | 立即停业整改+外部律师介入+监管主动报告 |
| 🟠中高 | 系统性违规/大量用户受影响 | 制定整改计划+内部问责+监管预沟通 |
| 🟡中 | 局部违规/单次违规 | 限期整改+合规培训+机制完善 |
| 🟢低 | 程序性违规/无实质损害 | 主动披露+承诺改进+记录归档 |

### 约束条件

⚠️ **非监管意见** - 本技能包提供合规分析和程序指引，不构成正式的监管意见或法律建议，不替代外部律师咨询。

⚠️ **时效性提醒** - 法规政策持续更新，分析结论应及时核实最新规定。

## L2扩展

### 六大合规领域

```
1. 反垄断合规
   - 经营者集中申报（营业额门槛/简易程序/普通程序）
   - 垄断协议（横向协议/纵向协议/宽大制度）
   - 滥用市场支配地位（不公平价格/拒绝交易/限定交易）
   - 行政调查应对（现场检查/询问调查/证据固定）

2. 数据合规
   - 个人信息保护（收集/存储/使用/传输/删除全周期）
   - 数据跨境传输（安全评估/标准合同/认证）
   - 重要数据管理（目录申报/出境评估）
   - App个人信息保护（隐私政策/权限申请/第三方SDK）

3. 出口管制
   - 禁限制清单（实体清单/被拒绝清单/最终用户核实）
   - 许可证管理（类别/申请流程/许可类型）
   - 再出口管制（知晓规则/被迫交付/视同出口）
   - 制裁合规（OFAC/联合国/欧盟/中国人民银行）

4. 反腐败合规
   - 商业贿赂（行贿受贿/单位行贿/情节认定）
   - 礼品与招待（价值标准/记录要求/审批流程）
   - 利益冲突（申报要求/回避管理/投资限制）
   - 第三方尽职调查（中间商/代理商/政府关系顾问）

5. 环境保护合规
   - 环评管理（登记表/报告表/报告书/豁免情形）
   - 排污许可（简化管理/重点管理/排污许可证换发）
   - 固体废物管理（危废鉴别/危废处置/危废经营许可证）
   - 行政处罚（按日连续处罚/停产停业/移送拘留）

6. 劳动合规
   - 平等就业（性别/年龄/地域歧视/婚育状况）
   - 工时休假（标准工时/综合工时/加班限制/年休假）
   - 劳动安全（职业病防护/安全生产/安全事故报告）
   - 劳务派遣（同工同酬/比例限制/退回情形）
```

```

  □ 申报后等候期届满前不得实施集中

□ 外商投资安全审查
  □ 初步审查：30个工作日
  □ 特别审查：60个工作日（可延长）

□ 上市公司重大资产重组
  □ 交易所审核：10个工作日

  □ 受理：5个工作日
  □ 评估：45个工作日（可延长15个工作日）

□ 危险化学品经营许可
  □ 受理：5个工作日
  □ 审批：20个工作日
```

### 转介判断标准

| 判断维度 | 可自行处理 | 需要转介 |
|----------|-----------|---------|
| 复杂程度 | 单一领域合规 | 跨领域/多法域 |
| 标的金额 | 行政处罚金额较小 | 重大罚款/吊销许可 |
| 监管态度 | 窗口指导/非正式沟通 | 正式立案调查 |
| 时间紧迫 | 尚在等候期/审批期 | 调查人员已进场 |
| 人员状态 | 无人员责任风险 | 涉及个人刑事风险 |
