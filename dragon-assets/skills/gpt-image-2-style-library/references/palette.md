## 1. 核心色号 · XHS 爆款主色

### 1.1 `#FDFFA7` · 柔和浅黄（XHS 真人出镜爆款专用）

| 属性 | 值 |
|------|---|
| HEX | `#FDFFA7` |
| RGB | `(253, 255, 167)` |
| HSL | `(61°, 100%, 83%)` |
| 命名 | 柔和浅黄 / 奶油黄 / soft pastel yellow |
| 适用场景 | 小红书真人出镜爆款封面主标题字色 / 关键词 / 底板 / 色块 / 横幅 / 箭头 |

### 1.2 `#FDFFA7` 的色号硬约束

**凡使用黄色，必须是 `#FDFFA7`**：

```
✅ 标题填充        → #FDFFA7
✅ 关键词          → #FDFFA7
✅ 标题底板        → #FDFFA7
✅ 标题色块        → #FDFFA7
✅ 横幅            → #FDFFA7
✅ 箭头            → #FDFFA7
✅ 装饰图标        → #FDFFA7
```

**禁止使用的黄色**（视觉会破坏 XHS 爆款风格）：

| 禁用 | HEX 范围 | 原因 |
|------|---------|------|
| 荧光黄 | `#FFFF00` / `#F0FF00` | 高饱和刺眼，违反"柔和"原则 |
| 柠檬黄 | `#FFF44F` | 偏荧光 |
| 金黄 | `#FFD700` | 偏橙，不柔和 |
| 偏橙黄色 | `#FFA500` / `#FFB347` | 完全偏离 |
| 芥末黄 | `#FFDB58` | 偏浊 |

### 1.3 `#FDFFA7` 的配套色

| 角色 | HEX | 用途 |
|------|-----|------|
| **粗黑描边** | `#000000` | 标题外轮廓描边，强化高对比 |
| **纯白** | `#FFFFFF` | 副标题 / 混排辅助词 / 深色背景高对比 |
| **白色高光** | `#FFFFFF`（低透明度） | 主标题立体感高光 |
| **绿色勾选** | `#22C55E` | ✅ 教程清单 / 效率清单 |
| **深色背景** | `#0A0A0A` / `#1A1A1A` | 黑底效率工作流 / 测评榜单 |

## 2. 通用配色模板

### 2.1 暖色钩子型（高点击感）

适用：爆款大字压顶风、种草推荐风、贴纸拼贴入门风

```
主标题字色：#FDFFA7
主标题描边：#000000
背景基调：暖光室内 / 主题相关场景
高光：#FFFFFF（5-15% 透明度）
点缀：#FF6B6B（小红心/emoji 配色，10% 占比以内）
```

### 2.2 强冲击对比型

适用：巨字拆分冲击风、黑底效率工作流风

```
主标题字色：#FDFFA7 + #FFFFFF 交替
主标题描边：#000000
背景基调：深色 / 黑灰 / 深色 Logo 墙
辅助：#22C55E（绿色勾选清单）
数字强调：#FDFFA7（最大字号）
```

### 2.3 教学清单型

适用：教程清单风、产品测评榜单风

```
主标题字色：#FDFFA7
主标题描边：#000000
清单勾选：#22C55E
清单文字：#FFFFFF + #000000 描边
箭头：#FDFFA7
维度标签：#FFFFFF + #000000 描边
```

### 2.4 科普问答型

适用：小白科普问答风

```
主标题字色：#FDFFA7
问号：#FFFFFF + #000000 描边
勾选标签：#22C55E + #FFFFFF 文字
背景：#0A0A0A / 黑灰科技海报
```

## 3. 色彩规则（任何模板通用）

### 3.1 主色上限

每个画面**最多 3 个主色**：

| 主色 | 角色 | 占比 |
|------|------|------|
| 主色（如 `#FDFFA7`） | 标题 / 关键词 / 主装饰 | 30-40% |
| 次色（如 `#FFFFFF`） | 副标题 / 辅助文字 | 25-35% |
| 点缀色（如 `#22C55E`） | 勾选 / 装饰元素 | 10-15% |
| 黑色 | 描边 / 文字 / 背景 | 20-30% |

### 3.2 对比度要求

| 元素 | 最低对比度 | 推荐 |
|------|-----------|------|
| 主标题 vs 背景 | **≥ 7:1**（AAA） | 12:1+ |
| 副标题 vs 背景 | ≥ 4.5:1（AA） | 7:1+ |
| 标签文字 vs 标签底 | ≥ 4.5:1（AA） | 7:1+ |

### 3.3 黄色使用禁区

- ❌ 黄色文字放在浅色背景（对比度不足）
- ❌ 黄色文字不描黑边
- ❌ 主色 + 多个黄色变体混用（必须统一 `#FDFFA7`）
- ❌ 黄色作为大面积背景（视觉过载）

## 5. 跨模板统一约束

### 5.1 凡写"黄色"必须显式写 HEX

```yaml
# ✅ 正确
- "主标题填充 #FDFFA7"
- "标题背后的黄色底板也使用 #FDFFA7"

# ❌ 错误（不能写"黄色"）
- "主标题是黄色"
- "背景是柔和黄"
```

**理由**：GPT-Image2 对自然语言"黄色"会输出多种黄色变体（荧光黄/柠檬黄/金黄），必须用 HEX 锁定。

### 5.2 必须在 prompt 中显式声明禁止其他黄色

每条 XHS 风格 prompt 都应包含：

```
禁止荧光黄/金黄/偏橙黄色
```

或更明确：

```
**禁止荧光黄/金黄/偏橙黄**
```

### 5.3 `#FDFFA7` 出现在每条 prompt 的关键词列表

```python
REQUIRED_KEYWORDS = ["#FDFFA7", "粗黑描边", "3:4", "竖版", "小红书", "真人出镜"]
```
