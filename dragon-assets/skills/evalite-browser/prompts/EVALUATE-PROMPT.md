# Evalite-Browser LLM 应用评估提示词

## 概述

本目录包含用于设计 LLM 应用浏览器评估的提示词模板。这些提示词帮助开发者构建全面的测试用例，覆盖视觉回归、无障碍访问和 UI 交互验证。

## 文件列表

| 文件 | 用途 |
|------|------|
| `EVALUATE-PROMPT.md` | LLM 应用评估设计指南 |
| `VISUAL-DESIGN.md` | 视觉测试设计提示词 |
| `A11Y-DESIGN.md` | 无障碍测试设计提示词 |
| `INTERACTION-DESIGN.md` | 交互测试设计提示词 |
| `PROJECT-TEMPLATE.md` | 项目初始化提示词 |

## 评估维度

### 1. 视觉回归测试

- 布局一致性
- 样式渲染
- 响应式设计
- 动态内容变化

### 2. 无障碍访问测试

- WCAG 2.1 AA 合规性
- 键盘导航
- 屏幕阅读器兼容性
- 颜色对比度

### 3. UI 交互测试

- 表单输入
- 按钮点击
- 导航流程
- 异步加载

## 使用方法

参考 `VISUAL-DESIGN.md` 等文件获取具体提示词模板。
