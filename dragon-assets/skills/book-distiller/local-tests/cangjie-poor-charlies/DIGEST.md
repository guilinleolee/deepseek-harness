# 穷查理宝典精华 · 不读全书只看这篇

## 一句话总结
芒格 80 年智慧的浓缩 — 用跨学科思维模型 + 逆向思考 + 能力圈 + 心理倾向检查清单
武装你的每一个判断。

## 4 大思维工具
1. **多元思维模型**——把 25+ 学科的核心模型装进脑子
2. **逆向思考**——先想"如何失败"再想"如何成功"
3. **能力圈**——只在"比 80% 的人都懂"的领域做判断
4. **心理倾向清单**——25 个常见心理偏差,每次决策前过一遍

## 6 个落地动作
1. 投资前:用能力圈 + 安全边际 + 内在价值三件套
2. 决策前:用心理倾向清单 25 项过一遍
3. 谈判前:用逆向思考想"对方会怎么骗我"
4. 学习时:每年学一个新学科的核心模型
5. 写文档时:先写"我可能是错的"清单
6. 选工作:只在能力圈内选,不为高薪跨界
