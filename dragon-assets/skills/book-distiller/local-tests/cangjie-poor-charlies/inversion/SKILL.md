# 逆向思考

## R · 原文
> "反过来想,总是反过来想。"——雅各布·伯努利 / 芒格引用

## I · 重写
先想"如何失败",列出所有失败原因,然后反向避免。

## A1 · 案例
芒格研究商业失败案例(破产 / 丑闻),归纳出 30+ 失败模式。

## A2 · 调用
用户说:"这件事怎么避免失败?"或"我应该反着想什么?"

## E · 步骤
1. 列出所有可能的失败方式
2. 对每种失败问"如何避免"
3. 优先消除高概率失败

## B · 边界
- 不适用于纯增量优化场景
