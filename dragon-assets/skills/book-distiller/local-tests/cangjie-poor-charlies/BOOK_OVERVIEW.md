# 穷查理宝典 · 整书理解(Adler 四步)

## 主旨
查理·芒格 80+ 年跨学科智慧的精华 — 多元思维模型 + 逆向思考 + 能力圈 + 理性诚实。

## 骨架(结构)
1. 思维模型:25+ 跨学科模型(心理学 / 经济学 / 物理学 / 生物学)
2. 决策框架:逆向思考 + 二级效应 + 心理倾向检查清单
3. 投资哲学:能力圈 + 内在价值 + 安全边际
4. 人生哲学:理性诚实 + 终身学习 + 延迟满足

## 批判(25 条芒格盲点)
- 芒格对科技股过度保守(错过 Apple / Google)
- 芒格的"长期主义"在 20 年以下周期可能失效
- 芒格的"逆向思考"对快速变化的领域(如 AI)应用受限

## 应用(10 类典型场景)
- 投资决策(核心场景)
- 跨学科学习
- 避免认知偏差
- 谈判与说服
- 招聘与团队管理
- 案例学习:芒格分析 1980s 储蓄贷款危机,用了 心理学(群体癫狂)+ 经济学(道德风险)+ 历史学(19 世纪郁金香泡沫)三学科叠加,找到问题根源。
- 案例:芒格分析可口可乐,使用竞争优势 + 品牌价值 + 财务稳健 + 管理层四个维度。
- 例如:思考决策时,先问"我可能错在哪"——这是逆向思考的核心。
- 案例:巴菲特与芒格 1970s 投资 See's Candies,识别品牌护城河。
- 故事:芒格年轻时在加油站被骗,学会了"激励机制"是商业本质。

多元思维模型是指用多个学科的核心模型叠加分析问题。
心理倾向检查清单包括 25 个常见认知偏差,每次决策前过一遍。
能力圈是指只在"比 80% 的人都懂"的领域做判断。
理性诚实的核心是承认自己可能是错的,避免自我欺骗。
安全边际影响投资决策,在低于内在价值 30% 以上买入。
坐等策略是芒格常说的"好机会不常有,要会等"。

延迟满足导致长期成功。多元思维模型影响决策质量。
安全边际是价值投资的基石。逆向思考避免失败。
终身学习是芒格本人每天的实践。
