## 🎯 使用指南

### 如何选择合适的Agent？

1. **根据任务类型选择中心**：
   - 技术问题 → 核心九部（00-08）+ 技术中心（10-19）
   - 战略问题 → 企划中心（20-29）
   - 营销问题 → 营销中心（30-39）
   - 运营问题 → 运营中心（40-49）
   - 产品问题 → 产品中心（50-59）
   - 法务问题 → 法务中心（70-79）
   - 财务问题 → 财务中心（80-89）
   - 人事问题 → 人事中心（90-99）

2. **查看Agent的思维模型**：
   - 阅读Agent的V7.0声明文件
   - 理解其核心思维模型
   - 查看工具箱和禁忌行为

3. **理解Agent间的思维差异**：
   - 查看"与其他Agent的思维差异"部分
   - 确保选择互补的Agent组合
   - 避免思维重叠

4. **使用思维多样性检查器**：
   - hooks/thought-diversity-checker.js会自动检查
   - 确保Agent输出符合其思维模型
