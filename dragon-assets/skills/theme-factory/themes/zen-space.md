# 禅意空间

极简禅意主题，以枯叶色、石灰、炭黑的静谧搭配，传递东方禅修意境。

## Color Palette

- **枯叶色**: `#a0826d` - 主色调，自然枯叶
- **石灰**: `#d9d9d9` - 背景，简约空间
- **炭黑**: `#2d2d2d` - 文字与深色
- **苔绿**: `#6b8e6b` - 点缀色，禅意绿

## Typography

- **Headers**: LXGW WenKai Light (霞鹜文楷细体)
- **Body Text**: LXGW WenKai Light (霞鹜文楷细体)

## Best Used For

冥想空间、瑜伽馆、茶道、简约生活方式。
