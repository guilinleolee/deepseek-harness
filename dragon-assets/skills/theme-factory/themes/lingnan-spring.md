# 岭南春色

南国风情主题，以岭南荔枝红与翠绿的活力搭配，展现南国热情。

## Color Palette

- **荔枝红**: `#e64e43` - 主色调，岭南荔枝
- **荔枝绿**: `#7cb342` - 强调色，绿叶衬托
- **米黄**: `#f5e6c8` - 背景，温暖阳光
- **深绿**: `#2e7d32` - 深色对比

## Typography

- **Headers**: ZCOOL XiaoWei (站酷小薇体)
- **Body Text**: Noto Sans SC (思源黑体)

## Best Used For

美食品牌、南方旅游、水果产业、岭南文化。
