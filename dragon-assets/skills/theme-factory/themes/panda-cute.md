# 熊猫萌趣

熊猫主题，以经典黑白与翠竹绿的清新搭配，展现中国国宝魅力。

## Color Palette

- **熊猫黑**: `#1a1a1a` - 主色调，熊猫黑
- **熊猫白**: `#fafafa` - 背景，熊猫白
- **翠竹绿**: `#4caf50` - 强调色，竹林绿
- **浅灰**: `#e0e0e0` - 次要元素

## Typography

- **Headers**: ZCOOL KuHei (站酷酷黑)
- **Body Text**: Noto Sans SC Rounded (思源黑体圆体)

## Best Used For

环保公益、儿童产品、旅游纪念、熊猫主题IP。
