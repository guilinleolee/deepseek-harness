# 10-02 AI研究员 V10.0

## L0: 一句话描述 (≤15字)
深度研究Agent，Planner-Executor-Publisher三层架构自动生成报告。

## L1: 使用场景 (50-100字)
当需要进行深度研究、竞品分析、行业调研、技术评估等需要系统性信息收集和综合分析的任务时调用。支持Planner-Agent问题链生成、流式报告输出、内联AI配图。与01调研师分工明确：01负责考古摸底，10-02负责深度研究。

## L2: 详细文档

### 核心能力

1. **Planner-Executor-Publisher三层架构**
   - **Planner-Agent**: 生成研究问题链，树状递归探索
   - **Executor-Agent**: 并行抓取+汇总每个问题
   - **Publisher**: 聚合为完整报告+来源追踪

2. **流式报告输出**: 实时进度+分块输出
3. **内联Gemini配图**: 报告自动配图
4. **多源聚合**: 本地文档+网络搜索+RSS订阅

### 使用方法

```bash
# 基本研究
gpt-researcher "AI Agent发展趋势研究"

# 深度探索
python3 ~/.claude/skills/gpt-researcher/scripts/gpt_researcher_wrapper.py deep "主题" --depth 3

# 本地文档研究
python3 ~/.claude/skills/gpt-researcher/scripts/gpt_researcher_wrapper.py local "分析文档" --docs ./report.pdf

# 指定研究深度
python3 ~/.claude/skills/gpt-researcher/scripts/gpt_researcher_wrapper.py research "主题" --depth 5 --breadth 3
```

### 研究工作流

```
┌─────────────────────────────────────────────────────────────┐
│                    研究工作流 L2标准格式                       │
├─────────────────────────────────────────────────────────────┤
│  Phase 1: 问题定义                                         │
│  ├── 问题类型判断（概念/决策/趋势/诊断/梳理）              │
│  └── 时效敏感性判断（极高/高/中/低）                      │
├─────────────────────────────────────────────────────────────┤
│  Phase 2: Planner-Agent                                   │
│  ├── 生成研究问题链                                        │
│  ├── 树状递归探索                                          │
│  └── 并行任务分配                                          │
├─────────────────────────────────────────────────────────────┤
│  Phase 3: Executor-Agent                                  │
│  ├── 并行抓取每个问题                                      │
│  ├── 来源验证                                              │
│  └── 事实卡片生成                                          │
├─────────────────────────────────────────────────────────────┤
│  Phase 4: Publisher                                        │
│  ├── 聚合为完整报告                                        │
│  ├── 来源追踪                                              │
│  └── 内联配图                                              │
├─────────────────────────────────────────────────────────────┤
│  Phase 5: 质量验证                                        │
│  ├── 独立Agent校验                                          │
│  ├── 逻辑谬误检测                                          │
│  └── 置信度评分                                            │
└─────────────────────────────────────────────────────────────┘
```

### 输出标准

- **格式**: Markdown + YAML frontmatter
- **结构**: 执行摘要→问题分析→证据链→结论→来源
- **置信度**: 每个结论标注置信度（高/中/低）
- **时效性**: 标注信息时效

### 协同天龙九部

- **00分析师**: 问题定义+可行性评估
- **01调研师**: 考古摸底+补充调研
- **06审查师**: 逻辑审查+引用验证
- **07记录师**: 报告归档+Wiki存储
