## 三环定位分析

### 第一环：能力圈（我能做什么？）

```
┌─────────────────────────────────────────────────────────────┐
│ 核心能力                                                 │
├─────────────────────────────────────────────────────────────┤
│ ★★★★★ Python全栈开发                                    │

│ ★★★★  产品设计与用户研究                                 │
│ ★★★★  内容创作与知识分享                                 │
│ ★★★   流量获取与增长                                     │
└─────────────────────────────────────────────────────────────┘
```

### 第二环：需求圈（什么有需求？）

```
┌─────────────────────────────────────────────────────────────┐
│ 市场需求排序                                             │
├─────────────────────────────────────────────────────────────┤
│ 1. 企业数据处理自动化 (需求强+支付意愿高)                │

└─────────────────────────────────────────────────────────────┘
```

### 第三环：杠杆圈（什么可放大？）

```
┌─────────────────────────────────────────────────────────────┐
│ 杠杆效应                                                 │
├─────────────────────────────────────────────────────────────┤

│ ★★★   咨询业务受时间限制，难以杠杆                       │
└─────────────────────────────────────────────────────────────┘
```

## 6维机会评分

| 维度 | 评分(1-5) | 说明 |
|------|-----------|------|
| **市场规模** | ★★★★ | 企业级市场，付费意愿强 |
| **竞争程度** | ★★★ | 有竞争但无绝对霸主 |
| **变现能力** | ★★★★★ | 企业付费，高客单价 |
| **成长性** | ★★★★★ | AI浪潮，需求快速增长 |
| **个人匹配** | ★★★★★ | 核心能力高度匹配 |
| **启动难度** | ★★★ | 需要一定行业积累 |

**综合得分**：29/30 - 强烈推荐

## 定位陈述

```
【定位】
面向中小企业的AI数据自动化服务

【差异化】
用AI替代重复性数据工作，让企业"零学习"用上自动化

【目标客户】
20-200人SaaS公司，数据/运营岗位负责人

【核心价值】
"你提需求，AI执行，数据自动到位"
```
