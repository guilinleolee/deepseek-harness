**用AI帮你从零开始规划一人企业：9阶段完整方法论，覆盖定位→产品→获客→复利→复盘全流程**

## 快速开始

```bash

/opc-resource     # 资源盘点
/opc-niche       # 利基定位
/opc-value       # 价值主张
/opc-canvas      # 商业模式
/opc-mvp         # MVP设计
/opc-conversion  # 转化闭环
/opc-asset      # 资产沉淀
/opc-review     # 经营复盘
```

## 核心框架速查

### 三环定位（Stage 02）

```
能力圈        需求圈        杠杆圈
   ○ ─────►  ○ ─────►  ○
   │          │          │
   │          │          │
   ▼          ▼          ▼
你擅长什么？ 什么赚钱？   什么可杠杆？
```

### Jobs/Pains/Gains（Stage 03）

| 类型 | 问题示例 |
|------|---------|
| **Jobs** | 用户想要完成什么任务？ |
| **Pains** | 用户的痛苦/障碍是什么？ |
| **Gains** | 用户期望的收益是什么？ |

### MVP三阶段（Stage 05）

```
Stage 1: Manual (手工)     ──►  亲自服务每个客户，写下每一步
        │
        ▼
Stage 2: Processized (流程化) ──► 把流程写在纸上，任何人都能做
        │
        ▼
Stage 3: Productized (产品化) ──► 自动化，让客户自助使用
```

### 转化漏斗（Stage 06）

```
触达(100人) → 承接(30人) → 信任(10人) → 成交(3人) → 复购(1人)
   流失70%       流失20%      流失70%       流失66%
```

### 四类资产（Stage 08）

| 资产类型 | 一次投入 | 可复用次数 |
|---------|---------|-----------|
| **内容资产** | 高 | 无数次 |
| **方法论资产** | 中 | 可复制 |
| **客户资产** | 低 | 关系网络 |
| **系统资产** | 高 | 自动化 |

### 唯一重点法则（Stage 09）

```
什么都想做 → 结果什么都没做好

解法: 同一时间，只做一个唯一重点

找唯一重点:
1. 列出所有可能做的事
2. 如果只做一件，能带来最大改变的是什么？
3. 那件事做好后，下一件影响最大的是什么？
4. 重复直到找到"唯一"
```
