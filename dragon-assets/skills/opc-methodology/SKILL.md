# OPC 一人企业方法论 (One-Person Business Methodology)

> 来源: [easychen/opc-methodology](https://github.com/easychen/opc-methodology)
> 作者: Easy (方糖)
> 授权: CC-BY-NC-SA 4.0

## 🎯 核心理念

**把已有能力重新组织成轻资产、可验证、可复用的个人业务系统**

```
┌─────────────────────────────────────────────────────────────┐
│              OPC 一人企业方法论 9阶段架构                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【线性阶段】（顺序执行，确保不跳步）                        │
│  ├── 00 总编排     - 阶段判断 + 进度恢复                   │
│  ├── 01 资源盘点  - 8类资源盘点                           │
│  ├── 02 利基定位  - 三环合一 + 6维评分                     │
│  ├── 03 价值主张  - Jobs/Pains/Gains                     │
│  ├── 04 商业模式  - Lean Canvas + 高风险假设             │
│  ├── 05 MVP设计   - 假设验证 + 成功标准                  │
│  └── 06 转化闭环  - 触达→承接→成交                       │
│                                                             │
│  【条件触发阶段】（按需启用）                              │
│  ├── 08 资产沉淀  - 可复用成果 + 优先级                   │
│  └── 09 经营复盘  - 瓶颈诊断 + 唯一重点                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 🎯 核心框架

### 1. 资源盘点8类

| 类别 | 说明 | 示例 |
|------|------|------|
| **经验** | 专业技能和知识 | 10年设计经验 |
| **人群** | 服务过的客户类型 | 企业主、创业者 |
| **能力** | 可交付的具体能力 | UI设计、前端开发 |
| **关系** | 可求助的人脉 | 行业专家、投资人 |
| **渠道** | 已有的触达能力 | 公众号、小红书 |
| **资产** | 已有的可复用成果 | 模板、课程、工具 |
| **约束** | 时间和资源限制 | 每天3小时 |
| **硬性边界** | 绝对不能做的 | 不做销售 |

### 2. 三环定位框架

```
新杠杆 × 边界变动 × 资源匹配
     ↓
  利基市场
```

| 维度 | 说明 |
|------|------|
| **新杠杆** | AI、新平台、政策变化等结构性机会 |
| **边界变动** | 行业边界、信任边界、交付边界的变化 |
| **资源匹配** | 自身资源与机会的契合度 |

### 3. 6维机会评分

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| **市场规模** | 20% | 可触达的目标客户数量 |
| **竞争强度** | 15% | 现有竞争者数量和质量 |
| **资源匹配** | 25% | 与自身资源的匹配度 |
| **利润空间** | 20% | 单客户的利润贡献 |
| **增长潜力** | 10% | 市场增长预期 |
| **退出路径** | 10% | 未来变现可能性 |
