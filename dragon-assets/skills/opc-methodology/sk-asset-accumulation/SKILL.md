# OPC 08 资产沉淀 (Asset Accumulation)

> 阶段编号: 08
> 阶段类型: 触发阶段（取得成果后启用）
> 核心功能: 将成果转化为可复用资产，形成复利效应

## 🎯 L0: 一句话描述

**把个人成果转化为可复用资产：内容资产+方法论资产+客户资产+系统资产**

## 📋 L1: 使用场景

- 取得第一个客户后
- 有了可复用的成果后
- 需要提升效率时

## 📖 L2: 详细文档

### 四类资产详解

#### 1. 内容资产

| 资产类型 | 一次投入价值 | 可复用次数 | 制作成本 |
|---------|------------|-----------|---------|
| **深度文章** | 高 | 无数次 | 中 |
| **短视频** | 中 | 无数次 | 低 |
| **在线课程** | 高 | 无数次 | 高 |
| **电子书** | 高 | 无数次 | 中 |
| **播客** | 中 | 无数次 | 低 |

#### 2. 方法论资产

```
核心原则: 不要用手工换钱，要用方法论换钱

例:
手工服务: 1小时 = 500元
方法论: 写1次SOP = 500元 × N次使用
```

| 方法论类型 | 价值 | 复用场景 |
|-----------|------|---------|
| **流程SOP** | 节省时间 | 新客户入职 |
| **检查清单** | 避免错误 | 质量把控 |
| **模板工具** | 提升效率 | 重复任务 |
| **框架模型** | 批量复制 | 标准化交付 |

#### 3. 客户资产

```
客户资产 = 名单 + 案例 + 证言 + 触达渠道

积累方式:
1. 每服务一个客户，沉淀一个案例
2. 收集客户证言，用于下一轮转化
3. 记录客户来源，优化获客渠道
```

#### 4. 系统资产

```
自动化层级:
Level 1: 手动 → 文档化
Level 2: 文档化 → 模板化
Level 3: 模板化 → 工具化
Level 4: 工具化 → 自动化
```

### 资产优先级矩阵

```
┌─────────────────────────────────────────────────────────────┐
│                 资产沉淀优先级矩阵                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│     高杠杆 + 容易做 ──────────────── → 立即做           │
│     │                                                    │
│     │  例: 案例整理SOP                                 │
│     │       客户好评收集                                 │
│     │       朋友圈素材模板                               │
│     │                                                    │
│     ▼                                                    │
│                                                             │
│     高杠杆 + 难做 ──────────────── → 规划做              │
│     │                                                    │
│     │  例: 在线课程                                     │
│     │       工具产品                                     │
│     │       内容矩阵                                     │
│     │                                                    │
│     ▼                                                    │
│                                                             │
│     低杠杆 + 容易做 ──────────────── → 以后做           │
│     │                                                    │
│     │  例: 社交媒体美化                                 │
│     │       网站升级                                     │
│     │                                                    │
│     ▼                                                    │
│                                                             │
│     低杠杆 + 难做 ──────────────── → 不做               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 资产积累节奏

```
┌─────────────────────────────────────────────────────────────┐
│  创业初期 (0-6月)                                          │
│  ├── 重点: 客户资产 + 方法论资产                          │
│  ├── 目标: 10个案例 + 3个SOP                            │
│  └── 警惕: 不要做高成本内容资产                          │
├─────────────────────────────────────────────────────────────┤
│  成长期 (6-12月)                                           │
│  ├── 重点: 内容资产 + 系统资产                             │
│  ├── 目标: 1门课程 + 1个工具                           │
│  └── 警惕: 不要过度追求自动化                             │
├─────────────────────────────────────────────────────────────┤
│  稳定期 (12月+)                                            │
│  ├── 重点: 资产变现                                      │
│  ├── 目标: 被动收入 > 主动收入                          │
│  └── 警惕: 不要停止积累                                   │
└─────────────────────────────────────────────────────────────┘
```

## 🚀 命令

```bash
/opc-asset 开始资产沉淀
/opc-asset 内容 评估内容资产
/opc-asset 方法 评估方法论资产
/opc-asset 客户 评估客户资产
/opc-asset 系统 评估系统资产
/opc-asset 优先级 确定沉淀优先级
```
