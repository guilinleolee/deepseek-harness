# OPC 01 资源盘点 (Resource Inventory)

> 阶段编号: 01
> 阶段类型: 线性阶段
> 核心功能: 按8类盘点用户已有资源

## 🎯 L0: 一句话描述

**系统盘点个人8类资源：经验、人群、能力、关系、渠道、资产、约束、硬性边界**

## 📋 L1: 使用场景

- 刚开始规划一人企业
- 不确定自己有什么可以变现
- 需要全面梳理自身资源

## 📖 L2: 详细文档

### 8类资源盘点框架

```
┌─────────────────────────────────────────────────────────────┐
│                    资源盘点8类矩阵                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【存量资源】                                               │
│  ├── 1. 经验 - 专业技能和知识积累                          │
│  ├── 2. 人群 - 服务过的客户类型和了解                      │
│  ├── 3. 能力 - 可独立交付的具体能力                        │

│                                                             │
│  【触达资源】                                               │
│  ├── 5. 渠道 - 已有的用户触达能力                            │

│                                                             │
│  【约束条件】                                               │

│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 各类盘点要点

#### 1. 经验 (Experience)
- 专业领域的工作年限
- 经历过的关键项目
- 踩过的坑和学到的东西

#### 2. 人群 (People)
- 深度了解哪类客户
- 知道他们的真实需求
- 能用他们的语言沟通

#### 3. 能力 (Capability)
- 能独立交付什么
- 需要他人配合什么
- 哪些可以标准化

#### 4. 关系 (Relationship)
- 直接认识的人
- 能帮到你的人
- 可能成为客户的人

#### 5. 渠道 (Channel)
- 已有粉丝的平台
- 活跃的社群
- 可用的推广资源

#### 6. 资产 (Asset)
- 已有内容产品
- 沉淀的方法论
- 可复用的模板工具

#### 7. 约束 (Constraint)
- 可用时间
- 可用资金
- 技能缺口

#### 8. 硬性边界 (Hard Boundary)
- 绝对不做的事
- 底线和原则
- 不适合的客户类型

## 🚀 命令

```bash
/opc-resource 开始资源盘点
/opc-resource [类别] 盘点指定类别
/opc-resource 导出 导出盘点结果
```
