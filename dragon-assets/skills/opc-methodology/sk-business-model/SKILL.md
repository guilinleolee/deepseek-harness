# OPC 04 商业模式 (Business Model)

> 阶段编号: 04
> 阶段类型: 线性阶段
> 核心功能: Lean Canvas轻量化商业模式设计 + 高风险假设识别

## 🎯 L0: 一句话描述

**用Lean Canvas画布轻量化设计商业模式：问题→解决方案→关键指标→独特价值主张**

## 📋 L1: 使用场景

- 完成价值主张后
- 需要确定如何盈利
- 需要识别最大风险

## 📖 L2: 详细文档

### Lean Canvas vs 传统Business Plan

```
┌─────────────────────────────────────────────────────────────┐
│  Lean Canvas vs Business Plan                               │
├─────────────────────────────────────────────────────────────┤
│  Business Plan (传统)                                      │
│  ├── 30-50页文档                                          │
│  ├── 需要大量市场调研                                       │
│  ├── 适合投资人汇报                                        │
│  └── 周期：2-4周                                          │
│                                                             │
│  Lean Canvas (OPC推荐)                                      │
│  ├── 1页纸                                                │
│  ├── 基于假设                                              │
│  ├── 适合一人企业                                          │
│  └── 周期：2小时                                          │
└─────────────────────────────────────────────────────────────┘
```

### 高风险假设识别

```
┌─────────────────────────────────────────────────────────────┐
│  四类高风险假设（必须验证）                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 客户问题假设                                             │
│     ├── 真的有这个问题吗？                                  │
│     ├── 问题有多严重？                                      │
│     └── 他们愿意付费吗？                                    │
│                                                             │
│  2. 产品解决方案假设                                        │
│     ├── 这个方案真的解决问题吗？                            │
│     ├── 用户愿意用吗？                                      │
│     └── 使用门槛有多高？                                    │
│                                                             │
│  3. 增长假设                                               │
│     ├── 客户会主动推荐吗？                                  │
│     ├── 获客成本是多少？                                   │
│     └── 能否规模化？                                       │
│                                                             │
│  4. 商业化假设                                              │
│     ├── 定价合理吗？                                        │
│     ├── 客户支付意愿验证了吗？                              │
│     └── LTV > CAC吗？                                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 假设验证优先级

| 优先级 | 假设类型 | 验证方法 | 验证成本 |
|--------|---------|---------|---------|
| P0 | 客户问题存在 | 访谈10个客户 | 低 |
| P1 | 愿意付费 | 先收款再开发 | 零 |
| P2 | 产品有效 | MVP测试 | 中 |
| P3 | 可规模化 | 小规模测试 | 高 |

### 一页纸总结

```
┌─────────────────────────────────────────────────────────────┐
│  一句话商业模式                                              │
│  我们为[目标客户]提供[核心价值]，                          │
│  通过[触达方式]，赚取[收益模式]。                          │
│                                                             │
│  例: 我们为"5-10人创业公司"提供"一键发薪"服务，             │
│      通过"小红书内容营销"触达客户，                         │
│      赚取"月订阅费299元"。                                 │
└─────────────────────────────────────────────────────────────┘
```

## 🚀 命令

```bash
/opc-canvas 开始Lean Canvas
/opc-canvas 假设 识别高风险假设
/opc-canvas 验证 [假设名称] 验证指定假设
/opc-canvas 打印 输出Canvas完整版
```
