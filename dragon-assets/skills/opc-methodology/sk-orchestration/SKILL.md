# OPC 00 总编排 (Orchestration)

> 阶段编号: 00
> 阶段类型: 线性阶段
> 核心功能: 判断当前阶段与用户模式，组织整体流程，管控阶段边界

## 🎯 L0: 一句话描述

**判断用户当前阶段，启动对应的方法论流程，自动恢复上次进度**

## 📋 L1: 使用场景

- 用户首次启动一人企业规划
- 用户中断后继续上次进度
- 需要判断当前最应该做什么

## 📖 L2: 详细文档

### 核心职责

1. **阶段判断**
   - 评估用户当前处于方法论的哪个阶段
   - 识别用户已有的成果和进度
   - 确定下一步应该进入哪个阶段

2. **进度恢复**
   - 读取历史会话记录
   - 恢复之前的决策和产出
   - 确认用户是否需要回顾或继续

3. **模式识别**
   - 直通模式: 用户熟悉方法论，快速推进
   - 详细模式: 用户需要深入解释每一步
   - 教练模式: 用户需要更多引导和提问

### 8类资源确认清单

| 类别 | 关键问题 |
|------|---------|
| **经验** | 你最核心的专业经验是什么？ |
| **人群** | 你服务过或最了解哪类人？ |
| **能力** | 你能独立交付什么？ |
| **关系** | 你能直接联系谁？ |
| **渠道** | 你有哪些触达能力？ |
| **资产** | 你有哪些可复用的成果？ |
| **约束** | 你的时间和资源限制？ |
| **硬性边界** | 你绝对不能做什么？ |

### 执行流程

```
1. 询问用户熟悉度
   ↓
2. 根据熟悉度选择模式
   ↓
3. 读取历史进度（如有）
   ↓
4. 判断当前阶段
   ↓
5. 输出阶段判断 + 下一步建议
```

## 🚀 命令

```bash
/opc 开始一人企业规划
/opc-status 查看当前阶段
/opc-resume 恢复上次进度
```

## 📤 输出格式

```markdown
## 阶段判断

**当前阶段**: [阶段编号] [阶段名称]
**进度**: [已完成/进行中/未开始]
**模式**: [直通/详细/教练]

## 下一步建议

[具体的下一步行动]

## 历史记录摘要

[已完成的阶段和产出]
```
