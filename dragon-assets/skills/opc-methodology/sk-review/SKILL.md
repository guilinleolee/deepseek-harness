# OPC 09 经营复盘 (Business Review)

> 阶段编号: 09
> 阶段类型: 触发阶段（遇到瓶颈或定期）
> 核心功能: 诊断经营瓶颈，找到唯一重点，持续改进

## 🎯 L0: 一句话描述

**经营复盘找唯一重点：瓶颈在哪？该做什么？**

## 📋 L1: 使用场景

- 月度/季度常规复盘
- 遇到增长瓶颈时
- 需要做出重大决策前

## 📖 L2: 详细文档

### 唯一重点法则

```
┌─────────────────────────────────────────────────────────────┐
│  唯一重点法则                                              │
│                                                             │
│  问题: 什么都想做，结果什么都没做好                        │
│                                                             │
│  解法: 同一时间，只做一个唯一重点                         │
│                                                             │
│  如何找唯一重点:                                          │
│  1. 列出所有可能做的事                                   │
│  2. 问: 如果只做一件，能带来最大改变的是？               │
│  3. 那件事做好后，下一件影响最大的是什么？               │
│  4. 重复直到找到"唯一"                                  │
│                                                             │
│  例: 创业初期                                              │
│  唯一重点 = 找到一个愿意付费的客户                       │
│  → 找到了 → 唯一重点 = 服务好这个客户                   │
│  → 服务好了 → 唯一重点 = 找到下一个客户                  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 复盘频率

| 复盘类型 | 频率 | 时间 | 重点 |
|---------|------|------|------|
| **日复盘** | 每天 | 5分钟 | 今天做了什么？ |
| **周复盘** | 每周 | 30分钟 | 本周进展+下周重点 |
| **月复盘** | 每月 | 2小时 | 核心指标+瓶颈诊断 |
| **季复盘** | 每季 | 半天 | 战略回顾+方向调整 |

## 🚀 命令

```bash
/opc-review 开始经营复盘
/opc-review 日报 每日快速复盘
/opc-review 周报 每周定期复盘
/opc-review 月报 每月深度复盘
/opc-review 瓶颈 诊断当前瓶颈
/opc-review 唯一 确定唯一重点
```
