# OPC 06 转化闭环 (Conversion Loop)

> 阶段编号: 06
> 阶段类型: 触发阶段（06）
> 核心功能: 设计从触达到成交的完整转化路径

## 🎯 L0: 一句话描述

**设计转化闭环：触达→承接→信任→成交，步步为营**

## 📋 L1: 使用场景

- MVP验证成功后
- 需要规模化获客
- 转化率低需要优化

## 📖 L2: 详细文档

### 转化漏斗模型

```
┌─────────────────────────────────────────────────────────────┐
│                    转化漏斗                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│         触达 (100人)                                        │
│              ↓                                              │
│         承接 (30人)  ← 流失70%                             │
│              ↓                                              │
│         信任 (10人)  ← 流失20%                             │
│              ↓                                              │
│         成交 (3人)   ← 流失70%                             │
│              ↓                                              │
│         复购 (1人)   ← 流失66%                             │
│                                                             │
│  核心公式: 成交 = 触达 × 承接率 × 信任率 × 成交率          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 四步转化闭环

```
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 触达                                              │
│  ├── 渠道选择: 哪个渠道能找到目标客户？                    │
│  ├── 触达方式: 内容/广告/推荐？                             │
│  └── 触达成本: CAC上限是多少？                             │
├─────────────────────────────────────────────────────────────┤
│  Step 2: 承接                                              │
│  ├── 第一印象: 第一眼给客户什么感觉？                       │
│  ├── 价值匹配: 如何让客户快速知道你能帮他？                 │
│  └── 门槛设计: 如何降低客户尝试成本？                       │
├─────────────────────────────────────────────────────────────┤
│  Step 3: 信任                                              │
│  ├── 信任来源: 为什么相信你？                               │
│  ├── 证明材料: 有什么证据？                                │
│  └── 风险消除: 如何消除购买顾虑？                           │
├─────────────────────────────────────────────────────────────┤
│  Step 4: 成交                                              │
│  ├── 成交时机: 什么时候推客户一把？                         │
│  ├── 成交方式: 如何让他现在就付款？                         │
│  └── 追销设计: 首次成交后如何追销？                       │
└─────────────────────────────────────────────────────────────┘
```

### 信任建立矩阵

| 信任类型 | 建立方式 | 成本 |
|---------|---------|------|
| **专家信任** | 输出专业内容、案例展示 | 低 |
| **社会信任** | 客户评价、推荐、案例 | 中 |
| **平台信任** | 第三方背书、平台认证 | 中 |
| **关系信任** | 一对一沟通、建立连接 | 高 |

### 追销体系设计

```
┌─────────────────────────────────────────────────────────────┐
│  首次成交后的追销路径                                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  新客户 → 欢迎序列(3-7天) → 激活产品价值                   │
│      ↓                                                      │
│  已激活 → 升级销售(30天) → 推荐更高价值                     │
│      ↓                                                      │
│  已付费 → 交叉销售(60天) → 相关产品推荐                     │
│      ↓                                                      │
│  高满意 → 推荐计划(90天) → 激励转介绍                       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 转化率基准

| 阶段 | 优秀 | 良好 | 平均 | 需优化 |
|------|------|------|------|--------|
| **触达→承接** | 50%+ | 30%+ | 15%+ | <15% |
| **承接→信任** | 50%+ | 30%+ | 20%+ | <20% |
| **信任→成交** | 30%+ | 15%+ | 5%+ | <5% |
| **成交→复购** | 50%+ | 30%+ | 20%+ | <20% |
