# OPC 03 价值主张 (Value Proposition)

> 阶段编号: 03
> 阶段类型: 线性阶段
> 核心功能: 用Jobs/Pains/Gains框架描述客户价值

## 🎯 L0: 一句话描述

**用Jobs/Pains/Gains框架描述客户价值：客户要做什么、痛在哪里、乐是什么**

## 📋 L1: 使用场景

- 完成利基定位后
- 需要明确具体提供什么价值
- 需要说服目标客户

## 📖 L2: 详细文档

### Jobs/Pains/Gains框架

```
┌─────────────────────────────────────────────────────────────┐
│                 价值主张设计框架                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【功能性Jobs】                                             │
│  客户需要完成的具体任务                                     │
│  例：我要管理10人小团队的发薪                               │
│                                                             │
│  【情感性Jobs】                                             │
│  客户希望感受到的情绪                                       │
│  例：我想让员工觉得公司专业                                 │
│                                                             │
│  【社会性Jobs】                                             │
│  客户希望在他人眼中的形象                                   │
│  例：我想让同行觉得我管理有方                               │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【Pains - 痛点】                                          │
│  当前解决方案的问题、风险、成本                             │
│  ├── 严重痛点（必须解决）                                  │
│  ├── 频繁痛点（经常遇到）                                  │
│  └── 情绪痛点（让人沮丧）                                  │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【Gains - 收益】                                          │
│  客户期望的积极结果                                         │
│  ├── 期望收益（主动追求）                                  │
│  ├── 必要收益（最低标准）                                  │
│  └── 超预期收益（惊喜加分）                                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### Pain-Gain连接设计

```
痛点 ──────── 收益桥 ──────── 你的解决方案

例：
痛点：发薪日要手动算3小时 → 收益：每月省3小时 → 你的方案：自动算薪
痛点：员工总问工资明细 → 收益：自助查询 → 你的方案：自助查询系统
```

### 反向价值主张（先卖后买）

```
┌─────────────────────────────────────────────────────────────┐
│  传统路径: 做出产品 → 找客户                               │
│  OPC路径:  找到客户 → 卖出去 → 再做产品                   │
│                                                             │
│  核心问题: 客户为什么现在必须解决这个问题？                  │
│                                                             │
│  5个关键问题:                                              │
│  1. 他们现在在用什么替代方案？                            │
│  2. 那个方案哪里不好用？                                  │
│  3. 他们愿意为更好的方案付多少钱？                        │
│  4. 他们在哪里可以看到你的方案？                          │
│  5. 他们的决策周期有多长？                                │
└─────────────────────────────────────────────────────────────┘
```

## 🚀 命令

```bash
/opc-value 开始价值主张设计
/opc-value jobs 分析Jobs
/opc-value pains 分析痛点
/opc-value gains 分析收益
/opc-value 桥接 Pain-Gain连接
/opc-value 反向 先卖后买测试
```
