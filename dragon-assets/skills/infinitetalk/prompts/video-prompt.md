# InfiniteTalk 视频提示词模板

## L0: 一句话描述 (≤15字)
唇形同步口播视频提示词模板库

## L1: 使用场景 (50-100字)
提供多种场景的口播视频提示词模板，支持产品介绍、品牌代言、培训讲解等场景。通过预设模板快速生成高质量口播内容，配合InfiniteTalk实现音频驱动的唇形同步视频生成。

## L2: 详细模板

### 一、通用模板

#### 基础提示词模板

```
A person speaking naturally, [描述说话内容],
[面部表情], [头部动作],
[光照条件], [背景环境],
high quality, realistic, lip-sync
```

#### 中文优化模板

```

[表情描述]，

[光线描述]，

```

### 四、负面提示词模板

#### 4.1 唇形同步负面提示词

```
避免以下情况：
- blurry, distorted, artifacts（模糊、扭曲、伪影）
- unnatural lip movement（非自然唇形运动）
- animation, cartoon, anime style（动画、卡通风格）
- low quality, poor rendering（低质量渲染）
- face deformation（面部变形）
- incorrect lip sync（错误的唇形同步）
- multiple faces visible（多个人脸可见）
- cropped face, partial face（面部被裁剪）
```

#### 4.2 完整负面提示词建议

```
blurry, low quality, distorted, artifacts,
animation, cartoon, anime, 3D render,
poor lip sync, unnatural mouth movement,
face deformation, facial distortion,
multiple people, extra limbs,
watermark, text overlay, logo,
low resolution, pixelated,
artificial, fake, uncanny valley,
nightmare, horror, creepy,
nsfw, inappropriate content
```

### 五、参数调优建议

#### 5.1 唇形同步质量

| 场景 | `sample_audio_guide_scale` | `sample_text_guide_scale` |
|------|--------------------------|--------------------------|
| 纯语音口播 | 4.0-5.0 | 1.0-2.0 |
| 带背景音 | 3.0-4.0 | 2.0-3.0 |
| 音乐节奏 | 2.0-3.0 | 2.0-3.0 |
| 唱歌 | 5.0 | 0.5 |

#### 5.2 头部动作幅度

| 场景 | `motion_frame` 推荐值 | 说明 |
|------|---------------------|------|
| 新闻播报 | 9-13 | 稳定为主 |
| 产品介绍 | 7-9 | 适度动感 |
| 激情演讲 | 5-7 | 动感强烈 |
| 虚拟主播 | 5-9 | 活泼动感 |

#### 5.3 分辨率选择

| 分辨率 | `size` 参数 | 适用场景 |
|--------|------------|---------|
| 480P | `infinitetalk-480` | 社交媒体、批量生成 |
| 720P | `infinitetalk-720` | 正式场合、高质量输出 |

### 七、模板使用流程

```
1. 场景识别 → 确定视频类型（产品/培训/品牌/新闻）
2. 模板选择 → 从场景库选择最匹配模板
3. 个性化调整 → 根据具体内容微调描述词
4. 情感标注 → 添加情绪模板元素
5. 负面提示 → 附加质量保证负面提示词
6. InfiniteTalk生成 → 配合音频生成视频
7. 质量检查 → 验证唇形同步效果
```
