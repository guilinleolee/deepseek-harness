## 项目原则

### 9条治理规则（天龙增强版）

1. **Library-First**: 每个功能先做独立库
   - 库必须有CLI接口
   - 库必须有完整测试
   - 库必须版本化管理

2. **CLI Interface**: 所有功能必须有CLI接口
   - 使用typer/click框架
   - 提供--help文档
   - 支持JSON/YAML输出

3. **Test-First**: 任何实现必须先有测试
   - 先写失败的测试
   - 再写最小实现
   - 持续重构

4. **Single Source of Truth**: 规范是唯一的真相
   - 规范文档 > 代码注释
   - 规范变更需要评审
   - 代码必须符合规范

5. **Drift Detection**: 规范-实现漂移必须检测
   - 每次PR必须检查漂移
   - 漂移超过阈值必须修复
   - 定期全量检查

6. **Incremental Compliance**: 渐进式符合规范
   - 新代码必须符合规范
   - 遗留代码逐步迁移
   - 技术债务可见化管理

7. **Human-in-the-Loop**: 关键决策必须人工确认
   - 架构变更
   - 依赖升级
   - 安全相关

8. **Agent-Agnostic**: 支持多种AI Agent
   - Claude Code
   - Gemini CLI
   - Cursor
   - 等26种Agent

9. **Observable**: 所有操作必须可观测
   - 日志记录
   - 指标采集
   - 链路追踪
