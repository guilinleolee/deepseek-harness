## Actions

### 1. 设备性能评估

#### 性能分级

| 等级 | 设备类型 | CPU | RAM | 量化推荐 |
|------|----------|-----|-----|----------|
| **T1 旗舰** | 高端手机/PC | 8+ 核 | 8GB+ | float16 / int8 |
| **T2 高端** | 中端手机/Pi 4 | 4-8 核 | 4-8GB | int8 |
| **T3 主流** | 入门手机/Pi 3 | 2-4 核 | 1-2GB | int8 / int4 |
| **T4 极限** | 低端设备/IoT | 1-2 核 | 512MB-1GB | int4 |

#### 性能指标

```
┌─────────────────────────────────────────────────────────────┐
│ 实时因子 (RTF) = 推理时间 / 音频时长                      │
├─────────────────────────────────────────────────────────────┤
│ RTF < 0.1  - 实时性优秀 ✓                                │
│ RTF 0.1-0.5 - 基本实时 ○                                │
│ RTF 0.5-1.0 - 接近实时 △                                │
│ RTF > 1.0  - 非实时 ✗                                   │
└─────────────────────────────────────────────────────────────┘
```

### 2. 量化配置优化

#### 量化级别对比

| 量化 | 精度损失 | 内存节省 | 速度提升 | 适用场景 |
|------|---------|---------|---------|---------|
| **float32** | 无 | 基准 | 基准 | 服务器/高精度场景 |
| **float16** | ~1% | 50% | 30-50% | 高端边缘设备 |
| **int8** | ~3% | 75% | 50-70% | **推荐默认** |
| **int4** | ~8% | 87.5% | 70-90% | 极低内存设备 |

#### 量化配置推荐

```yaml
# 高端设备 (T1-T2)
quantization: float16
threads: 4-8
batch_size: 1
memory_mapped: false

# 主流设备 (T3)
quantization: int8
threads: 2-4
batch_size: 1
memory_mapped: true

# 极限设备 (T4)
quantization: int4
threads: 1-2
batch_size: 1
memory_mapped: true
preload: false
```

### 4. 流式推理实现

#### 流式架构

```
┌─────────────────────────────────────────────────────────────┐
│ 流式推理数据流                                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  文本输入                                                   │
│      │                                                      │
│      ▼                                                      │
│  ┌─────────────┐                                            │
│  │  文本分词  │  ──► Token 1, Token 2, ...               │
│  └─────────────┘                                            │
│      │                                                      │
│      ▼                                                      │
│  ┌─────────────┐                                            │
│  │  首 token   │  ──► 立即输出首音频块                      │
│  └─────────────┘                                            │
│      │                                                      │
│      ▼                                                      │
│  ┌─────────────┐                                            │
│  │  增量生成   │  ──► 持续输出音频块 (chunk_size_ms)        │
│  └─────────────┘                                            │
│      │                                                      │
│      ▼                                                      │
│  ┌─────────────┐                                            │
│  │  音频合并   │  ──► 连续音频流                           │
│  └─────────────┘                                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 流式配置

```yaml
streaming:
  enabled: true
  chunk_size_ms: 50-200    # 越小延迟越低, 开销越大
  lookahead_tokens: 5        # 预生成 token 数
  buffer_size: 3            # 环形缓冲区大小
```

### 5. 延迟优化

#### 延迟构成

| 阶段 | 占比 | 优化方法 |
|------|------|---------|
| **模型加载** | 10-30% | Memory Mapping, 模型分片 |
| **首 token** | 20-40% | 预热, 轻量首层 |
| **增量生成** | 30-50% | KV Cache, 批量处理 |
| **音频合成** | 10-20% | GPU 加速, DSP 优化 |

#### 优化策略矩阵

| 策略 | 延迟降低 | 内存增加 | 适用场景 |
|------|---------|---------|---------|
| **预热** | 30-50% | +50MB | 连续推理 |
| **KV Cache** | 40-60% | +100MB | 长文本 |
| **GPU 加速** | 50-80% | +500MB | 支持 GPU 设备 |
| **流式输出** | 感知延迟↓ | 0 | 实时交互 |
| **模型精简** | 30-50% | -50% | 极端场景 |

## Rules

### 基础规则

1. **实时优先**: RTF 必须 < 1.0，推荐 < 0.3
2. **内存安全**: 预留 20% 内存作为缓冲
3. **渐进优化**: 先量化, 再流式, 最后硬件加速
4. **测试验证**: 优化后必须测试 RTF 和内存

### 优化顺序

```
Step 1: 量化配置 (int8 起步)
    ↓
Step 2: 内存映射 (如果支持)
    ↓
Step 3: 流式推理 (降低感知延迟)
    ↓
Step 4: 硬件加速 (GPU/DSP)
    ↓
Step 5: 模型精简 (如仍不满足)
```

### 配置检查清单

| 检查项 | 标准 | 状态 |
|--------|------|------|
| RTF | < 0.3 | □ |
| 首 token 延迟 | < 500ms | □ |
| 内存峰值 | < 80% 可用 | □ |
| 模型加载 | < 5s | □ |
| 流式延迟 | < 100ms/chunk | □ |

## Tips

### 快速诊断

```bash
# 检查设备性能
python3 edge_deploy.py check

# 测试实际 RTF
python3 benchmark.py --device cpu --duration 30

# 内存压力测试
python3 stress_test.py --memory-limit 1024
```

### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| RTF > 1 | 量化不足/线程过少 | int4 或增加 threads |
| OOM | 内存不足 | 减小 buffer, 禁用 preload |
| 首 token 慢 | 模型未预热 | 启用预热, memory mapping |
| 流式卡顿 | chunk 过大 | 减小 chunk_size_ms |

### 性能监控

```python
# 启用性能日志
config.logging.performance_logging = True

# 实时监控
watch_perf.py --rtf --memory --interval 1s
```
