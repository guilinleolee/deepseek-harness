# Publish Template Workflow

> 模板发布工作流

## 触发条件

用户要求将模板发布到市场时触发。

## 工作流程

### Step 1: 准备模板

检查模板是否完整：
- design_spec.md
- 必要的资源文件
- 预览图

### Step 2: 添加元数据

添加发布信息：
- 名称
- 描述
- 标签
- 分类
- 截图

### Step 3: 质量检查

自动检查：
- 格式正确性
- 内容完整性
- 品牌合规性

### Step 4: 发布

发布到模板市场。

### Step 5: 评分开启

开启用户评分功能。
