# Title Generator

> 智能标题生成器 - 为演示文稿生成多种风格的标题

## 模块定位

本模块用于生成专业演示文稿的标题选项，支持多种风格和策略。

## 标题风格

### 1. 按场景分类

| 场景 | 风格特点 | 示例 |
|------|----------|------|
| 商业汇报 | 专业、简洁、数据驱动 | "2024Q3营收同比增长25%" |
| 产品发布 | 创新、震撼、引领趋势 | "重新定义智能办公" |
| 技术分享 | 专业、深度、易于理解 | "AI驱动的架构优化实践" |
| 学术答辩 | 规范、严谨、逻辑清晰 | "基于深度学习的图像识别研究" |
| 营销提案 | 吸引力强、差异化、行动导向 | "逆势增长：细分市场突破策略" |

### 2. 按表达策略

| 策略 | 特点 | 适用内容 |
|------|------|----------|
| 数字驱动 | 具体、可信、有冲击力 | 数据汇报、效果展示 |
| 问题导向 | 引发思考、痛点共鸣 | 痛点分析、解决方案 |
| 趋势宣言 | 引领感、未来感 | 战略发布、趋势预测 |
| 成果展示 | 成就导向、正向激励 | 业绩汇报、成果展示 |
| 对比反差 | 戏剧性、差异化 | 方案对比、改革展示 |

## 标题生成算法

### 1. 标题公式

```
标题 = [定语] + [核心词] + [修饰语] + [结果/价值]
```

### 2. 常用结构

| 结构 | 公式 | 示例 |
|------|------|------|
| 数字+结果 | "[N个X]实现[成果]" | "3大策略实现增长200%" |
| 问题+方案 | "[痛点]→[解决方案]" | "效率低？新系统帮你提速3倍" |
| 对比+亮点 | "从[A]到[B]的跨越" | "从传统到智能的跨越" |
| 趋势+宣言 | "[行业/领域]的[趋势]" | "AI赋能企业数字化转型" |
| 成果+数据 | "[核心成果]：[数据]" | "用户增长500万的背后逻辑" |

## 标题评分系统

### 评分维度

| 维度 | 权重 | 评估标准 |
|------|------|----------|
| 清晰度 | 25% | 信息明确，无歧义 |
| 吸引力 | 25% | 引发兴趣，激发点击 |
| 专业度 | 20% | 措辞得体，符合场景 |
| 简洁度 | 15% | 长度适中，不过冗长 |
| SEO友好 | 15% | 包含关键词，便于搜索 |

### 评分标准

| 分数 | 等级 | 说明 |
|------|------|------|
| 90-100 | 优秀 | 完美标题 |
| 80-89 | 良好 | 优秀标题，可直接使用 |
| 70-79 | 可用 | 合格标题，可微调使用 |
| 60-69 | 待优化 | 需要修改 |
| <60 | 不合格 | 不建议使用 |

## 标题优化规则

### 应该做

✅ 使用阿拉伯数字（更醒目）
✅ 使用动词（更有力）
✅ 包含关键词（便于理解）
✅ 保持简洁（8-20字最佳）

### 不应该做

❌ 使用模糊表达（"一些进展"）
❌ 过度夸张（"史上最牛"）
❌ 冗长啰嗦（超过25字）
❌ 堆砌术语（晦涩难懂）

## 集成说明

### 与 Strategist 集成

在 Strategist 阶段的内容分析中，自动调用标题生成器：

```python
async def strategist_phase(source_content):
    # 1. 分析源文档
    analysis = analyze_source(source_content)

    # 2. 生成标题选项
    title_options = generate_title_options(
        content=analysis.key_content,
        scenario=analysis.scenario
    )

    # 3. 结构建议
    structure = suggest_structure(analysis)

    # 4. 输出 design_spec
    return DesignSpec(
        title_options=title_options,
        structure=structure,
        ...
    )
```
