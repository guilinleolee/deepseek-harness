## 4. AI-Enhanced Search Protocol
When tasked with a complex workflow, follow this "External First" logic:
1. **Search**: Use `WebSearch` with specific node combinations (e.g., `n8n workflow Gmail to Notion with AI filtering`).
2. **Fetch**: Locate a raw JSON or detailed description on GitHub or n8n.io.
3. **Analyze**: Compare retrieved logic with current `n8n-skill` node documentation.
4. **Adapt**: Modify the JSON structure to match the user's specific requirements and environment.
