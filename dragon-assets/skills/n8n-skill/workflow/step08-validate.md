## 验证规则

### 节点级验证

```yaml
必需字段:
  - id: 唯一标识符
  - name: 节点名称
  - type: 节点类型
  - typeVersion: 版本号
  - position: 坐标位置

连接验证:
  - 源节点存在
  - 目标节点存在
  - 连接类型有效 (main/ai)
  - 索引在范围内

凭据验证:
  - 凭据类型匹配
  - 凭据 ID 存在
  - OAuth 已授权
```

### 表达式验证

```javascript
// 常见错误模式
const errors = [
  {
    pattern: /{{.*\{\{.*\}\}.*}}/,
    message: "嵌套表达式语法错误"
  },
  {
    pattern: /\$\[[^\]]+\]\.\w+/,
    message: "节点引用格式错误，应使用 $node.name"
  },
  {
    pattern: /{{\s*\w+\.\w+\s*}}/,
    message: "可能需要安全访问 ?. "
  }
];

// 验证函数
function validateExpression(expr) {
  for (const error of errors) {
    if (error.pattern.test(expr)) {
      return { valid: false, message: error.message };
    }
  }
  return { valid: true };
}
```
