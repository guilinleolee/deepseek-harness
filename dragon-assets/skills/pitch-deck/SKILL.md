# Pitch Deck - 融资路演PPT生成

## Overview

融资路演是创业公司获取资金的敲门砖。本技能提供投资人视角的PPT生成能力，支持种子轮/A轮/B轮多阶段融资场景，与天龙xlsx技能深度集成。

## 路演阶段

### 种子轮 (Seed)

```bash
# 创建种子轮路演
pitch-deck new --stage seed --company "示例公司"

# 种子轮核心结构
# - 一句话介绍
# - 问题痛点
# - 解决方案
# - 市场规模
# - 商业模式
# - 团队介绍
# - 融资需求
```

### A轮 (Series A)

```bash
# 创建A轮路演
pitch-deck new --stage a --company "示例公司"

# A轮核心结构
# - 公司愿景
# - 问题痛点（数据支撑）
# - 解决方案（产品截图）
# - 市场机会（TAM/SAM/SOM）
# - 商业模式
# - 竞争优势（护城河）
# - 运营数据（MRR/ARR/用户数）
# - 团队介绍
# - 融资需求
# - 里程碑规划
```

### B轮 (Series B)

```bash
# 创建B轮路演
pitch-deck new --stage b --company "示例公司"

# B轮核心结构
# - 业绩回顾
# - 市场领导力
# - 规模化能力
# - 单位经济模型（LTV/CAC/Payback）
# - 竞争格局
# - 战略规划
# - 团队升级
# - 融资需求
# - 退出路径
```

## 市场规模分析 (TAM/SAM/SOM)

### 市场规模模板

```bash
# 生成市场规模分析
pitch-deck market --tam "全球市场" --sam "目标市场" --som "可服务市场"

# TAM/SAM/SOM金字塔
# TAM: 全部潜在市场（最大）
# SAM: 目标细分市场
# SOM: 可立即服务的市场
```

### 市场规模数据来源

```bash
# 市场数据来源优先级
# 1. 权威报告（Gartner, Forrester, McKinsey）
# 2. 行业协会数据
# 3. 公开财务数据推算
# 4. 第三方研究机构
```

## 竞品分析

### 竞争格局图

```bash
# 生成竞争格局图
pitch-deck competitor --matrix "功能维度" --players "竞品A,竞品B,竞品C"

# 竞品分析维度
# - 功能覆盖
# - 价格策略
# - 目标客户
# - 技术实力
# - 市场渠道
```

### 差异化定位

```bash
# 生成差异化矩阵
pitch-deck differentiate --us "我们的优势" --them "竞品劣势"
```

## 财务预测摘要

### 关键指标

```bash
# 生成财务摘要
pitch-deck financials --revenue "收入预测" --costs "成本结构" --margin "利润率"

# 核心指标
# - MRR/ARR（月度/年化经常性收入）
# - 毛利率
# - CAC（客户获取成本）
# - LTV（客户终身价值）
# - LTV/CAC比率
# - Payback Period（回收期）
# - 增长率
```

### 三表联动预测

```bash
# 引用财务模型数据
pitch-deck financials --link "financial-model.xlsx"

# 联动数据
# IS利润表 → 收入预测
# BS资产负债表 → 资产结构
# CF现金流量表 → 融资需求
```

## 团队介绍模板

### 创始人档案

```bash
# 生成创始人介绍
pitch-deck team founder --name "姓名" --role "职位" --background "背景"

# 创始人要点
# - 教育背景（名校+理工科加分）
# - 行业经验（相关行业加分）
# - 过往成就（可量化）
# - 关键人脉（行业资源）
```

### 团队矩阵

```bash
# 生成团队总览
pitch-deck team overview --members "CEO,CTO,COO,CFO"
```

## 命令速查

```bash
# 创建路演
pitch-deck new --stage seed/a/b --company "公司名"

# 添加页面
pitch-deck add-slide --section problem/solution/market/business/team/financials

# 生成市场规模
pitch-deck market --tam "金额" --sam "金额" --som "金额"

# 竞品分析
pitch-deck competitor --players "竞品A,竞品B"

# 财务摘要
pitch-deck financials --link model.xlsx

# 团队介绍
pitch-deck team founder --name "姓名" --role "职位"

# 导出
pitch-deck export --format pptx/pdf
```
