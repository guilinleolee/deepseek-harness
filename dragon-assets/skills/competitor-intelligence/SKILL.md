# Competitor Intelligence - 竞品情报技能

基于天龙dragon-scraper + agent-reach技术栈构建的专业竞品情报技能，无需第三方API费用。

## 核心能力

| 功能 | 描述 | 平台支持 |

## 工作流

### Workflow 1: 竞品发现

```
任务进度:
- [ ] Step 1: 用户输入品牌/行业关键词
- [ ] Step 2: 多平台搜索相关品牌/商家
- [ ] Step 3: 提取竞品列表（名称、规模、市场占有率）
- [ ] Step 4: 竞品分级（直接竞品/间接竞品/潜在竞品）
- [ ] Step 5: 生成竞品全景图
```

### Workflow 2: 定价策略分析

```
任务进度:
- [ ] Step 1: 用户输入竞品列表或产品关键词
- [ ] Step 2: 采集竞品价格数据（历史+实时）
- [ ] Step 3: 价格对比分析（价格区间、折扣策略）
- [ ] Step 4: 定价策略推测（成本导向/竞争导向/价值导向）
- [ ] Step 5: 生成定价建议
```

### Workflow 3: 广告策略监测

```
任务进度:
- [ ] Step 1: 用户输入竞品品牌
- [ ] Step 2: 监测各平台广告投放
- [ ] Step 3: 分析广告创意、投放时间、目标受众
- [ ] Step 4: 推测广告预算和策略
- [ ] Step 5: 生成广告情报报告
```

### Workflow 4: 内容策略分析

```
任务进度:
- [ ] Step 1: 用户输入竞品社媒账号
- [ ] Step 2: 采集竞品内容数据（帖子、视频、评论）
- [ ] Step 3: 分析内容主题、发布频率、互动数据
- [ ] Step 4: 识别爆款内容和内容策略
- [ ] Step 5: 生成内容策略报告
```

### Workflow 5: 评论情感分析

```
任务进度:
- [ ] Step 1: 用户输入竞品产品/服务
- [ ] Step 2: 采集用户评论数据
- [ ] Step 3: 情感分析（正面/负面/中性）
- [ ] Step 4: 提取用户痛点和满意度
- [ ] Step 5: 生成用户洞察报告
```

## 竞品分析模型

### 竞品分级矩阵

```
          │ 高市场重叠
          │
    直接竞品 │ 潜在威胁
  (重点关注) │(定期监测)
────────────┼────────────
    间接竞品 │ 可忽略
  (季度回顾) │(年度回顾)
          │
          │ 低市场重叠
```

### 竞争强度评分

```
竞争强度 = (市场重叠度 × 0.3) + (价格竞争 × 0.25) +
           (内容竞争 × 0.2) + (用户争夺 × 0.15) +
           (渠道竞争 × 0.1)

解释:
- > 7分: 激烈竞争，需重点应对
- 4-7分: 中等竞争，保持关注
- < 4分: 低竞争，适度关注
```

## 常见问题

### Q: 如何确保数据的时效性？
A: 系统支持定时监测（每日/每周），并在数据变化时推送提醒。

### Q: 如何处理竞品数据不完整？
A: 系统会标注数据完整度，建议参考多方数据源综合分析。

### Q: 如何保护自己的竞品情报不被分析？
A: 系统仅采集公开数据，无法访问私密账号或后台数据。
