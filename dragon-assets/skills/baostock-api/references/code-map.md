## 代码转换函数

```python
def to_baostock_code(code: str, market: str = None) -> str:
    """
    转换为 Baostock 格式代码

    Args:
        code: 股票代码，如 '600519' 或 '600519.SH'
        market: 市场，如 'sh', 'sz'

    Returns:
        Baostock 格式代码，如 'sh.600519'
    """
    code = code.strip().upper()

    # 已经是 baostock 格式
    if '.' in code:
        return code

    # 去掉后缀
    code = code.replace('.SH', '').replace('.SZ', '').replace('.HK', '')

    # 根据代码判断市场
    if market is None:
        if code.startswith('6'):
            market = 'sh'
        elif code.startswith(('0', '3')):
            market = 'sz'
        elif code.startswith(('4', '8')):
            market = 'bj'
        else:
            market = 'sh'

    return f"{market}.{code}"
```
