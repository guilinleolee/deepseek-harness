# Legal Clinic - 法律诊所技能包

## L0: 一句话描述 (≤15字)
法律常识普及，基础咨询引导

## L1: 使用场景 (50-100字)
当需要进行法律常识普及、基础法律咨询引导、法律自助服务指导，或需要帮助当事人了解诉讼流程和权利救济途径时，使用本技能包。支持民事、刑事、行政、劳动、婚姻家庭五大基础法律领域。

## L2: 详细文档

### 核心能力

| 技能 | 功能 | 核心能力 |
|------|------|---------|
| **intake** | 来访接待 | 诉求收集+问题分类+紧急程度评估 |
| **legal-education** | 法律教育 | 法律知识普及+权利义务说明+程序告知 |
| **self-help-guide** | 自助指引 | 诉讼流程指引+材料清单+格式模板 |
| **referral** | 转介分流 | 专业领域识别+转介建议+对接指引 |
| **hotline-script** | 热线话术 | 标准话术+情绪安抚+专业转接 |
| **rights-explanation** | 权利说明 | 当事人权利告知+救济途径说明+时效提示 |

### IRAC分析框架

所有法律分析遵循IRAC框架：

```
Issue（问题）→ Rule（规则）→ Application（适用）→ Conclusion（结论）
```

### 置信度分级

| 标记 | 含义 | 使用场景 |
|------|------|---------|
| `[CONFIRMED]` | 确认 | 现行法律/司法解释 |
| `[LIKELY]` | 可能 | 主流观点/倾向性意见 |
| `[UNCERTAIN]` | 不确定 | 存在争议/理论分歧 |
| `[VERIFY]` | 需核实 | 地方规定/最新动态 |

### 核心命令

```bash
# 来访接待
/legal-clinic intake --type civil/labor/marriage --urgency high/normal/low

# 法律教育
/legal-clinic educate --topic "劳动合同" --level basic/intermediate

# 自助指引
/legal-clinic guide --procedure arbitration/litigation --step 1-6

# 转介分流
/legal-clinic refer --case-type complex/simple --reason "超出能力范围"

# 热线话术
/legal-clinic hotline --emotion calm/urgent/hostile --script standard
```

|----------|---------|---------|

## L2扩展

### 五大基础法律领域

```
1. 民事法律
   - 合同纠纷（买卖、租赁、借贷）
   - 侵权责任（人身、财产）
   - 婚姻家庭（离婚、抚养、继承）

2. 劳动法律
   - 劳动合同（签订、履行、解除）
   - 工资福利（拖欠、加班、解约补偿）
   - 社会保险（工伤、失业、养老保险）

3. 刑事法律
   - 报案指引（证据保存、立案条件）
   - 被害人权利（附带民事诉讼）
   - 在押人员权利（家属须知）

4. 行政法律
   - 行政复议（60日申请期限）
   - 行政诉讼（6个月起诉期限）
   - 国家赔偿

5. 婚姻家庭
   - 结婚离婚（协议/诉讼）
   - 子女抚养（抚养费、探望权）
   - 财产分割（共同财产、个人财产）
```

### 自助服务清单

```
□ 劳动争议自助
  □ 收集证据清单（劳动合同、工资条、社保记录）
  □ 劳动仲裁申请书格式
  □ 仲裁委联系方式查询

□ 民事诉讼自助
  □ 起诉状格式模板
  □ 证据目录编制
  □ 诉讼费计算

□ 婚姻家事自助
  □ 离婚协议要点
  □ 子女抚养方案
  □ 财产申报清单

□ 消费维权自助
  □ 投诉渠道选择（消协/市监/法院）
  □ 证据保全方法
  □ 赔偿计算标准
```

### 转介判断标准

| 判断维度 | 可自行处理 | 需要转介 |
|----------|-----------|---------|
| 复杂程度 | 单一法律关系 | 多重法律关系交叉 |
| 标的金额 | 金额较小 | 金额重大 |
| 证据状况 | 证据充分 | 证据缺失复杂 |
| 当事人 | 双方争议不大 | 对方委托律师 |
| 程序阶段 | 一审阶段 | 二审/再审/执行 |
