# Infographic Designer 技能使用说明

本技能允许 Claude 充当顶级平面设计师，利用 **Tailwind CSS** 和 **瑞士设计美学** 自动生成并导出专业海报。

## 核心优势
- **全自动化**：你只需提供文案，Claude 会自动完成设计、HTML 生成、文件保存以及截图。
- **品牌固化**：自动注入“卡巴格企业管理培训”水印、页眉和标语。
- **即拿即用**：生成的 PNG 图片直接保存在本地，无需手动操作浏览器。

## 存储规范
所有生成的文件将按照以下路径存放：
- **HTML 源码**：`D:/文生图/HTML/{YYYYMMDDHHmm}.html`
- **高清截图**：`D:/文生图/截图/{YYYYMMDDHHmm}.png`

## 如何使用

### 1. 启动任务
直接发送文案给 Claude，例如：
> "使用 infographic-designer 技能，生成关于『时间管理系统』的海报：..."

### 2. 自动化执行
Claude 将自动：
1. 获取当前时间戳。
2. 调用 `swiss-long-poster.html` 模板生成代码。
3. 写入 D 盘指定目录。
4. 调用 `playwright-skill` 截图。

### 3. 获取结果
任务完成后，Claude 会直接给出图片的本地路径，你可以直接打开查看。

## 故障排除
- 如果截图失败，请确保 `playwright-skill` 已正确安装且 D 盘路径可写。
- 若需修改品牌文字，请直接联系管理员修改 `SKILL.md`。
