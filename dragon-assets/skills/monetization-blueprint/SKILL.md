│     ├── 缺点: 收入天花板低，需要持续获取新客户              │

│     ├── 优点: 收入与价值成正比，客户接受度高               │
│     ├── 缺点: 收入不稳定，需要精细化计费系统               │
│     ├── 适合: API服务，AI产品，存储服务                     │
│     └── 定价: $0.001/次 或 $10/1000次                     │

### 单位经济模型

```markdown
## 单位经济模型 (Unit Economics)

### 核心指标
| 指标 | 公式 | 健康值 |
|------|------|--------|
| CAC | 获客总成本 / 新客数 | < LTV/12 |
| LTV | ARPU × 续费率 × 平均生命周期 | > 3× CAC |
| LTV:CAC | LTV / CAC | > 3:1 |
| Payback Period | CAC / (ARPU - COGS) | < 12个月 |
| Churn | 流失客户数 / 月初客户数 | < 5%/月 |

### 计算示例
```
目标: $10,000 MRR

假设:
- ARPU = $29/月
- 续费率 = 90%/月 (年留存85%)
- CAC = $50 (Google Ads)
- 转化率 = 2%

计算:
- 目标客户数 = $10,000 / $29 = 345 客户
- 月流失 = 345 × 10% = 35 客户
- 月新增 = 35 + (345 × 2% × 转化率) = 需要更多计算
- LTV = $29 × 0.9 × 12 = $313
- LTV:CAC = $313 : $50 = 6.26:1 ✅ 健康
```

### CAC优化策略
1. SEO有机流量 - CAC接近0
2. 内容营销 - CAC $20-50
3. 口碑推荐 - CAC $10-30
4. 付费广告 - CAC $50-200
5. 社交媒体 - CAC $30-100
```

### 常见变现陷阱

```
❌ 定价过低
   - "先低价吸引用户" → 用户质量低，转化难
   - 建议: 从第一天就定合理价格

❌ 复杂定价
   - 太多功能组合 → 用户决策瘫痪
   - 建议: 不超过3个方案，清晰差异化

❌ 忽视续费率
   - 只关注获客 → 流失吞噬增长
   - 建议: 续费率 > 85% 才能健康增长

❌ 免费试用陷阱
   - 太多免费用户 → 服务器成本高，转化率低
   - 建议: Freemium限制严格，或直接收费

❌ 忽视单位经济
   - CAC > LTV → 烧钱不可持续
   - 建议: LTV:CAC > 3:1 才能规模化
```
