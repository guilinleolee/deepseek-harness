## 测试2: business-decision-sop（商业决策SOP）

### 测试输入
```
/business-decision 我该不该开始做TikTok Shop?
```

### 预期输出格式
```markdown
## 商业决策分析 | TikTok Shop

### 复杂度判断
- 金额：¥5000（中等）
- 时间：1-3个月
- 可逆性：可逆
- 流程：📋 标准版

### Hormozi四要素
| 要素 | 判断 | 证据 | 来源 |
|------|------|------|------|
| Pain | ✅ | 卖家痛点：平台流量成本高 | 行业报告 |
| Purchasing Power | ✅ | TikTok用户年轻有消费力 | 平台数据 |
| Easy to Target | ⚠️ | 需要学习新平台规则 | 实操经验 |
| Growing | ✅ | TikTok电商GMV年增长300% | 财报 |

**综合判断**：3/4通过，可以做

### 假设压力测试
Q1: 隐性共识：TikTok流量红利还在早期
Q2: 核心假设：平台政策稳定 → 如果政策收紧，风险增大
Q3: 投资人问题：为什么是你？你的差异化是什么？

### 事前验尸
假设3个月失败，最可能原因：
1. 选品方向错误（40%）
2. 平台规则变化（30%）
3. 内容质量不足（20%）

### 建议
- **结论**：✅ 可以做
- **置信度**：中
- **第一步**：选3个品类进行小规模测试，预算¥2000
```

## 测试3: mental-models-checker（思维模型检查器）

### 测试输入
```
/check-bias 我觉得这个项目一定能成功，因为竞品都失败了
```

### 预期输出格式
```markdown
## 认知偏差检查报告

### 已识别偏差
| 编号 | 偏误 | 风险等级 | 证据 | 建议对策 |
|------|------|----------|------|---------|
| B12 | 乐观偏见 | 🔴高 | "一定能成功"过于自信 | 列出3个可能的失败原因 |
| B23 | 幸存者偏差 | 🔴高 | 只看了失败的竞品，忽略成功案例 | 寻找成功的竞品案例 |
| B2 | 确认偏误 | 🟡中 | 只找支持"成功"的证据 | 主动寻找反对证据 |

### 应用的思维模型
1. **逆向思维**：如果失败，最可能原因是XXX
2. **幸存者偏差**：应该研究成功者做对了什么
3. **安全边际**：预留XX%缓冲应对不确定性

### 检查结论
- **发现偏差数**：3个
- **高风险偏差**：2个
- **建议**：
  1. 寻找同类项目的成功案例
  2. 进行事前验尸分析
  3. 设置风险预警指标
```
