# War Room Decision - 作战室决策模式

> 来源：openclaw-strategist (https://github.com/wade56754/openclaw-strategist)
> 集成时间：2026-03-15

## 功能

6位专业参谋围绕决策展开辩论，提供多维视角决策支持。

## 触发词

- `/warroom {问题}`
- "多角度分析"
- "参谋团分析"
- "作战室"

## 6位参谋角色

| 角色 | 表情 | 原型 | 关注点 | 核心问题 |
|------|------|------|--------|---------|
| **战略师** | 🎯 | Druckenmiller | 时机、趋势、市场定位 | "现在的时机对吗？趋势在哪里？" |
| **实战官** | 🔥 | Peter Lynch | 谁做成过？给我看数据 | "有没有人做成过？具体怎么跑通的？" |
| **财务官** | 💰 | Ben Graham | ROI、现金流、安全边际 | "算过账吗？安全边际是多少？" |
| **风控官** | ⚠️ | Michael Burry | 黑天鹅、最坏情况 | "你没想到的风险是什么？" |
| **创新官** | 🧪 | Cathie Wood | AI杠杆、不对称机会 | "有没有降维打击的可能？" |
| **用户官** | 👤 | Phil Fisher | 用户真付费吗？痛点有多痛？ | "用户真的会为此付钱吗？" |

## 流程

```
Step 1: 信息收集（并行）
   - 查知识库
   - 历史决策检查
   - 需要时 spawn research

Step 2: 六角色独立分析
   - 每个角色独立输出判断
   - 允许互相矛盾

Step 3: 交叉质询
   - 实战官 vs 战略师
   - 财务官 vs 风控官
   - 创新官 vs 用户官

Step 4: 综合决策
   - 加权判断
   - 支持/反对票
   - 置信度（高/中/低）
   - 第一步行动
```

## 输出格式

```markdown

🎯 战略师：{判断}
🔥 实战官：{判断 + 案例}
💰 财务官：{测算}
⚠️ 风控官：{风险}
🧪 创新官：{差异化机会}
👤 用户官：{用户视角}

━━ 交叉质询 ━━
{关键分歧点}

━━ 综合判断 ━━
投票：{X支持 - Y反对}
置信度：{高/中/低}
建议：{明确建议}
第一步：{具体行动}
```

## 使用示例

```bash
# 触发作战室
/warroom 我们应该自建AI内容工具还是用现成的？

# 军师会：
# 1. 六位顾问独立分析
# 2. 策略师说时机对了
# 3. CFO说开发成本太高
# 4. 风控官标记维护负担
# 5. 创新者看到差异化机会
# 6. 用户代言人质疑用户是否在意
# 7. 交叉质询暴露核心分歧
# 8. 综合建议：4-2投票、置信度、第一步行动
```

## 硬性规则

1. **每次必须给出明确建议** - 禁止"看情况"
2. **必须标注置信度** - 高(90%+)/中(60-90%)/低(<60%)
3. **案例优先** - 没有真实案例就标注"纯推理"
4. **投票必须明确** - 支持几票、反对几票
