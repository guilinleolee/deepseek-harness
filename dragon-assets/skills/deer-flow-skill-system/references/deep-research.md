# DeerFlow Deep Research Skill

## Overview

深度研究方法论 - 三阶段系统化研究流程。

## Research Phases

### Phase 1: Broad Exploration (广泛探索)
1. 初始调研：搜索主主题了解整体背景
2. 识别维度：从结果中识别关键子主题
3. 领域映射：标注不同观点和利益相关者

### Phase 2: Deep Dive (深度挖掘)
1. 精确查询：针对每个子主题进行定向研究
2. 多种表达：尝试不同关键词组合
3. 获取全文：阅读重要来源的完整内容
4. 跟踪引用：追踪来源提到的其他重要资源

### Phase 3: Diversity & Validation (多样性验证)
确保覆盖多种信息类型：

| 信息类型 | 目的 | 示例搜索 |
|---------|------|---------|
| 事实与数据 | 具体证据 | "statistics", "data", "numbers" |
| 案例与示例 | 实际应用 | "case study", "example" |
| 专家观点 | 权威视角 | "expert analysis", "interview" |
| 趋势预测 | 未来方向 | "trends 2026", "forecast" |
| 对比分析 | 背景参考 | "vs", "comparison" |
| 挑战批评 | 平衡视角 | "challenges", "limitations" |

### Phase 4: Synthesis Check (综合检查)
- [ ] 是否从至少3-5个不同角度搜索？
- [ ] 是否获取并阅读了最重要来源的全文？
- [ ] 是否有具体数据、示例和专家观点？
- [ ] 是否同时探索了正面和挑战/局限性？
- [ ] 信息是否最新且来源权威？

## Search Strategy

### 时间意识
```
# 今日新闻
"技术新闻 2026-04-02"

# 本周
"技术发布 2026年4月第一周"

# 最近
"AI突破 2026年3月"

# 年度趋势
"软件趋势 2026"
```

### 查询模式
```
# 具体化上下文
❌ "AI trends"
✅ "enterprise AI adoption trends 2026"

# 包含权威来源提示
"[主题] research paper"
"[主题] McKinsey report"

# 搜索具体内容类型
"[主题] case study"
"[主题] statistics"
```

## Quality Bar

研究足够时，应该能够自信回答：
- 主要事实和数据点是什么？
- 2-3个具体实例是什么？
- 专家对此有何看法？
- 当前趋势和未来方向是什么？
- 挑战或局限性是什么？
- 为什么这个主题现在相关或重要？

## Common Mistakes

- ❌ 1-2次搜索后停止
- ❌ 仅依赖搜索片段而不阅读全文
- ❌ 只探索主题的一个方面
- ❌ 忽略矛盾观点或挑战
- ❌ 使用过时信息
- ❌ 在研究完成前开始内容生成
