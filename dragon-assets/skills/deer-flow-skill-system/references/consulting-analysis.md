# DeerFlow Consulting Analysis Skill

## Overview

咨询级分析报告技能 - 麦肯锡/BCG风格专业研究报告。

## Two Phases

### Phase 1: Analysis Framework Generation (分析框架生成)

给定研究主题，产生完整的**分析框架**，包括：
- 章节骨架
- 每章数据需求
- 分析逻辑
- 可视化计划

### Phase 2: Report Generation (报告生成)

接收数据收集阶段的**数据包**，综合成最终**专业报告**。

## Analysis Frameworks

### 战略与环境分析

| 框架 | 描述 | 适用场景 |
|------|------|---------|
| SWOT | 优势/劣势/机会/威胁 | 品牌评估、竞争定位 |
| PEST/PESTEL | 政治/经济/社会/技术 | 宏观环境扫描、政策影响分析 |
| Porter's Five Forces | 五力分析 | 行业竞争格局 |
| VRIO | 价值/稀缺/模仿/组织 | 核心竞争力评估 |

### 市场与增长分析

| 框架 | 描述 | 适用场景 |
|------|------|---------|
| STP | 细分/目标/定位 | 市场细分、目标选择 |
| BCG Matrix | 波士顿矩阵 | 产品组合管理 |
| TAM-SAM-SOM | 市场规模 | 市场机会量化 |
| AARRR | 增长黑客漏斗 | 用户增长分析 |

### 消费者行为分析

| 框架 | 描述 | 适用场景 |
|------|------|---------|
| Consumer Decision Journey | 消费者决策旅程 | 行为路径映射 |
| RFM | 最近/频率/金额 | 客户价值细分 |
| Maslow | 马斯洛需求层次 | 消费者心理分析 |
| JTBD | 待完成工作 | 需求洞察、产品创新方向 |

## Data Authenticity Protocol

**严格遵守规则**：
- 所有数据和图表必须直接来自提供的**数据摘要**或**外部搜索发现**
- **零幻觉**：不发明、不估算、不模拟数据
- **可追溯**：每个主要论点必须能追溯到来源

## Formatting Standards

### 咨询风格
- **语气**：麦肯锡/BCG - 权威、客观、专业
- **语言**：中文（zh_CN）或英文（en）
- **数字**：英文逗号千位分隔（1,000 not 1，000）
- **强调**：**粗体**重要观点和关键数字

### 标题约束
- 使用标准编号（1., 1.1）直接跟标题
- 禁止前缀："Chapter", "Part", "Section"
- 允许词汇：Analysis, Profiling, Overview, Insights, Assessment
- 禁止词汇："Decoding", "DNA", "Secrets", "Mindscape"

## Quality Checklist

### Phase 1
- [ ] 分析框架覆盖所有自然维度
- [ ] 选择2-4个专业分析框架并明确映射
- [ ] 每章有清晰的分析目标、逻辑、核心假设
- [ ] 数据需求具体、可测量、有搜索关键词
- [ ] 每章至少一个可视化计划

### Phase 2
- [ ] **零幻觉**：所有数字和图表经数据摘要验证
- [ ] 所有图表在报告写作前生成
- [ ] 所有章节按正确顺序（摘要→引言→主体→结论→参考文献）
- [ ] 每子章节遵循"视觉锚点→数据对比→综合分析"
- [ ] 每子章节以200字+分析段落结尾
