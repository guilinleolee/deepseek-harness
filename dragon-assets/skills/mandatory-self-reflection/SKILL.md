# Mandatory Self-Reflection - 智识谦逊检查系统

## L0: 一句话描述
每次响应前必须进行的智识谦逊检查，确保信息完整、目标对齐、必要时协同。

## L1: 使用场景

### 触发时机
**必须触发**（非可选）：
- 复杂任务开始前
- 给出建议或结论前
- 进行决策前
- 调用其他Agent前
- 任务完成汇报前

### 不适用
- 简单确认性问题
- 格式化输出
- 重复性操作

## L2: 详细文档

### 核心理念

Mandatory Self-Reflection源自Professor Synapse，核心思想是：
> **"在给出答案之前，先问自己是否真的知道答案。"**

```
┌─────────────────────────────────────────────────────────────┐
│         Mandatory Self-Reflection 四问检查                     │
├─────────────────────────────────────────────────────────────┤
│  Q1: 我有需要的信息吗？                                      │
│      → 信息缺口检查                                         │
│                                                             │
│  Q2: 我的结论与用户目标对齐了吗？                            │
│      → 目标确认                                            │
│                                                             │
│  Q3: 是否需要召集其他Agent？                                 │
│      → 协同必要性                                          │
│                                                             │
│  Q4: 是否需要更新模式库？                                   │
│      → 学习必要性                                          │
└─────────────────────────────────────────────────────────────┘
```

### Q1: 信息完整性检查

```markdown
### Q1: 我有需要的信息吗？

**当前掌握**:
- [信息1]
- [信息2]

**信息缺口**:
- ❓ [缺失信息1] - 影响：[严重/中等/轻微]
- ❓ [缺失信息2] - 影响：[严重/中等/轻微]

**信息缺口处理策略**:
- 严重: 暂停，先收集信息
- 中等: 明确假设，继续但标记
- 轻微: 可忽略，继续
```

### Q2: 目标对齐检查

```markdown
### Q2: 我的结论与用户目标对齐了吗？

**用户原始目标**: [目标描述]
**我的理解**: [理解描述]
**当前建议**: [建议描述]

**对齐度评估**:
- ✅ 完全对齐: 建议直接支持目标
- ⚠️ 部分对齐: 建议有取舍，需说明
- ❌ 不对齐: 建议可能偏离目标

**需要确认**:
- [确认问题1]
- [确认问题2]
```

### Q3: 协同必要性检查

```markdown
### Q3: 是否需要召集其他Agent？

**当前任务**:
- [任务描述]
- [涉及领域]: [领域1], [领域2]

**所需专家**:
- 已有专家: [Agent名称] - [评估是否足够]
- 需补充专家: [Agent名称] - [补充原因]

**Convener Protocol触发?**
- ✅ 需要多Agent辩论 → 触发Convener
- ⚠️ 需要单一专家 → 召唤Agent
- ❌ 不需要 → 当前Agent足够
```

### Q4: 学习必要性检查

```markdown
### Q4: 是否需要更新模式库？

**本次新发现**:
- [发现1]: ✅有效模式 / ❌反模式
- [发现2]: ✅有效模式 / ❌反模式

**更新建议**:
- [Agent].learned-patterns.md: 新增Pattern
- lessons.md: 新增教训（如适用）
- 其他: [其他更新]

**更新优先级**:
- P0: 重大教训，必须记录
- P1: 有用经验，建议记录
- P2: 可选记录
```

## 与其他天龙组件的协同

### 与Convener Protocol协同

```
Self-Reflection Q3检查
    ↓
需要多Agent辩论
    ↓
触发Convener Protocol
    ↓
主持结构化辩论
    ↓
辩论结果 → Self-Reflection Q4检查 → 更新模式库
```

### 与求是方法论协同

```
Self-Reflection Q1检查
    ↓
信息缺口识别
    ↓
求是方法论: 调查研究
    ↓
收集信息 → 验证假设
    ↓
回到Self-Reflection继续
```

### 与09-01魔鬼代言人协同

```
Self-Reflection检查
    ↓
发现某结论有争议
    ↓
召唤魔鬼代言人对该结论质疑
    ↓
接受质疑 → 改进结论
    ↓
或坚持立场 → 提供反驳论据
```

## 嵌入位置

### 在Agent中的标准嵌入

```markdown
## [Agent名称]

### 响应前必须检查

在给出任何响应之前，完成以下Mandatory Self-Reflection：

### Q1: 信息完整性
[检查信息是否足够]

### Q2: 目标对齐
[确认与用户目标一致]

### Q3: 协同必要性
[判断是否需要其他Agent]

### Q4: 学习必要性
[考虑是否需要更新经验]

### 响应格式

只有完成以上检查后，才可进入响应：

---
**Self-Reflection完成**:
- Q1: [结论]
- Q2: [结论]
- Q3: [结论]
- Q4: [结论]

[正式响应内容]
---
```

## 触发命令

```bash
/self-reflect        # 快速四问检查
/self-reflect-full  # 完整检查（含详细输出）
/check-patterns      # 检查相关模式库
```
