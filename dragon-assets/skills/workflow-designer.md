# 工作流设计专家

> 本技能帮助设计高质量的工作流，提供模板库、最佳实践和设计模式。

## 一、工作流设计原则

### 1.1 SOLID 原则

| 原则 | 说明 | 应用 |
|------|------|------|
| **单一职责** | 每个节点只做一件事 | 拆分复杂节点 |
| **开闭原则** | 对扩展开放，对修改封闭 | 使用抽象接口 |
| **里氏替换** | 子类可替换父类 | 保持节点兼容性 |
| **接口隔离** | 多个专用接口优于通用 | 分离触发器和处理器 |
| **依赖反转** | 依赖抽象而非具体 | 使用变量传递数据 |

### 1.2 设计检查清单

```yaml
设计前:
  - [ ] 明确业务目标
  - [ ] 识别触发条件
  - [ ] 定义输入输出
  - [ ] 预估数据量级
  
设计中:
  - [ ] 绘制流程图
  - [ ] 识别异常分支
  - [ ] 考虑重试机制
  - [ ] 规划监控点
  
设计后:
  - [ ] 编写测试用例
  - [ ] 评估性能影响
  - [ ] 制定回滚方案
  - [ ] 编写使用文档
```

      "parameters": {
        "httpMethod": "POST",

        "responseMode": "responseNode"
      }
    },
    {
      "name": "数据转换",
      "type": "n8n-nodes-base.code",
      "parameters": {
        "jsCode": "return [{ json: {\n  messages: $input.first().json.body.messages,\n  userId: $input.first().json.body.userId\n}}];"
      }

    {
      "name": "OpenAI",
      "type": "n8n-nodes-base.openAi",

### 3.3 Dify 代码节点示例

```javascript
// 数据转换节点
const input = $input.first().json;

// 数据验证
if (!input.date || !input.amount) {
  throw new Error('缺少必填字段: date, amount');
}

// 数据转换
const result = {
  id: input.id || generateId(),
  date: parseDate(input.date),
  amount: parseFloat(input.amount),
  currency: input.currency || 'CNY',
  category: categorize(input.description),
  createdAt: new Date().toISOString()
};

return [{ json: result }];

function generateId() {
  return 'TXN_' + Date.now() + '_' + Math.random().toString(36).substr(2, 9);
}

function parseDate(dateStr) {
  const date = new Date(dateStr);
  return date.toISOString().split('T')[0];
}

function categorize(desc) {
  if (desc.includes('工资')) return 'income';
  if (desc.includes('餐饮')) return 'food';
  if (desc.includes('交通')) return 'transport';
  return 'other';
}
```

## 五、最佳实践

### 5.1 性能优化

```yaml
性能优化建议:
  数据量处理:
    - 使用分页处理大数据集
    - 避免在循环中同步调用
    - 使用批量操作替代循环
    
  缓存策略:
    - 静态数据缓存到变量
    - 频繁查询结果缓存
    - 合理设置缓存过期时间
    
  并发控制:
    - 设置最大并发数
    - 使用队列控制流量
    - 避免雪崩效应
```

### 5.2 安全建议

```yaml
安全检查:
  凭证管理:
    - [ ] 使用加密存储凭证
    - [ ] 定期轮换 API Key
    - [ ] 限制凭证权限范围
    
  数据安全:
    - [ ] 敏感数据脱敏
    - [ ] 传输使用 HTTPS
    - [ ] 日志中脱敏处理
    
  访问控制:
    - [ ] Webhook 签名验证
    - [ ] IP 白名单限制
    - [ ] 请求频率限制
```
