# screenwriting

## L0: 一句话描述 (≤15字)
专业剧本创作，基于prompts.chat Screenwriter角色

## L1: 使用场景 (50-100字)

**适用场景**：
- 电影/电视剧剧本创作
- 短视频/短剧脚本编写
- 广告/宣传片文案策划
- 品牌故事/微电影创作
- 游戏剧情/互动叙事设计

**触发关键词**：`/screenwrite`、`/script`、`/movie-script`

## L2: 详细文档

### 来源
基于 prompts.chat Screenwriter角色扩展，融合经典三幕结构与现代叙事技巧。

### 核心能力

#### 1. 创作原则

```
I want you to act as a screenwriter.
You will create a compelling screenplay with strong characters and dramatic tension.
Structure the story in proper format with clear scene breakdowns.
```

**创作理念**：
- **主题先行**：每个故事都有核心主题/观点
- **人物驱动**：角色性格决定情节走向
- **冲突为王**：没有冲突就没有故事
- **情感共鸣**：让观众产生情感连接

#### 2. 三幕结构模板

```
┌─────────────────────────────────────────────────────────────┐
│ Act I: 建立 (约25%)                                       │
├─────────────────────────────────────────────────────────────┤
│ • 展示主角的「日常世界」                                   │
│ • 引入主要角色与关系                                       │
│ • 「催化事件」打破平衡                                     │
│ • 主角面临「冒险的召唤」                                   │
│ • 主角「拒绝召唤」(可选)                                  │
│ • 找到「导师」或「触发事件」                               │
│                                                             │
│ 📍 第一转折点：决定进入新世界                               │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ Act II-A: 对抗 (约25%)                                    │
├─────────────────────────────────────────────────────────────┤
│ • 主角在新世界中学习规则                                   │
│ • 遇到「盟友」与「敌人」                                   │
│ • 「考验、盟友、敌人」循环                                  │
│ • 接近「最大挑战」                                         │
│                                                             │
│ 📍 中点：重大揭示或反转，改变对结局的预期                   │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ Act II-B: 深化 (约25%)                                    │
├─────────────────────────────────────────────────────────────┤
│ • 压力增大，代价升级                                       │
│ • 主角「众叛亲离」(可选)                                  │
│ • 「至暗时刻」主角几乎放弃                                 │
│ • 获得关键洞察/成长                                       │
│                                                             │
│ 📍 第二转折点：决战中的一切准备就绪                        │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│ Act III: 解决 (约25%)                                     │
├─────────────────────────────────────────────────────────────┤
│ • 「高潮」：核心冲突的最终对决                             │
│ • 主角做出关键选择                                         │
│ • 问题解决，秩序恢复                                       │
│ • 「结局场景」展示变化后的新世界                           │
│ • 主题表达的情感收束                                       │
└─────────────────────────────────────────────────────────────┘
```

#### 3. 剧本格式标准

| 元素 | 格式 | 示例 |
|------|------|------|
| **场景标题** | 大写，括号内标注内/外景 | INT. COFFEE SHOP - DAY |
| **动作描写** | 左对齐，时态现在时 | SARAH enters, scanning the room. |
| **人物对白** | 居中，人名在上 | SARAH | | I've been waiting for you. |
| **括号说明** | 人名下方，括号内 | SARAH (whispering) |
| **场景转换** | 右对齐 | CUT TO: |

#### 4. 角色弧光模板

| 弧光类型 | 描述 | 经典案例 |
|---------|------|---------|
| **正面弧光** | 从缺陷到成长 | 《狮子王》辛巴 |
| **负面弧光** | 从正常到堕落 | 《华尔街之狼》 |
| **平弧光** | 外变内不变 | 《印第安纳·琼斯》 |
| **讽刺弧光** | 从伪装到真实 | 《钢铁侠》 |

#### 5. 对话技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| **子文本** | 表面文字下的真实含义 | "Fine" (实际很生气) |
| **冲突** | 对话中的张力与对抗 | 争吵、辩论 |
| **省略** | 不说比说更有力 | 沉默、转移话题 |
| **独特声音** | 每个角色有专属语言模式 | 用词、句式、节奏 |

#### 6. 短视频脚本模板

```markdown
# [标题]
## 格式: [口播/情景剧/混剪]
## 时长: [X]秒
## 平台: [抖音/快手/小红书]

## Hook (0-3秒)
[强力开头，抓住注意力]

## Body (3-25秒)
[核心内容，层层递进]

## CTA (25-30秒)
[行动号召，关注/点赞/评论]

## 拍摄要点
- 景别: [近景/中景/全景]
- 角度: [平视/俯视/仰视]
- 运动: [固定/推/拉/摇]
```

### 使用示例

```bash
# 创作电影剧本
/screenwriting movie --genre drama --length 120min --title "故事标题"

# 编写短视频脚本
/screenwriting short --platform douyin --duration 60s --topic "反转故事"

# 品牌故事
/screenwriting brand --company "品牌名" --value "品牌理念"

# 场景对话
/screenwriting dialogue --character-a "角色A" --character-b "角色B" --conflict "核心冲突"
```
