# MD-to-PPTX 布局指南

> 本文档描述 md-to-pptx 支持的布局类型及其使用场景

## 布局类型

### 1. Cover (封面布局)

**特点**: 居中大标题，深色背景，专业感

**使用场景**:
- 演讲开场
- 主题介绍
- 产品发布

**示例**:
```markdown
# 2024年度技术峰会
## 创新·协作·未来
### 2024年8月20日
```

---

### 2. Title (章节标题布局)

**特点**: 左对齐标题，简洁大气

**使用场景**:
- 章节分隔
- 主题过渡
- 大纲展示

**示例**:
```markdown
## 核心功能介绍
```

---

### 3. Content (标准内容布局)

**特点**: 标题 + 要点列表，层次分明

**使用场景**:
- 常规内容页
- 列表展示
- 要点讲解

**示例**:
```markdown
## 功能特点

- 高性能处理
- 智能分析
- 可视化展示
- 实时协作
```

---

### 4. Two-Column (双栏布局)

**特点**: 左右分栏，可同时展示文字和图片

**使用场景**:
- 图文并茂
- 对比展示
- 左右分区内容

**示例**:
```markdown
## 产品展示

![产品图](product.png)

左侧文字内容...
```

---

### 5. Code (代码布局)

**特点**: 代码高亮，大字体显示

**使用场景**:
- 代码演示
- 技术讲解
- 配置说明

**示例**:
````markdown
## 快速开始

```python
def hello():
    print("Hello, World!")
```
````

---

### 6. Chart (图表布局)

**特点**: 数据可视化，图表占位

**使用场景**:
- 数据分析
- 统计展示
- 趋势展示

**示例**:
````markdown
```chart
type: bar
title: 季度销售额
data: |
  Q1 100
  Q2 150
  Q3 200
  Q4 250
```
````

---

### 7. Table (表格布局)

**特点**: 表格展示，数据对比

**使用场景**:
- 数据表格
- 对比分析
- 规格说明

**示例**:
```markdown
## 产品对比

| 功能 | 基础版 | 专业版 | 企业版 |
|------|--------|--------|--------|
| 用户数 | 10人 | 50人 | 无限制 |
| 存储 | 10GB | 100GB | 1TB |
| 价格 | 免费 | ¥99/月 | ¥999/月 |
```

---

### 8. Ending (结尾布局)

**特点**: 感谢语，联系方式

**使用场景**:
- 演讲结尾
- 联系方式
- 问答环节

**示例**:
```markdown
<!-- slide:layout:ending -->

# 谢谢

## 欢迎提问

📧 contact@example.com
🌐 www.example.com
```

---

## 布局选择指南

### 按内容类型选择

| 内容类型 | 推荐布局 |
|----------|----------|
| 封面/开场 | cover |
| 章节标题 | title |
| 要点列表 | content |
| 图文并茂 | two-column |
| 代码演示 | code |
| 数据分析 | chart |
| 数据对比 | table |
| 结尾/致谢 | ending |

### 按风格选择

| 风格 | 默认布局 |
|------|----------|
| corporate | content |
| minimal | title |
| academic | content |
| tech | code |
| dark | content |
| creative | two-column |

---

## 自定义布局

### 手动指定布局

使用注释指令:
```markdown
<!-- slide:layout:two-column -->

## 双栏内容
```

### 可用布局指令

| 指令 | 说明 |
|------|------|
| `slide:layout:cover` | 封面布局 |
| `slide:layout:title` | 章节标题 |
| `slide:layout:content` | 内容布局 |
| `slide:layout:two-column` | 双栏布局 |
| `slide:layout:code` | 代码布局 |
| `slide:layout:chart` | 图表布局 |
| `slide:layout:table` | 表格布局 |
| `slide:layout:ending` | 结尾布局 |

---

## 布局最佳实践

1. **保持一致**: 同一种内容类型使用相同布局
2. **适度使用**: 不要每页都换布局
3. **内容适配**: 布局服务于内容，不要强行使用
4. **留白适度**: 保持视觉呼吸空间
5. **重点突出**: 关键信息使用醒目布局
