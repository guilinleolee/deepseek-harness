# 费曼学习法执行器 (Feynman Technique)

## L0: 一句话
**缺口驱动的多角色协作费曼**，用"教中学"攻克知识缺口，每次讲解都指向未掌握的核心漏洞，GapAdaptiveSM2精准调度复习，让遗忘曲线为你服务

## L1: 使用场景
- 学习新技术栈
- 准备技术面试
- 向团队传授知识
- 检验自己是否真正理解
- 写技术博客前的概念确认
- **建立破局思考力 / 发现知识缺口**
- **通关式学习：概念闯关、星星奖励、不通关不下一关**
- **V9.0多角色费曼：同伴辩论发现缺口 → 费曼讲解攻克缺口 → 间隔复习巩固记忆**

## L2: 详细流程

### 多角色协作费曼完整流程

#### Phase 0: 同伴辩论发现缺口【V9.0新增】

**触发时机**：用户刚学习完某个概念，或对某个概念理解存疑

**同伴模拟器调用**：
```
调用同伴学习模拟器，基于概念"X"，模拟四角色辩论
→ 输出：知识缺口清单 (Knowledge Gaps)
→ 输出：深化费曼问题列表
```

**同伴角色配置**：
```yaml
peer_roles:
  novice:
    name: "新手小白"
    question_types:
      - "这是什么？"
      - "和XXX有什么区别？"
      - "为什么需要这个？"
    common_misconceptions:
      - "以为X就是Y的简单重复"
      - "混淆使用场景"
      - "忽视核心前提"

  practitioner:
    name: "实践者老王"
    question_types:
      - "实际怎么用？"
      - "遇到过什么问题？"
      - "最佳实践是什么？"
    concerns:
      - "性能影响"
      - "维护成本"
      - "集成难度"

  skeptic:
    name: "怀疑论者"
    question_types:
      - "真的比X更好吗？"
      - "有什么场景不适用？"
      - "有什么隐藏代价？"

  synthesizer:
    name: "综合者"
    contributions:
      - "总结各方观点"
      - "构建统一框架"
      - "指出深层联系"
```

**输出示例**：
```markdown
## 同伴辩论发现的知识缺口

| 缺口类型 | 具体描述 | 优先度 |
|---------|---------|--------|
| 基础概念混淆 | 以为闭包就是return函数 | P0 |
| 适用场景不清 | 不知道何时用箭头函数vs普通函数 | P0 |
| 原理理解缺失 | 不理解词法作用域机制 | P1 |
| 实战应用不足 | 知道但不会举一反三 | P2 |

## 费曼深化问题

1. "如果闭包的核心原理失效，会发生什么？" (原理理解)
2. "举一个你亲身经历过的闭包应用场景" (实战应用)
3. "用一句话向小学生解释什么是闭包？" (基础理解)
```

### Phase 1: 针对性讲解（只讲缺口）

```
基于知识缺口清单，生成针对性费曼讲解
规则：
- 禁止讲已掌握内容（节省时间）
- 聚焦缺口类型：
  - P0：基础概念 ─ 从最简单的比喻开始
  - P1：原理机制 ─ 第一性原理拆解
  - P2：实战应用 ─ 具体场景举例
```

```yaml
讲解顺序:
  P0缺口:
    方法: 最简单比喻（小学生能听懂）
    示例: "闭包就像一个有记忆的机器人..."
    禁止: 不使用任何专业术语

  P1缺口:
    方法: 第一性原理拆解
    示例: "函数为什么能记住创建时的变量..."
    关键: 解释"为什么"而不是"是什么"

  P2缺口:
    方法: 具体场景+动手练习
    示例: "在项目中，我曾经这样用闭包..."
    关键: 连接理论与实践
```

---

### Phase 2: 费曼追问检验

```
基于同伴辩论生成的费曼问题，进行苏格拉底追问

追问链（Level 1-4递进）:
Level 1 - 检验理解：
  - "你说[某点]，能再详细说说吗？"
  - "这个例子很好，还有其他例子吗？"

Level 2 - 挖掘深度：
  - "为什么是[这个原因]而不是[另一种原因]？"
  - "这个和[相关概念]有什么联系和区别？"

Level 3 - 挑战巩固：
  - "如果有人反对这个观点，你觉得他们会怎么说？"
  - "如果情况改变，这个结论还成立吗？"

Level 4 - 提炼升华：
  - "你能用一句话概括[概念]吗？"
  - "如果向完全不懂的人解释，你会怎么说？"
```

---

### Phase 3: 简化类比

```
## [原始概念]
类比: [生活化的比喻]
类比解释: [为什么这个类比贴切]
原文对照: [用术语重新表述]

示例:
## 闭包（Closure）
类比: 就像一个有记忆的机器人，它记住了自己被创造时
      周围的环境，即使它被带到不同的地方，它还记得
      当初的那些东西。

类比解释: 机器人 = 函数，记忆 = 变量环境，创建时 =
          定义时，不同地方 = 函数执行完毕

原文对照: 闭包是指一个函数能够访问其词法作用域外的变量，
         即使该函数在其原始作用域之外执行。
```

### Phase 4: 通关考核【V8.82】

```
通关考核题目（每概念3题）:

1. 概念理解题：
   "用你自己的话解释什么是[概念]，让一个不懂技术的人也能听懂"

2. 辨析区分题：
   "[概念]和[相关概念]有什么相同和不同？"

3. 迁移应用题：
   "在[新场景]中，你会怎么应用[概念]？"

五星奖励体系【V9.0新增】:
├── ⭐ 通关星  ─ 3题通过即获得
├── 🌟 速度星  ─ 一次性通过（无重来）
├── 💪 坚持星  ─ 重来后通过
├── 📚 复习星  ─ GapAdaptiveSM2复习按时完成（间隔期内完成）
└── 🔥 连续星  ─ 连续3天缺口攻克

结果判定:
✅ 全部正确 → 🎉 获得⭐通关星 + 🌟速度星（一次性通过）
✅ 部分正确 → 🎉 获得⭐通关星
❌ 未通过 → 诊断原因 + 针对性辅导 + 再次考核
            → 再次通过后获得💪坚持星

GapAdaptiveSM2协同【V9.0新增】:
通关后自动触发 → 记录缺口等级(P0/P1/P2) → GapAdaptiveSM2调度首次复习
- P0缺口复习 → 间隔×0.5（短频快攻，明天即复习）
- P1缺口复习 → 间隔×1.0（标准节奏）
- P2缺口复习 → 间隔×1.5（长时深潜，隔更久巩固）
```

## 检查清单

### 费曼讲解合格标准
- [ ] 用自己的话写出来（不是照抄定义）
- [ ] 有生活化的类比（不是技术类比）
- [ ] 有具体例子（不是抽象说明）
- [ ] 能回答追问（不是背答案）
- [ ] 能举一反三（不是只会一个例子）

### 知识缺口识别（同伴辩论）
- [ ] 新手视角的问题：基础概念是否清晰？
- [ ] 实践者视角的问题：实战应用是否掌握？
- [ ] 怀疑论者的问题：假设前提是否成立？
- [ ] 综合者的问题：整体框架是否完整？

### 通关考核标准
- [ ] 概念理解：用自己的话解释清楚
- [ ] 辨析区分：能区分相似概念
- [ ] 迁移应用：能应用到新场景
- [ ] 苏格拉底追问：全部追问能回答
