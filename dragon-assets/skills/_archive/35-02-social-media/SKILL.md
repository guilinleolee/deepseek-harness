
**R1 越大越细伪代码**（方法论启发）：

```python
def check_越大越细(card):
    # 找出视觉权重 Top-3 元素
    elements = sorted(card.elements, key=lambda e: e.size, reverse=True)[:3]
    # 每个元素的"信息密度" = 文字数 + 装饰元素数 / 面积
    for elem in elements:
        density = elem.char_count / elem.area
        if density < THRESHOLD:  # 默认阈值 = 0.05
            return False, f"元素 {elem.id} 视觉权重高但信息密度低"
    return True, "✅ 越大越细成立"
```

## §5 越大越细（视觉权重 ⇄ 信息密度）

### 5.1 原则陈述

> **视觉权重 ⇄ 信息密度**：元素在画面中越大、越显眼，承载的"信息/细节"就该越多。
> 违背此原则会变成"大字堆文字"反 AI 味儿。

### 5.2 反模式 vs 正例

| 反模式 ❌ | 正例 ✅ |
|----------|--------|
| 大标题 + 大白底（无细节） | 大标题 + 副文 + 装饰小元素 |
| 主图占满 + 无文字层 | 主图周边留出 caption / 标签位 |
| 大色块 + 大留白 | 加微纹理或小元素破单调 |

### 5.3 5 大常见场景校验清单

- [ ] 主图位是否留出 caption 位（避免主图吞字）
- [ ] Top-3 视觉元素的"信息密度"是否都 ≥ 阈值 0.05
- [ ] 标题字号 > 副文 > 装饰元素（金字塔结构）
- [ ] 留白占比 30-50%（过多=浪费，过少=拥挤）
- [ ] 颜色对比度 WCAG AA 4.5:1+（小字）/ 3:1+（大字）

```
│  Step 5. 校验门禁（R1-R7）                                   │
```

- **主题色与平台调性冲突**（如 cool 主题用于小红书美妆）→ 35-02 警告并建议
