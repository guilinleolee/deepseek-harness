# dbs-content

## L0: 一句话描述
内容创作四维框架——通过去AI味、分层递进、钩子钩尾、情感共鸣提升内容转化。

## L1: 使用场景
当需要创作面向用户的文案（公众号文章、销售页面、社媒帖子）时使用。解决AI生成内容的"AI腔调"问题，提升真实感和转化率。

## L2: 详细文档

### 核心能力
基于Adlerian心理学 + Wittgenstein语言哲学的内容创作框架，通过四维叠加提升内容质量。

### 四维内容框架

```
┌─────────────────────────────────────────────────────────────┐
│ 维度1: 去AI味                                           │
│ 移除模式化表达 → 活人感写作                             │
├─────────────────────────────────────────────────────────────┤
│ 维度2: 分层递进                                         │
│ 信息密度递增 → 不同认知层级都能获益                        │
├─────────────────────────────────────────────────────────────┤
│ 维度3: 钩子钩尾                                        │
│ 开头吸引 + 结尾行动 → 转化闭环                           │
├─────────────────────────────────────────────────────────────┤
│ 维度4: 情感共鸣                                         │
│ Adler六信号 → 真实情感连接                               │
└─────────────────────────────────────────────────────────────┘
```

### 维度1: 去AI味检查表

| AI腔调模式 | 替代方案 |
|-----------|---------|
| "值得注意的是..." | 直接陈述观点 |
| "首先...其次...最后..." | 自然段落流动 |
| "综上所述..." | 用具体案例收尾 |
| "在这个时代..." | 具体到具体场景 |
| "不言而喻..." | 明确表达观点 |
| 被动语态 | 主动语态 + 具体主体 |
| 过度使用"非常" | 具体形容词 |
| 学术化长句 | 短句 + 具体名词 |

### 维度2: 分层递进结构

```
Tier 1 (表层, 60%读者):
  - 核心观点一句话
  - 1个具体案例/故事
  - 行动建议

Tier 2 (中层, 30%读者):
  - 观点展开（3-5个支撑点）
  - 2-3个案例对比
  - 数据/引用支持

Tier 3 (深层, 10%读者):
  - 底层逻辑解释
  - 方法论框架
  - 延伸阅读指引
```

### 维度3: 钩子钩尾设计

**钩子类型选择**:
- 反常识钩: "努力就能成功？不一定"
- 身份钩: "真正的XX不会Y"
- 数字钩: "73%的人不知道..."
- 场景钩: "深夜11点，你是否也..."
- 问答钩: "如何做到X？"

**钩尾类型选择**:
- 行动钩尾: "现在就能做的X步"
- 紧迫钩尾: "窗口期只剩X天"
- 好奇钩尾: "下期我们将..."
- 社群钩尾: "加入XX社群一起..."
- 资源钩尾: "回复'666'获取..."

### 维度4: Adler情感六信号

```
1. 归属感信号
   - 用户属于哪个群体？
   - 如何让用户感到"这就是我"？

2. 重要性信号
   - 如何让用户感到被看见？
   - 具体点名而非泛泛而谈

3. 能力感信号
   - 如何让用户感到"我能行"？
   - 提供具体的成功路径

4. 自主感信号
   - 如何让用户感到选择权在自己？
   - 提供多个选项而非强制

5. 进步感信号
   - 如何让用户感到在变好？
   - 可衡量的进展指标

6. 联结感信号
   - 如何创造用户之间的连接？
   - 共同挑战/社群归属
```

```markdown

[保留的真实表达]

**维度2 - 分层递进设计:**
- Tier 1 (60%): [核心观点 + 案例 + 行动]
- Tier 2 (30%): [展开 + 对比 + 数据]
- Tier 3 (10%): [逻辑 + 方法论 + 延伸]

**维度3 - 钩子钩尾:**
- 开头钩子: [类型] - [具体内容]
- 结尾钩尾: [类型] - [具体内容]

**维度4 - 情感共鸣设计:**
- 归属感: [设计内容]
- 重要性: [设计内容]
- 能力感: [设计内容]
- 自主感: [设计内容]
- 进步感: [设计内容]
- 联结感: [设计内容]

### 内容成品框架
[结构化的大纲]

### 转化预期
- 目标行动: [用户被期望做的行为]
- 转化路径: [从钩子到行动的完整路径]
```

### 使用命令

```bash
/dbs-content                     # 启动内容创作

```

### 内容自检清单

- [ ] 通过去AI味检查（读出来是否像活人写的？）
- [ ] 三个层级读者都能找到价值
- [ ] 开头3秒能吸引注意力
- [ ] 结尾有明确行动指引
- [ ] 至少覆盖2个Adler情感信号
