# dbs-hook

## L0: 一句话描述
钩子工程学——从用户语言中提取认知锚点，构建"认知-情感-行动"触发链。

## L1: 使用场景
当用户表达需求、抱怨或愿望时，从语言中提取真实痛点，设计触发下一步行动的信息框架。用于内容创作、产品文案、销售话术。

## L2: 详细文档

### 核心能力
基于用户原始语言构建认知锚点，形成"认知重置→情感共鸣→行动触发"三段式钩子。

### 三段式钩子结构

```
┌─────────────────────────────────────────────────────────────┐
│ 认知重置 (Hook)                                           │
│ 打破常规认知 → "你知道的可能是错的"                       │
│ 目的: 引起注意，创造认知空白                              │
├─────────────────────────────────────────────────────────────┤
│ 情感共鸣 (Bridge)                                         │
│ 说出用户感受 → "这就是我经历的"                          │
│ 目的: 建立连接，让用户感到被理解                          │
├─────────────────────────────────────────────────────────────┤
│ 行动触发 (Call)                                           │
│ 提供清晰路径 → "你可以这样做"                             │
│ 目的: 降低行动门槛，创造紧迫感                           │
└─────────────────────────────────────────────────────────────┘
```

### 五维钩子提取法

从用户原话中提取以下要素:

```
维度1: 认知障碍
  - 用户相信什么（可能是错的）？
  - "人们通常认为..."

维度2: 情感触发
  - 用户感受到什么？
  - "这让你感到..."

维度3: 身份渴望
  - 用户想成为什么样的人？
  - "你想成为那种..."

维度4: 社会证明
  - 用户参考谁的看法？
  - "谁的评价对你重要？"

维度5: 行动障碍
  - 什么阻止用户行动？
  - "是什么让你还没开始？"
```

### 钩子类型库

| 类型 | 模式 | 示例 | 适用场景 |
|------|------|------|---------|
| **反常识** | "你以为X，实际是Y" | "努力就能成功？不一定" | 知识型内容 |
| **身份认同** | "真正XX的人会Y" | "真正的创业者从不解释" | 社群营销 |
| **紧迫制造** | "再不X就Y了" | "再不学AI就被淘汰" | 课程销售 |
| **对比落差** | "以前Y，现在Z" | "同样的努力，不同的结果" | 案例分享 |
| **问题唤醒** | "你是否也..." | "你是否也在深夜怀疑自己" | 情感共鸣 |
| **数字冲击** | "73%的XX" | "73%的创业者死在前6个月" | 数据驱动 |

```markdown
- 情感触发: [从原话提取]
- 身份渴望: [从原话提取]
- 行动障碍: [从原话提取]

### 三段式设计
**认知重置:**
[设计的反常识或反直觉陈述]

**情感共鸣:**
[设计的用户感受描述]

**行动触发:**
[设计的清晰行动路径]

### 钩子变体

```

### 使用命令

```bash
/dbs-hook                       # 启动钩子提取
dbs-hook "用户说：我觉得..."    # 从给定话语提取钩子
```

### 钩子质量检查

- [ ] 认知重置打破了一个常见误解？
- [ ] 情感共鸣说出了用户内心感受？
- [ ] 行动触发具体且门槛低？
- [ ] 三段之间有逻辑递进？
- [ ] 语言风格与目标受众匹配？

### 禁忌

- ❌ 虚假紧迫感（狼来了效应）
- ❌ 过度承诺（无法兑现的钩子）
- ❌ 攻击用户（"你是错的"语气）
- ❌ 脱离用户原意的强行解读
