# dbs-action

## L0: 一句话描述
心理阻力诊断——识别用户在执行决策时的内在心理障碍。

## L1: 使用场景
当用户表达了目标但反复拖延、犹豫不决，或在多个选项间无法做出选择时使用。诊断六类心理阻力：感知困难、情感回避、身份冲突、认知过载、行动瘫痪、关系恐惧。

## L2: 详细文档

### 核心能力
基于Alfred Adler个体心理学，分析用户在追求目标时的心理阻力。

### 六类心理阻力诊断

| 类型 | 关键词 | 表现 | 应对策略 |
|------|--------|------|---------|
| **感知困难** | "我不知道"、"不清楚" | 信息不足导致无法决策 | 提供结构化问题框架 |
| **情感回避** | "担心"、"害怕" | 负面情绪阻止行动 | 情绪标注 + 小步验证 |
| **身份冲突** | "我不应该是这样的人" | 目标与自我认知矛盾 | 重新框架目标意义 |
| **认知过载** | "太复杂了"、"太多选项" | 信息过载导致分析瘫痪 | 简化选项 + 2选1 |
| **行动瘫痪** | "万一失败了怎么办" | 对失败的恐惧阻止行动 | 最小可行行动 |
| **关系恐惧** | "别人会怎么看" | 过度在意他人评价 | 区分真实需求 vs 社会期待 |

### 执行流程

```
1. 识别阻力类型
   - 询问："你现在的感受是什么？"
   - 观察语言模式（否定词、疑问词频率）
   - 检测决策延迟时间

2. 确认阻力来源
   - 追问具体担忧点
   - 追溯首次出现阻力的时间点
   - 评估阻力强度（1-10分）

3. 应用对应策略
   - 感知困难 → 提供结构化框架
   - 情感回避 → 情绪标注 + 接纳
   - 身份冲突 → 重新框架
   - 认知过载 → 简化 + 聚焦
   - 行动瘫痪 → 最小行动承诺
   - 关系恐惧 → 价值澄清

4. 验证阻力缓解
   - 询问："现在感觉如何？"
   - 观察语言变化
   - 确认行动意愿
```

### 输出格式

```markdown
## dbs-action 诊断报告

### 阻力类型识别
- 主要阻力: [类型]
- 次要阻力: [类型]
- 阻力强度: [1-10]

### 阻力来源分析
[具体担忧点描述]

### 应用策略
- 策略1: [策略描述]
- 策略2: [策略描述]

### 阻力缓解验证
- 行动意愿: [高/中/低]
- 建议下一步: [具体行动]
```

### 使用命令

```bash
/dbs-action                    # 启动心理阻力诊断
dbs-action "描述你的困境"     # 直接分析给定场景
```

### 禁忌

- ❌ 不对用户情感进行评判
- ❌ 不提供未经用户确认的解决方案
- ❌ 不将心理阻力误判为能力不足
