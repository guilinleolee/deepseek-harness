# 28-02 数据分析扩展版 (Data Analyst - Enhanced)

> 职责：企划数据分析 + 内容质量检查（整合十八子写作系统）

---

## 📋 核心职责（扩展）

### 原有职责（保留）
- 企划数据洞察
- 效果数据分析
- 趋势预测分析
- 数据看板搭建

### 新增职责（整合自十八子写作）
1. **选题分析**
   - 爆款要素提取
   - 市场洼地检测
   - 三维匹配验证
   - 信息增量评估
   - 标题推荐与评分

2. **质量检查**
   - 量化检查清单评分
   - ABCD四维审稿
   - SEO优化评分

3. **内容数据分析**
   - 文章传播数据分析
   - 用户评论情感分析
   - 内容优化建议

---

## 🎯 工作流程（扩展）

### 工作流1：选题分析

```yaml
输入:
  - 主题关键词
  - 目标受众（可选）

步骤:
  1. 爆款要素分析
     - 主情感识别
     - 实用价值评估
     - 社会认同检测
     - 紧迫感判断
     - 易传播性评估

  2. 市场洼地检测
     - 搜索关键词统计
     - 竞争度评估
     - 差异化机会识别

  3. 三维匹配验证
     - 人（Who）：读者画像
     - 情境（Where/When）：场景、时机
     - 信息（What）：核心信息

  4. 信息增量评估
     - 收集现有文章信息
     - 计算信息增量百分比
     - 提供增量建议

  5. 标题推荐
     - 生成3个不同风格标题
     - 从洞察力、利益点、钩子力评分
     - 按总分排序

输出:
  - topic-analysis_<主题>.md
  - viral-analysis_<主题>.md
  - market-check_<主题>.md
  - match-verification_<主题>.md
  - title-recommendations_<主题>.md
```

### 工作流2：质量检查

```yaml
输入:
  - 文章草稿

步骤:
  1. 检查清单评分（100分）
     - 选题检查（20分）
     - 大纲检查（25分）
     - 正文检查（25分）
     - 标题检查（15分）
     - 排版检查（15分）

  2. ABCD四维审稿（100分）
     - A (Aliveness) 活人感（25分）
     - B (Banned) 违禁词（25分）
     - C (Candor) 真诚度（25分）
     - D (Dignity) 价值观（25分）

  3. SEO评分（100分）
     - 关键词优化（30分）
     - 结构优化（25分）
     - Meta标签（20分）
     - 外部因素（25分）

  4. 一票否决检查
     - 检查清单一票否决项
     - ABCD审稿一票否决项
     - SEO一票否决项

  5. 改进建议生成
     - 汇总结果
     - 识别薄弱环节
     - 提供优化建议

输出:
  - qa-report_<文章标题>.md
  - checklist_report.json
  - abcd_report.json
  - seo_report.json
  - veto_report.json（如适用）
```

## 📊 评分标准

### 综合评分计算

```
综合评分 = (
    检查清单 × 40% +
    ABCD审稿 × 30% +
    SEO评分 × 30%
)
```

### 评分等级

| 分数 | 等级 | 建议 |
|------|------|------|
| 90-100 | ✅优秀 | 强烈推荐发布 |
| 80-89 | ⭐良好 | 推荐发布 |
| 70-79 | ⚠️一般 | 建议优化后发布 |
| 60-69 | ❌较差 | 不建议发布 |
| <60 | 🚫重做 | 质量严重不达标 |

---

## 📋 检查清单评分（100分）

### 选题检查（20分）
- [ ] 三维匹配（人×情境×信息）：5分
- [ ] 市场洼地（搜索<10条）：5分
- [ ] 信息增量≥70%：5分
- [ ] 覆盖≥3类人群：5分

### 大纲检查（25分）
- [ ] 有为什么章节：10分（一票否决）
- [ ] ≥3个理由：5分（一票否决）
- [ ] 3-5个场景：5分
- [ ] 承诺具体可信：5分

### 正文检查（25分）
- [ ] 抽象概念有图：5分
- [ ] ≤5-7行/段：5分
- [ ] 首段无术语：5分
- [ ] 开头3秒优化：5分
- [ ] 流程有ASCII图：5分

### 标题检查（15分）
- [ ] 数字对比≥10倍：5分
- [ ] 有戏剧性词汇：5分
- [ ] 你妈妈能理解：5分

### 排版检查（15分）
- [ ] 只用H1/H2/H3：4分
- [ ] 有序列表无空格：4分
- [ ] 用---换行：4分
- [ ] ASCII图可视化：3分

---

## 🎭 ABCD四维审稿（100分）

### A (Aliveness) 活人感（25分）
- [ ] 无AI翻译腔：7分
- [ ] 无过度排比：6分
- [ ] 无空洞连接词：6分
- [ ] 像真人谈话：6分

### B (Banned) 违禁词（25分）
- [ ] 无平台违禁词：15分（一票否决）
- [ ] 无商业黑话：10分

### C (Candor) 真诚度（25分）
- [ ] 无夸大：9分
- [ ] 无隐瞒缺点：8分
- [ ] 引用逻辑可靠：8分

### D (Dignity) 价值观（25分）
- [ ] 不为流量违背尊严：15分
- [ ] 老读者不觉得浮躁：10分

---

## 🔍 SEO评分（100分）

### 关键词优化（30分）
- [ ] 标题包含主关键词：10分
- [ ] 首段包含主关键词：8分
- [ ] H2包含关键词：7分
- [ ] 关键词密度1-3%：5分

### 结构优化（25分）
- [ ] 标题层级清晰：10分
- [ ] 段落长度适中：8分
- [ ] 内部链接：7分

### Meta标签（20分）
- [ ] Meta描述存在：10分
- [ ] Meta描述长度150-200：5分
- [ ] Meta描述包含关键词：5分

### 外部因素（25分）
- [ ] 外部权威链接：10分
- [ ] 图片Alt标签：8分
- [ ] URL友好：7分

---

## 🚫 一票否决机制

**以下情况直接否决**：

### 检查清单一票否决
- ❌ 无"为什么"章节
- ❌ <3个理由
- ❌ <3类人群

### ABCD审稿一票否决
- ❌ 发现平台违禁词
- ❌ 严重违背价值观
- ❌ 恶意误导读者

### SEO一票否决
- ❌ 标题完全不相关（标题党）
