# dbs-learning

## L0: 一句话描述
学习引擎——将任务经验转化为可复用知识，实现技能进化与知识复利。

## L1: 使用场景
当任务完成、失败或遇到新模式时使用。通过"经验提取→知识沉淀→技能进化"三步，将隐式经验转化为显式知识。解决经验流失、重复踩坑、技能退化问题。

## L2: 详细文档

### 核心能力
基于维特根斯坦语言哲学（"语言的边界就是世界的边界"）和阿德勒个体心理学（"优越感是人生的推动力"），通过"经验→知识→技能"的转化循环，实现AI Agent的持续进化。

### 学习光谱

```markdown
┌─────────────────────────────────────────────────────────────┐
│ 学习深度光谱                                                │
├─────────────────────────────────────────────────────────────┤
│ L1: 任务完成（零学习）                                     │
│     - 按预期完成，无新知识产生                             │
│     - 记录完成状态即可                                     │
│                                                             │
│ L2: 经验提取（浅层学习）                                   │
│     - 成功完成任务，发现可复用模式                         │
│     - 提取成功要素，沉淀为经验                             │
│                                                             │
│ L3: 教训总结（中层学习）                                   │
│     - 任务遇到困难或失败                                   │
│     - 分析根因，记录教训，避免重复踩坑                     │
│                                                             │
│ L4: 知识抽象（深层学习）                                   │
│     - 跨任务发现通用模式                                   │
│     - 抽象为原则、框架、方法论                             │
│     - 建议调用 dbs-deconstruct 解构知识结构               │
│                                                             │
│ L5: 技能进化（最高学习）                                  │
│     - 发现技能缺陷，主动学习新能力                        │
│     - 升级技能库，触发技能进化                             │
│     - 建议调用 dbs-ai-check 验证进化效果                 │
└─────────────────────────────────────────────────────────────┘
```

### 三步学习流程

```markdown
Step 1: 经验提取
  - 判断学习深度（L1-L5）
  - 识别关键事件（成功/失败/新模式）
  - 提取核心要素（what/how/why）
  - 标注上下文（任务类型、难度、环境）

Step 2: 知识沉淀
  - 格式化输出（经验卡片/教训记录/知识条目）
  - 建立关联（与现有知识连接）
  - 标注适用边界（when/where/who）
  - 更新知识库（wiki/memories/lessons）

Step 3: 技能进化
  - 评估技能缺口（基于任务表现）
  - 触发技能更新（提示词/工具/流程）
  - 验证进化效果（下次任务检验）
  - 记录进化轨迹（能力增长曲线）
```

### 知识复利公式

```
┌─────────────────────────────────────────────────────────────┐
│ 知识价值随时间复利                                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  价值(第N次) = 价值(第1次) × (1 + 链接数 × 0.1)^N          │
│                                                             │
│  示例:                                                      │
│  - 首次记录: 价值=10                                       │
│  - 引用1次:  价值=10 × (1+1×0.1)^1 = 11                    │
│  - 引用3次:  价值=10 × (1+3×0.1)^3 = 13.1                  │
│  - 引用10次: 价值=10 × (1+10×0.1)^10 = 25.9                │
│                                                             │
│  结论: 知识被引用越多，价值越高                             │
└─────────────────────────────────────────────────────────────┘
```

### 学习触发条件矩阵

| 触发类型 | 条件 | 学习深度 | 输出格式 |
|---------|------|---------|---------|
| **任务完成** | 预期完成 | L1-L2 | 状态记录/经验卡片 |
| **成功发现** | 发现可复用模式 | L2-L3 | 经验卡片/知识条目 |
| **失败挫折** | 遇到困难或失败 | L3 | 教训记录/根因分析 |
| **新模式发现** | 跨任务通用模式 | L4 | 原则/框架/方法论 |
| **技能缺口** | 能力不足以完成任务 | L5 | 技能升级计划 |
| **用户纠正** | 用户指出AI错误 | L3 | 教训记录 |
| **三次失败** | 同一问题三次失败 | L4 | 根因分析+解决方案 |

### 自检清单

- [ ] 学习深度已正确判断（L1-L5）
- [ ] 核心要素已完整提取（what/how/why）
- [ ] 上下文已明确标注（场景/边界/前提）
- [ ] 知识关联已建立（相关/前置/后续）
- [ ] 适用边界已标注（when/where/who）
- [ ] 知识复利已计算（引用次数×价值）
- [ ] 技能进化已验证（进化效果检验）

### 禁忌

- ❌ 不判断学习深度直接记录（无分类记录）
- ❌ 只记录成功，忽视失败教训（教训流失）
- ❌ 不建立知识关联（孤立知识无价值）
- ❌ 不标注适用边界（错误复用）
- ❌ 技能缺口不触发进化（能力停滞）
- ❌ 知识不更新不验证（陈旧知识）
- ❌ 学习记录不与Wiki同步（知识孤岛）
