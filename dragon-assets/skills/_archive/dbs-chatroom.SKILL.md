# dbs-chatroom

## L0: 一句话描述
聊天室管理——构建高效AI对话空间，管理对话上下文，追踪对话历史。

## L1: 使用场景
当需要创建、管理聊天室或处理多人对话场景时使用。解决AI对话中的空间混乱、信息丢失、上下文断裂问题。

## L2: 详细文档

### 核心能力
基于维特根斯坦语言哲学，通过"空间创建→上下文管理→历史追踪→状态同步"四步，构建高效的AI对话环境。

### 聊天室架构

```
┌─────────────────────────────────────────────────────────────┐
│ 聊天室三层架构                                              │
├─────────────────────────────────────────────────────────────┤
│ Layer 1: 物理空间                                           │
│  - 会话隔离（每个项目/任务独立空间）                        │
│  - 上下文持久化（会话快照）                                 │
│  - 文件管理（上传/下载/引用）                               │
├─────────────────────────────────────────────────────────────┤
│ Layer 2: 逻辑空间                                           │
│  - 角色分配（主持人/参与者/观察者）                         │
│  - 权限控制（读写权限）                                     │
│  - 消息分类（问题/回答/评论/附件）                         │
├─────────────────────────────────────────────────────────────┤
│ Layer 3: 元空间                                             │
│  - 对话目标（当前任务/长期目标）                           │
│  - 关系网络（谁在和谁讨论什么）                             │
│  - 知识沉淀（共识/分歧/待办）                               │
└─────────────────────────────────────────────────────────────┘
```

### 上下文管理策略

| 场景 | 策略 | 实现方式 |
|------|------|---------|
| 新建对话 | 空白上下文 | 清除历史，专注当前任务 |
| 延续对话 | 快照恢复 | dbs-restore读取上下文 |
| 复杂任务 | 分层上下文 | 核心问题+背景+约束+参考 |
| 多人协作 | 角色上下文 | 每条消息标注角色和意图 |
| 快速切换 | 上下文保存 | 定期保存快照，标签管理 |

### 聊天室操作清单

```
创建聊天室:
1. 定义空间边界（项目/任务/主题）
2. 设置角色权限（主持人/参与者）
3. 初始化上下文（空白/模板/历史）
4. 建立沟通规范（格式/节奏/反馈）

管理对话:
1. 追踪对话目标（显式声明）
2. 维护上下文清晰（定期总结）
3. 识别角色分工（谁负责什么）
4. 沉淀知识成果（保存关键结论）

归档与恢复:
1. 标记关键节点（决策/结论/待办）
2. 保存完整上下文（dbs-save快照）
3. 清理冗余信息（压缩历史）
4. 建立索引标签（方便检索）
```

### 天龙引擎协同

| 天龙岗位 | 协同方式 |
|---------|---------|
| **00分析师** | 聊天室目标澄清 → 上下文初始化 |
| **01调研师** | 多源信息整理 → 上下文分层 |
| **07记录师** | 对话存档 → Wiki归档 |
| **dbs-save** | 上下文快照 → 保存当前状态 |
| **dbs-restore** | 历史恢复 → 重建对话上下文 |

### 使用命令

```bash
/chatroom create             # 创建新聊天室
/chatroom join [id]         # 加入聊天室
/chatroom save              # 保存当前上下文
/chatroom restore [id]     # 恢复历史会话
/chatroom archive           # 归档当前聊天室
/chatroom list              # 列出可用聊天室
```

### 聊天室自检清单

- [ ] 空间边界清晰吗？
- [ ] 角色权限明确吗？
- [ ] 对话目标显式声明了吗？
- [ ] 上下文保持一致吗？
- [ ] 关键结论被记录了吗？
- [ ] 待办事项被追踪了吗？

### 禁忌

- ❌ 创建无边界聊天室（什么都讨论等于没空间）
- ❌ 上下文无限膨胀（定期压缩/归档）
- ❌ 角色混乱（主持人缺失或多人争权）
- ❌ 忽视沉默信号（参与者不说话可能有问题）
