# dbs-slowisfast

## L0: 一句话描述
慢就是快——通过刻意减速减少焦虑，提高决策质量和执行效果。

## L1: 使用场景
当用户陷入"必须马上做"的紧迫焦虑，或在高压下做出冲动决策时使用。通过强制减速，恢复理性思考空间。

## L2: 详细文档

### 核心能力
基于认知心理学"慢思考"理论，通过"减速三问"和"决策缓冲"机制，将冲动反应转化为深思熟虑的行动。

### 为什么要慢

```
┌─────────────────────────────────────────────────────────────┐
│ 慢思考 vs 快思考                                          │
├─────────────────────────────────────────────────────────────┤
│ 快思考（系统1）:                                          │
│  - 自动反应，本能驱动                                      │
│  - 容易出错，认知偏见                                      │
│  - 压力下更依赖快思考                                     │
│                                                             │
│ 慢思考（系统2）:                                          │
│  - 刻意用力，逻辑驱动                                      │
│  - 准确度高，但消耗精力                                     │
│  - 需要主动切换                                            │
└─────────────────────────────────────────────────────────────┘
```

### 减速三问

```
问题1: "真的紧急吗？"
  - 如果不做，最坏结果是什么？
  - 24小时后这件事还重要吗？
  - 这是谁的紧急感？（你的还是别人的）

问题2: "我已经了解足够了吗？"
  - 我是基于什么做出判断的？
  - 有没有遗漏关键信息？
  - 这个判断的可逆性如何？

问题3: "我能承担后果吗？"
  - 如果错了，我怎么办？
  - 有没有更稳妥的方案？
  - 是否需要征求他人意见？
```

### 决策缓冲机制

| 紧急程度 | 缓冲时间 | 操作 |
|---------|---------|------|
| 🔴 极度紧急（1小时内） | 即时决策 | 但执行前问减速三问 |
| 🟠 紧急（24小时内） | 2小时缓冲 | 写下决策理由再执行 |
| 🟡 一般（1周内） | 24小时缓冲 | 睡一觉再做决定 |
| 🟢 不紧急（1周以上） | 1周缓冲 | 设定提醒再做决定 |

### 慢速行动计划

```
阶段1: 强制暂停
  - 深呼吸3次（4-7-8呼吸法）
  - 离开现场（物理隔离）
  - 写下"我很想做X"

阶段2: 减速三问
  - 逐条回答减速三问
  - 写下每问的答案

阶段3: 决策缓冲
  - 根据紧急程度选择缓冲时间
  - 设定提醒时间

阶段4: 执行复盘
  - 决策质量如何？
  - 减速是否有价值？
  - 下次如何改进？
```

### 输出格式

```markdown
## dbs-slowisfast 减速报告

### 当前冲动
"[我想马上去做的行动]"

### 减速三问答案
1. 真的紧急吗？
   答案: [具体分析]
   结论: [紧急/不紧急]

2. 我已经了解足够了吗？
   答案: [已知信息]
   未知信息: [遗漏的关键点]

3. 我能承担后果吗？
   最坏情况: [描述]
   应对方案: [如果有]

### 决策缓冲
- 缓冲时间: [X小时/天]
- 提醒时间: [具体时间]
- 缓冲期行动: [做什么]

### 最终决策
[执行/不执行/修改后执行] + [理由]
```

### 天龙引擎协同

| 天龙岗位 | 协同方式 |
|---------|---------|
| **00分析师** | 决策前减速 → 分析更准确 |
| **02架构师** | 架构决策 → 强制缓冲期 |
| **09-06反合理化师** | 识别借口性紧急 → 真实 vs 虚假紧迫 |

### 使用命令

```bash
/dbs-slowisfast                    # 启动减速分析
dbs-slowisfast "我很想做X"      # 直接分析冲动
```

### 减速自检清单

- [ ] 呼吸3次完成了吗？
- [ ] 物理隔离了吗？
- [ ] 减速三问都回答了吗？
- [ ] 选择了合适的缓冲时间吗？
- [ ] 设置了提醒吗？

### 适用信号

🚨 **需要减速的信号**:
- 感觉"必须马上做"、"来不及了"
- 在愤怒/兴奋/恐惧状态下做决定
- 承诺"我一定会在X时间完成"
- 被催促做出承诺

✅ **可以快速行动**:
- 每天重复的例行决策
- 明确的A/B选项，无第三选择
- 完全可逆的小决策
- 信息充分、无需更多思考
