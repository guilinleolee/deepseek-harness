# dbs-goal

## L0: 一句话描述
目标审计——通过Wittgenstein语言哲学审查目标陈述，识别自欺性目标。

## L1: 使用场景
当用户提出模糊目标（"我想做点有意义的事"、"我应该更努力"）或反复未能达成的目标时使用。区分真实目标与愿望、幻想、义务、逃避。

## L2: 详细文档

### 核心能力
基于Wittgenstein语言游戏理论，审查目标陈述是否构成可执行的"语言游戏"。

### 五类虚假目标识别

| 类型 | 语言模式 | 示例 | 识别信号 |
|------|---------|------|---------|
| **愿望** | "我希望..." | "我希望有一天能..." | 无时间约束 |
| **幻想** | "如果...就..." | "如果中了彩票就..." | 条件不现实 |
| **义务** | "我应该..." | "我应该更努力" | 被动表述，无主体性 |
| **逃避** | "我要不是..." | "要不是没时间我就..." | 否定式表述 |
| **模糊** | "更有意义" | "做有意义的事" | 缺乏可衡量标准 |

### 真实目标的四要素

```
1. 主体性: "我要" 而非 "我应该"
2. 可衡量: 有明确成功标准
3. 时间约束: 有截止日期
4. 行动指向: 描述行为而非状态
```

### 七表解构法

```
Table 1: 目标语言分析
- 原句是什么？逐字记录
- 动词是行动型还是状态型？
- 有无可衡量的标准？

Table 2: 主体性检查
- 是"我要"还是"我应该"？
- 如果是"应该"，谁在期待？

Table 3: 时间约束检查
- 有截止日期吗？
- 如果没有，合理的时间框架是什么？

Table 4: 可衡量性检查
- 如何知道目标达成了？
- 有什么可见的标志？

Table 5: 障碍预判
- 实现这个目标的障碍是什么？
- 哪个障碍最可能在第3天出现？

Table 6: 行动分解
- 第一步行动是什么？
- 能在5分钟内开始吗？

Table 7: 承诺验证
- 你愿意为这个目标付出什么代价？
- 如果失败了，原因最可能是什么？
```

### 目标重写模板

```
原始目标: [用户的原话]
目标类型: [愿望/幻想/义务/逃避/模糊/真实]
核心问题: [为什么这个目标无效]

重写后:
我[具体主体][具体行动动词][可衡量标准]，
在[具体时间]之前完成。
第一步行动是[具体行动]，预计需要[时间]。

如果[可能障碍]出现，我将[应对策略]。
```

### 使用命令

```bash
/dbs-goal                    # 启动目标审计
dbs-goal "我的目标是..."     # 直接审计给定目标
```

### 关键提问

```
"你说的'有意义'，具体指什么？"
"你能描述一下目标达成后，你的一天会有什么不同吗？"
"如果没有时间限制，你会做什么？"
"你是在为自己说，还是在为别人说？"
```

### 审计信号

🚨 **红旗信号**:
- 目标表述包含"应该"、"必须"、"不得不"
- 目标是消除负面状态而非创造正面状态
- 用户无法描述目标达成后的具体场景
- 目标存在超过1年但从未开始

✅ **合格信号**:
- 包含"我要"而非"我应该"
- 有具体数字或可观测标准
- 有明确时间约束
- 用户能描述达成后的具体画面
