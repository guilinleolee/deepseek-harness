# dbs-restore

## L0: 一句话描述
会话恢复——基于快照文档还原上下文，快速进入工作状态。

## L1: 使用场景
当需要恢复之前会话的工作状态，或在新会话中承接历史工作时使用。通过快照文档快速还原决策背景和行动进度。

## L2: 详细文档

### 核心能力
从dbs-save生成的快照文档中提取关键信息，重建工作上下文，让用户快速"进入状态"。

### 恢复流程

```
┌─────────────────────────────────────────────────────────────┐
│ Step 1: 定位快照                                           │
│    - 查找最近的快照文件                                      │
│    - 确认快照主题与当前任务匹配                               │
├─────────────────────────────────────────────────────────────┤
│ Step 2: 读取概览                                           │
│    - 会话主题和时间                                         │
│    - 决策数和行动项数                                        │
│    - 关键背景信息                                           │
├─────────────────────────────────────────────────────────────┤
│ Step 3: 重建决策上下文                                     │
│    - 关键决策及理由                                         │
│    - 决策依据的信息来源                                     │
│    - 未解决的分歧点                                         │
├─────────────────────────────────────────────────────────────┤
│ Step 4: 确认行动进度                                        │
│    - 已完成的行动项                                         │
│    - 进行中的行动项                                         │
│    - 待开始的行动项                                         │
├─────────────────────────────────────────────────────────────┤
│ Step 5: 识别风险和障碍                                      │
│    - 标注的未解决问题                                       │
│    - 风险点                                                │
│    - 需要注意的上下文                                       │
└─────────────────────────────────────────────────────────────┘
```

### 快速恢复报告

```markdown
## 📋 上下文恢复报告

### 🎯 当前任务
"[快照主题]"

### 📅 会话历史
- 上次会话: [日期]
- 会话时长: [X分钟]
- 决策数: [N个]

### ✅ 已完成
- [已完成行动1]
- [已完成行动2]

### 🔄 进行中
- [进行中行动] - 进度: [描述]
- 当前卡点: [如有]

### 📋 待办
- [ ] [行动1] - 截止: [日期]
- [ ] [行动2] ...

### ⚠️ 需要注意
- [风险点1]
- [风险点2]

### ❓ 未解决问题
1. [问题1] - 阻塞: [因素]
2. [问题2] ...

### 🚀 建议继续点
[基于快照的建议下一步行动]
```

### 恢复质量标准

```
恢复完整性 = 上下文还原度 × 决策可追溯度 × 行动可执行度

上下文还原度:
  - 能回答"这是什么任务"？
  - 能回答"为什么做这个"？
  - 能回答"做到了哪一步"？

决策可追溯度:
  - 决策理由清晰？
  - 决策依据可查？
  - 有记录可验证？

行动可执行度:
  - 行动项具体明确？
  - 负责人和截止日期清晰？
  - 有继续点提示？
```

### 多快照恢复

当需要整合多个会话的快照时：

```
多快照恢复流程:

1. 收集所有相关快照
2. 按时间线排序
3. 提取每个快照的决策链
4. 合并行动项（去重+状态同步）
5. 识别跨会话的未解决问题
6. 生成整合恢复报告
```

### 使用命令

```bash
/dbs-restore                    # 恢复最近快照
dbs-restore --id [快照ID]      # 恢复指定快照
dbs-restore --topic [主题]      # 按主题恢复
dbs-restore --multi            # 整合多快照
```

### 恢复自检清单

- [ ] 能回答"这是什么任务"吗？
- [ ] 能回答"做到了哪一步"吗？
- [ ] 所有行动项都清晰吗？
- [ ] 未解决问题都有上下文吗？
- [ ] 知道下一步该做什么吗？

### 恢复信号

🚀 **需要恢复的情况**:
- 新会话开始时接手之前任务
- 中断后继续之前的工作
- 需要回顾之前的决策
- 团队成员交接工作
