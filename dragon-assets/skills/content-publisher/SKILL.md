# 内容发布 (Content Publisher)

> **自媒体工作台 · 发布层** | 天龙生成内容 → 多平台适配 → PostBot 一键发布

## 用途

把一篇内容（文章/笔记/脚本）生成**多平台适配的发布包**：
- 各平台的标题（长度/风格不同）
- 各平台的正文（格式/语气不同）
- 各平台的标签/话题（平台差异）
- 封面/首图文案建议

生成后，用户复制到 **PostBot 浏览器扩展** 一键同步发布。

## 前置：安装 PostBot 扩展

发布动作由 PostBot 浏览器扩展完成（半自动，安全）。

- **安装指南**：`third-party/PostBot安装指南.md`
- **核心步骤**：Chrome `chrome://extensions/` → 开发者模式 → 加载已解压扩展 → 选 `third-party/postbot-extension/`

## 多平台适配要点

| 平台 | 标题要点 | 正文风格 | 标签/话题 | 封面 |
|---|---|---|---|---|
| **小红书** | ≤20字，口语化，有钩子 | 分段短句，emoji适度，末尾引导收藏 | 3-5 个话题标签 + 关键词 | 首图大字 + 标题 |
| **抖音** | 前3秒钩子，口语 | 口播脚本（标题+开场+主体+CTA） | 3-5 个相关话题 | 封面大字吸睛 |
| **公众号** | ≤25字，信息明确 | 结构完整，可长文，配图 | 文末标签（可选） | 头图 |
| **知乎** | 问题式，专业 | 深度回答，分点论证 | 3-5 个话题标签 | 无/文字 |
| **B站** | ≤25字，标题党适度 | 视频简介 + 时间戳 | 3-5 个标签 | 封面 + 标题 |

## 工作流

### Step 1 · 确认内容与目标平台
- 输入：一篇内容（文章/笔记/脚本）
- 确认目标平台（默认：小红书 + 抖音 + 公众号）

### Step 2 · 生成多平台发布包
输出结构化 Markdown：

```markdown
# 发布包 · {内容标题}

> 生成时间：{date} | 源内容：{来源}

## 📱 小红书
**标题**：{≤20字，口语钩子}
**正文**：{分段短句，含引导收藏}
**标签**：#AI训练师 #副业 #干货 #{关键词}
**封面**：{首图建议}

## 🎬 抖音
**标题/口播前3秒**：{钩子}
**脚本**：{开场+主体+CTA，口语化}
**标签**：#AI #副业 #干货 #{关键词}

## 💬 公众号
**标题**：{≤25字}
**正文**：{结构化长文，配图建议}
**封面**：{头图建议}

## ✅ 发布前检查
- [ ] 各平台标题未超字数
- [ ] 标签平台差异已适配
- [ ] 无敏感词/违禁内容
```

### Step 3 · 复制到 PostBot 发布
用户打开 PostBot 扩展 → 粘贴对应平台的内容 → 勾选平台 → 一键发布。

### Step 4 · 记录到数据复盘
发布后，把互动数据记录到 **content-review-dashboard**（自媒体工作台第⑤层）：
```bash
python scripts/run_dashboard.py add --platform xiaohongshu --title "..." --views ... 
```

## 质量门（交付前自查）

1. 每个平台的标题都**适配其字数/风格**，不是同一标题硬套
2. 正文**平台化**（小红书短句emoji、公众号长文、抖音口播）
3. 标签**平台差异**已处理（各平台话题格式不同）
4. 发布包可直接复制，无需二次修改
5. 含发布前检查清单（字数/敏感词）
