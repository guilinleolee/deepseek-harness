# 03-正文

> **核心原则**
>
> 1. **视觉优先**：图像处理50ms，文字200ms
> 2. **块化阅读**：段落≤5-7行
> 3. **术语降维**：首段无术语或有解释
> 4. **开头3秒**：痛点/对比/反常识
> 5. **内容深度**：数据+案例+研究支撑
> 6. **SEO优化**：关键词密度+结构化+内链
> 7. **Geo定位**：地域化内容+本地案例+区域适配

---

## 视觉优先

```
处理速度：
图像 50ms >> 文字 200ms

结论：抽象概念必须有图
```

**执行标准**：
```
□ 抽象概念有图？
□ 操作步骤有截图？
□ 流程有流程图？
```

---

## 块化阅读

```
1块 = 1个核心观点
1块 ≤ 5-7行

太长 → 拆分
太短 → 合并
```

**段落结构**：
```
观点（1行）
↓
解释（2-3行）
↓
例子/证据（2-3行）
```

---

## 术语降维

**原则**：首段无术语，或有即时解释

**降维模板**：
```
[术语]，就是[小白能懂的说法]

示例：
- API → "程序之间的对话接口"
- Token → "AI的阅读成本"
```

**检查**：
```
□ 首段无术语？
□ 必须用术语时有解释？
□ 用类比让小白理解？
```

---

## 开头3秒

**三种开头方式**：

### 方式1：痛点前置
```
"你是不是遇到过这个问题：[具体痛点]"
```

### 方式2：对比冲击
```
"以前需要[旧方法]，现在只需要[新方法]"
```

### 方式3：反常识
```
"大多数人以为[错误认知]，其实[正确认知]"
```

## 内容深度

### 数据支撑

```
可信度 = 数据权威性 × 样本规模 × 新鲜度
```

**数据等级**：
| 等级 | 来源 | 可信度 |
|------|------|--------|
| A类 | 顶级期刊/Nature | ★★★★★ |
| B类 | 行业白皮书/Gartner | ★★★★ |
| C类 | 公司官方报告 | ★★★ |
| D类 | 个人经验/估算 | ★★ |

**使用原则**：
```
□ 引用数据标注来源？
□ 样本规模≥1000？
□ 数据时间≤2年？
```

### 案例深度

**案例三要素**：
```
1. 背景情境（Who + When + Where）
2. 具体行动（What + How）
3. 可量化结果（数据指标）
```

**案例结构模板**：
```
### 案例X：[公司/个人]如何[达成目标]

**背景**：
- 行业：[行业]
- 规模：[规模]
- 痛点：[具体问题]

**行动**：
1. [步骤1]：[具体做法]
2. [步骤2]：[具体做法]
3. [步骤3]：[具体做法]

**结果**：
- [指标1]：[数字]
- [指标2]：[数字]
- ROI：[计算方式]
```

### 研究引用

**研究引用标准**：
```
□ 有明确出处？
□ 有具体数据？
□ 有研究方法？
□ 有样本描述？
```

## SEO优化

### 关键词策略

**关键词金字塔**：
```
          主关键词（1个）
         /    |    \
   长尾词1  长尾词2  长尾词3（3-5个）
   /  \
LSI词1 LSI词2（5-10个）
```

**密度控制**：
```
主关键词密度：1-2%
长尾词密度：0.5-1%
LSI词自然出现
```

**关键词布局**：
```
□ 标题：主关键词
□ 前100字：主关键词+1个长尾词
□ H2/H3：长尾词
□ 结尾：主关键词
□ 图片alt：描述性+关键词
```

### 结构化优化

**SEO友好结构**：
```
H1：主标题（含主关键词）
├── H2：章节标题（含长尾词）
│   ├── H3：小节
│   └── 段落（200-300字）
├── H2：章节标题
│   └── 列表/表格
└── H2：总结/行动建议
```

**内容长度**：
```
最佳长度：1500-2500字

<1000字：深度不足
>3000字：用户读不完
```

### 内链策略

**内链原则**：
```
□ 链向相关主题文章
□ 链向权威来源（外链）
□ 使用描述性锚文本
□ 每篇文章3-5个内链
```

**锚文本模板**：
```
❌ "点击这里"
✅ "了解[具体主题]的详细步骤"
```

## Geo定位

### 地域化内容

**Geo三层定位**：
```
Geo = 国家层 → 城市层 → 本地层
```

**定位策略**：

| 层级 | 内容策略 | 示例 |
|------|----------|------|
| 国家层 | 国家政策、文化背景 | "中国互联网用户" |
| 城市层 | 城市特色、产业分布 | "上海金融从业者" |
| 本地层 | 具体地点、场景化 | "北京朝阳区的..." |

### 本地案例

**地域案例模板**：
```
### [城市/地区]案例：本地化实践

**背景**：
- 地区：[城市/省份]
- 行业特点：[当地特色]
- 用户画像：[年龄/职业/收入]

**本地化调整**：
1. [适配点1]：[具体调整]
2. [适配点2]：[具体调整]

**结果**：
- 本地转化率：[数字]%
- 与全国平均对比：[±X%]
```

### 区域适配

**适配维度**：

**1. 语言方言**：
```
□ 考虑当地方言？
□ 避免地域误解词汇？
```

**2. 文化习俗**：
```
□ 尊重当地习俗？
□ 避开敏感话题？
□ 使用当地文化符号？
```

**3. 经济水平**：
```
□ 价格适配当地收入？
□ 案例适配当地规模？
```

**4. 气候环境**：
```
□ 季节性内容适配？
□ 气候相关案例？
```

### Geo SEO

**本地SEO元素**：
```
□ 标题包含地域词（如"北京""上海"）
□ 内容提及本地地标
□ 本地关键词（如"朝阳区XX"）
□ 本地案例/公司
□ 本地事件/新闻
```

**地域词库**：
```
国家级：中国、国内、全国
省级：北京、上海、广东...
市级：朝阳区、浦东新区、天河区...
本地：具体商圈、地标、地铁站
```

```
□ 抽象概念有图？

□ 首段无术语？

```

□ 案例含情境+行动+结果？
□ 有研究引用？
□ 数据时间≤2年？
```

```
□ 主关键词密度1-2%？
□ 前100字含主关键词？
□ H2/H3含长尾词？
□ 长度1500-2500字？
□ 有3-5个内链？
□ 图片有alt描述？
```

### Geo检查
```
□ 有地域定位（国家/城市/本地）？
□ 有本地案例？
□ 适配当地文化/经济/气候？
□ 标题含地域词？
□ 内容提及本地地标？
□ 避免地域敏感词？
