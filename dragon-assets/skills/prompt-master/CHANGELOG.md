## 版本说明

### 语义化版本

版本号格式: MAJOR.MINOR.PATCH

- **MAJOR**: 不兼容的API变更
- **MINOR**: 向后兼容的功能新增
- **PATCH**: 向后兼容的问题修复

### 贡献指南

欢迎贡献！请遵循以下规范：

1. **提交信息格式**:
   ```
   feat: 添加新功能
   fix: 修复问题
   docs: 更新文档
   refactor: 代码重构
   test: 添加测试
   chore: 构建/工具变更
   ```

2. **PR模板**:
   - 变更说明
   - 相关Issue
   - 测试情况
   - 截图（如适用）
