# lib-bingling-v2 · 用以致学图文生成器 V2.0

> **版本**：V2.0.0（2026-07-10）
> **定位**：老李品牌全平台图文生成中心

---

## 快速开始

### 双击运行测试

直接双击 `运行测试.bat` 生成8张示例封面图到 `output/` 目录。

### 命令行使用

```bash
# 列出所有选项
python cli.py list

# 封面图
python cli.py cover "标题" -s "副标题" -p gongzhonghao -j zhuji -l full-title

# 金句卡片
python cli.py quote "金句内容" -a 李秉凌 -p pengyouquan -j wudao
```

## 核心功能

### 1. 多画板尺寸（7种）

| 平台 | 比例 | 尺寸 |
|------|------|------|
| 公众号头图 | 16:9 | 1920×1080 |
| 公众号封面 | 21:9 | 2100×900 |
| 公众号分享卡 | 1:1 | 1080×1080 |
| 小红书图文 | 3:4 | 1080×1440 |
| 朋友圈分享 | 1:1 | 1080×1080 |
| 视频封面 | 16:9 | 1920×1080 |

### 2. 12套配色方案

**老李七境系列（7套）**
- 筑基蓝 · 悟道紫 · 结丹金 · 炼气橙 · 炼丹暗橙 · 破境翠 · 长生银

**特殊主题（5套）**
- 摸鱼绿（老李专属）
- 廉颇金
- 深夜墨
- 商务蓝
- 简约白

### 3. 8种版式骨架

- full-title（全幅大字）
- center-float（居中悬浮）
- dual-title（双标题对比）
- left-right（左图右文）
- kpi-card（数据卡片）
- flowchart（流程图）
- comparison（对比表格）
- framework（框架图）
