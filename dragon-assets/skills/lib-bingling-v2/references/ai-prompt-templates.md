# AI生图Prompt模板库

> **版本**：V1.0（2026-07-10）
> **用途**：老李品牌配图的AI生图Prompt模板

---

## 一、Prompt基础框架

### 1.1 系统设定

```
【角色】
你是老李品牌御用插画师，为"用以致学"品牌创作正文配图。

【品牌介绍】
- 创始人：李秉凌（老李）
- 金句：心不老，身不灭。吾未老，尚能战！
- 风格：商务手绘、专业、简洁
- 核心：副业创业、价值方程、用以致学
```

### 1.2 画面要求

```
【画面要求】
- 比例：16:9 横版
- 背景：纯白 #FFFFFF 或 #F8F9FA
- 线条：黑色手绘线条，轻微抖动感
- 风格：商务手绘，不是可爱卡通
- 留白：40-60%

【禁止】
- ❌ 标题标注（"流程图"、"对比图"）
- ❌ 大段文字
- ❌ PPT感
- ❌ 幼稚可爱风
- ❌ 纯扁平插画
```

## 三、概念Prompt模板

### 3.1 核心判断类

```
【画面】
{concept}

【构图】
居中构图，核心概念突出显示。主体占据画面40-60%，留白充足。

【元素】
- 核心概念可视化
- 1-2个辅助元素
- 中文手写批注1-3个

【批注】
- 位置：画面边缘或空白处
- 颜色：金色#FFD700
- 内容：核心关键词

【示例Prompt】
商业手绘风格，16:9横版，纯白背景，黑色手绘线条，主体居中，占画面50%，金色强调色。画出"副业=第二颗丹"的概念：丹炉中炼出两颗丹，一大一小，象征主业和副业。右上角金色批注："第二颗丹"。无文字标注，简洁专业。
```

### 3.2 流程步骤类

```
【画面】
{steps}

【构图】
流程图式，步骤清晰。步骤用圆形编号，箭头连接。

【元素】
- 3-5个步骤节点
- 箭头连接
- 每步1个关键词批注

【批注】
- 颜色：橙色#DD6B20
- 内容：步骤关键词

【示例Prompt】
商业手绘风格，16:9横版，纯白背景，黑色手绘线条。画出"价值方程"流程：天平左边"梦想×概率"（火焰/星星），天平右边"时间×努力"（沙漏/重量）。天平中央发光。步骤用圆形标注，橙色批注关键词。无文字标题，简洁专业。
```

### 3.3 对比差异类

```
【画面】
左边：{wrong}
右边：{right}

【构图】
左右分栏，对比鲜明。中间用VS或箭头分隔。

【元素】
- 左：错误做法（红色警示）
- 右：正确做法（蓝色正确）
- 中：分隔线或VS标记

【批注】
- 红色标注错误
- 蓝色标注正确

【示例Prompt】
商业手绘风格，16:9横版，纯白背景，黑色手绘线条。左右对比构图，中间虚线分隔。左边：一个人疯狂降价，价格牌越来越低，红色标注"降价求量"。右边：一个人自信展示产品，价格合理，蓝色标注"价值包装"。无文字标题，简洁专业。
```

### 3.4 概念隐喻类

```
【画面】
{metaphor}

【构图】
创意隐喻，概念可视化。画面有创意但不怪诞。

【元素】
- 隐喻物体
- 概念关联
- 批注说明

【批注】
- 颜色：金色#FFD700或紫色#805AD5
- 内容：隐喻解释

【示例Prompt】
商业手绘风格，16:9横版，纯白背景，黑色手绘线条。画出"用以致学"的概念隐喻：书本变成工具箱，工具箱发光，箭头指向实践成果。金色强调发光部分。紫色批注："用→学"。无文字标题，简洁专业，创意隐喻。
```

### 3.5 常见误区类

```
【画面】
{pitfall}

【构图】
警示风格，红色强调。画面有警示感但不过度。

【元素】
- 警示元素（❌/感叹号）
- 问题可视化
- 红色批注

【批注】
- 颜色：红色#E53E3E
- 内容："坑"/"误区"/"注意"

【示例Prompt】
商业手绘风格，16:9横版，纯白背景，黑色手绘线条。警示构图，画面中央一个大大的价格牌，数字疯狂下降，红色标注"降价求量"。旁边一个小人看着崩溃，红色批注"坑"。无文字标题，警示感强，简洁专业。
```

### 3.6 情感转折类

```
【画面】
{emotional}

【构图】
情感表达，氛围渲染。画面有感染力但不过度煽情。

【元素】
- 情感象征物
- 转折箭头
- 积极元素

【批注】
- 颜色：橙色#DD6B20
- 内容：转折关键词

【示例Prompt】
商业手绘风格，16:9横版，纯白背景，黑色手绘线条。画出"谷底反弹"的情感转折：左边黑暗中的人影，低头；右边光芒中站起的人影，抬头。橙色箭头从左指向右，上方金色批注"心不老，身不灭"。无文字标题，情感氛围强，简洁专业。
```

## 四、人物Prompt模板

### 4.1 老李形象

```
【老李形象】
- 外观：商务装/西装，中年男性
- 表情：自信/微笑/思考
- 姿态：讲解/示范/展示
- 风格：简笔卡通，非写实

【示例Prompt】
包含老李卡通形象：中年男性，商务装，站在画面左侧，正在用手比划讲解，表情自信。商务手绘风格，简洁专业。
```

### 4.2 廉颇形象

```
【廉颇形象】
- 外观：战士姿态，肌肉线条
- 元素：铁拳/盾牌
- 风格：简笔卡通，非写实
- 象征：抗揍/坚韧/坚持

【示例Prompt】
包含简笔战士形象：肌肉线条，战士姿态，举起拳头。背景用裂纹/压力元素表示困难。商务手绘风格，简洁专业，象征抗压精神。
```

### 5.2 价值方程

### 5.3 降价求量是坑

### 5.4 谷底反弹

