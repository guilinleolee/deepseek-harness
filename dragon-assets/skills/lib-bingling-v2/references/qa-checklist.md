# 质检清单 · QA Checklist

> **版本**：V1.0（2026-07-10）

---

## 一、生成前检查

### 1.1 内容检查
- [ ] 标题文字完整，无截断
- [ ] 副标题与标题语义相关
- [ ] 无错别字或乱码
- [ ] 品牌标识文字正确（李秉凌·用以致学）

### 1.2 配置检查
- [ ] 平台尺寸正确（gongzhonghao/xiaohongshu等）
- [ ] 配色与七境匹配（zhuji/wudao等）
- [ ] 版式与内容类型匹配
- [ ] 品牌标识开启（除非用户要求关闭）

---

## 二、生成后检查

### 2.1 视觉检查
- [ ] 背景色正确（深色/浅色）
- [ ] 主色调与配色方案一致
- [ ] 装饰条/边框正常显示
- [ ] 无明显的锯齿或模糊

### 2.2 文字检查
- [ ] 标题完整显示，无溢出
- [ ] 副标题完整显示，无溢出
- [ ] 文字描边清晰可读
- [ ] 无乱码或乱码字符
- [ ] 品牌标识正确显示

### 2.3 布局检查
- [ ] 内容居中或符合版式设计
- [ ] 留白比例适当（40-60%）
- [ ] 无元素重叠
- [ ] 底部品牌标识可见

### 2.4 格式检查
- [ ] 文件格式为PNG
- [ ] 尺寸与平台匹配
- [ ] 文件命名规范

---

## 三、不同版式检查要点

### 3.1 full-title（全幅大字）
- [ ] 标题占据视觉中心
- [ ] 上下装饰条对称
- [ ] 七境徽章位置正确

### 3.2 center-float（居中悬浮）
- [ ] 四周边距均匀
- [ ] 无描边，更简洁
- [ ] 适合金句类内容

### 3.3 dual-title（双标题对比）
- [ ] 上下两个标题清晰区分
- [ ] 中间分隔线可见
- [ ] 适合对比类内容

### 3.4 kpi-card（数据卡片）
- [ ] 数据数字突出
- [ ] 标签文字清晰
- [ ] 适合数据展示

---

## 四、不同平台检查

### 4.1 公众号（gongzhonghao）
- [ ] 尺寸 1920×1080
- [ ] 标题适合16:9比例
- [ ] 可用作公众号头图

### 4.2 公众号封面（gongzhonghao-wide）
- [ ] 尺寸 2100×900
- [ ] 21:9超宽比例
- [ ] 适合封面展示

### 4.3 小红书（xiaohongshu）
- [ ] 尺寸 1080×1440
- [ ] 竖版3:4比例
- [ ] 适合小红书图文

### 4.4 朋友圈（pengyouquan）
- [ ] 尺寸 1080×1080
- [ ] 正方形1:1比例
- [ ] 适合朋友圈分享

---

## 五、问题修复

### 5.1 文字溢出
**问题**：文字超出画布边界
**解决**：
1. 减小字号
2. 增加换行
3. 缩短文本

### 5.2 配色不匹配
**问题**：配色与预期不符
**解决**：
1. 检查jingjie参数
2. 检查palette参数
3. 确认color_scheme

### 5.3 品牌标识缺失
**问题**：底部没有品牌标识
**解决**：
1. 确认brand_mark=True
2. 检查字体是否支持中文
