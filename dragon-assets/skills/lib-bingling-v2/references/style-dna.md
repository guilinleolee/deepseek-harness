# 老李配图风格 DNA · Style Guide

> **版本**：V1.0（2026-07-10）
> **定位**：老李品牌专属正文配图风格

---

## 一、核心定位

老李配图是"用以致学"品牌视觉系统的重要组成部分，用于公众号文章、小红书图文等平台的**正文配图**。

**与封面的区别**：
- 封面：冲击力、品牌展示
- 配图：解释说明、认知锚点

**与"小黑"的区别**：
- 小黑：手绘怪诞、黑色小人
- 老李配图：商务手绘、老李形象、品牌视觉

---

## 二、视觉DNA

### 2.1 整体风格

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   关键词：商务手绘 · 品牌一致 · 认知清晰 · 怪诞但专业       │
│                                                             │
│   不是：可爱卡通 / 幼稚涂鸦 / 纯装饰图 / PPT风             │
│   是：   手绘线条 / 品牌色彩 / 概念可视化 / 有记忆点      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 颜色系统

| 角色 | 色值 | 用途 |
|------|------|------|
| **背景** | #FFFFFF 或 #F8F9FA | 干净白底 |
| **主线条** | #2D3748 | 黑色手绘线稿 |
| **强调色1** | #E53E3E | 红色批注 |
| **强调色2** | #DD6B20 | 橙色标注 |
| **强调色3** | #3182CE | 蓝色说明 |
| **老李标识** | #FFD700 | 金色品牌色 |
| **辅助色** | #718096 | 灰色辅助 |

### 2.3 线条风格

```
特征：
- 轻微手绘抖动感（非完美直线）
- 线条粗细：2-4px
- 线型：实线为主，偶有虚线
- 风格：Sketch/Hand-drawn

禁止：
- ❌ 完美几何线条
- ❌ 粗黑描边
- ❌ 复杂阴影
- ❌ 扁平插画风
```

## 三、构图原则

### 3.1 留白法则

```
画面占比：主体占 40-60%
留白比例：40-60%
目的：保持清爽、易读、不拥挤
```

### 3.2 视觉锚点

```
必须有视觉焦点：
- 一个核心概念
- 一个主要视觉元素
- 一个清晰的信息层次

禁止：
- ❌ 多中心
- ❌ 信息过载
- ❌ 平均分配注意力
```

### 3.3 文字原则

```
批注文字：
- 数量：每张图 1-3 个关键词
- 位置：画面边缘或空白处
- 颜色：红/橙/蓝三色
- 字体：手写体或楷体
- 大小：适中，不抢主体

禁止：
- ❌ 大段文字
- ❌ 标题式文字
- ❌ 密集小字
- ❌ 左上角"流程图"等标签
```

## 四、老李元素

### 4.1 老李形象

```
形象定位：商务手绘风格的老李剪影或卡通形象

特征：
- 侧影或简单卡通
- 穿西装或商务装
- 表情：自信/微笑/思考
- 姿态：正在做某件事

应用场景：
- 讲解示范
- 对比展示
- 流程参与
- 观点表达
```

### 4.2 廉颇元素

```
形象定位：王者荣耀廉颇的简化手绘版

特征：
- 战士姿态
- 铁拳/重拳
- 抗揍/坚韧感

应用场景：
- 抗压主题
- 坚持主题
- 创业艰辛
```

### 4.3 品牌标识

```
位置：右下角或底部
内容："李秉凌·用以致学" 或品牌符号
大小：较小，不抢主体
颜色：金色 #FFD700 或灰色 #718096
```

## 五、配图类型

### 5.1 概念解释图

```
用途：解释抽象概念
特征：
- 隐喻可视化
- 核心概念突出
- 简明扼要

示例：
- "副业=第二颗丹" → 画出丹炉/丹药
- "认知升级" → 画眼镜/放大镜
- "时间管理" → 画时钟/沙漏
```

### 5.2 流程步骤图

```
用途：展示步骤/流程
特征：
- 清晰步骤编号
- 箭头连接
- 简洁明了

示例：
- 7天落地步骤
- 变现流程
- 学习路径
```

### 5.3 对比图

```
用途：展示优劣/前后对比
特征：
- 左右分栏
- 对比清晰
- 结论明确

示例：
- 错误做法 vs 正确做法
- 之前 vs 之后
- 低效 vs 高效
```

### 5.4 场景图

```
用途：展示真实场景/案例
特征：
- 有场景感
- 有人物
- 有情境

示例：
- 创业场景
- 学习场景
- 赚钱场景
```

### 5.5 数据图

```
用途：展示数据/指标
特征：
- 数据可视化
- 数字突出
- 简明易懂

示例：
- KPI卡片
- 对比柱状
- 增长曲线
```

## 六、禁止事项

### 6.1 风格禁止

```
❌ 纯扁平插画风
❌ 儿童卡通风格
❌ 可爱emoji风格
❌ 幼稚涂鸦风格
❌ 复杂架构图
❌ 商业插画风
❌ 过度装饰
```

### 6.2 内容禁止

```
❌ 大段解释文字
❌ 标题式标注（"流程图"、"对比图"）
❌ 过多颜色
❌ 信息过载
❌ 装饰性图形过多
```

### 6.3 老李形象禁止

```
❌ 老李做奇怪表情
❌ 老李穿奇装异服
❌ 老李形象过于卡通/可爱
❌ 廉颇形象过于暴力
```

## 七、成功标准

### 7.1 视觉标准

```
✅ 干净白底
✅ 手绘线条感
✅ 留白充足（40-60%）
✅ 色彩克制（3色以内）
✅ 视觉焦点清晰
```

### 7.2 信息标准

```
✅ 每张图一个核心概念
✅ 批注简洁（1-3个关键词）
✅ 信息层次清晰
✅ 易于理解
```

### 7.3 品牌标准

```
✅ 品牌色金色出现
✅ 老李/廉颇元素（可选）
✅ 品牌标识可见
✅ 风格统一
```

## 八、示例参考

### 示例1：副业=第二颗丹

```
画面：丹炉中炼出两颗丹，一大一小
批注：主业=第一颗丹 / 副业=第二颗丹
颜色：金色强调
风格：商务手绘
```

### 示例2：价值方程

```
画面：天平，一边是"梦想×概率"，一边是"时间×努力"
批注：价值 = (梦想×概率) / (时间×努力)
颜色：红/蓝色强调
风格：商务手绘
```

### 示例3：7天落地

```
画面：7个步骤，用箭头连接
批注：每步1个关键词
颜色：红/橙色
风格：商务手绘
```

## 九、与小黑的差异化

| 维度 | 老李配图 | 小黑配图 |
|------|---------|---------|
| IP形象 | 老李/廉颇 | 小黑（黑色小人） |
| 风格 | 商务手绘 | 怪诞手绘 |
| 色彩 | 品牌金色+红蓝 | 黑白红橙蓝 |
| 适用 | 品牌内容 | 通用内容 |
| 商业感 | 强 | 中 |
| 个人风格 | 强 | 中 |
