# Frontend Design - 前端视觉设计

> **来源**: [Anthropic官方技能](https://github.com/anthropics/skills/tree/main/skills/frontend-design)
> **版本**: V1.0 | **集成**: 天龙引擎 V9.1
> **说明**: 官方前端设计指南，强调独特、有意图的视觉设计

## L0: 一句话描述

像设计工作室首席设计师一样创建独特、有意图的视觉设计

## L1: 核心设计理念

### 设计原则

> **核心心态**: 把这当作一家小型设计工作室的设计负责人，客户已经拒绝了感觉模板化的提案，正在付费获取独特的视角。

### 设计方法论

| 维度 | 原则 | 反模式 |
|------|------|--------|
| **主题关联** | 从产品主题的世界中汲取灵感 | 通用模板设计 |
| **Hero定位** | Hero是论点，用最典型的内容开篇 | 大数字+渐变accent模板 |
| **字体个性** | 配对字体要体现页面个性 | 通用的Inter/Roboto |
| **结构信息** | 编码真实内容，不是装饰 | 随意使用01/02/03编号 |
| **动效意图** | 动画要有明确目的 | 分散的无关动效 |

### AI设计三大默认 (需避免)

| 默认风格 | 特征 | 何时适用 |
|---------|------|---------|
| **温暖奶油风** | 背景#F4F1EA，高对比serif标题，土褐色accent | 真正适合时 |
| **深色酸性风** | 近黑背景，单一亮色accent | 真正适合时 |
| **报纸风格** | 细线规则，零圆角，密排 | 真正适合时 |

## L2: 两轮工作流程

### 第一轮：设计计划

```markdown
创建紧凑的token系统：

颜色: 4-6个命名hex值
字体: 2+角色
  - 角色感display字体（克制使用）
  - 互补的body字体
  - 工具字体（如需要）

布局: 布局概念
  - 一句话ASCII线框图

签名: 唯一记忆点
  - 页面被记住的那个元素
```

### 第二轮：自检

```markdown
在构建前审查计划：
- 是否有读起来像通用默认的部分？
- 如果用类似prompt是否会得到类似结果？
- 如果是，修改并说明原因

只有在确认设计计划的相对独特性后，才开始写代码
```
