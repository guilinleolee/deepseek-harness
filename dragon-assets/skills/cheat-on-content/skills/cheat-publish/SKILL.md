# Cheat-Publish — 发布决策系统

## L0: 一句话描述
基于评分和预测的发布决策

## L1: 使用场景
确认发布前的最终决策，记录buffer状态

## L2: 详细文档

### 触发词
- "发布这个"
- "ship it"
- "确认发布"
- "发布 [path]"

### 工作流

```
1. 验证评分已完成（cheat-score）
2. 验证预测已写完（cheat-predict）
3. 记录发布时间
4. Buffer -1
5. 创建发布记录
```

### 发布记录格式

```markdown
# 发布记录

## 基础信息
- 标题: [标题]
- 脚本路径: [path]
- 发布时间: 2026-05-24
- 平台: Douyin

## 评分摘要
- 综合分: 7.3/10
- ER/SR/HP: 4/5/3

## 预测摘要
- 预测播放: 10万+
- 预测互动: 5%
- 预测爆款: 70%

## 状态
- Buffer: -1
- 复盘状态: 待T+3d
```

### Buffer管理

```
Buffer初始值: 5
发布 -1
shot +1
Buffer耗尽 → 必须完成复盘才能继续发布
```
