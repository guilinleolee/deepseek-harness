# Cheat-Shoot — 拍摄计划系统

## L0: 一句话描述
将脚本转化为可执行的拍摄计划

## L1: 使用场景
将评分合格的脚本转化为拍摄任务清单

## L2: 详细文档

### 触发词
- "拍摄计划"
- "shoot this"
- "制定shot"
- "拍摄清单"

### 拍摄计划格式

```markdown
# 拍摄计划: [脚本标题]
## 基本信息
- 脚本路径: scripts/[脚本名].md
- 预计时长: 60秒
- 拍摄地点: [位置]
- 设备: [设备清单]

## 分镜表
| 镜头 | 时长 | 内容 | 要点 | B-roll |
|------|------|------|------|--------|
| 1 | 5s | 开场 | [描述] | [素材] |
| 2 | 15s | 核心1 | [描述] | [素材] |

## 道具清单
- [ ] 道具1
- [ ] 道具2

## 拍摄顺序
1. B-roll素材
2. 主镜头
3. 补拍镜头

## Buffer影响
- Buffer: 当前状态
- Shoot后: Buffer +1
```

### 拍摄流程

```
1. 验证脚本已评分（cheat-score）
2. 验证预测已写完（cheat-predict）
3. 创建拍摄计划
4. 更新buffer状态（+1）
5. 记录到shot-log/
```

### 天龙引擎集成

- **天龙岗位**: 35-05短视频编导、35-02社媒运营
- **协同**: cheat-score（前提）、cheat-publish（后续）、cheat-status（状态追踪）
