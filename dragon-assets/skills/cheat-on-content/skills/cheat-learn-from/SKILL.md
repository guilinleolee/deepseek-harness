# Cheat-Learn-from — 判断进化系统

## L0: 一句话描述
从复盘数据中提取判断进化规则

## L1: 使用场景
分析偏差模式，更新判断规则库

## L2: 详细文档

### 触发词
- "学习这个"
- "learn from this"
- "提取规则"
- "判断进化"

### 偏差分类

| 偏差类型 | 定义 | 示例 |
|----------|------|------|
| ER偏差 | 情感共鸣判断失误 | 高ER预测但低互动 |
| SR偏差 | 社交传播预测失误 | 低SR预测但高转发 |
| HP偏差 | 钩子强度误判 | 强HP但低完播 |
| 系统偏差 | 三次同向偏差 | 连续三次预测偏高 |

### 进化规则格式

```markdown
# 判断进化规则

## 规则001
- 类型: HP偏差
- 发现时间: 2026-05-24
- 样本: 视频A
- 原判断: HP=4（开头强）
- 实际: 完播率低
- 原因分析: 开场吸引但后续节奏拖沓
- 新规则: HP不仅要开场强，还要评估"前30秒钩子+30-120秒节奏"
- 验证样本: 视频B、视频C
```
