# Cheat-Evaluate — 系统评估系统

## L0: 一句话描述
评估rubric有效性和预测准确率

## L1: 使用场景
定期检查评分系统的准确性和预测偏差

## L2: 详细文档

### 触发词
- "评估rubric"
- "evaluate"
- "检查准确性"
- "rubric健康度"

### 评估维度

```
1. 预测准确率
   - 播放量预测命中率
   - 互动率预测偏差
   - 爆款识别率

2. Rubric有效性
   - 校准样本一致性
   - 维度区分度
   - 评分稳定性

3. 系统健康度
   - 复盘完成率
   - Bump触发频率
   - Buffer使用效率
```

### 评估报告格式

```markdown
# 系统评估报告
生成日期: 2026-05-24

## 预测准确率
| 指标 | 预测 | 实际 | 偏差 |
|------|------|------|------|
| 播放量 | 15万 | 12万 | -20% |
| 互动率 | 6% | 5.2% | -13% |
| 爆款 | 否 | 否 | ✅ |

## Rubric有效性
| 维度 | 区分度 | 稳定性 |
|------|--------|--------|
| ER | 0.85 | 0.92 |
| SR | 0.78 | 0.88 |
| HP | 0.45 ⚠️ | 0.95 |

## 系统建议
- HP维度区分度偏低，建议细化标准
- Bump历史重打分匹配率92%，rubric稳定
```
