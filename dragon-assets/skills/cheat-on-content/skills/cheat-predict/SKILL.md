# Cheat-Predict — 盲预测系统

## L0: 一句话描述
在不看数据的情况下写下可追踪的预测

## L1: 使用场景
发布前必须完成的赌注记录，用于事后对账学习

## L2: 详细文档

### 触发词
- "启动预测 [path]"
- "盲预测这篇"
- "写预测"
- "bet this"

### 三条铁律

```
1. 预测必须在看数据前写完
2. 写完的预测不可改，只能追加review
3. 必须写出具体的bucket预测（爆/普通/冷）
```

### 工作流

```
1. 读取脚本内容和当前rubric
2. 生成预测（不看任何数据）
3. 写入 predictions/[date]-[title].md
4. 输出决策日志（预测理由）
```

### 预测文件格式

```markdown
# 盲预测: [标题]

## 预测日期
2026-05-24

## 预测内容
[不看数据写下的预测]

## Bucket预测
- 预期播放量: 10万+
- 预期互动率: 5%+
- 预期爆款概率: 70%

## 决策理由
[写预测时的核心判断依据]

## 预测元数据
- 评分综合分: 7.3
- ER/SR/HP: 4/5/3
- 关键判断: [rubric维度决策]

---
## Review (发布后填写)
[实际数据出来后追加的复盘]
```

### 关键约束

- 预测文件创建后，主内容区不可修改
- 只能追加 `## Review` 部分
- 必须包含具体的量化预测（不能模糊）

### 天龙引擎集成

- **天龙岗位**: 35-02社媒运营、40-01用户增长、35-05短视频编导
- **协同**: cheat-score（预测基础）、cheat-retro（对账）
