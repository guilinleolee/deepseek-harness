# Cheat-Recommend — 选题推荐系统

## L0: 一句话描述
基于趋势和历史数据推荐最优选题

## L1: 使用场景
从趋势话题中筛选最具潜力的选题

## L2: 详细文档

### 触发词
- "推荐选题"
- "recommend"
- "选题建议"
- "哪个话题好"

### 推荐流程

```
1. [cheat-trends] 获取趋势数据
2. 匹配受众画像（cheat-persona）
3. 历史表现分析（learned-rules）
4. 竞品分析（避免同质化）
5. 输出推荐排序
```

### 推荐报告格式

```markdown
# 选题推荐报告
生成日期: 2026-05-24

## Top 3 推荐
1. **[话题A]** ⭐推荐
   - 趋势热度: 🔥🔥🔥🔥🔥
   - 受众匹配: 95%
   - 历史同类: 播放15万+，ER 8%
   - 建议角度: [差异化切入点]

2. **[话题B]**
   - 趋势热度: 🔥🔥🔥🔥
   - 受众匹配: 80%
   - 历史同类: 播放8万+
   - 建议角度: [新视角]

3. **[话题C]** 🔥潜力股
   - 趋势热度: 🔥🔥🔥
   - 受众匹配: 90%
   - 历史同类: 无（蓝海）
   - 风险提示: [需要验证]
```

### 评分维度

| 维度 | 权重 | 说明 |
|------|------|------|
| 趋势热度 | 30% | 话题上升期 |
| 受众匹配 | 30% | 与persona重合度 |
| 历史验证 | 25% | 同类内容表现 |
| 竞品差异 | 15% | 避免红海 |

### 天龙引擎集成

- **天龙岗位**: 35-02社媒运营、35-05短视频编导、32-01市场研究
- **协同**: cheat-trends（数据源）、cheat-persona（锚定）、cheat-learn-from（历史）
