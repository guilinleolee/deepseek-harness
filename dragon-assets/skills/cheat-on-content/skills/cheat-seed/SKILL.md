# Cheat-Seed — 脚本种子系统

## L0: 一句话描述
从话题生成高质量脚本框架和创意种子

## L1: 使用场景
根据趋势或选题，生成可执行的脚本框架

## L2: 详细文档

### 触发词
- "生成脚本"
- "seed this"
- "写脚本"
- "脚本框架"

### 脚本模板格式

```markdown
# 脚本: [标题]
## 元数据
- 话题: #[话题标签]
- 时长: 60秒
- 类型: 观点/教程/故事
- 目标受众: [persona]

## 开场钩子 (0-5s)
[强吸引力的开场，3种变体]

## 内容结构
### 第一段 (5-20s)
[核心内容，3个要点]

### 第二段 (20-40s)
[深度展开，故事/案例/数据]

### 第三段 (40-55s)
[高潮/反转/金句]

## 结尾CTA (55-60s)
[引导互动话术]

## 金句储备
- "[可引用的金句1]"
- "[可引用的金句2]"

## 视觉提示
- 开场: [镜头描述]
- 转场: [切换方式]
- 结尾: [定格/动作]
```

### 生成流程

```
1. [cheat-trends] 获取趋势话题
2. [cheat-recommend] 筛选最佳选题
3. [cheat-persona] 匹配受众画像
4. [cheat-seed] 生成脚本框架
5. [cheat-score] 评分优化
```
