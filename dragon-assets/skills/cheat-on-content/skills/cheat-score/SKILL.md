# Cheat-Score — 内容评分

## L0: 一句话描述
对单篇内容进行七维量化打分

## L1: 使用场景
发布前快速评估内容质量，无需写入文件，用于探索性打分

## L2: 详细文档

### 触发词
- "打分这篇 [path]"
- "score this [path]"
- "给这稿子打分"
- "先打分看看"

### 工作流

```
1. 读取草稿内容 + rubric_notes.md
2. 委托盲子Agent进行评分（避免主对话上下文偏差）
3. 解析JSON评分结果
4. 计算综合得分
5. 控制台输出（无文件写入）
```

### 关键约束

- ❌ **禁止**：写入文件
- ❌ **禁止**：预测bucket概率
- ❌ **禁止**：触发发布/复盘逻辑
- ❌ **禁止**：提议rubric升级
