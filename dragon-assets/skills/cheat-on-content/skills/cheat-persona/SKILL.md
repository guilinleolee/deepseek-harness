# Cheat-Persona — 受众画像系统

## L0: 一句话描述
建立内容受众画像，锚定评分标准

## L1: 使用场景
初始化rubric时定义目标受众，用于校准评分标准

## L2: 详细文档

### 触发词
- "定义受众画像"
- "create persona"
- "设定目标用户"
- "persona"

### 受众画像模板

```markdown
# 受众画像

## 基本信息
- 年龄段: [如25-35岁]
- 职业: [如互联网从业者]
- 地域: [如一线城市]
- 兴趣标签: [如科技、创业、成长]

## 内容偏好
- 喜欢的内容类型: [如深度分析、实战分享]
- 讨厌的内容类型: [如水内容、标题党]
- 观看场景: [如通勤、睡前]

## 互动模式
- 点赞vs评论比例: [如10:1]
- 转发动机: [如认知价值、情绪共鸣]
- 评论特征: [如求资源、提问、表达观点]

## 评分锚定
- 8分以上内容特征: [如需要满足...]
- 5分以下内容特征: [如常见问题是...]
- 爆款特征: [如必须满足...]
```

### 锚定原则

```
1. 锚定必须有≥5个校准样本
2. 锚定分数对应的内容必须有实际数据验证
3. 锚定应包含正面和负面例子
```

### 天龙引擎集成

- **天龙岗位**: 40-01用户增长、35-02社媒运营、32-03用户洞察
- **协同**: cheat-init（初始化）、cheat-score（锚定校准）
