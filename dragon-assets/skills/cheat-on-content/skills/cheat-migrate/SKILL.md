# Cheat-Migrate — 规则迁移系统

## L0: 一句话描述
将判断进化规则迁移到rubric

## L1: 使用场景
将复盘学习到的规则沉淀到评分标准

## L2: 详细文档

### 触发词
- "迁移规则"
- "migrate this"
- "更新rubric"
- "规则沉淀"

### 迁移流程

```
1. [cheat-learn-from] 提取进化规则
2. 验证规则阈值（≥3个样本）
3. 编写rubric更新
4. [cheat-bump] 触发升级验证
5. 验证通过后更新rubric文件
```

### 迁移报告格式

```markdown
# 规则迁移报告

## 待迁移规则
- 规则ID: rule-001
- 类型: HP偏差
- 来源: 复盘A、复盘B、复盘C
- 规则内容: HP需评估"前30秒+30-120秒节奏"

## Rubric更新
```markdown
### HP (Hook Potential) - 1-5分
- 5分: 开场强钩子(3s内) + 30-120秒有节奏变化
- 4分: 开场强钩子 + 节奏单一
- 3分: 开场普通 + 中间有亮点
- 2分: 开场平淡
- 1分: 无钩子
```

## 验证结果
- 样本数: 3个
- 历史重打分匹配率: 90%
- 状态: ✅ 验证通过
```

### 天龙引擎集成

- **天龙岗位**: 04验证师、06审查师、35-02社媒运营
