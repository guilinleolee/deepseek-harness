# 脚本模板.md

> 标题吸睛 + 情绪开场 + 干货展开 + 悬念收尾

## 1. 脚本结构（7秒钩 + 30秒观点 + 30秒内容 + 15秒互动）

### 🎬 开场钩（7秒黄金位）

| 元素 | 内容 | 时长 |
|------|------|------|
| 视觉 | 强冲击画面/字幕高亮 | 7s |
| 话术 | 观点前置，不说废话 | 7s |

**开场话术模板库**：

| 类型 | 话术 | 适用 |
|------|------|------|
| 反常识 | "99%的人都在做，完全错了" | 争议话题 |
| 数字冲击 | "坚持这个习惯，我瘦了32斤" | 成果型 |
| 场景还原 | "你有没有这种感觉，凌晨3点..." | 情感型 |
| 身份锚定 | "作为一个10年程序员，我告诉你" | 专业型 |
| 悬念预设 | "这个秘密，没人告诉过你" | 揭秘型 |

### 🧠 观点展开（30秒）

**观点公式**：主题词 + 反常识视角 + 具体例子

```
[主题] + [反常识视角] + [具体案例/数据]
       ↓              ↓
   你的立场        让它可信
```

**观点展开检查**：
- [ ] 一句话说清楚你的观点
- [ ] 有没有具体的数据/案例支撑
- [ ] 能不能在15秒内讲完

### 📝 干货内容（30秒）

**内容类型**：

| 类型 | 特征 | 适用场景 |
|------|------|---------|
| 方法论 | 步骤1-2-3 | 教学类 |
| 清单体 | 首先/然后/最后 | 操作类 |
| 对比型 | A vs B，各有优劣 | 评测类 |
| 故事型 | 冲突+转折+结局 | 经历分享 |

### 🤝 互动收尾（15秒）

**钩子话术**：
- "你觉得呢？评论区告诉我"
- "你同意吗？点个赞支持一下"
- "下一期想听什么？告诉我"
