# 8 问交互决策流程 `xhs-decision-flow`

## L0：一句话定位
小红书真人出镜封面生成的 8 步顺序决策。每一步必须是编号选择题，一次只问一个问题，用户回答后再问下一个。

## L1：流程总览

```
┌─────────────────────────────────────────────────────────────┐
│  XHS 真人出镜爆款封面 · 8 问决策流程                            │
├─────────────────────────────────────────────────────────────┤
│  Q1 风格（8 选 1）                                            │
│   ↓                                                          │
│  Q2 人物参考图（必传）                                          │
│   ↓                                                          │
│  Q3 表情+动作（6 选 1 + 1 兜底）                                │
│   ↓                                                          │
│  Q4 额外素材图（0/1/2/3 张 + 4 种用途）                          │
│   ↓                                                          │
│  Q5 背景色调（6 选 1）                                          │
│   ↓                                                          │
│  Q6 字体风格（6 选 1）                                          │
│   ↓                                                          │
│  Q7 字体颜色效果（6 选 1）                                       │
│   ↓                                                          │
│  Q8 标题候选（3 候选 + 1 重生成）                                 │
│   ↓                                                          │
│  按所选风格模板生成完整 Prompt                                   │
└─────────────────────────────────────────────────────────────┘
```

## L2：每步详细规则

### Q1 · 选择风格（必选）

提供以下 8 种风格编号（一次性全部列出，让用户选编号）：

1. **爆款大字压顶风** — 顶部超大标题，人物居中，适合强钩子标题
2. **巨字拆分冲击风** — 2-4 个核心大词拆开放满画面，适合概念/能力/方法论
3. **小白科普问答风** — 黑灰科技海报，大问号 + 大白话，适合"什么是/怎么理解"
4. **教程清单风** — 绿色勾选清单+步骤感，适合安装/部署/上手
5. **产品测评榜单风** — 大数字 + 箭头 + 维度标签，适合横评/榜单
6. **种草推荐风** — 人物点赞/推荐，emoji + 温暖背景，适合资源/播客/工具
7. **贴纸拼贴入门风** — 人物+小卡片+产品图标+贴纸，适合"入门/搭建/组合"
8. **黑底效率工作流风** — 深色背景+Logo 墙+清单，适合工作法/效率流/工具组合

### Q2 · 人物参考图（必传）

要求用户上传图 1 人物参考图。只问：

> 请上传图 1 人物参考图。可以上传 1 张清晰人脸照，也可以上传 2-3 张同一人物照片用于保持人物一致性。

**严格要求**：
- ❌ **不提供"默认形象"或"通用博主形象"选项**
- 如果用户明确说不露脸，也必须要求上传局部出镜参考图（手部、半脸、侧脸）
- 用户上传图片后，只记录为图 1 人物参考，不额外追问外貌

### Q3 · 表情和动作（6 选 1 + 1 兜底）

1. **张嘴震惊** — 嘴巴张开，眼睛睁大，适合测评/反差/发现
2. **双手点赞** — 双手竖大拇指，适合推荐/种草/公开私藏
3. **指向标题** — 一只手指向大字或清单，适合教程/认知
4. **托腮疑惑** — 单手托腮，表情认真疑问，适合科普/问题钩子
5. **举拳自信** — 单手举拳或握拳，适合入门/搭建/行动感
6. **双手打开讲解** — 双手在脸旁或胸前展开，适合分享方法
7. **交给模型决定**

### Q4 · 额外素材图

只给以下选项：

1. **有 1 张素材图** — 图 2 是软件截图/产品图/Logo/工具界面
2. **有 2 张素材图** — 图 2 是主素材，图 3 是辅助素材
3. **有 3 张及以上素材图** — 适合贴纸拼贴/产品测评/工具墙
4. **没有素材图** — 模型根据主题生成贴纸/图标/清单/箭头/卡片

若用户在选项 1-3 后必须说明素材用途，给 4 种用途选择：

1. **产品/工具主体**
2. **教程结果证明**
3. **背景氛围素材**
4. **贴纸拼贴元素**

### Q5 · 背景色调（6 选 1）

1. **室内暖光背景** — 真实房间/书架/桌面，适合推荐/经验分享
2. **黑灰科技海报背景** — 黑/深灰网格+数字标注，适合 AI/工具/概念
3. **深色工具墙背景** — 深灰/黑底+软件 Logo 墙，适合效率流/工具组合
4. **模糊软件界面背景** — 产品截图/工具界面作为氛围
5. **高饱和撞色背景** — 黄/蓝/紫/绿强对比，适合爆款强钩子
6. **交给模型决定**

### Q6 · 字体风格（6 选 1）

1. **综艺超粗黑体** — 默认首选，最像高点击小红书封面
2. **漫画爆款标题字** — 更夸张，适合震惊/测评/反差
3. **圆润粗黑体** — 更亲切，适合种草推荐/播客分享
4. **科技感粗黑体** — 更硬朗，适合 AI 工具/效率工作流
5. **粗标题+手写涂鸦小字** — 主标题粗 + 旁边少量涂鸦
6. **交给模型决定**

### Q7 · 字体颜色效果（6 选 1）

1. **`#FDFFA7` 填充 + 粗黑描边** — 默认首选，最强点击感
2. **纯白填充 + 粗黑描边** — 深色背景更清晰
3. **`#FDFFA7` / 白混排 + 粗黑描边** — 关键词用 `#FDFFA7`，辅助词用白
4. **`#FDFFA7` + 白色高光 + 粗黑描边** — 像短视频爆款标题
5. **深底白字 + `#FDFFA7` 关键词** — 适合黑底效率工作流和测评榜单
6. **交给模型决定**

### Q8 · 封面标题（3 候选 + 1 重生成）

根据用户已提供的内容提炼 3 个候选封面标题，让用户只选编号：

1. **候选标题 A**
2. **候选标题 B**
3. **候选标题 C**
4. **重新生成 3 个标题**

**标题规则**：
- 主标题优先 4-10 个字
- 测评类必须突出数字："5 款产品"、"7 个维度"
- 教程类必须突出低门槛："零基础"、"不用命令行"、"纯小白"
- 强钩子优先："别瞎选了"、"从 0 搭建"、"全流程公开"、"小白上手"

## L3：流程约束（必须遵守）

| # | 约束 | 说明 |
|---|------|------|
| 1 | **一次只问一个问题** | 严格 8 步顺序，绝不一次全问 |
| 2 | **用户已提供的跳过** | 如用户上传了图片、给出了标题，直接使用并跳过对应问题 |
| 3 | **所有问题做成选择题** | 风格/人物/素材/背景/字体/字色/标题 7 项必须有编号选项 |
| 4 | **不开放追问偏好** | 不允许"你想要什么风格？"这种开放问题 |
| 5 | **不复述参考图细节** | Prompt 中写"参考图 1/图 2/图 3"，不展开描述 |
| 6 | **不凭空生成默认人物** | 必须有用户上传的参考图 |
| 7 | **最终只套用所选风格** | 不要混入其他风格的元素 |

## L4：跳步规则

| 用户已提供 | 可跳过的问题 |
|-----------|--------------|
| 上传了图片 | Q2 |
| 给出标题 | Q8（直接使用） |
| 指定风格 | Q1 |
| 指定字体偏好 | Q6 + Q7 |

## L5：集成到 blogger-hologram-to-poster

本流程可拆为 pipeline 决策模块：

```python
# 伪代码（实际由 agent 决策驱动）
def cover_style_selector(blogger):
    """8 问决策 → 选定风格 + 所有参数"""
    answers = {}
    answers['style'] = ask(questions.Q1)       # 8 选 1
    answers['figure_1'] = ask_upload(Q2)        # 必传
    answers['expression'] = ask(questions.Q3)    # 6+1 选
    answers['extra_materials'] = ask(Q4)        # 0/1/2/3
    answers['background'] = ask(questions.Q5)   # 6 选 1
    answers['font_style'] = ask(questions.Q6)   # 6 选 1
    answers['font_color'] = ask(questions.Q7)    # 6 选 1
    answers['title'] = ask(questions.Q8)         # 3+1 选

    return render_template(
        blogger=blogger,
        style_template=f"templates/xhs/styles/{answers['style']}.md",
        params=answers
    )
```
