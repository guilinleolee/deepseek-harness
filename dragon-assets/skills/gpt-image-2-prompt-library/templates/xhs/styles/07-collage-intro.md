# 风格七：贴纸拼贴入门风 `xhs-collage-intro`

## L0：一句话定位
人物居中举拳自信 + 多张小卡片/截图/Logo 围绕人物 + 上下夹击大标题，适合"多 Agent 入门"、"搭建 AI 小队"、"组建工作流"类内容。

## L1：适用场景
- 入门/搭建/组合类教程
- 多 Agent / 多工具组合
- 工作流搭建类爆款

## L2：视觉特征

| 维度 | 规则 |
|------|------|
| 人物位置 | 中央，约 45% |
| 人物动作 | 单手举拳 / 手指向上 / 手掌托起小卡片 |
| 人物表情 | 自信得意 / 兴奋入门 / 认真推荐 |
| 主标题（前半） | 顶部大字，`#FDFFA7` |
| 主标题（后半） | 底部大字，白色 或 `#FDFFA7` |
| 素材处理 | 3-5 张贴纸式小卡片，白色圆角边框，轻微旋转 |
| 卡片内容 | 截图 / Logo / 工具图标 / 头像贴纸 |
| 主题图标 | 右下/左下，醒目主题图标 + 投影 |
| 背景 | 室内或浅色，叠加贴纸层 |

## L3：可执行 Prompt 模板

```
参考图 1 的人物五官特征，保持人物一致性，真人半身出镜。

[具体表情：自信得意/兴奋入门/认真推荐]，
人物位于画面中央，占画面约 45%，
[具体动作：单手举拳/手指向上/手掌托起小卡片]，
人物边缘有 #FDFFA7 描边。

画面顶部放置大标题"[封面标题前半]"，
字体为 #FDFFA7 超粗黑体 + 粗黑描边；
画面底部放置大标题"[封面标题后半]"，
白色或 #FDFFA7 填充 + 粗黑描边，形成上下夹击；
标题背后的黄色底板或色块统一使用 #FDFFA7，
**禁止其他黄色**。

围绕人物放置 3-5 个贴纸式小卡片：
[卡片1，例如：Cursor 截图]
[卡片2，例如：Claude Code logo]
[卡片3，例如：终端命令截图]
[卡片4，例如：人物头像贴纸]
[卡片5，例如：流程图截图]
每张卡片有白色圆角边框、轻微旋转和投影，
像手机截图或工具卡片。

如果有图 2/图 3，将参考图作为最重要的小卡片，
放在人物左侧或右侧前景；
其余卡片生成[主题相关工具图标/流程图标/头像贴纸]。

右下角或左下角加入一个醒目的主题图标，例如：
- 红色麦克风（播客类）
- 纸飞机（部署类）
- AI 工具 Logo（AI 类）
- 机器人图标（自动化类）
带投影，作为视觉收口。

背景是[背景描述，例如：浅色工作台/叠加贴纸的干净背景/室内一角]，
保持干净但有层次，贴纸和人物形成拼贴感。

3:4 竖版小红书真人出镜封面，入门感强，信息丰富，
卡片不遮挡人物脸部，标题清晰可读，所有重要元素不超出安全区。
```

## L4：变体参数

| 参数 | 选项 | 默认 |
|------|------|------|
| 卡片数 | 3 / 4 / 5 | 4 |
| 主题图标位置 | 左下 / 右下 | 右下 |
| 背景 | 浅色贴纸底 / 干净纯色 / 室内一角 | 浅色贴纸底 |
| 标题后半 | 白 / `#FDFFA7` | 白 |

## L6：避坑指南

- ❌ 卡片压在人物脸部
- ❌ 卡片朝向全部一致（必须有轻微旋转错落）
- ❌ 标题单边（必须上下夹击）
- ❌ 主题图标太小不醒目

## L7：典型主题图标

- 🤖 机器人（AI 自动化）
- 🚀 火箭（部署/上线）
- 🎙️ 麦克风（播客/语音）
- 🛠️ 工具组合（多工具）
- ⚡ 闪电（效率流）
