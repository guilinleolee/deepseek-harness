# 风格四：教程清单风 `xhs-checklist`

## L0：一句话定位
顶部/底部大字主标题 + 竖向绿色勾选清单，明确告诉用户"能学到什么"。适合部署/安装/上手/全流程公开类内容。

## L1：适用场景
- 安装/部署/上手类教程
- 从 0 搭建类内容
- 全流程公开类爆款

## L2：视觉特征

| 维度 | 规则 |
|------|------|
| 主标题位置 | 顶部或底部（紧凑、有冲击力） |
| 主标题字色 | `#FDFFA7` + 粗黑描边 |
| 清单排列 | 竖向 3 条绿色勾选，放在侧边 |
| 清单内容 | 白色粗体 + 黑色描边，间距紧凑 |
| 人物位置 | 左侧/右侧/中下方，约 45% |
| 人物动作 | 食指指向清单 / 竖大拇指 / 手掌朝向标题 |
| 底部 | 可选彩色条（紫/`#FDFFA7`/白色）做收尾锤 |

## L3：可执行 Prompt 模板

```
参考图 1 的人物五官特征，保持人物一致性，真人半身出镜。

[具体表情]，人物位于画面[左侧/右侧/中下方]，
占画面约 45%，[具体动作：食指指向清单/竖大拇指/手掌朝向标题]，
人物边缘有 #FDFFA7 描边。

画面顶部放置超大中文标题"[封面主标题]"，
字体为超粗黑体，#FDFFA7 填充 + 粗黑描边，
文字紧凑有冲击力；标题背后的黄色底板或色块统一使用 #FDFFA7。

画面[左侧/右侧]竖向排列 3 条绿色勾选清单：
✅ [清单1，例如：从 0 安装]
✅ [清单2，例如：一键部署]
✅ [清单3，例如：跑通第一个案例]
清单文字为白色粗体 + 黑色描边，每条间距紧凑，像教程卖点。

如果有图 2，将图 2 作为[软件界面/产品截图/教程结果图]
放在人物身后或侧边，轻微倾斜，带投影，作为教程证据。

底部可以加入一条[紫色/#FDFFA7/白色]横幅，
写"[底部强化短句，例如：跟着做，小白也能搞定]"，
字体粗大，形成收尾锤。

背景是[背景描述，例如：暖色调开发桌面/真实开发环境/软件界面截图]，
略微虚化，让标题、人物、清单三者最醒目。

3:4 竖版小红书真人出镜封面，教程感强，信息密度高，
清单清晰可读，所有重要元素不超出安全区。
```

## L4：变体参数

| 参数 | 选项 | 默认 |
|------|------|------|
| 主标题位置 | 顶部 / 底部 | 顶部 |
| 清单侧 | 左 / 右 | 右 |
| 清单数 | 2-4 | 3 |
| 底部横幅 | 紫 / `#FDFFA7` / 白 / 无 | `#FDFFA7` |

## L6：避坑指南

- ❌ 清单条目超过 6 个字
- ❌ 清单没有勾选符号
- ❌ 人物手指方向和清单不匹配
- ❌ 主标题用荧光黄

## L7：典型清单条目模板

- 安装类：✅ 从 0 安装 ✅ 配置环境 ✅ 跑通第一个 case
- 部署类：✅ 一键部署 ✅ 自动更新 ✅ 监控告警
- 流程类：✅ 选题 ✅ 脚本 ✅ 拍摄 ✅ 剪辑
