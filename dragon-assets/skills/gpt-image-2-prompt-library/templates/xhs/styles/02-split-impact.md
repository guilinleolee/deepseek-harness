# 风格二：巨字拆分冲击风 `xhs-split-impact`

## L0：一句话定位
标题拆为 2-4 个巨大词块铺满画面，人物被文字包围或夹在中间，适合概念/能力/方法论类主题。

## L1：适用场景
- 核心概念类内容（"产品经理软技能"、"录音工作大法"）
- 大型方法论拆解
- 强冲击爆款标题

## L2：视觉特征

| 维度 | 规则 |
|------|------|
| 主标题处理 | 拆成 2/3/4 个巨大词块铺满画面 |
| 词块字色 | `#FDFFA7` 和纯白交替 + 粗黑描边 |
| 词块布局 | 上/左/右/底围绕人物，部分被人物身体轻微遮挡 |
| 人物位置 | 中央，约 38% |
| 人物动作 | 夸张动作（双手举起/指向上方/双手打开） |
| 背景 | 深色街景/室内/模糊工作场景 |
| 整体感 | 像短视频封面，强冲击、强节奏 |

## L3：可执行 Prompt 模板

```
参考图 1 的人物五官特征，保持人物一致性，真人半身出镜。

[具体表情 + 夸张动作]，人物位于画面中央，占画面约 38%，
动作[双手指向上方/双手举起/双手打开]，人物边缘有
白色或 #FDFFA7 描边。

将中文标题"[原标题]"拆分成 [N, 2-4] 个巨大词块：
[词块1]、[词块2]、(可选 [词块3]、[词块4])。

词块使用超粗综艺黑体，#FDFFA7 和纯白交替填充，全部加粗黑描边。
词块分别放在画面上方、左侧、右侧和底部，围绕人物排布，
部分文字被人物身体轻微遮挡，形成前后层次；如果词块背后有
底板或色块，黄色统一使用 #FDFFA7。

背景是[深色或中性背景描述，例如：深色街景/暗色办公桌/模糊工作场景]，
轻微虚化，局部有暗角，让 #FDFFA7 和白色大字更突出。

加入少量手绘箭头、短横线、感叹号或英文涂鸦小字，
数量控制在 3 个以内，增加街头感和节奏感。

3:4 竖版小红书真人出镜封面，强对比，超大字视觉锤，
人物与文字紧密组合但不遮挡眼睛和嘴巴，所有元素不超出安全区。
```

## L4：变体参数

| 参数 | 选项 | 默认 |
|------|------|------|
| 词块数 | 2 / 3 / 4 | 3 |
| 词块字色交替 | `#FDFFA7`+白 / 全 `#FDFFA7` / 全白 | 交替 |
| 背景深浅 | 深色街景 / 中性灰 / 暗色背景 | 深色 |

## L6：避坑指南

- ❌ 词块压在人物眼睛或嘴巴上
- ❌ 词块字色不一致（必须显式说"交替"或"统一"）
- ❌ 词块太小（必须"巨大"）
- ❌ 留白过多（必须是高密度铺满）

## L7：典型标题示例
- "产品经理 / 三大软技能"（3 词块）
- "录音 / 剪辑 / 后期 / 全流程"（4 词块）
- "从写下 / 到发表"（2 词块）
