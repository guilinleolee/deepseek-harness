# 风格一：爆款大字压顶风 `xhs-press-top`

## L0：一句话定位
顶部超大主标题压画面，人物中下方居中，适合强钩子标题、经验公开、教程入口类封面。

## L1：适用场景
- 主标题自带强钩子词（"别瞎选了"、"全流程公开"）
- 经验分享 / 工作方法公开类内容
- 教程类封面入口图

## L2：视觉特征

| 维度 | 规则 |
|------|------|
| 主标题位置 | 顶部 35%-45% |
| 主标题字色 | `#FDFFA7` 或纯白 + 粗黑描边 |
| 人物位置 | 中下方居中，占画面约 45% |
| 人物动作 | 强烈表情（震惊/指向/张开/讲解），眼神看镜头 |
| 背景 | 室内或主题相关场景，轻微虚化 |
| 点缀 | 少量箭头/emoji/贴纸，强化情绪 |

## L3：可执行 Prompt 模板

```
参考图 1 的人物五官特征，保持人物一致性，真人半身出镜。

[具体表情，例如：张嘴震惊/食指指向上方/双手打开讲解]，
人物居中偏下，占画面约 45%，[具体手势和身体姿态]，
眼神看向镜头，人物边缘有 #FDFFA7 描边，形成清晰抠图感。

画面顶部放置超大中文标题"[封面主标题]"，字体为综艺感超粗黑体，
#FDFFA7 填充 + 粗黑描边 + 轻微白色高光，文字占据画面上方约 40%，
有强烈压迫感；如果标题背后需要底板或色块，也使用 #FDFFA7，
**禁止荧光黄/金黄/偏橙黄色**。

如果有副标题，将"[副标题]"放在画面底部，白色粗体黑色描边，
字号小于主标题但仍然醒目。

背景是[背景描述，例如：暖色调书桌前/模糊软件界面/室内书架场景]，
轻微虚化，降低细节，让人物和标题成为绝对主体。

画面两侧加入 3-5 个[主题相关贴纸/emoji/箭头/问号]，
只做情绪强化，不抢主标题视觉权重。

3:4 竖版小红书真人出镜封面，高对比、高密度、强点击感，
标题清晰可读，人物脸部不被文字遮挡，所有重要元素不超出安全区。
```

## L4：变体参数

| 参数 | 选项 | 默认 |
|------|------|------|
| 主标题色 | `#FDFFA7` / 白色 / 混排 | `#FDFFA7` |
| 副标题 | 有/无/底部横幅 | 底部小字 |
| 描边色 | 黑色 | 黑色 |
| 背景类型 | 暖光室内 / 模糊软件界面 / 主题强相关 | 主题强相关 |

## L6：避坑指南

- ❌ 标题字色用荧光黄/柠檬黄/金黄
- ❌ 标题放在人物脸部或眼睛上
- ❌ 极简留白（没有对比度）
- ❌ 冷淡杂志风（不符合高点击密度）
- ❌ 细字体（必须是综艺感超粗黑体）

## L7：典型钩子词
- 强钩子："别瞎选了"、"全流程公开"、"从 0 到 1"、"一文搞定"
- 教程类："零基础"、"不用命令行"、"纯小白"、"跟着做就行"
