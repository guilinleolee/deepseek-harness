# 风格八：黑底效率工作流风 `xhs-dark-workflow`

## L0：一句话定位
深色工具 Logo 墙 + 绿色勾选清单 + 高饱和 `#FDFFA7` 大字 + 人物前景抠图，适合效率方法、工具组合、工作流公开。

## L1：适用场景
- 效率方法、工具组合流
- 工作流公开 / AI 工作流
- 工具墙类爆款

## L2：视觉特征

| 维度 | 规则 |
|------|------|
| 背景 | 深色工具墙 / 模糊软件界面 / 工作流卡片网格 |
| 背景处理 | 网格或错落铺在后景，轻微虚化和压暗 |
| 人物位置 | 中下方，约 45% |
| 人物动作 | 张嘴兴奋 / 双手打开 / 惊讶推荐 |
| 人物边缘 | 白色或 `#FDFFA7` 描边，和深色背景形成强对比 |
| 主标题位置 | 顶部或左上 |
| 主标题字色 | `#FDFFA7` + 粗黑描边，局部白色字强调关键词 |
| 清单 | 3 条绿色勾选清单，靠右或靠左 |
| 前景 | 主题相关 emoji / 喇叭 / 键盘 / 闪电 / 工具图标 + 投影 |

## L3：可执行 Prompt 模板

```
参考图 1 的人物五官特征，保持人物一致性，真人半身出镜。

[具体表情：张嘴兴奋/双手打开/惊讶推荐]，
人物位于画面中下方，占画面约 45%，
[具体动作：双手展开讲解/指向 Logo 墙/惊讶张手]，
人物边缘有白色或 #FDFFA7 描边，
和深色背景形成强对比。

背景是深色工具墙：[主题相关软件 Logo/工具界面/工作流卡片]
以网格或错落方式铺在后景，整体轻微虚化和压暗，
不抢人物和标题的视觉权重。

画面顶部放置超大中文标题"[封面主标题]"，
字体为 #FDFFA7 超粗黑体 + 粗黑描边，
局部可以用白色字强调关键词；
标题背后的黄色底板或色块统一使用 #FDFFA7，**禁止其他黄色**。

画面右侧或左侧放置 3 条绿色勾选清单：
✅ [收益1，例如：每天省 2 小时]
✅ [收益2，例如：所有笔记自动归档]
✅ [收益3，例如：一键同步到多平台]
清单文字为白色粗体 + 黑色描边，
像短视频封面的效率卖点。

前景加入一个[主题相关 emoji/喇叭/键盘/闪电/工具图标]，
靠近人物手势，带投影，强化效率感。

3:4 竖版小红书真人出镜封面，深色高对比，高密度，
效率感和工具感强，标题一眼可读，人物脸部清晰，
所有重要元素不超出安全区。
```

| 清单侧 | 左 / 右 | 右 |
| 前景图标 | emoji / 喇叭 / 键盘 / 闪电 | 主题相关 |

## L6：避坑指南

- ❌ 背景 Logo 抢标题（必须虚化和压暗）
- ❌ 白色字过多（必须 `#FDFFA7` 主色）
- ❌ 没有勾选清单（必须有 3 条收益清单）
- ❌ 前景图标太小（必须醒目）

## L7：典型清单条目

- 收益类：✅ 每天省 2 小时 ✅ 全自动跑通 ✅ 一键同步
- 工具类：✅ Notion ✅ Cursor ✅ Claude Code ✅ Slack
- 流程类：✅ 选题 ✅ 生成 ✅ 审校 ✅ 一键发布
