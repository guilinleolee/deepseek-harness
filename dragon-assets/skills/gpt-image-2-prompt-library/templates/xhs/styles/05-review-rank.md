# 风格五：产品测评榜单风 `xhs-review-rank`

## L0：一句话定位
顶部主标题 + 底部超大数字（5 款、7 维度）+ 黄色箭头指向测评结果，适合横评、榜单、测评类内容。

## L1：适用场景
- 多产品横评（"5 款 AI 工具实测"）
- 多维度测评（"7 个维度对比"）
- 排行榜类内容

## L2：视觉特征

| 维度 | 规则 |
|------|------|
| 主标题（前半） | 顶部中小字，"测评主题" |
| 主标题（后半） | 底部巨大数字+"测评结果短语" |
| 数字字色 | `#FDFFA7` + 粗黑描边 |
| 数字位置 | 底部约 30% |
| 箭头 | `#FDFFA7` 粗箭头，从人物手势指向测评结果 |
| 维度标签 | 白色粗体 + 黑色描边，紧贴箭头 |
| 人物位置 | 左下/右下/中央，约 40% |
| 人物动作 | 震惊 / 认真 / 指向数字 / 侧身看榜单 |

## L3：可执行 Prompt 模板

```
参考图 1 的人物五官特征，保持人物一致性，真人半身出镜。

[具体表情：张嘴震惊/认真测评/眉毛上扬]，
人物位于画面[左下/右下/中央]，占画面约 40%，
[具体动作：手指指向数字/手掌推向产品卡片/侧身看向榜单]，
人物边缘有 #FDFFA7 描边。

画面顶部放置中文标题"[封面标题前半]"，
字体为 #FDFFA7 超粗黑体 + 粗黑描边。

画面底部放置巨大数字和结果短语"[封面标题后半]"，
例如 "5 款产品"、"7 个维度"、"横评结果"，
数字字号最大，#FDFFA7 填充 + 黑色描边，占据底部约 30%。

用一条粗 #FDFFA7 浅黄色箭头从人物手势指向测评结果，
箭头旁边放置小字标签"[测评维度/核心结论]"，
白色粗体 + 黑色描边。

如果有图 2/图 3，将参考图作为产品卡片或软件截图，
围绕人物错落摆放，带轻微倾斜和投影；
如果没有素材，则生成[主题相关产品卡片/软件 Logo/工具图标]。

背景是[深色/工具界面/模糊工作台]，局部暗角，
突出 #FDFFA7 / 白色标题和数字的视觉权重。

3:4 竖版小红书真人出镜封面，测评感强，数字极醒目，
人物表情有反差，所有文字清晰可读，所有重要元素不超出安全区。
```

## L4：变体参数

| 参数 | 选项 | 默认 |
|------|------|------|
| 测评对象数 | 3 / 5 / 7 / 10 | 5 |
| 维度数 | 3 / 5 / 7 | 7 |
| 数字位置 | 底部 / 中央 / 侧边 | 底部 30% |
| 排行榜 | 有/无 | 有 |

## L6：避坑指南

- ❌ 数字字号不够大
- ❌ 数字字色用了其他黄色（必须 `#FDFFA7`）
- ❌ 没有箭头或箭头反向
- ❌ 产品卡片太小或散乱

## L7：典型数字模板

- 数量型：3 款 / 5 款 / 7 款 / 10 款
- 维度型：3 个 / 5 个 / 7 个 / 9 个
- 排名型：Top 3 / Top 5 / Top 10
- 时间型：30 天 / 90 天 / 一年
