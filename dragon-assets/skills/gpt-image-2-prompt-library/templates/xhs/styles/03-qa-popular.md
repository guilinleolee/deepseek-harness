# 风格三：小白科普问答风 `xhs-qa-popular`

## L0：一句话定位
黑灰科技海报/模糊软件界面背景 + 大问号 + 大白话主标题，给小白讲清楚概念。

## L1：适用场景
- 概念解释类内容（"什么是 X？"、"怎么理解 Y？"）
- AI 工具科普
- 给入门者的解释型封面

## L2：视觉特征

| 维度 | 规则 |
|------|------|
| 背景 | 黑灰科技海报 / 模糊软件界面 / 真实室内 / 参考素材延展 |
| 人物位置 | 中下方，约 42% |
| 人物动作 | 托腮疑惑 / 微微睁大眼睛 / 认真解释 |
| 主标题位置 | 顶部大字，2-3 行分块 |
| 主标题字色 | `#FDFFA7` + 粗黑描边 |
| 点缀 | 大问号（白底黑边）、绿色勾选人群标签 |

## L3：可执行 Prompt 模板

```
参考图 1 的人物五官特征，保持人物一致性，真人半身或大头出镜。

[具体表情：托腮疑惑/认真解释/微微睁大眼睛]，
人物位于画面中下方，占画面约 42%，
[手部动作：单手托腮/手指轻点脸侧/指向上方标题]，
人物边缘有白色或 #FDFFA7 描边。

画面上方放置超大中文标题"[封面主标题]"，
字体为超粗黑体，#FDFFA7 填充 + 粗黑描边，
文字分成 2-3 行，像在用大白话解释概念；
标题背后的黄色底板或色块统一使用 #FDFFA7，**禁止其他黄色**。

人物旁边放置 2 个巨大的白色问号，黑色描边，轻微投影，
问号围绕人物头部摆放但不遮挡脸部。

画面左下或右下放置 3 条绿色勾选标签：
[标签1，例如：文科生也能懂]
[标签2，例如：3 分钟看完]
[标签3，例如：不需要任何基础]
每条是绿色勾选框 + 白色粗体文字 + 黑色描边。

背景是[黑灰科技海报/模糊软件界面/真实室内/参考素材延展背景]，
略微虚化或压暗，保留科技科普氛围，不抢标题和人物的视觉权重。

3:4 竖版小红书真人出镜封面，标题一眼可读，信息清楚，
适合小白科普，所有重要元素不超出安全区。
```

## L4：变体参数

| 参数 | 选项 | 默认 |
|------|------|------|
| 背景类型 | 黑灰科技 / 模糊软件 / 真实室内 | 主题相关 |
| 问号数 | 1-3 | 2 |
| 标签数 | 2-4 | 3 |

## L6：避坑指南

- ❌ 问号遮挡人物脸部
- ❌ 标题用学术术语（必须"大白话"）
- ❌ 标签用纯灰色（必须绿色勾选）
- ❌ 背景太亮抢主角

## L7：典型标题公式
- "[概念] 是什么？/ 全讲明白"
- "什么是 [概念]？/ 一文看懂"
- "[概念] / 怎么理解？/ 看完就懂"
