# 风格六：种草推荐风 `xhs-recommend`

## L0：一句话定位
人物点赞或推荐姿势 + `#FDFFA7`/白色大标题 + emoji 装饰 + 暖色背景，营造"私藏公开"、"你一定要试试"的亲切感。

## L1：适用场景
- 资源 / 播客 / 工具种草推荐
- 私藏工具公开类内容
- 个人推荐型封面

## L2：视觉特征

| 维度 | 规则 |
|------|------|
| 人物位置 | 中央偏左/右，约 48% |
| 人物动作 | 微笑推荐 / 双手点赞 / 认真安利 |
| 主标题位置 | 顶部或底部 |
| 主标题字色 | `#FDFFA7` 和白色组合 + 粗黑描边 |
| 字体 | 圆润粗黑体（亲切感） |
| 装饰 | 爱心/笑脸/喇叭/耳机/星星 emoji |
| 背景 | 温暖室内 / 书架 / 桌面 / 生活化场景 |
| 推荐对象卡片 | 人物手边小卡片或封面缩略图 |

## L3：可执行 Prompt 模板

```
参考图 1 的人物五官特征，保持人物一致性，真人半身出镜。

[具体表情：微笑推荐/双手点赞/认真安利]，
人物位于画面中央偏[左/右]，占画面约 48%，
[具体动作]，眼神看向镜头，人物边缘有 #FDFFA7 描边，
形成清晰抠图感。

画面[顶部/底部]放置超大中文标题"[封面主标题]"，
字体为超粗圆润黑体，#FDFFA7 和白色组合填充 + 粗黑描边，
亲切但醒目；标题背后的黄色底板或色块统一使用 #FDFFA7，
**禁止荧光黄/金黄/偏橙黄**。

在人物旁边加入[主题相关 emoji]，例如：
- 笑脸、爱心、喇叭（资源类）
- 耳机、麦克风、小宇宙 logo（播客类）
- 星星、书本、工具图标（工具书类）
数量控制在 3-5 个，围绕人物手势分布。

如果有图 2，将图 2 作为推荐对象的小卡片或封面缩略图，
放在人物手边，轻微倾斜，带白色边框和投影。

背景是[温暖室内/书架/桌面/生活化场景]，轻微虚化，
有真实分享感，不抢标题和人物的视觉权重。

画面可以加入一行竖排小字"[推荐理由短句，例如：亲测好用]"，
白色粗体 + 黑色描边，贴近人物侧边。

3:4 竖版小红书真人出镜封面，种草感强，亲切可信，高点击感，
标题和人物都清晰，所有重要元素不超出安全区。
```

## L4：变体参数

| 参数 | 选项 | 默认 |
|------|------|------|
| 主标题位置 | 顶部 / 底部 | 顶部 |
| 字体圆润度 | 标准 / 圆润 / 漫画感 | 圆润 |
| emoji 主题 | 资源 / 播客 / 工具 | 主题相关 |
| 推荐卡片 | 有/无 | 有（如果有图 2） |

## L5：JSON 模板

```json
{
  "style_id": "xhs-recommend",

  "prompt_template": "参考图1人物...（同L3）",

  "tags": ["xhs", "portrait", "recommend", "warm-tone"]

```

## L6：避坑指南

- ❌ 用冷淡杂志风字体（必须圆润）
- ❌ emoji 数量超过 6 个（画面拥挤）
- ❌ 推荐卡片太小看不出来
- ❌ 背景太冷色（必须暖色）

## L7：典型 emoji 组合

- 资源类：📚 + ⭐ + 💎 + 🔥
- 播客类：🎙️ + 🎧 + ❤️ + 小宇宙 logo
- 工具类：🛠️ + ⚡ + 📱 + 🚀
- 综合：💯 + ✨ + 👍 + ❤️
