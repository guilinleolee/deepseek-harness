# XHS-真人类爆款封面提示词库（V1.0）

> 适配场景：小红书真人出镜类封面（AI 工具教程 / 产品测评 / 效率方法 / 教程部署 / 个人经验 / 播客推荐 / 职场认知）
>
> **来源**：天龙引擎自研（参考社区 atutun 风格实践经验，2026-07-20 整合）
> **核心主色**：`#FDFFA7`（柔和浅黄，禁止荧光黄/金黄/柠檬黄）
> **比例硬约束**：3:4 竖版
> **人物占比**：35%-55%（除非风格另有说明）

---

## 通用视觉规范（8 套共用）

### 构图与比例
- **小红书封面必须是 3:4 竖版比例**，不接受"接近 3:4"或其他比例
- 真人出镜，人物占画面 35%-55%，表情强烈、动作明确
- 人物边缘必须有 `#FDFFA7` / 白色 / 高对比亮色描边，形成明显抠图感
- 重要文字、人物脸部、清单条目都不能超出安全区

### 标题规范
- 主标题必须视觉第一优先级，超大、清晰、短促
- 主标题优先 `#FDFFA7` 或纯白，必须有粗黑描边
- **黄色色号**：标题填充、关键词、底板、色块、横幅、箭头凡是用黄色，**统一指定 `#FDFFA7`**
- 字体使用综艺感超粗黑体、漫画标题字、短视频封面大字
- 主标题 4-10 字，副标题字号小于主标题但仍醒目

### 钩子词库
- 强钩子："别瞎选了" / "从 0 搭建" / "全流程公开" / "小白上手" / "到底行不行"
- 测评类："5 款产品" / "7 个维度" / "横评"
- 教程类："零基础" / "不用命令行" / "纯小白"

### 高频装饰元素
- 绿色勾选框（3 条左右）
- `#FDFFA7` 箭头
- 问号、感叹号、emoji、贴纸
- 小卡片、软件 Logo

### 严禁清单
- ❌ 极简留白
- ❌ 细字体
- ❌ 冷淡杂志风
- ❌ 低对比浅灰字
- ❌ 全息投影、数据流、粒子特效
- ❌ 标题遮挡人物眼睛和嘴巴
- ❌ 荧光黄/高饱和柠檬黄/金黄/偏橙黄色

## 8 问决策流程

封面生成前的 8 步决策（详见 [`interaction/08-step-flow.md`](./interaction/08-step-flow.md)）：

1. 选风格（8 选 1）
2. 人物参考图（必传，无默认）
3. 表情+动作（6 选 1 + 1 个"交给模型"）
4. 额外素材图（0/1/2/3 张 + 4 种用途）
5. 背景色调（6 选 1）
6. 字体风格（6 选 1）
7. 字体颜色效果（6 选 1）
8. 标题候选（3 候选 + 重生成）

**重要**：8 问必须顺序进行、一次一题；用户已提供的信息直接记录并跳过。
