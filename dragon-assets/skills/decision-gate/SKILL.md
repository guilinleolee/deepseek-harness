# Decision Gate

## 核心理念

借鉴自 GSD-2 的强制门控机制，确保 AI Agent 在关键决策点暂停并等待用户确认。

**金句**：盲目执行不如等待确认。

## 门控类型

### Gate 1: 分析完成门 (ANALYSIS COMPLETE)

当Agent完成问题分析后，必须输出：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 分析完成
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 发现摘要：
- 问题类型：[类型]
- 根本原因：[原因]
- 影响范围：[范围]

🎯 建议下一步：
1. 立即修复
2. 创建发现文档
3. 进一步探索
4. 获取第二意见
5. 其他

请选择 [1-5]：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**触发条件**：
- 完成代码分析后
- 完成问题诊断后
- 完成架构评估后

### Gate 2: 高风险操作门 (HIGH RISK OPERATION)

当Agent准备执行高风险操作时：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⚠️ 高风险操作警告
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

准备执行：[操作描述]
影响范围：[文件数量/代码行数/影响模块]
风险评估：[高/中/低]

安全选项：
1. 确认执行（了解风险）
2. 先创建备份再执行
3. 查看详细影响分析
4. 取消操作

请选择 [1-4]：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**高风险操作定义**：
- 删除文件 > 5个
- 修改代码 > 100行
- 架构变更
- 数据库迁移
- 依赖升级

### Gate 3: 多路径选择门 (MULTI-PATH SELECTION)

当存在多种解决方案时：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### Gate 4: 发布确认门 (RELEASE CONFIRMATION)

当准备发布时：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 与天龙岗位集成

### 集成方式

每个天龙岗位在关键节点自动触发Decision Gate：

| 岗位 | 触发门控 | 触发时机 |
|------|---------|---------|
| **00分析师** | 分析完成门 | 问题分析完成 |
| **02架构师** | 多路径选择门 | 架构方案确定前 |
| **03构建师** | 高风险操作门 | 大规模修改前 |
| **04验证师** | 发布确认门 | 测试通过后 |
| **05安全师** | 高风险操作门 | 安全配置修改前 |
| **06审查师** | 分析完成门 | 代码审查完成 |
| **08发布师** | 发布确认门 | 发布执行前 |

### 自动触发规则

```yaml
# 在Agent配置中添加
decision_gates:
  - trigger: "analysis_complete"
    required: true  # 强制门控
    timeout: null   # 无超时，必须用户响应

  - trigger: "high_risk"
    condition: "files_modified > 5 OR lines_changed > 100"
    required: true

  - trigger: "multi_path"
    condition: "solutions_count > 1"
    required: true
```

## 实现机制

### Hook集成

```javascript
// hooks/decision-gate-trigger.js

const DECISION_GATES = {
  analysis_complete: {
    name: "分析完成门",
    options: ["立即执行", "创建发现文档", "进一步探索", "获取第二意见", "其他"]
  },
  high_risk: {
    name: "高风险操作门",
    options: ["确认执行", "先创建备份", "查看详细影响", "取消操作"]
  },
  multi_path: {
    name: "多路径选择门",
    options: ["方案A（推荐）", "方案B", "方案C", "查看对比", "自定义方案"]
  }
};

function triggerGate(gateType, context) {
  const gate = DECISION_GATES[gateType];
  if (!gate) return null;

  // 生成门控UI
  const gateUI = formatGateUI(gate, context);

  // 使用AskUserQuestion工具
  return {
    tool: "AskUserQuestion",
    questions: [{
      question: gateUI,
      options: gate.options.map((opt, i) => ({
        label: opt,
        value: String(i + 1)
      }))
    }]
  };
}
```

### 格式化函数

```javascript
function formatGateUI(gate, context) {
  const divider = "━".repeat(50);
  let ui = `${divider}\n${gate.name}\n${divider}\n\n`;

  if (context.summary) {
    ui += `📋 发现摘要：\n${context.summary}\n\n`;
  }

  if (context.options) {
    ui += `🎯 建议下一步：\n`;
    context.options.forEach((opt, i) => {
      ui += `${i + 1}. ${opt}\n`;
    });
  }

  ui += `\n请选择 [1-${context.options.length}]：\n${divider}`;
  return ui;
}
```

```yaml
# .claude/decision-gate-config.yaml

# 全局开关
enabled: true

# 各类门控配置
gates:
  analysis_complete:
    enabled: true
    required: true  # 强制等待用户响应

  high_risk:
    enabled: true
    required: true
    threshold:
      files: 5

  multi_path:
    enabled: true
    required: false  # 可选，默认选择推荐方案

  release:
    enabled: true

  default: null  # 默认无超时
  optional_gates: 300  # 可选门控5分钟超时
```
