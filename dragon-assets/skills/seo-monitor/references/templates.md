# SEO Monitoring Reference

## Alert Thresholds

### Critical (Immediate Action)
| Metric | Threshold | Response Time |
|--------|-----------|---------------|
| Site down | Any | 0-15 min |
| Traffic drop | >20% | 0-4 hours |
| Index coverage drop | >10% | 0-24 hours |
| Manual action | Any | Immediate |

### High Priority (24-48 hours)
| Metric | Threshold |
|--------|-----------|
| Rank drop | >10 positions |
| New crawl errors | >5 |
| HTTPS issue | Any |

### Medium (1 week)
| Metric | Threshold |
|--------|-----------|
| Competitor ranking | New top 5 |
| Backlinks lost | >20% |
| Core Web Vitals | Below threshold |

## Weekly Review Checklist

- [ ] Download rank tracking report
- [ ] Review Search Console data
  - [ ] Performance tab (clicks, impressions, CTR)
  - [ ] Coverage tab (errors, valid pages)
  - [ ] Links tab (new/lost)
- [ ] Check for technical issues
- [ ] Review competitor movements
- [ ] Document findings

## Monthly Report Sections

### 1. Performance Summary
- Organic traffic trend
- Keyword ranking changes
- Conversion metrics
- Comparison to previous month/year

### 2. Wins
- Rankings gained
- New backlinks
- Content that performed well
- Technical issues fixed

### 3. Issues
- Rankings lost
- Technical problems
- Competitor moves
- Content underperforming

### 4. Recommendations
- Priority actions for next month
- Content opportunities
- Technical fixes needed
