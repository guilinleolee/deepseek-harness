# Claude Code 插件使用说明

> 本目录存放 Claude Code 的插件配置和资源

## 📁 目录结构

```
plugins/
├── agent-sdk-dev/           # Agent SDK 开发相关
├── cache/                   # 插件缓存
├── claude-opus-4-5-migration/ # Opus 4.5 迁移
├── code-review/             # 代码审查插件
├── commit-commands/         # Git 提交命令
├── explanatory-output-style/ # 说明性输出样式
├── feature-dev/             # 功能开发插件
├── frontend-design/         # 前端设计插件
├── hookify/                 # Hooks 相关
├── learning-output-style/   # 学习输出样式
├── marketplaces/            # 插件市场
│   ├── claude-plugins-official/  # 官方插件
│   └── thedotmack/              # 第三方市场
├── plugin-dev/              # 插件开发
├── pr-review-toolkit/       # PR 审查工具包
├── ralph-wiggum/            # Ralph Wiggum 插件
├── repos/                   # 插件仓库
├── security-guidance/       # 安全指导
├── installed_plugins.json   # 已安装插件列表
└── known_marketplaces.json  # 已知市场列表
```

---

## 🔧 配置文件

### installed_plugins.json
已安装的插件配置，包含插件名称、版本、路径等信息。

### known_marketplaces.json
已知的插件市场地址列表。

## 🛠️ 常用操作

### 添加新插件
1. 克隆插件到 `plugins/` 目录
2. 更新 `installed_plugins.json`
3. 如有新市场，更新 `known_marketplaces.json`

### 查看插件状态
```bash
# 查看已安装插件
cat C:\Users\li\.claude\plugins\installed_plugins.json

# 查看可用市场
cat C:\Users\li\.claude\plugins\known_marketplaces.json
```

### 清理缓存
```bash
# 清理插件缓存
rm -rf C:\Users\li\.claude\plugins\cache
```

## 💡 使用提示

1. **插件位置** - 全局插件放在 `C:\Users\li\.claude\plugins`，项目插件放在项目 `.claude/plugins`
2. **优先级** - 项目插件会覆盖全局同名插件
3. **缓存管理** - 定期清理 cache 目录可以解决插件加载问题
4. **市场同步** - 使用 `known_marketplaces.json` 管理常用插件源
