# 质量检查命令

> 快捷别名：`/check`

## 命令语法

```bash
/check <文章文件> [选项]
```

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `<文章文件>` | Markdown 文章路径 | 必需 |
| `--quick` | 快速检查 | 完整检查 |
| `--strict` | 严格模式 | 标准模式 |
| `--format <格式>` | 输出格式 | markdown |

## 检查维度

### 1. 检查清单评分（40%）

| 维度 | 分值 | 检查项 |
|------|------|--------|
| 选题检查 | 20分 | 三维匹配、市场洼地、信息增量、人群覆盖 |
| 大纲检查 | 25分 | 为什么章节、理由数量、场景数量、承诺可信 |
| 正文检查 | 25分 | 配图、段落长度、首段术语、开头优化、ASCII图 |
| 标题检查 | 15分 | 数字对比、戏剧性词汇、易懂性 |
| 排版检查 | 15分 | 标题层级、列表格式、换行符、可视化 |

### 2. ABCD四维审稿（30%）

| 维度 | 分值 | 检查项 |
|------|------|--------|
| A 活人感 | 25分 | 无AI翻译腔、无过度排比、无空洞连接词 |
| B 违禁词 | 25分 | 无平台违禁词（一票否决）、无商业黑话 |
| C 真诚度 | 25分 | 无夸大、无隐瞒缺点、引用逻辑可靠 |
| D 价值观 | 25分 | 不为流量违背尊严、老读者不浮躁 |

### 3. SEO评分（30%）

| 维度 | 分值 | 检查项 |
|------|------|--------|
| 关键词优化 | 30分 | 标题、首段、H2、密度 |
| 结构优化 | 25分 | 标题层级、段落长度、内部链接 |
| Meta标签 | 20分 | 描述存在、长度、关键词 |
| 外部因素 | 25分 | 外部链接、图片Alt、URL友好 |

## 评分标准

```
综合评分 = 检查清单(40%) + ABCD审稿(30%) + SEO评分(30%)
```

| 分数 | 等级 | 建议 |
|------|------|------|
| 90-100 | ✅优秀 | 强烈推荐发布 |
| 80-89 | ⭐良好 | 推荐发布 |
| 70-79 | ⚠️一般 | 建议优化后发布 |
| 60-69 | ❌较差 | 不建议发布 |
| <60 | 🚫重做 | 质量严重不达标 |

## 使用示例

### 基础检查
```bash
/check article.md
```

### 快速检查
```bash
/check article.md --quick
```

### 严格模式
```bash
/check article.md --strict
```

### JSON输出
```bash
/check article.md --format json
```
