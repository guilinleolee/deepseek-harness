# 客户深度访谈（customer-interview）

FDE 工作流 **discover** 阶段的核心动作。用结构化访谈替代"随便聊聊"，输出可落地的问题陈述。

## 参数

- **客户名**: $1 (必需) - 必须已通过 `/customer-onboard` 建档
- **访谈主题**: $2 (可选) - 默认 "全业务面"

## 执行流程

### 1. 加载客户档案

读取 `~/customers/$1/profile.md`，确认：
- 干系人列表（决策人/使用人/配合人）
- 决策链深度
- 已记录的"客户自述问题"

### 2. 调用 customer-interview-template skill

加载 `~/.claude/skills/customer-interview-template/SKILL.md` 的访谈模板：

**A. 情境问题（Situation）—— 5-10 min**
1. 你们团队现在是怎么处理 [业务场景] 的？
2. 这个流程谁负责？一天/一周处理多少？
3. 用过哪些工具？哪些环节卡壳？
4. 数据存放在哪些系统里？权限怎么分？
5. 老板对这个流程有什么期待？员工有什么抱怨？

**B. 痛点问题（Pain）—— 10-15 min**
6. 最近一次"事故/出错/延误"是什么时候？损失有多大？
7. 这件事是怎么处理的？花了多久？
8. 如果再发生一次，你们能做什么预防？
9. 这个问题影响了哪些人/哪些业务？
10. 不解决的话，明年会有什么后果？

**C. 价值问题（Value / JTBD）—— 5-10 min**
11. 理想情况下，这个流程跑顺之后，团队应该是什么样的？
12. 你个人会因为这个变化获得什么？（晋升/效率/收入）
13. 公司会因为这个变化获得什么？
14. 你愿意为这个变化付出多大成本？（钱/时间/组织调整）
15. 评估"成功"的可量化指标是什么？

**D. 边界问题（Boundary）—— 5-10 min**
16. 这个项目谁会是反对者？为什么？
17. 哪些系统/数据不能动？
18. 合规/审计有什么红线？
19. 时间窗口有要求吗？（反季节/财年/项目周期）
20. 预算大致在什么区间？

### 3. 实时记录到 interviews/

每场访谈独立文件 `interviews/YYYY-MM-DD-{主题}-{干系人}.md`：

```markdown
# 访谈记录 - $1 - YYYY-MM-DD

## 基本信息
- 干系人: [姓名/角色]
- 时长: X 分钟
- 地点: [现场/线上]

## 关键引述（原文/原话，至少 3 条）
> "..."
> "..."
> "..."

## A. 情境事实
- ...

## B. 痛点确认
- ...

## C. 价值/成功指标
- 量化指标: ...
- 时间窗: ...

## D. 边界/红线
- ...

## 证据等级
- 一手: ✅（亲耳所闻）
- 推断: ⚠️（需验证）
- 未验证: ❌（不作为决策依据）

## 访谈后 24h 内待办
- [ ] 客户确认本次记录
- [ ] 进入 problem-statement 提炼
```

### 4. 提炼 problem-statement（24h 内）

基于访谈记录，输出标准问题陈述：

```markdown
## 问题陈述（Problem Statement）

[客户名] 在 [场景] 中，因为 [根因]，
导致 [可量化损失]，影响 [哪些干系人]。
成功标准：[基线 X] → [目标 Y]，时间窗 [Z 月]。
不做的话，[业务后果 N]。

不做什么：[明确范围外 3 项]
```

### 5. 调用 [[agents/02-architect]] 准备 D 节

把 problem-statement 传给架构师，启动 [[03-FDE交付模板]] D 节"可行性评估"。

### 6. 更新天龙 memory

```
## [YYYY-MM-DD] customer-interview | $1 - $2
- 访谈数: X 场
- 关键发现: [一句话]
- 下一步: 调用 /02架构师
```
