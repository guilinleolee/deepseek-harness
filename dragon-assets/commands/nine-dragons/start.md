启动九部天龙全自动开发军团。

## 用法

```bash
/九天龙 [工作流] [任务描述]
```

## 工作流类型

### 1. 完整开发流程（full）
```
/九天龙 full 实现用户认证功能
```

**包含阶段**：调研→设计→开发→测试→审查→发布

**适用场景**：新功能开发（>2小时）

**预期时间**：30-60 分钟

---

### 2. 功能开发（feature）
```
/九天龙 feature 添加评论系统
```

**包含阶段**：设计→开发→测试→审查

**适用场景**：需求明确的中小功能

**预期时间**：15-30 分钟

---

### 3. 并行测试（test）
```
/九天龙 test 订单模块
```

**包含阶段**：测试验证

**适用场景**：代码已完成，需要测试

**预期时间**：5-15 分钟

---

### 4. 代码审查（review）
```
/九天龙 review 支付模块
```

**包含阶段**：安全+质量审查

**适用场景**：代码完成准备提交

**预期时间**：5-10 分钟

---
