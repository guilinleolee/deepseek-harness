# dbs-diagnosis - 商业诊断命令

使用 dbskill 商业诊断方法论分析问题。

## 使用方式

```bash
/dbs-diagnosis "问题描述"
```

## 示例

```bash
/dbs-diagnosis "用户增长停滞"
/dbs-diagnosis "产品变现困难"
/dbs-diagnosis "团队执行力差"
```

## 诊断流程

1. **问题陈述** - 原始问题记录
2. **问题类型识别** - 战略/战术/执行/心理
3. **问题拆解** - 表面→深层→根本
4. **问题消解** - 问题是否真的存在？
5. **行动建议** - 针对性解决方案

## 核心理念

> "消解问题，不回答问题" - 问题可能不存在，或问题本身需要被重新定义
