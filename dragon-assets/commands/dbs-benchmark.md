# dbs-benchmark - 五重过滤对标分析

使用 dbskill 五重过滤对标分析方法。

## 使用方式

```bash
/dbs-benchmark "对标对象描述"
```

## 示例

```bash
/dbs-benchmark "对比竞品A的商业模式"
/dbs-benchmark "分析行业头部玩家的策略"
/dbs-benchmark "研究对标公司的增长路径"
```

## 五重过滤框架

| 过滤层 | 检查内容 | 排除对象 |
|--------|---------|---------|
| 第一重 | 规模差异 | >10倍规模差 |
| 第二重 | 行业本质 | 行业逻辑不同 |
| 第三重 | 资源护城河 | 不可复制资源 |
| 第四重 | 可持续性 | 短期红利依赖 |
| 第五重 | 可复用模式 | 提取可学习模式 |

## 核心理念

> "五重过滤，排除噪音" - 模仿是对结果负责，创新常是逃避的借口
