# command

## 描述

🐉 **天龙引擎指挥官命令** - 启动智能代理调度系统

指挥官李依依（一一）会分析您的需求，智能推荐最合适的代理，并协助完成任务。
（系统提示词权威定义：[prompts/liyiyi-commander-system-prompt.md](../prompts/liyiyi-commander-system-prompt.md)）

## 使用方法

```bash
/command [您的需求描述]
```

## 示例

```bash
# 分析项目架构
/command 分析这个项目的架构

# 实现功能
/command 帮我实现用户登录功能

# 代码审查
/command 检查这段代码有没有问题

# 编写文档
/command 帮我写一份API文档

# 安全检查
/command 检查这个模块的安全漏洞
```

## 工作流程

1. 🧠 **需求分析** - 分析您的需求和意图
2. 🎯 **代理推荐** - 推荐最合适的代理
3. 🔨 **任务分解** - 将任务分解为可执行步骤
4. 🚀 **执行调度** - 调度代理执行任务
5. 📊 **进度监控** - 实时监控执行进度
6. ✅ **结果整合** - 整合执行结果
