# /critical-check - Agent批判性思维检查

**天龙引擎 V7.4批判性思维 Layer 2 - Agent检查命令**

## 功能

检查Agent输出是否符合批判性思维标准，包括：
- 6大批判性思维维度评分
- 改进建议生成
- 不合格Agent警告

## 用法

```bash
/critical-check <agent-id>
```

### 参数

- `agent-id`: Agent编号或名称
  - 数字编号：`00`, `01`, `02`, ...
  - 中文名称：`分析师`, `调研师`, `架构师`, ...
  - 英文ID：`00-analyst`, `02-architect`, ...

## 示例

### 检查指定Agent
```bash
/critical-check 02
```

### 使用中文名称
```bash
/critical-check 架构师
```

### 使用英文ID
```bash
/critical-check 02-architect
```

## 输出格式

```
## 🧠 批判性思维检查报告

**Agent**: 02-architect
**得分**: 0.85 / 1.00
**等级**: ✅ 良好
**检查时间**: 2026-02-28T10:30:00.000Z

### 📊 各维度得分

- **质疑假设**: 80% (权重20%) ✅
- **验证证据**: 90% (权重15%) ✅
- **检查逻辑**: 85% (权重15%) ✅
- **考虑反例**: 75% (权重15%) ✅
- **自我反思**: 70% (权重10%) ⚠️
- **可证伪性**: 100% (权重25%) ✅

### 💡 改进建议

#### ⚠️ 自我反思 (得分70%)
- 自我反思不够深入
- 建议格式："🤔 自我反思：[认知偏见/局限性]"
- 询问：我的判断有什么偏见？有什么局限？

---

## ✅ 验收通过

批判性思维得分 (0.85) 达到最低标准 (0.6)。
```

## 不合格示例

```
## 🧠 批判性思维检查报告

**Agent**: 03-builder
**得分**: 0.45 / 1.00
**等级**: ❌ 不及格
**检查时间**: 2026-02-28T10:35:00.000Z

### 📊 各维度得分

- **质疑假设**: 50% (权重20%) ⚠️
- **验证证据**: 60% (权重15%) ⚠️
- **检查逻辑**: 40% (权重15%) ❌
- **考虑反例**: 0% (权重15%) ❌
- **自我反思**: 30% (权重10%) ❌
- **可证伪性**: 50% (权重25%) ⚠️

### 💡 改进建议

#### ⚠️ 质疑假设 (得分50%)
- 隐含假设未完全列出
- 建议格式："⚠️ 假设：[X]，验证方法：[Y]"

#### ❌ 考虑反例 (得分0%)
- **未考虑反例或失败案例**
- 建议格式："🔄 反例：[X]，避免方法：[Y]"
- 询问：什么情况下这个方案不成立？有失败案例吗？

#### ❌ 自我反思 (得分30%)
- 未进行自我反思或偏见检查
- 建议格式："🤔 自我反思：[认知偏见/局限性]"
- 询问：我的判断有什么偏见？有什么局限？

#### ⚠️ 可证伪性 (得分50%)
- **关键缺失**：无可证伪性声明
- 建议格式："🔬 证伪方法：[如何证明我是错的]"
- 询问：如何证明这个决策是错的？什么情况下被推翻？

2. 确保输出包含6大批判性思维维度
