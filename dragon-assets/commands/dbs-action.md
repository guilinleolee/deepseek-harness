# dbs-action - 执行力诊断

使用阿德勒心理框架诊断执行力问题。

## 使用方式

```bash
/dbs-action "执行力问题描述"
```

## 示例

```bash
/dbs-action "我总是拖延"
/dbs-action "不敢开始新项目"
/dbs-action "完美主义导致无法完成"
```

## 阿德勒四维度诊断

| 维度 | 核心问题 | 诊断目的 |
|------|---------|---------|
| **目的论** | 行为背后的目的是什么？ | 识别真实动机 |
| **课题分离** | 这是谁的课题？ | 厘清责任边界 |
| **自卑与超越** | 是否有自卑情结？ | 发现心理阻塞 |
| **社会兴趣** | 行为是否符合社会利益？ | 评估可持续性 |

## 阻塞类型

- **能力阻塞** → 需要学习/资源
- **意愿阻塞** → 需要动机调整
- **资源阻塞** → 需要资源获取
- **心理阻塞** → 需要心态转变

## 核心理念

> "焦虑的反面是具体" - 执行力 = 具体化能力
