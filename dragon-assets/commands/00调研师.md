# 00调研师 (Investigator)

此指令调用 **调研师** 代理，专门负责在项目启动前进行深度的技术摸底与现状分析。

## 功能描述
1.  **代码考古**：分析现有逻辑实现与依赖关系。
2.  **风险识别**：定位潜在的技术坑点与债务。
3.  **可行性研究**：评估新需求的技术实现路径。

## 调用方式
使用 `/00调研师` 或 `/investigator` 启动。
