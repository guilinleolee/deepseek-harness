# 九部天龙任务规划

> 融合场景路由+文件持久化的智能规划系统

你现在需要为用户创建任务规划: **$ARGUMENTS**

## 📋 执行步骤

### 步骤1: 任务复杂度评估

根据以下标准评估任务复杂度:

| 维度 | 🟢 简单(1-2步) | 🟡 中等(3-5步) | 🟠 复杂(5-10步) | 🔴 高难度(10+步) |
|------|----------------|----------------|----------------|-----------------|
| **时间** | <5分钟 | 5-15分钟 | 15-30分钟 | >30分钟 |
| **文件** | 0-1个 | 2-5个 | 5-10个 | >10个 |
| **依赖** | 无 | 少量 | 中等 | 复杂 |
| **架构** | 无需修改 | 小修改 | 中度修改 | 架构变更 |

### 步骤2: 场景判断

根据任务特征判断场景:

**场景1: 提示增强**
- ✅ 1-2步可完成
- ✅ 无需代码修改
- ❌ 不推荐: 复杂任务

**场景2: Skill直接复用**
- ✅ 单个Skill可解决
- ✅ 任务类型明确

**场景3: 计划+评审(默认)**
- ✅ 中等/复杂任务
- ✅ 需要质量保证
- 大多数开发任务属于此类

**场景4: Lead-Member**
- ✅ 需要团队分工
- ✅ 需要Leader协调

**场景5: 复杂编排**
- ✅ 超复杂任务
- ✅ 需要动态组合

### 步骤3: 创建3文件

如果3文件不存在,自动创建:

1. **task_plan.md** - 任务计划和阶段追踪
   - Goal: 目标声明
   - Phases: 7个阶段(00→01→02→03→04→06→08)
   - Cost Summary: 成本预估
   - Errors Encountered: 错误记录

2. **findings.md** - 研究发现和知识积累
   - Requirements Analysis: 需求分析
   - Research Findings: 研究发现
   - Technical Decisions: 技术决策
   - Visual/Browser Findings: 浏览发现

3. **progress.md** - 执行日志和进度记录
   - Phase日志: 每个阶段详细记录
   - Test Results: 测试结果
   - Error Log: 错误日志
   - Cost Tracking: 成本追踪

### 步骤4: 引导填写

引导用户填写:
1. **Goal** - 一句话目标
2. **Key Questions** - 关键问题
3. **Phase 1任务** - 第一阶段任务清单

### 步骤5: 输出规划报告

```markdown
# 🎯 九部天龙任务规划报告

## 📊 任务评估
**任务描述**: [用户输入]
**复杂度**: 🟡 中等 / 🟠 复杂 / 🔴 高难度
**场景分类**: 场景3(计划+评审)

## 📁 已创建文件
- ✅ task_plan.md - 任务计划和阶段追踪
- ✅ findings.md - 研究发现和知识积累
- ✅ progress.md - 执行日志和进度记录

## 👥 推荐执行路径

### 阶段1: 需求分析 (00分析师)
- **模型**: Sonnet
- **成本**: $0.01-0.02
- **产出**: 需求解构文档

### 阶段2: 考古摸底 (01调研师)
- **模型**: Sonnet
- **成本**: $0.015-0.025
- **产出**: 技术调研报告

### 阶段3: 架构设计 (02架构师)
- **模型**: Opus [重要决策]
- **成本**: $0.03-0.05
- **产出**: 架构设计文档

### 阶段4: 代码施工 (03构建师)
- **模型**: Codex/Sonnet
- **成本**: $0.02-0.04
- **产出**: 可执行代码

### 阶段5: 测试验证 (04验证师)
- **模型**: Sonnet
- **成本**: $0.02-0.03
- **产出**: 测试报告

### 阶段6: 代码审查 (06审查师)
- **模型**: Gemini [免费] / Opus
- **成本**: $0-0.05
- **产出**: 审查报告

### 阶段7: 发布交付 (08发布师)
- **模型**: Sonnet
- **成本**: $0.01
- **产出**: Git提交/PR

## 💰 总体预估
- **总成本**: $0.105-0.215
- **总时间**: 23-40分钟
- **性价比**: ⭐⭐⭐⭐⭐

## 🚀 下一步
1. 读取 task_plan.md 填写Goal
2. 添加Key Questions
3. 开始Phase 1: 需求分析

## 📚 相关命令
- `/plan:status` - 查看当前进度
- `/nine-dragons-help` - 智能助手
- `/nine-dragons-cost-opt` - 成本优化模式
```

## 使用示例

### 示例1: 简单任务
```bash
/plan "实现一个用户登录表单"

🎯 场景判断: 场景3(计划+评审)
📊 复杂度: 🟡 中等
📁 已创建: task_plan.md, findings.md, progress.md
💰 预估成本: $0.03
```

### 示例2: 复杂任务
```bash
/plan "实现完整的JWT认证系统,包含注册、登录、密码重置"

🎯 场景判断: 场景3(计划+评审)
📊 复杂度: 🟠 复杂
👥 推荐路径: 00→01→02→03→04→06→08
💰 预估成本: $0.105-0.215
```

### 示例3: 高难度任务
```bash
/plan "重构微服务架构,从单体应用拆分为用户服务、订单服务、支付服务"

🎯 场景判断: 场景4(Lead-Member)
📊 复杂度: 🔴 高难度
👥 推荐路径: 完整九部天龙 + Agent Team协作
💰 预估成本: $0.125+
```

## 注意事项

1. **成本估算为近似值**: 实际消耗会因任务细节而异
2. **时间预估不含等待**: 仅计算AI处理时间
3. **模型选择可调整**: 根据预算和质量需求灵活调整
4. **3文件自动创建**: 基于templates/目录下的模板
