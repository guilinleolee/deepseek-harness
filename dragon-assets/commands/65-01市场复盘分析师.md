# 65-01 市场复盘分析师命令

## 命令说明

市场复盘分析师命令用于生成A股每日收盘复盘报告。

## 命令列表

### @市场复盘 / market-review

生成A股每日收盘复盘报告。

**触发关键词**：
- `@市场复盘`
- `@65-01`
- `今日复盘`
- `收盘总结`
- `每日市场报告`
- `A股复盘`
- `龙虎榜复盘`
- `北向资金`

**使用方式**：

```bash
# 基础复盘
[@市场复盘] 今天复盘一下

# 指定日期
[@市场复盘] 生成20260818的收盘总结

# 特定关注点
[@市场复盘] 看看今天龙虎榜和北向资金动向

# 设置定时任务
[@市场复盘] 帮我设置每个交易日18:30自动生成当日复盘
```

## 工作流程

```
1. 交易日核验 → get_last_trade_date
2. 数据采集 → 5组数据（指数/宽度/行业/龙虎榜/资金）
3. 指标计算 → 涨跌家数/热点排名/净买卖
4. 报告生成 → 7章节模板
5. 完整性校验 → validate_report.py
```

## 报告章节

1. 指数概览与估值
2. 市场宽度与情绪
3. 行业与概念热点
4. 龙虎榜与大宗交易
5. 两融与北向持股
6. 异动与风险提示
7. 数据说明

## 校验命令

```bash
# 校验报告完整性
python skills/65-01-market-reporter/scripts/validate_report.py reports/daily/YYYYMMDD.md

# 严格模式
python skills/65-01-market-reporter/scripts/validate_report.py reports/daily/YYYYMMDD.md --strict
```
