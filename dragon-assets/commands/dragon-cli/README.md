## 命令列表

### 基础命令

#### `/agent-list` - 查看所有代理

**描述**：显示所有可用的天龙代理及其详细信息

**用法**：
```
/agent-list [department]
```

**参数**：
- `department`（可选）：按部门过滤，如"核心九部"

**示例**：
```
/agent-list              # 显示所有代理
/agent-list 核心九部      # 只显示核心九部代理
```

**输出示例**：

#### `/recommend` - 智能推荐

**描述**：根据指定条件智能推荐最合适的代理

**用法**：
```
/recommend [--capabilities <能力>] [--model <模型>] [--max-cost <成本>] [--min-success <成功率>]
```

**参数**：
- `--capabilities`：能力要求（可多个）
- `--model`：偏好模型（opus/sonnet）
- `--max-cost`：最大成本限制
- `--min-success`：最低成功率要求

**示例**：
```
/recommend --capabilities 代码 安全 --max-cost 0.8
/recommend --model sonnet --min-success 90
```

**输出示例**：
```
🎯 智能推荐结果
========================================

筛选条件：
  能力：代码、安全
  最大成本：$0.8

找到 1 个匹配代理：

🥇 05安全师 (05-security-reviewer)
   评分：1.20
   理由：
   • 能力匹配：安全
   • 成本符合：0.7 <= 0.8
```

## 交互式命令

#### `/interactive` - 交互式模式

**描述**：进入交互式命令模式，可以连续执行多个命令

**用法**：
```
/interactive
```

**支持的交互命令**：
- `list` - 列出代理
- `status` - 显示状态
- `analyze` - 分析需求
- `recommend` - 推荐代理
- `help` - 显示帮助
- `exit` - 退出交互模式

**示例**：
```
/interactive

进入交互模式...
输入 'help' 查看可用命令
输入 'exit' 退出

> list
> status
> analyze 实现用户登录
> exit
```

## 通用参数

### `--json` - JSON输出

**描述**：以JSON格式输出结果


**描述**：显示更详细的信息

**示例**：
```
/status --verbose
/analyze 实现登录 --verbose
```

### `--help` - 帮助信息

**描述**：显示命令帮助

**示例**：
```
/agent-list --help
/analyze --help
```

## 配置文件

### `.dragonclirc` 配置

**位置**：`~/.dragonclirc` 或项目根目录

**示例**：
```toml
# API服务器地址
api_url = "http://localhost:3000"

# 默认输出格式
output_format = "table"  # table | json

# 是否启用彩色输出
color_output = true

# 默认模型偏好
preferred_model = "sonnet"

# 默认成本限制
max_cost = 1.0
```
