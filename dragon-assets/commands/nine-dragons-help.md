# 九部天龙智能助手

> 基于V3.3成本感知机制的智能决策系统

你现在需要分析用户的需求：**$ARGUMENTS**

## 📋 执行步骤

### 步骤1：任务复杂度评估

请根据以下标准评估任务复杂度：

| 维度 | 🟢 简单（1-2步） | 🟡 中等（3-5步） | 🟠 复杂（5-10步） | 🔴 高难度（10+步） |
|------|----------------|-----------------|------------------|-------------------|
| **时间** | <5分钟 | 5-15分钟 | 15-30分钟 | >30分钟 |
| **文件** | 0-1个 | 2-5个 | 5-10个 | >10个 |
| **依赖** | 无 | 少量 | 中等 | 复杂 |
| **架构** | 无需修改 | 小修改 | 中度修改 | 架构变更 |

### 步骤2：场景判断

根据任务特征，判断属于以下哪个场景：

**场景1：提示增强**
- ✅ 1-2步可完成
- ✅ 无需代码修改
- ❌ 不推荐：复杂任务

**场景2：Skill直接复用**
- ✅ 单个Skill可解决
- ✅ 任务类型明确（如文档转换、PPT生成）
- ❌ 不推荐：需要多步骤开发

**场景3：计划+评审（默认）**
- ✅ 中等/复杂任务
- ✅ 需要质量保证
- ✅ 需要多文件修改
- 大多数开发任务属于此类

**场景4：Lead-Member**
- ✅ 需要团队分工
- ✅ 需要Leader协调
- ✅ 大型并行任务

**场景5：复合编排**
- ✅ 超复杂任务
- ✅ 需要动态组合策略

### 步骤3：推荐模型组合

根据复杂度推荐最优模型组合：

**🟢 简单任务**
```markdown
推荐模型：Haiku
预估成本：$0.001-0.005
预估时间：3-5分钟
执行策略：直接在主会话完成
```

**🟡 中等任务**
```markdown
推荐模型：Sonnet
预估成本：$0.01-0.03
预估时间：10-15分钟
执行策略：单个宗师完成
```

**🟠 复杂任务**
```markdown
推荐模型组合：
  - 00分析师：Sonnet ($0.01)
  - 02架构师：Sonnet ($0.015)
  - 03构建师：Codex ($0.02)
预估总成本：$0.045
预估时间：20-30分钟
执行策略：九部天龙工作流
```

**🔴 高难度任务**
```markdown
推荐模型组合：
  - 00分析师：Sonnet ($0.01)
  - 01调研师：Sonnet ($0.015)
  - 02架构师：Opus ($0.05) [重要决策用最强模型]
  - 03构建师：Codex ($0.03)
  - 04验证师：Sonnet ($0.02)
  - 06审查师：Gemini (免费)
预估总成本：$0.125
预估时间：30-60分钟
执行策略：完整九部天龙 + Agent Team协作
```

### 步骤4：输出执行路径

请生成以下格式的输出：

```markdown
# 🎯 九部天龙智能分析

## 📊 任务评估

**复杂度**：🟡 中等 / 🟠 复杂 / 🔴 高难度

## 👥 推荐执行路径

### 阶段1：需求分析

### 阶段3：代码施工

### 阶段4：质量审查

## 💰 总体预估
- **总成本**：$0.045
- **总时间**：23分钟
- **性价比**：⭐⭐⭐⭐⭐

## 💡 优化建议

## 🚀 开始执行？
```

## 注意事项

1. **成本估算为近似值**：实际消耗会因任务细节而异
2. **时间预估不含等待**：仅计算AI处理时间，不含网络延迟
3. **模型选择可调整**：根据预算和质量需求灵活调整
4. **复杂度评估主观**：最终以00分析师的深度分析为准
