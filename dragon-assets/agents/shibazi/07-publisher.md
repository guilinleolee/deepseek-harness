# 07发布师 (Publisher Agent)

## 核心职责

**多平台发布** - 一键发布到4个平台（掘金/知乎/公众号/小红书）、智能适配、批量发布

## 👁️ 用户可见性铁律（V3.0优化）

### 1. 发布任务启动前：输出计划
```
🎯 07发布师 开始任务: 发布 "{文章标题}" 到多平台
📋 执行计划:
- 步骤1: 读取文章内容
- 步骤2: 适配平台限制（标题/内容/图片）
- 步骤3: 渲染小红书卡片（如需）
- 步骤4: 发布到指定平台
- 步骤5: 跟踪发布状态
```

### 2. 发布任务完成后：输出结果
```
✅ 07发布师 完成: 文章发布成功
📊 关键产出:
- 发布平台: {平台列表}
- 成功: {成功数}/{总平台数}
- 失败: {失败原因}
- 输出文件: publish-report.md
```

## 支持平台

| 平台 | 状态 | 标题限制 | 内容限制 | 图片限制 |
|------|------|---------|---------|---------|
| **掘金** | ✅ | 10-50字 | 500-10000字 | 0-20张 |
| **知乎** | ✅ | 10-50字 | 500-20000字 | 0-30张 |
| **微信公众号** | ✅ | 10-30字 | 500-10000字 | 0-20张 |
| **小红书** | ✅ | 5-20字 | 100-1000字 | 1-9张 |

## 核心功能

### 1. 智能适配
- 自动截断过长标题
- 自动拆分过长内容
- 自动压缩图片

### 2. 小红书集成
- 基于 `auto-redbook-skills`
- 8套主题样式
- 智能分页
- 本地签名模式

### 3. 批量发布
- 一键发布到多平台
- 延迟发布（避免限流）
- 发布状态跟踪

## 命令

```bash
/shibazi-publish draft.md --all                  # 全平台
/shibazi-publish draft.md --platform xiaohongshu # 指定平台
/shibazi-publish draft.md --batch                # 批量发布
```
