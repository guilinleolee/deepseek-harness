## 专属约束

### 1. 写作模板选择逻辑

**5种写作模板**：

| 模板 | 适用场景 | 核心特征 | 目标受众 |
|------|---------|---------|---------|
| **标准模板** | 通用技术文章、教程、指南 | 逻辑清晰、结构完整、实操性强 | 开发者、技术学习者 |
| **德鲁克模板** | 深度思考、管理洞察、趋势分析 | 洞察驱动、故事化、哲理性 | 管理者、决策者、深度思考者 |
| **SEO模板** | 流量导向、搜索优化、热点内容 | 关键词密集、结构化、易于抓取 | 搜索用户、泛读者 |
| **品牌模板** | 品牌宣传、产品介绍、观点输出 | 品牌声音一致、价值观鲜明 | 潜在客户、合作伙伴 |
| **增量模板** | 快速跟进、热点评论、信息整合 | 信息增量大、时效性强、观点犀利 | 关注热点的读者 |

**模板选择算法**：
```python
def select_template(topic, audience, platform, urgency):
    """
    写作模板选择器

    Args:
        topic: 主题特征（技术/管理/热点/产品）
        audience: 目标受众（开发者/管理者/泛读者）
        platform: 发布平台（掘金/知乎/公众号/小红书）
        urgency: 紧急程度（高/中/低）

    Returns:
        str: 模板名称
    """
    # 规则1：热点+紧急 → 增量模板
    if urgency == "high" and is_hot_topic(topic):
        return "incremental"

    # 规则2：管理/洞察 → 德鲁克模板
    if topic in ["管理", "洞察", "趋势"] and audience == "管理者":
        return "drucker"

    # 规则3：SEO导向 + 泛读者 → SEO模板
    if platform in ["掘金", "知乎"] and audience == "泛读者":
        return "seo"

    # 规则4：品牌相关 → 品牌模板
    if has_brand_keywords(topic):
        return "brand"

    # 默认：标准模板
    return "standard"
```

### 2. 各模板详细规范

#### 📄 标准模板 (Standard Template)

**结构**：
```markdown

## 开篇钩子（3秒法则）
- 问题/痛点/场景（150字）
- 核心论点（50字）

## 背景与问题
- 当前现状（200字）
- 存在问题（200字）
- 解决动机（100字）

## 核心方案/方法
- 方案概述（150字）
- 实施步骤（3-5步，每步200字）
- 代码示例/案例（300字）

## 进阶技巧
- 技巧1（150字）
- 技巧2（150字）
- 最佳实践（200字）

## 常见问题
- Q1（100字）
- Q2（100字）
- Q3（100字）

## 总结与行动
- 核心要点回顾（100字）
- 行动建议（50字）

## 扩展阅读
- 相关资源（3-5个链接）
```

**字数分配**：总计 2000-2500字

### 3. 信息架构设计原则

**金字塔原理**：
```
          核心论点（TOP）
         /    |    \
      论点1  论点2  论点3
      /  \   /  \   /  \
   证据 证据 证据 证据 证据 证据
```

**MECE原则**（Mutually Exclusive, Collectively Exhaustive）：
- 相互独立（不重叠）
- 完全穷尽（无遗漏）

**SCQA模型**（Situation, Complication, Question, Answer）：
- Situation：背景情况
- Complication：冲突/问题
- Question：核心问题
- Answer：解决方案

---

### 4. 大纲质量标准

| 维度 | 标准 | 验证方法 |
|------|------|---------|
| **逻辑性** | 章节之间有清晰的逻辑关系 | 绘制思维导图验证 |
| **完整性** | 覆盖主题的所有关键方面 | 对比同类文章大纲 |
| **平衡性** | 各章节字数分配合理 | 检查字数占比 |
| **可执行** | 每节有明确的关键点 | 03构建师能直接执行 |
| **SEO友好** | 包含主关键词和长尾词 | 统计关键词分布 |
