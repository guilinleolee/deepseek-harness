## 核心方法论

### 杜邦分析法
```
ROE = 净利率 × 资产周转率 × 权益乘素

分解路径：
ROE → 销售净利率（盈利能力）
   → 总资产周转率（运营效率）
   → 权益乘数（财务杠杆）
```

### 财务比率体系
| 类别 | 比率 | 计算公式 | 理想值 |
|------|------|----------|--------|
| **盈利能力** | 毛利率 | (收入-成本)/收入 | 行业依赖 |
| | 净利率 | 净利润/收入 | >5% |
| | ROE | 净利润/权益 | >15% |
| **偿债能力** | 流动比率 | 流动资产/流动负债 | >1.5 |
| | 资产负债率 | 负债/资产 | <60% |
| **运营能力** | 存货周转率 | COGS/存货 | 行业依赖 |
| | 应收周转天数 | 365/(收入/应收) | 逐下降 |

### 投资决策指标
```
NPV (净现值) = Σ(CFt / (1+r)^t) - 初始投资
IRR (内含报酬率) = NPV=0时的折现率
ROI (投资回报率) = 年均收益/初始投资
Payback (回收期) = 初始投资/年均现金流
```

## 工作流程

```
Step 1: 数据收集

Step 4: 建模预测
  ├─ 假设设定
  ├─ 模型构建
  ├─ 敏感性测试
  └─ 情景分析

Step 5: 报告沟通
  ├─ 分析报告撰写
  ├─ 可视化图表制作
  ├─ 管理层汇报
  └─ 行动建议提出
```

## 常见场景

### 场景1: 月度经营分析
```
输入: 月度财务报表、业务数据
处理:
  1. 关键指标汇总（收入、毛利、净利润、现金流）
  2. 同比环比分析
  3. 预算达成分析
  4. 异常数据深挖（产品/区域/客户维度）
  5. 经营亮点与问题识别
  6. 改进建议提出
输出: 月度经营分析报告 + 管理仪表板
```

### 场景2: 投资项目评估
```
输入: 投资项目商业计划书
处理:
  1. 现金流预测（收入、成本、 Capex）
  2. 财务指标计算（NPV、IRR、ROI、回收期）
  3. 敏感性分析（关键变量±10%/±20%）
  4. 风险评估（市场、技术、财务）
  5. 投资建议（Go/No-Go + 条件）
输出: 投资项目评估报告
```

### 场景3: 产品盈利性分析
```
输入: 产品销售数据、成本数据
处理:
  1. 产品收入分析（销量、价格、结构）
  2. 产品成本分析（直接成本、间接分摊）
  3. 产品毛利分析（毛利率、贡献）
  4. 客户盈利性分析（客户获取成本、终身价值）
  5. 产品组合优化建议
输出: 产品盈利性分析报告
```

### 场景4: 现金流预测
```
输入: 历史现金流、业务计划
处理:
  1. 经营现金流预测（收入、成本、营运资本）
  2. 投资现金流预测（Capex计划）
  3. 融资现金流预测（债务、分红）
  4. 滚动预测更新
  5. 现金预警设置
输出: 13周现金流预测 + 月度滚动预测
```

### 场景5: 竞争对手分析
```
输入: 竞争对手财报、行业报告
处理:
  1. 关键财务指标对比（规模、增速、盈利）
  2. 业务模式对比（收入结构、成本结构）
  3. 战略举措跟踪（投资、并购、新产品）
  4. 优劣势分析（SWOT）
  5. 应对建议
输出: 竞争对手分析报告
```

## 最佳实践 (Enrichment)

### 财务分析原则
1. **数据为王**: 基于事实，而非直觉
2. **追问到底**: 不仅是什么，更要为什么
3. **业务导向**: 分析服务于决策
4. **简单清晰**: 一图胜千言
5. **行动导向**: 分析终将转化为行动

### 分析常见错误
| 错误 | 后果 | 避免方法 |
|------|------|----------|
| 数据来源不可靠 | 结论错误 | 交叉验证、注明来源 |
| 相关当作因果 | 错误决策 | 严谨的逻辑推理 |
| 过度拟合模型 | 预测失效 | 留出测试集、专家验证 |
| 忽视异常值 | 偏差分析 | 识别并处理异常值 |
| 只看数字不看业务 | 脱离实际 | 深入业务一线 |

### 好的分析报告特征
- **金字塔结构**: 结论先行，层层支撑
- **数据可视化**: 图表优先，表格辅助
- **洞察驱动**: 回答"那又怎样"
- **行动导向**: 给出明确建议
- **篇幅控制**: 执行摘要≤1页，全文≤10页
