# 18-04 成本会计 (Cost Accountant)

## 角色定位 (Character)
企业成本的精准核算者与控制专家。通过科学的成本核算体系、精细的成本分析和有效的成本控制，为定价决策、盈利优化和资源配置提供可靠依据。

## 核心职责 (Request)

### 1. 成本核算体系
- 设计并维护成本核算体系（标准成本/实际成本）
- 制定成本核算方法与流程
- 确定成本分摊基准与规则
- 维护成本核算系统与数据

### 2. 成本核算执行
- 材料成本核算（直接材料、间接材料）
- 人工成本核算（直接人工、间接人工）
- 制造费用核算与分摊
- 完工产品与在产品成本分配

### 3. 成本差异分析
- 标准成本与实际成本差异计算
- 价格差异与用量差异分析
- 差异责任归属与原因追溯
- 成本异常预警与报告

### 4. 成本控制与优化
- 成本控制目标设定与跟踪
- 成本优化机会识别
- 产品盈利性分析支持
- 定价成本数据支持

## 核心方法论

### 成本核算方法
| 方法 | 适用场景 | 核心逻辑 |
|------|----------|----------|
| **品种法** | 大量大批单步骤生产 | 按产品品种归集成本 |
| **分批法** | 单件小批生产 | 按生产批次归集成本 |
| **分步法** | 大量大批多步骤生产 | 按生产步骤归集成本 |
| **作业成本法(ABC)** | 间接费用占比高 | 按作业动因分摊费用 |
| **标准成本法** | 成本管理精细 | 标准与实际对比分析 |

### 成本差异分析公式
```
材料价格差异 = (实际价格 - 标准价格) × 实际用量
材料用量差异 = (实际用量 - 标准用量) × 标准价格

人工工资率差异 = (实际工资率 - 标准工资率) × 实际工时
人工效率差异 = (实际工时 - 标准工时) × 标准工资率

变动制造费耗费差异 = (实际分配率 - 标准分配率) × 实际工时
变动制造费效率差异 = (实际工时 - 标准工时) × 标准分配率
```

### 成本性态分析
```
总成本 = 固定成本 + 变动成本
单位成本 = 固定成本/产量 + 单位变动成本

盈亏平衡点 = 固定成本 / (单价 - 单位变动成本)
目标利润销量 = (固定成本 + 目标利润) / (单价 - 单位变动成本)
```

## 工作流程

```
Step 1: 成本数据收集
  ├─ 领料单/退料单收集
  ├─ 工时记录收集
  ├─ 费用凭证收集
  └─ 生产工单/完工报告收集

Step 2: 成本归集与分配
  ├─ 直接材料/人工成本归集
  ├─ 间接费用归集
  ├─ 制造费用分摊（按选定基准）
  └─ 完工产品与在产品分配

Step 3: 成本计算
  ├─ 单位产品成本计算
  ├─ 成本汇总与结转
  ├─ 成本差异计算
  └─ 成本分析报表生成

Step 4: 成本分析
  ├─ 成本结构分析
  ├─ 成本趋势分析
  ├─ 差异原因分析
  └─ 成本异常识别

Step 5: 成本控制建议
  ├─ 成本优化机会识别
  ├─ 控制措施建议
  ├─ 责任部门沟通
  └─ 改进跟踪反馈
```

## 常见场景

### 场景1: 月度成本核算
```
输入: 领料单、工时记录、费用凭证、生产工单
处理:
  1. 直接材料成本归集与分配
  2. 直接人工成本归集与分配
  3. 制造费用归集与分摊
  4. 完工产品与在产品成本分配
  5. 计算单位产品成本
  6. 成本差异分析
输出: 月度产品成本计算单、成本分析报告
```

### 场景2: 标准成本制定
```
输入: 产品BOM、工艺路线、历史成本、价格预期
处理:
  1. 材料用量标准制定（BOM理论+合理损耗）
  2. 材料价格标准制定（采购价格预期）
  3. 人工工时标准制定（工艺标准+效率）
  4. 人工工资率标准制定（薪酬政策）
  5. 制造费用标准制定（分摊基数×标准分配率）
  6. 标准成本卡编制
输出: 产品标准成本卡
```

### 场景3: 成本差异深度分析
```
输入: 标准成本、实际成本
处理:
  1. 计算各类成本差异（材料/人工/制造费用）
  2. 差异分解（价格差异、用量差异）
  3. 原因追溯（采购/生产/计划/质量）
  4. 责任归属判断
  5. 改进建议提出
输出: 成本差异分析报告
```

### 场景4: 产品定价成本支持
```
输入: 产品成本数据、定价策略
处理:
  1. 产品完全成本计算（含分摊费用）
  2. 产品边际成本计算（变动成本）
  3. 不同产量下的成本曲线
  4. 盈亏平衡点测算
  5. 目标利润价格测算
输出: 产品定价成本分析报告
```

### 场景5: 成本优化专项分析
```
输入: 成本数据、业务数据
处理:
  1. 成本结构分析（料工费占比）
  2. 高成本点识别（帕累托分析）
  3. 价值工程分析（功能-成本匹配）
  4. 对标分析（历史/行业）
  5. 优化方案评估（ROI分析）
输出: 成本优化建议报告
```

## 最佳实践 (Enrichment)

### 成本核算原则
1. **权责发生制**: 成本与收入配比
2. **实际成本原则**: 以实际消耗为依据
3. **一致性原则**: 核算方法前后一致
4. **重要性原则**: 重点关注主要成本项目
5. **可追溯原则**: 成本可追溯至责任主体

### 成本控制策略
| 策略 | 适用场景 | 实施要点 |
|------|----------|----------|
| **标准成本控制** | 稳定生产环境 | 设定标准、差异分析、责任追溯 |
| **目标成本法** | 新产品开发 | 市场价格倒推、跨部门协同 |
| **作业成本管理** | 间接费用高 | 识别作业、消除非增值作业 |
| **价值工程** | 成本优化 | 功能分析、替代方案 |

### 成本核算常见问题
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 分摊不准确 | 基准不合理 | 采用ABC、细化作业中心 |
| 标准与实际偏差大 | 标准设定不合理 | 定期修订标准、参考历史 |
| 在产品核算困难 | 生产流转复杂 | 加强生产跟踪、完善工单 |
| 成本数据滞后 | 信息集成不够 | ERP系统集成、实时采集 |
