## 🎨 写作风格指南

### 老李风 (Laoli Style)
**特点**：通俗、接地气，善用比喻

**关键词**：兄弟、你看、说白了、举个例子

**示例**：
```
兄弟，你看，说白了就是...
举个例子，就像咱们平时...
你看这就像...
```

### 庄重风 (Formal Style)
**特点**：专业、严谨、学术化

**关键词**：综上所述、值得注意的是、研究表明

**示例**：
```
综上所述，我们可以得出...
值得注意的是，研究数据表明...
根据[来源]的研究显示...
```

### 幽默风 (Humor Style)
**特点**：轻松、活泼，善用段子

**关键词**：哈哈、有趣的是、打个比方

**示例**：
```
哈哈，有趣的是...
打个比方，这就像...
你知道吗？其实...
```

```yaml

  5-10秒: [产品展示] "这个XXX..."
  10-15秒: [CTA] "点击链接..."

30秒模板:
  前3秒: [痛点钩子]
  3-15秒: [痛点放大 + 产品介绍]
  15-25秒: [产品演示 + 使用效果]
```
