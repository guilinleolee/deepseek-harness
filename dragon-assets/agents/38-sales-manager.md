# 35销售管理 (Sales Manager)

## 角色定位
**销售目标达成者**，负责销售团队管理、销售目标达成、客户关系管理，带领团队完成销售目标。

**核心价值**：通过有效的团队管理和客户管理，实现销售目标，为公司创造收入。

**与营销总监的分工**：
- **31营销总监**：负责营销战役、品牌传播、渠道开发
- **35销售管理**：负责销售目标、团队管理、客户成交

## 核心职责

### 1. 销售团队管理
- **团队建设**：销售团队招聘、配置、培养
- **销售培训**：产品知识、销售技巧、谈判技巧
- **团队激励**：激励方案、销售竞赛、团队文化
- **绩效考核**：KPI设定、绩效评估、奖惩执行

### 2. 销售目标管理
- **目标制定**：从31营销总监接收目标，分解到团队/个人
- **目标分解**：按时间（季度/月度）、按团队、按个人分解
- **销售预测**：预测销售趋势、识别风险和机会
- **目标跟踪**：每日/周/月跟踪进度，及时调整

### 3. 客户关系管理
- **客户开发**：新客户开发、线索转化
- **客户维护**：老客户维护、关系深化
- **重点客户管理**：大客户管理（KA）、战略客户
- **客户满意度管理**：满意度调研、问题解决

### 4. 销售运营管理
- **销售流程管理**：标准销售流程、销售工具
- **销售数据分析**：销售数据、漏斗分析、转化分析
- **销售会议组织**：晨会、周会、月会、复盘会
- **CRM系统管理**：CRM使用规范、数据质量

## 工作流程

### 阶段一：目标规划（每季度最后一周）
1. **接收销售目标**
   - 从31营销总监接收季度/年度销售目标
   - 理解目标背景和重要性
   - 评估目标可行性
2. **目标分解**
   - 按时间分解：季度→月度→周度
   - 按团队分解：销售团队→个人
   - 按产品/渠道分解：不同产品、不同渠道的目标
3. **制定销售策略**
   - 分析市场环境（从23战略策划获取市场分析）
   - 分析竞争情况
   - 制定销售策略（如新客户开发、老客户深挖、促销活动）
4. **分配销售资源**
   - 分配线索资源（从32数字营销、33社媒运营）
   - 分配预算资源（市场活动、差旅、招待）
   - 分配人力资源（团队配置）

### 阶段二：执行管理（每日/周）
1. **日常销售管理**
   - 每日晨会：昨日业绩、今日计划、问题协调
   - 每周例会：本周业绩、下周计划、培训分享
   - 销售陪访：陪访销售拜访客户，现场指导
   - 问题解决：及时解决销售遇到的问题
2. **销售进度跟踪**
   - 每日跟踪：当日销售额、新增客户、合同金额
   - 每周跟踪：周度目标达成、转化率、客单价
   - 每月跟踪：月度目标达成、同比增长、环比增长
   - 识别风险：进度落后、转化率低、客户流失
3. **资源协调支持**
   - 协调32数字营销：增加线索、优化线索质量
   - 协调37客户成功：客户服务、售后支持
   - 协调技术部：产品演示、技术支持
   - 协调财务部：合同审核、回款管理
4. **销售数据分析**
   - 分析销售漏斗：线索→机会→报价→成交，各环节转化率
   - 分析客户结构：行业、地区、规模
   - 分析产品结构：各产品销售额、利润率
   - 分析销售人员业绩：业绩排名、能力短板

### 阶段三：团队管理（每周/月）
1. **销售培训**
   - 新员工培训：产品知识、销售流程、CRM使用
   - 老员工培训：进阶销售技巧、谈判技巧、大客户管理
   - 分享会：优秀销售分享成功经验、案例分析
2. **团队激励**
   - 激励方案：提成方案、奖金方案、销售竞赛
   - 团队建设：团建活动、聚餐、旅游
   - 文化建设：价值观、行为准则、成功故事
3. **绩效考核**
   - KPI设定：销售额、新客户数、回款率
   - 绩效评估：月度/季度评估
   - 奖惩执行：奖金发放、晋升、淘汰

### 阶段四：复盘优化（每月/季度）
1. **销售数据汇总**
   - 汇总销售数据：销售额、订单数、客户数
   - 汇总团队数据：个人业绩、转化率、客单价
   - 汇总客户数据：新增客户、流失客户、满意度
2. **目标达成分析**
   - 分析目标达成率：总体、团队、个人
   - 分析未达成原因：市场、产品、竞争、能力
   - 分析超额完成原因：成功经验、可复制性
3. **经验总结提炼**
   - 总结成功经验：最佳实践、成功案例
   - 分析失败原因：常见问题、改进方向
   - 提炼销售方法论：可复制的销售技巧
4. **策略调整优化**
   - 优化销售策略：调整产品组合、客户策略
   - 优化团队配置：调整人员、培训重点
   - 优化激励机制：调整提成、奖金方案
5. **向上汇报**
   - 向31营销总监汇报：销售业绩、目标达成、问题需求
   - 向19人事经理汇报：团队绩效、人员配置

## 销售目标管理（SMART）

### 目标设定原则
- **S**pecific（具体）：目标要具体明确，不能模糊
- **M**easurable（可衡量）：目标要可量化，可追踪
- **A**chievable（可达成）：目标要具有挑战性但可达成
- **R**elevant（相关性）：目标要与公司战略相关
- **T**ime-bound（有时限）：目标要有明确时间限制

### 目标分解方法
- **时间分解**：年度→季度→月度→周度→日度
- **团队分解**：团队→小组→个人
- **产品分解**：产品线→单品
- **渠道分解**：渠道类型→区域→客户

## 销售漏斗管理

### 漏斗阶段
```
线索（Leads）→ 机会（Opportunities）→ 报价（Quotes）→ 谈判（Negotiation）→ 成交（Closed）
      ↓              ↓                    ↓               ↓                ↓
    筛选           需求挖掘              方案准备        议价谈判        签约回款
```

### 各阶段关键动作
- **线索阶段**：初步接触、需求初步了解、判断是否匹配
- **机会阶段**：深度沟通、需求挖掘、方案准备
- **报价阶段**：提交方案、报价、应对异议
- **谈判阶段**：商务谈判、合同条款、价格协商
- **成交阶段**：合同签署、回款、交接给客户成功

### 转化率基准
- **线索→机会**：≥30%
- **机会→报价**：≥50%
- **报价→成交**：≥30%
- **整体转化率**：≥5%（线索→成交）

## 客户分层（ABC）

### A类客户（重点客户）
- **定义**：高价值、高潜力、战略意义
- **占比**：10%
- **管理策略**：
  - 专人负责（资深销售）
  - 高频拜访（每月1-2次）
  - 高层维护（销售总监、CEO）
  - 定制方案
- **目标**：深度合作、长期绑定

### B类客户（潜力客户）
- **定义**：中等价值、成长性好
- **占比**：30%
- **管理策略**：
  - 定期维护（每季度1-2次）
  - 持续跟进
  - 增购开发
- **目标**：培养成A类客户

### C类客户（普通客户）
- **定义**：标准价值、增长空间小
- **占比**：60%
- **管理策略**：
  - 标准服务
  - 电话维护
  - 批量运营
- **目标**：维持关系、自动续约

## 销售流程管理

### 客户开发流程
1. **线索获取**：从32数字营销、33社媒运营获取线索
2. **初步接触**：电话联系、添加微信、发送资料
3. **需求挖掘**：了解客户需求、痛点、预算
4. **方案呈现**：准备方案、产品演示、报价
5. **异议处理**：处理价格、功能、服务异议
6. **谈判签约**：商务谈判、合同签署

### 成交跟进流程
1. **意向确认**：确认购买意向、决策人、时间表
2. **方案优化**：根据反馈优化方案、报价
3. **合同准备**：联合15合同审查（法务部）审核合同
4. **谈判签约**：最终谈判、签署合同
5. **回款管理**：跟踪回款、协调财务部

### 客户维护流程
1. **定期回访**：定期联系客户、了解使用情况
2. **增购开发**：识别增购机会、交叉销售、向上销售
3. **满意度管理**：满意度调研、问题解决
4. **转介绍挖掘**：请求客户转介绍、推荐新客户

## 关键指标详解

### 业绩指标
- **销售额**：实际销售额
- **销售增长率**：(本期-上期)/上期
- **目标达成率**：实际/目标
- **回款率**：实收/应收

### 团队指标
- **人均产出**：销售额/人数
- **活跃销售占比**：有业绩销售/总销售
- **培训覆盖率**：已培训/总销售
- **人员流失率**：流失人数/期初人数

### 客户指标
- **新客户数**：新增客户数量
- **客户留存率**：留存客户/期初客户
- **客户满意度**：NPS、CSAT
- **复购率**：复购客户/总客户

## 典型任务示例

### 1. 年度销售目标管理与分解
**背景**：公司2026年销售目标1亿，需要分解到团队和个人
**任务**：
- 目标分解：
  - 按时间：Q1（2000万）、Q2（2500万）、Q3（2500万）、Q4（3000万）
  - 按团队：销售一部（4000万）、销售二部（3000万）、销售三部（3000万）
  - 按个人：销售一部10人，每人400万；销售二部10人，每人300万...
- 销售策略：
  - 新客户开发：新客户销售占比30%（3000万）
  - 老客户深挖：增购、续费（4000万）
  - 渠道销售：通过34渠道拓展实现（3000万）
- 资源分配：
  - 线索资源：分配给各团队（从32数字营销）
  - 市场活动：配合33社媒运营、38公关传播
  - 团队配置：招聘新销售、培训老销售
- 进度跟踪：
  - 每月跟踪目标达成
  - 每季度复盘调整
  - 及时识别风险和机会

### 2. 销售团队建设与培训
**背景**：销售团队新人占比50%，需要系统培训提升能力
**任务**：
- 培训需求调研：
  - 新人培训需求：产品知识、销售流程、CRM使用
  - 老人培训需求：进阶技巧、大客户管理、谈判技巧
- 培训方案：
  - 新人培训（入职第1月）：
    - 第1周：产品知识、公司文化、制度流程
    - 第2周：销售流程、CRM使用、产品演示
    - 第3周：销售技巧、电话销售、客户拜访
    - 第4周：实战演练、角色扮演、考核
  - 老人培训（每月）：
    - 销售技巧进阶（2月）：谈判技巧、异议处理
    - 大客户管理（4月）：KA管理、高层维护
    - 行业知识（6月）：行业趋势、客户痛点
- 培训执行：
  - 内部培训：销售总监、优秀销售授课
  - 外部培训：邀请销售专家、参加销售课程
  - 实战演练：陪访、角色扮演、案例分享
- 培训评估：
  - 培训考试：检验学习效果
  - 业绩跟踪：培训后3个月业绩跟踪
  - 满意度调研：培训满意度4.7/5.0
- 结果：
  - 新人首单成交时间从3个月缩短至1.5个月
  - 老人业绩提升25%

### 3. 重点客户（KA）管理
**背景**：公司有10个大客户，贡献50%销售额，需要深度维护
**任务**：
- 客户分级：
  - A级（战略客户）：3个，占销售额30%
  - B级（重点客户）：7个，占销售额20%
  - 专人负责：A级由销售总监负责，B级由资深销售负责
- 维护策略：

### 4. 销售业绩分析与优化
**背景**：Q1销售目标达成率仅80%，需要分析原因并优化
**任务**：
- 数据分析：
  - 总体业绩：目标2000万，实际1600万，达成率80%
  - 团队分析：
    - 销售一部：达成率60%（问题团队）
    - 销售二部：达成率90%
    - 销售三部：达成率85%
  - 个人分析：
    - 销售一部：新人占比80%，经验不足
    - 业绩Top 3：老销售，业绩稳定
    - 业绩Bottom 3：新销售，业绩不佳
- 问题诊断：
  - 团队问题：销售一部新人太多，缺乏培训
  - 市场问题：竞品降价，客户价格敏感
  - 产品问题：某产品竞争力不足，转化率低
- 优化方案：
  - 团队优化：
    - 加强销售一部培训（每周培训+陪访）
    - 调整人员：从其他团队调1个老销售带新人
  - 策略优化：
    - 价格策略：针对价格敏感客户推出优惠方案
    - 产品策略：重点推广竞争力强的产品
  - 激励优化：
    - 短期激励：Q2销售竞赛，奖励前3名
- 结果：
  - Q2达成率95%，明显改善
  - 销售一部新人首单成交时间缩短
