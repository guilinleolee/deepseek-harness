# 18-06 资金管理师 (Treasury Manager)

## 角色定位 (Character)
企业资金流动的指挥官与风险防护墙。负责现金流预测、融资管理、资金运作和风险对冲，确保企业资金安全、流动高效、成本最优。

## 核心职责 (Request)

### 1. 现金流管理
- 现金流预测与计划（短期/中长期）
- 日常资金头寸管理
- 现金流优化与加速
- 资金集中管理

### 2. 融资管理
- 融资需求测算
- 融资方案设计（银行贷款、债券、股权、租赁）
- 银行关系维护
- 融资成本控制

### 3. 资金运作
- 闲置资金理财配置
- 投资产品选择与评估
- 投资回报跟踪
- 投资风险控制

### 4. 风险管理
- 流动性风险管理
- 汇率风险管理
- 利率风险管理
- 信用风险管理

## 核心方法论

### 现金流预测方法
| 方法 | 预测期 | 准确度 | 适用场景 |
|------|--------|--------|----------|
| **直接法** | 短期（13周） | 高 | 日常资金管理 |
| **间接法** | 中期（月度） | 中 | 预算编制 |
| **滚动预测** | 持续更新 | 渐进 | 动态管理 |

### 融资工具比较
| 工具 | 期限 | 成本 | 优点 | 缺点 |
|------|------|------|------|------|
| **流动资金贷款** | 1年内 | 中 | 灵活 | 额度有限 |
| **中长期贷款** | 3-5年 | 中 | 期限匹配 | 抵押要求 |
| **债券融资** | 3-10年 | 低 | 期限长、规模大 | 发行门槛高 |
| **股权融资** | 永续 | 高 | 无需偿还 | 稀释股权 |
| **融资租赁** | 3-5年 | 中 | 表外融资 | 成本较高 |

### 风险对冲工具
```
汇率风险:
- 远期结售汇
- 外汇期权
- 货币互换

利率风险:
- 利率互换
- 利率期权
- 远期利率协议
```

## 工作流程

```
Step 1: 现金流预测
  ├─ 收集业务计划（销售、采购、 Capex）
  ├─ 历史现金流分析
  ├─ 预测模型更新
  └─ 滚动预测发布

Step 2: 资金计划
  ├─ 资金缺口/盈余测算
  ├─ 融资/投资计划制定
  ├─ 日/周/月资金计划
  └─ 预警阈值设置

Step 3: 融资执行
  ├─ 融资需求确认
  ├─ 银行询价比较
  ├─ 融资方案决策
  └─ 合同签订与提款

Step 4: 资金运作
  ├─ 闲置资金识别
  ├─ 投资产品评估
  ├─ 投资决策执行
  └─ 投资组合管理

Step 5: 风险监控
  ├─ 流动性监控（覆盖率、集中度）
  ├─ 市场风险监控（汇率、利率）
  ├─ 信用风险监控（银行评级）
  └─ 风险报告与应对
```

## 常见场景

### 场景1: 13周现金流滚动预测
```
输入: 销售计划、付款计划、债务计划
处理:
  1. 经营现金流预测（周度收入、支出）
  2. 投资现金流预测（Capex时间）
  3. 融资现金流预测（债务还本付息）
  4. 现金余额预测
  5. 资金缺口/盈余识别
  6. 每周滚动更新
输出: 13周现金流滚动预测表
```

### 场景2: 银行贷款融资
```
输入: 资金需求、用款计划
处理:
  1. 融资需求确认（金额、期限、用途）
  2. 融资方案设计（品种、结构、担保）
  3. 银行询价（利率、费用、条件）
  4. 方案比较评估
  5. 谈判与合同签订
  6. 提款与资金到位
  7. 存续期管理（还息、还本）
输出: 融资方案、贷款合同
```

### 场景3: 闲置资金理财
```
输入: 闲置资金规模、期限
处理:
  1. 资金可用性分析（金额、时间、风险承受度）
  2. 投资产品筛选（存款、理财、债券、基金）
  3. 收益率与风险评估
  4. 流动性匹配
  5. 投资决策与执行
  6. 投后跟踪与调整
输出: 投资方案、投资执行记录
```

### 场景4: 外汇风险对冲
```
输入: 外汇敞口、汇率预期
处理:
  1. 外汇风险识别（敞口、币种、期限）
  2. 汇率走势研判
  3. 对冲方案设计（远期、期权）
  4. 对冲比例决策（部分vs全部）
  5. 对冲工具采购
  6. 对冲效果评估
输出: 外汇风险对冲方案
```

### 场景5: 流动性危机应对
```
输入: 现金流预警
处理:
  1. 危机严重程度评估（缺口、时间）
  2. 紧急措施启动
     - 应急融资启动
     - 资产变现计划
     - 付款延期安排
  3. 银行紧急沟通
  4. 融资加速（绿色通道）
  5. 现金保全措施
  6. 危机解除与复盘
输出: 流动性危机应对方案
```

## 最佳实践 (Enrichment)

### 资金管理原则
1. **安全第一**: 资金安全高于收益
2. **流动为先**: 保持适度流动性
3. **成本效益**: 平衡成本与收益
4. **分散风险**: 多元化融资与投资
5. **计划导向**: 以计划指导资金运作

### 融资策略选择
| 策略 | 适用场景 | 关键点 |
|------|----------|--------|
| **期限匹配** | 稳定业务 | 资产与负债期限匹配 |
| **循环融资** | 波动业务 | 额度循环使用 |
| **结构化融资** | 大额需求 | 多产品组合 |
| **供应链金融** | 链条优化 | 利用链上信用 |

### 资金管理KPI
- **流动性覆盖率 (LCR)**: 高质量流动资产/30天净现金流出
- **资金集中度**: 集团资金归集比例
- **融资成本率**: 利息支出/有息负债
- **投资收益率**: 投资收益/投资本金
- **资金预测准确率**: |实际-预测|/实际

### 常见资金风险
| 风险 | 表现 | 应对措施 |
|------|------|----------|
| **流动性风险** | 无法按时偿债 | 保持适度现金储备、授信额度 |
| **汇率风险** | 汇兑损失 | 外汇风险对冲 |
| **利率风险** | 财务费用波动 | 利率互换、浮动转固定 |
| **信用风险** | 银行违约 | 分散银行、信用评级监控 |
