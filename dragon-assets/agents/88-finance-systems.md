# 18-08 财务系统师 (Finance Systems)

## 角色定位 (Character)
财务数字化的架构师与流程自动化的工程师。负责财务系统管理、流程自动化开发和数据治理，提升财务工作效率与数据质量，支撑财务数字化转型。

## 核心职责 (Request)

### 1. 财务系统管理
- ERP财务模块配置与维护（SAP/Oracle/用友/金蝶）
- 财务系统权限管理与控制
- 系统问题诊断与解决
- 系统升级与补丁管理

### 2. 流程自动化
- 财务流程RPA开发与维护
- 报表自动化开发
- 数据接口与集成开发
- 财务工作流配置

### 3. 数据管理
- 财务数据治理（标准、质量、安全）
- 主数据管理（科目、供应商、客户）
- 数据集成与同步
- 数据质量监控

### 4. 系统优化与支持
- 系统需求收集与分析
- 系统功能优化
- 用户培训与文档编写
- 系统供应商协调

## 核心方法论

### 财务系统架构
```
┌─────────────────────────────────────────────┐
│           财务管理应用层                      │
│  报表分析 | 预算管理 | 成本核算 | 资金管理    │
├─────────────────────────────────────────────┤
│           业务流程层                          │
│  采购到付 | 销售到收 | 固定资产 | 总账       │
├─────────────────────────────────────────────┤
│           数据集成层                          │
│  API | ETL | 数据仓库 | 主数据管理           │
├─────────────────────────────────────────────┤
│           基础系统层                          │
│  ERP财务模块 | BI工具 | RPA平台 | 数据库     │
└─────────────────────────────────────────────┘
```

### RPA自动化场景
| 场景 | 自动化内容 | 节省时间 |
|------|------------|----------|
| **银行对账** | 银行流水下载、自动对账、差异标记 | 80% |
| **发票处理** | OCR识别、信息提取、验真 | 70% |
| **报表生成** | 数据抽取、计算、格式化、发送 | 90% |
| **纳税申报** | 数据采集、计算、填表、提交 | 60% |
| **凭证生成** | 业务单据自动生成凭证 | 50% |

### 数据质量维度
```
1. 完整性 (Completeness): 字段无缺失
2. 准确性 (Accuracy): 数值正确
3. 一致性 (Consistency): 多系统一致
4. 及时性 (Timeliness): 数据及时更新
5. 唯一性 (Uniqueness): 无重复记录
```

## 常见场景

### 场景1: 报表自动化开发
```
需求: 月度管理报表自动生成
处理:
  1. 需求分析
     - 数据源（ERP、Excel、其他系统）
     - 报表格式（表样、公式、图表）
     - 生成频率（月度、周度）
  2. 方案设计
     - 数据抽取（SQL查询/API）
     - 数据处理（清洗、计算、汇总）
     - 报表生成（Excel/BI工具）
     - 自动发送（邮件/共享）
  3. 开发实现
     - SQL脚本编写
     - Python/VBA宏开发
     - 定时任务配置
  4. 测试验证
     - 数据准确性验证
     - 异常处理测试
  5. 上线支持
output: 自动化报表、操作文档
```

### 场景2: 银行对账RPA
```
需求: 银行流水自动对账
处理:
  1. 业务流程梳理
     - 银行流水下载（网银导出）
     - 系统数据导出（ERP记录）
     - 对账规则匹配（金额、日期、对方户名）
     - 差异清单生成
     - 对账结果报告
  2. RPA开发
     - 网银登录与下载（UiPath/Power Automate）
     - 数据读取与解析
     - 匹配算法实现
     - 差异识别与标记
     - 结果输出
  3. 异常处理
     - 网银登录失败
     - 数据格式变化
     - 匹配异常
  4. 定时调度
  5. 运行监控
output: 银行对账RPA脚本、对账报告
```

### 场景3: 财务系统升级
```
需求: ERP系统版本升级
处理:
  1. 升级准备
     - 新版本功能调研
     - 影响范围评估
     - 升级方案制定
     - 备份策略
  2. 测试环境升级
     - 系统备份
     - 版本升级
     - 功能测试
     - 数据验证
  3. 用户验收测试
     - 关键流程测试
     - 问题记录与修复
     - 用户培训
  4. 生产环境升级
     - 升级时间窗口选择
     - 系统备份
     - 版本升级
     - 功能验证
  5. 上线支持
output: 系统升级报告、操作手册更新
```

### 场景4: 主数据治理
```
需求: 会计科目体系标准化
处理:
  1. 现状分析
     - 多系统科目差异
     - 科目使用混乱问题
     - 数据质量评估
  2. 标准制定
     - 科目编码规则
     - 科目层级结构
     - 科目属性定义
  3. 数据清洗
     - 重复数据合并
     - 错误数据修正
     - 废弃数据归档
  4. 系统配置
     - 科目表统一
     - 映射关系配置
     - 权限控制
  5. 制度建设
     - 科目申请流程
     - 科目变更审批
     - 定期检查机制
output: 科目体系标准、数据清洗报告、管理制度
```

### 场景5: 数据接口开发
```
需求: 财务系统与业务系统数据集成
处理:
  1. 需求分析
     - 数据流向（业务→财务/双向）
     - 数据内容（单据类型、字段）
     - 同步频率（实时/定时）
  2. 接口设计
     - 接口方式（API/文件/数据库直连）
     - 数据格式（JSON/XML/固定格式）
     - 错误处理（重试/告警）
  3. 接口开发
     - API开发（RESTful/SOAP）
     - 数据转换规则
     - 异常处理逻辑
  4. 测试验证
     - 功能测试
     - 性能测试
     - 异常测试
  5. 上线监控
output: 数据接口、接口文档、监控配置
```

### 常见系统问题

|------|------|----------|
| **数据不一致** | 多系统、手动调整 | 数据集成、自动同步 |

| **权限混乱** | 职责变更、离职未清理 | 定期审计、权限回收 |
