## ⚠️ 升级时常见坑

1. **BIBLE.md 与实际不同步**：
   - 升级后必须人工检查 BIBLE.md §3 阶段数
   - 用 `grep -c "|" BIBLE.md` 估算表格行数

2. **smoke test 偶发失败**：
   - async-task-pattern poll 偶发 GitHub 连接 timeout
   - 重跑一次或用 `--exclude-poll` 跳过

3. **新 skill 没放对路径**：
   - 真主树：`~/projects/c--Users-li--claude/dragon-engine/skills/<name>/`
   - 不是 `~/.claude/skills/`（那个是根级 V2/V3 skill）

4. **升级 push 失败**：
   - 检查 token：gh auth status
   - 检查网络：curl https://api.github.com -I
   - 检查 master 分支是否被保护

5. **忘更新 VERSION**：
   - 升级不 bump VERSION → GitHub Actions 检测不到，无法自动 tag
   - Step 5 强制 echo "V$NEW" > VERSION

6. **忘跑 sync-dragon.py**：
   - 升级完 Cursor 还在用旧版天龙
   - Step 7 强制 sync

## ❓ FAQ

**Q：升级中途断电怎么办？**
A：所有步骤用 git 跟踪。断电后 `git status` 看哪些文件已 add / 改动。从 Step 2 接着做即可。

**Q：升级失败怎么回滚？**
A：`git revert <commit_hash>` 或 `git reset --hard HEAD~1`。

**Q：升级后其它 AI 应用不更新？**
A：跑 Step 7 `sync-dragon.py`。它会自动检测 GitHub 最新 VERSION 并下载 + 同步。

**Q：升级跨多 stage 怎么办？**
A：拆成多个 commit（每 stage 一个 commit），每个 commit 跑一次 smoke。

**Q：AI co-pilot 卡住怎么办？**
A：手动检查 `git status` 和 `cat VERSION`。co-pilot 不是替代品，只是辅助。
